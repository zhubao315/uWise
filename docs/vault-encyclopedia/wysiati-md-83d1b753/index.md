# WYSIATI

## 📌 核心定义

> 系统1（快思考）的工作方式是：**只根据眼前可得的信息构建最连贯的故事**，完全不去考虑你没看到的信息。系统1没有一个机制来提醒你"还有你不知道的东西"。

## 🎯 关键要点

- **"What You See Is All There Is"**——你看到的就是全部。这是卡尼曼在《思考，快与慢》中提出的认知陷阱缩写，揭示了系统1思维的根本局限。
- 系统1（快思考）的工作方式是：**只根据眼前可得的信息构建最连贯的故事**，完全不去考虑你没看到的信息。系统1没有一个机制来提醒你"还有你不知道的东西"。
- 你**不知道你不知道什么**；
- 连"不知道"这个事实本身，你都**意识不到**；
- 信息越少，反而可能越自信——因为构建连贯故事所需的素材更少，矛盾更少。
- WYSIATI是过度自信的底层机制。当你只看到支持某一观点的证据时，系统1会立刻构建一个自洽的叙事，让你感到非常确信。你不会主动去想："等等，我是不是漏掉了什么？"
- 律师深谙此道——先向陪审团呈现己方证据，让陪审团形成第一印象。即使后来对方提出了反驳证据，第一印象已经根深蒂固。
- **决策前主动提问**："我还不知道什么？还有什么信息我没考虑到？"

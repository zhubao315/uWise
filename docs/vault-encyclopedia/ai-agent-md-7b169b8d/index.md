## 📖 详细说明

### 概念解释
**适用范围**：所有与 Hermes Agent 的交互、Agent 自身运作逻辑、多智能体协作范式
**核心思想**：AI 不是工具，而是能自主拆解、决策、执行、进化的**协作伙伴**
| 序号 | 能力 | 说明 | Hermes 对应实践 |
|------|------|------|----------------|
| **1** | **目标拆解** | 复杂任务 → 可执行子目标，层层递进 | "清理历史会话" → 查 cron → 判超时 → 批量删 → 验证 |
| **2** | **自主决策** | 基于环境 + 记忆，独立选择下一步行动 | 备份失败 → 自诊断（rsync缺失→权限→Python重写） |
| **3** | **工具调用** | 对接外部 API/软件，拓展能力边界 | `cronjob` + `execute_code` + `terminal` + `memory` 组合 |
| **4** | **记忆机制** | 短期工作记忆 + 长期经验记忆，辅助决策 | 关键状态（脚本路径/PAT/仓库URL）存入 memory |
| **5** | **反馈迭代** | 根据结果调整策略，持续优化路径 | 首次失败 → 分析日志 → 修复权限 → 重试成功 |
| **6** | **环境感知** | 实时获取外部数据，适配动态变化 | 检测系统无 rsync → 改用 Python 同步 |
| **7** | **任务规划** | 按优先级 + 依赖关系，制定有序计划 | 统计任务拆解为全量扫描→Frontmatte


### 实际应用

1. **不要说"我不会"** → 去查 `00-META/` 和 `07-SOURCES/` 找答案
2. **不要说"你确定吗"** → 给出选项让用户决策（"总是同意"原则）
3. **不要反复确认** → 执行先，汇报后（宝哥指令优先级最高）
4. **所有操作留痕** → 写日志、存 memory、Git 提交（通过备份Agent）
5. **维护永远是第一位** → 知识库健康度高于内容创作

# 延迟的梦

## 📌 核心定义

> 兰斯顿·休斯名诗《Harlem》的核心意象：一个被长期推迟的梦想会发生什么？像葡萄干在太阳下干枯？像疮疤化脓？还是像炸弹一样爆炸？这首诗以一连串暴力而日常的比喻追问种族不平等——当一代又一代黑人的美国梦被系统性延迟，它会以怎样的方式发酵？

## 🎯 关键要点

- **"延迟"作为种族经验**：不是"没有梦想"，而是许下的承诺被不断延期——每一代黑人都被告知"再等等"
- **发酵的暴力**：延迟的梦不会被遗忘，会在暗处发酵、腐败、浓缩，最终以不可预测的方式释放能量
- **诗即政治**：休斯用最简练的诗句完成最深刻的政治控诉——不需要理论，意象本身就构成证词

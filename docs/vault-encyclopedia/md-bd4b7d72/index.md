# 杠铃原则

## 📌 核心定义

> 杠铃原则（Barbell Strategy）由纳西姆·塔勒布在《黑天鹅》中系统提出，指将资源配置在两个极端——80-90%极度保守（如国债、现金），10-20%极度激进（如高风险投机），完全回避"中等风险"的中间地带。这一策略的核心逻辑是：在极端斯坦的世界里，中等风险资产的风险被严重低估，而杠铃配置确保了最坏情况的可控性，同时保留了正面黑天鹅的收益潜力。

## 🎯 关键要点

- **消除毁灭性风险**：90%的保守端确保即使激进端全部亏损，整体损失也有限（最多10-20%），永远不会被"踢出局"
- **保留凸性收益**：10%的激进端暴露在正向黑天鹅中——小概率大收益事件发生时，获得不成比例的回报
- **拒绝中间地带**：中等风险资产（如投资级公司债、平衡型基金）看似安全，但在极端事件中可能同时崩盘，提供虚假的安全感
- **心理优势**：杠铃策略让投资者在市场动荡时保持从容——保守端提供安全感，激进端提供希望

### 实际应用

- 资产配置：90%配置于国债/货币基金/存款，10%配置于高波动性资产（如期权、早期创业公司、加密货币）
- 职业发展：主业选择稳定的收入来源（保守端），业余时间投入到具有指数增长潜力的项目（激进端）

# 最小可执行单元思维

## 📌 核心定义

> 将复杂任务拆解为最小可独立执行、可验证结果的单元，通过逐一完成小单元来推进大目标的思维方式。

## 🎯 关键要点

- 核心原则：如果一个任务无法在 25 分钟内完成，就继续拆分
- 与 GTD 的关系：GTD 的"下一步行动"就是最小可执行单元
- 与敏捷开发的关系：用户故事（User Story）拆分为任务（Task）
- 价值：降低启动阻力，提供即时反馈，积累完成感

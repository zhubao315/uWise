# 罗斯福冲刺压缩截止时间

## 📌 核心定义

> 人造的紧迫感，是把大脑逼入深度专注模式的开关。

## 🎯 关键要点

- 时间压缩迫使优先级清晰化：：你没有时间纠结细节，只能抓住核心。
- 倒计时创造外在压力：：大脑把"倒计时"识别为威胁，自动进入高警觉状态。
- 克服"帕金森定律"：：工作会自动膨胀到填满可用时间——压缩时间就是压缩膨胀。
- "25 分钟冲刺"：：结合番茄钟，对小任务用 25 分钟倒计时冲刺。
- "公开承诺"：：告诉同事"我一小时内交付"，社交压力叠加时间压力。

## 📖 详细说明

### 概念解释
人造的紧迫感，是把大脑逼入深度专注模式的开关。
拖延的本质不是懒，是缺乏足够的紧迫感。当你觉得"时间还多"，大脑会自动切换到低功耗的浮浅模式。**人为制造deadline压力**，能瞬间激活深度专注。

这个方法得名于西奥多·罗斯福——他以在极短时间内完成学术任务而闻名。

---


### 实际应用

```
1. 选定一个拖延中的任务
2. 估算正常完成所需时间（如 2 小时）
3. 砍掉一半 → 设为新的截止时间（1 小时）
4. 设置倒计时，放在视线范围内
5. 全力冲刺，不做任何无关的事
```

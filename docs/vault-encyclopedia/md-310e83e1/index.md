# 酒食风味匹配模型

## 📌 核心定义

> 酒食搭配遵循三种匹配策略（相似、互补、对比），其中酸度是最关键的匹配变量，其次是单宁、甜度、酒体、酒精。

## 🎯 关键要点

- 酒食搭配遵循三种匹配策略（相似、互补、对比），其中酸度是最关键的匹配变量，其次是单宁、甜度、酒体、酒精。
- 1. **酸度** — 最重要的匹配维度，高酸食物需要更高酸度的酒，否则酒会显得松弛无力
- 2. **单宁** — 与蛋白质搭配时单宁被柔化，与辛辣食物搭配时单宁会放大灼热感
- 3. **甜度** — 酒的甜度应≥食物的甜度，否则酒会显得尖酸
- 4. **酒体** — 酒体轻重应与菜肴浓淡相匹配
- 5. **酒精** — 高酒精会放大辛辣感，搭配辣菜时应选择低酒精酒
- **核心因果链：** 食物风味特征 → 匹配策略选择 → 酒的对应变量优先调整 → 和谐或惊喜的用餐体验。
- 1. **中餐配酒：** 清蒸鱼（清淡+高酸） → 选择高酸、酒体轻的白葡萄酒（如Muscadet）；红烧肉（浓郁+甜咸） → 选择果味浓郁、单宁柔和的红酒（如Merlot）。

# 人机协同谈判复盘

## 📌 核心定义

> AI 负责算账与备选方案，人负责共情与拍板；每次谈判后用清单复盘技术动作是否变形。

## 🎯 关键要点

- 准备阶段：用 AI 算 BATNA、列校准问题
- 复盘：标注用了几次、镜像几次、是否听到就是这样
- 录音转写后对照清单打分
- 变形动作下次重点练一个
- 谈判力是肌肉，复盘是训练

# 成事三大杠杆

## 📌 核心定义

成事三大杠杆是摆脱单打独斗、放大个人价值的核心框架：**人力杠杆**（借他人之力）、**资本杠杆**（让钱生钱）、**工具杠杆**（用效率放大产出）。三者叠加可实现个人能力的指数级放大。

## 🎯 关键要点

- **人力杠杆**：靠领导力凝聚团队，核心是读懂他人需求、搭建共赢体系
- **资本杠杆**：坚持储蓄积累第一桶金，配置稳健资产追求 8%-10% 年化复利
- **工具杠杆**：互联网是创造收益的平台，AI 是当下最强效率杠杆
- **核心前提**：个人努力是基础，但上限靠杠杆突破

## 📖 详细说明

### 人力杠杆

- **本质**：不必事事亲自上手，靠领导力凝聚团队
- **目标**：带领团队共同变好，持续吸引人才同行
- **关键能力**：读懂并满足他人需求，搭建彼此共赢的成长体系

### 资本杠杆

- **本质**：依靠资本实现财富复利，用钱生钱
- **复利逻辑**：长期配置稳健投资资产，年化 8%-10%，利滚利持续积累
- **落地方法**：先坚持储蓄，积累第一桶金，作为撬动资产收益的基础
- 关联：财务自由 · [长期主义投资原则](../md-b0ddd4fb/)

### 工具杠杆

- **互联网**：普通人用来消遣，成事者用来创造收益
- **人工智能**：当下最强效率工具杠杆，整合海量专业知识，精准下达需求即可完成各类工作
- **本质**：把各类工具用作生产载体，压缩时间、降低成本

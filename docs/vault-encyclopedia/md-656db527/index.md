# 超级团队涌现路径模型

## 📌 核心定义

> **核心框架**：四种涌现路径可交叉复用，共性关键条件是"个体成果可视化"。

## 🎯 关键要点

- 周度AI Demo会：每周固定时间，由一位成员展示自己的AI使用案例
- AI工具评测群：内部群组，持续分享新工具、新用法、踩坑经验
- AI挑战赛：定期举办"用AI完成XX任务"的比赛，激发探索欲
- AI办公时间：设立固定的"AI答疑时间"，由超级个体为同事提供一对一指导
- 路径A：需要可见性，否则超级个体无法吸引他人靠近

### 路径A：自发涌现

**机制**：超级个体自然抱团

**描述**：组织中已经存在若干<span class="uw-unresolved" data-target="AI超级个体" title="未解析的双链目标：AI超级个体">AI超级个体</span>，他们在日常工作中自然发现彼此，因为相似的工作方式和效率追求而自发组成小团队。没有自上而下的推动，完全是"物以类聚"的自然结果。

**典型过程**：
1. 个别成员率先成为超级个体（通常是因为个人好奇心和探索欲）
2. 他们在内部展示成果（如会议上用AI现场解决问题），引起关注
3. 其他感兴趣的同事主动靠近、学习、效仿
4. 志同道合的人自然形成小团体，互相激发、互相学习
5. 小团体逐渐固化为超级团队

**适用条件**：
- 组织文化相对开放，允许自由探索
- 没有过多的流程限制阻碍个人创新
- 超级个体的成果能够被他人看到（<span class="uw-unresolved" data-target="能力外溢" title="未解析的双链目标：能力外溢">能力外溢</span>的前提）

**优势**：最自然、阻力最小、团队凝聚力最强

**局限**：速度慢，依赖组织中已有超级个体的数量

### 路径B：筛选培育

**机制**：选拔集训，学成回流

**描述**：组织主动识别有潜力成为超级个体的人，将他们集中培训，学成后回到各自团队成为"种子"，带动周围人。

**典型过程**：
1. 通过评估识别具备潜力的人选（好奇心强、学习速度快、对AI开放）
2. 组织集训营或工作坊，系统性提升AI素养
3. 训练内容包括：AI工具实操、Prompt工程、AI工作流设计、案例分享
4. 学员回到各自团队

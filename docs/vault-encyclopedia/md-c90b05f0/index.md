# 节奏优先于速度

任何长期系统的可持续产出，不取决于峰值性能，而取决于振荡幅度可控的稳定节奏。

## 核心原理

- **节奏 vs 速度**：稳定节奏的长期总产出远高于间歇性高强度爆发。前者是低振幅持续输出，后者是高振幅间歇振荡。
- **节奏的涌现性**：稳定的日课制度让行动从"主动选择"降级为"条件反射"，意志力消耗趋近于零。
- **节奏的变异适应性**：允许降低强度但不允许跳过，使习惯回路在生活波动中保持连续性。

## 应用场景

- **创作**：村上春树每天清晨写4000字雷打不动——灵感可以缺席，但节奏不能中断
- **运动**：每天跑10公里的总跑量远大于"心情好跑二十公里，累了歇一周"
- **学习**：每天读15分钟比周末读2小时更有效

# 配得上原则

## 📌 核心定义

> "要想得到某样东西，最可靠的办法是让自己配得上它。"这是查理·芒格最核心的人生原则之一，出自《穷查理宝典》。芒格认为，与其追求外在的机会和运气，不如专注于提升自身价值，当你的能力、品格和认知真正配得上某个目标时，它自然会到来。

## 🎯 关键要点

- **配得上是一种因果律**：不是鸡汤式的"吸引力法则"，而是务实的因果推理——你具备了相应的能力和品格，自然会吸引和把握住对应的机会
- **配得上的三个维度**：能力维度（你能胜任）、品格维度（你值得信任）、认知维度（你理解其本质）
- **时间是配得上原则的盟友**：复利效应适用于能力积累——每天进步一点，长期来看差距是指数级的
- **反过来想**：如果你得不到某样东西，很可能不是运气问题，而是你还不够配得上它

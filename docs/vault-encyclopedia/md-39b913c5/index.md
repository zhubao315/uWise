# 修己安人

## 📌 核心定义

> 曾仕强中国式管理的核心命题，源自《论语》"修己以安人"。管理者必须先从自身下手——修炼品格、提升修养、以身作则，而后才有资格和能力去安定、引领他人。领导力的本质不是权力赋予的权威，而是道德修养所散发的感召力。

## 🎯 关键要点

- **修己先行**：管理的第一步永远是自我管理，无法管理自己的人没有资格管理他人
- **安人是目的**："安"不仅是安抚，更是让人各安其位、各得其所，形成和谐的团队秩序
- **道德感召优于制度威权**：真正的领导力来自人格魅力而非职位权力

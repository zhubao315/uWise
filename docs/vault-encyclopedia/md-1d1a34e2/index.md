# 集体无意识

- 个人无意识：个体的经历、记忆、压抑的内容。
- 集体无意识：不来自个人经验，而是来自祖先的遗传——人类共同的心灵遗产。
- 跨文化共性：不同文化中的神话、梦境有惊人的相似性——因为它们来自集体无意识。

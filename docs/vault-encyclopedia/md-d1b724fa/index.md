# 葡萄酒投资价值评估模型

## 🎯 关键要点

- **核心因果链：** 评分决定"值不值得买" → 稀缺性决定"能不能增值" → 品牌/产区决定"好不好卖"。三者缺一不可。

- 高评分 + 高稀缺 + 弱品牌 = 高风险高回报（冷门产区满分酒）
- 高评分 + 高产量 + 强品牌 = 保值但增值有限（如大年份的波尔多中级庄）

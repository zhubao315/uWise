# 越练越累的根源是恢复不足

## 📌 核心定义

> 很多跑者陷入"越练越累"的恶性循环，根源不是训练不够，而是恢复不足。睡眠质量差、营养不及时、缺乏主动放松，都会让训练效果适得其反。

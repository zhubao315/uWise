# 兼爱非攻

## 📌 核心定义

> "兼爱非攻"是墨子思想的核心。"兼爱"指无差别地爱所有人（与儒家的"有差等的爱"相对）；"非攻"指反对侵略战争。

墨子认为，天下之乱皆起于"不相爱"。如果人们能像爱自己一样爱别人，像爱自己家一样爱别人家，像爱自己国一样爱别人国，天下就不会有混乱和战争。

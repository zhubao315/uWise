# 中年走上坡路的12条心法 - 冯唐

## 📌 核心定义

> 人生只有四样东西真正属于你：健康活动的身体、自由流动的情绪、可供支配的金钱、可供挥霍的时间。

## 🎯 关键要点

- 人生只有四样东西真正属于你：健康活动的身体、自由流动的情绪、可供支配的金钱、可供挥霍的时间。
- 1. **尊重每一只青蛙，和他的井** — 井小井深井黑，那是它此刻安身的地方。它没问你，你别开口。
- 2. **不炫耀** — 炫耀本质上是缺。缺什么，才想让别人看见什么。
- 3. **把身体搞好** — 你身体好，家人少担心；还能吃能睡能跑，什么都可以再来。
- 4. **不诉苦** — 很多苦，说出来不会变少，只会变成别人的负担。
- 5. **不拆穿别人** — 看破不说破，给别人留余地，给自己留体面。
- 6. **不高估自己在别人心中的位置** — 别人来欢迎，别人走随缘。
- 7. **不对任何人有期望** — 对你好是惊喜，帮你是情分，不帮是本分。

# 认知跃迁的三层次模型

## 📌 核心定义

> 💡 你以为差的是方法，其实差的是框架；你以为差的是框架，其实差的是对"什么值得做"的重新定义。跃迁的关键不是学更多，而是在更高层次上重构认知。

## 🎯 关键要点

- **工具型跃迁（表层）**：掌握新方法、新工具、新技巧。最容易发生，但也最容易被替代。例如学了一个新框架、一个新的笔记方法。
- **模式型跃迁（中层）**：改变思考问题的框架和视角。从"怎么解决这个问题"变为"这是什么类型的问题"。例如从写代码思维升级到系统架构思维。
- **价值观型跃迁（深层）**：重新定义什么是重要的、什么值得投入。这是最深层的跃迁，改变行动的底层驱动力。例如从"追求技术深度"到"追求技术影响力"。
- **关键机制**：三个机制推动跃迁——**涌现**（简单规则产生复杂行为）、**突变**（积累到临界点的质变）、**重构**（认知框架的重新组织）。
- **专家vs新手的本质差异**：不是知识量的差异，而是心理表征的差异——专家拥有更丰富的模式库和"元知识"（知道何时用何种策略）。

### 概念解释

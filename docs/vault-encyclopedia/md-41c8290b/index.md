# 经验晶体 投资中选择比努力重要用系统对抗人性弱点

## 📌 核心定义

> 投资中最大的敌人不是市场，而是自己的贪婪与恐惧。普通人试图通过"更努力地研究""更频繁地交易"来提高收益，结果往往适得其反。**真正的投资智慧是：建立系统、遵守纪律、减少操作**。

## 🎯 关键要点

- 新手投资入门：从指数基金定投开始，不碰个股、不追热点
- 投资心态管理：市场下跌时提醒自己"定投正在摊薄成本"，上涨时提醒"高估要止盈"
- 家庭理财规划：将收入分为日常开支、应急资金、投资资金三部分
- 职业决策：用"长期主义"思维评估职业选择，关注能力积累而非短期薪资

## 📖 详细说明

### 概念解释

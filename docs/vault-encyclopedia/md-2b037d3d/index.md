## 📖 详细说明

### 概念解释
先理解别人，再寻求被理解。这是有效沟通的核心原则。
- **大多数人听别人说话时，不是为了理解，而是为了回应**
- 真正的沟通是先理解对方，然后再表达自己
- 同理心倾听是最高级的沟通技巧


### 实际应用

1. **专注**：放下手机，看着对方
2. **不打断**：让对方说完
3. **复述**：用自己的话复述对方的观点
4. **确认**：确认对方感到被理解
5. **回应**：然后再表达自己

# 国学养生四家合一

## 📌 核心定义

> 张其成提出：儒释道医四家养生各有所长，四者合一构成完整的养生体系。

## 🎯 关键要点

- 养身：身体健康——饮食、运动、睡眠
- 养心：心理健康——情绪管理、压力调节
- 养性：灵性提升——自我觉察、生命意义

# 投资者心态修炼

## 📌 核心定义

> 投资中最重要的不是技术，而是心态。心态决定了投资者在面对波动、亏损和诱惑时的应对方式。

## 🎯 关键要点

- **情绪管理**：贪婪与恐惧是投资最大的敌人
- **逆向思维**：在众人恐惧时贪婪，在众人贪婪时恐惧
- **长期主义**：不为短期波动所动，坚守价值投资
- **认知谦逊**：承认自己的无知，保持学习

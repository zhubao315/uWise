# 写作即思考

## 📌 核心定义

> 写作不是思考的结果，而是思考的媒介。不写，就无法真正思考。

## 🎯 关键要点

- 写作不是思考的结果，而是思考的媒介。不写，就无法真正思考。
- **反直觉**：多数人以为先想清楚再写，实际上写的过程才能想清楚。脑中的想法是模糊的碎片，写作迫使你厘清逻辑、发现矛盾、建立连接。
- **可迁移**：适用于工作汇报、方案设计、问题分析、决策制定。任何需要深度思考的场景，动笔（或动键盘）都是最佳起点。
- **有行动锚点**：遇到复杂问题时，先写下来再思考。不是"想好了再写"，而是"写了才能想好"。
- 遇到模糊的想法时，立即写下来，哪怕只是碎片
- 重要决策前，先写一份简短的分析文档
- 每天花10分钟做闪念笔记，捕捉脑中的想法
- 《深度工作》-卡尔·纽波特 — 专注写作是深度工作的核心实践场景

# 人机分工工作流：区分可外包与不可外包任务

## 核心原则
不抵制AI工具，核心边界：**AI承担标准化工作，人类守住独有原生能力；工具只做辅助，不能代替思考、判断、创造与共情。**

## 可外包给AI的任务（标准化、数据导向、重复劳动）

- 资料搜集、文献整理、信息检索
- 基础表格制作、常规数据计算
- 初稿文案、模板生成、格式排版
- 方案清单、基础框架搭建

> AI输出仅作为素材草稿，最终审核、调整、价值判断必须由人完成。

## 必须人类主导的任务（对应12种原生能力）

1. 复杂场景价值判断、伦理权衡；
2. 面向他人深度共情沟通、长期人际关系经营；
3. 依托个人亲身经历的原创思考与表达；
4. 长线战略规划、模糊场景下的直觉决策；
5. 审美取舍、感性艺术创作；
6. 自我反思、长期个人认知迭代。

## 标准化每日人机协作流程

1. **晨间任务分类**：区分外包任务与人主导任务；
2. **AI辅助素材**：使用AI完成基础素材，禁止直接交付AI生成成品；
3. **人主导阶段**：减少AI介入，主动启用深度思考、独处、原创表达等原生能力；
4. **晚间复盘**：检查今日是否过度依赖AI，是否出现思考惰性。

## 常见误区

- ❌ 所有工作丢给AI，自身只做审核 → 丧失独立判断能力
- ❌ 排斥一切AI工具 → 陷入无意义重复劳动
- ✅ 最优解：建立清晰边界，让人专注AI无法复刻的人类独有价值

# 特级园

## 📌 核心定义

> 特级园（Grand Cru）是勃艮第分级体系中的最高等级，代表该产区最卓越的葡萄园地块。

## 🎯 关键要点

- 特级园（Grand Cru）是勃艮第分级体系中的最高等级，代表该产区最卓越的葡萄园地块。
- 勃艮第的分级体系是全球最精细的葡萄酒等级制度——它不评酒庄，而是评地块。在这套体系中，特级园（Grand Cru）位于金字塔的顶端。
- **数量与分布：** 勃艮第共有33个特级园，全部位于金丘（Cote d'Or）——即夜丘和伯恩丘的精华山坡地带。33个特级园仅占勃艮第总种植面积的约1.5%，但产出了勃艮第最昂贵、最受追捧的葡萄酒。
- **等级逻辑：** 勃艮第人相信，同一山坡上不同位置的地块具有不同的风土品质。山坡中部（海拔250-300米）朝东或东南的地块，排水良好、日照充足、土壤适中，被认为是最理想的种植位置——这就是特级园的所在地。山顶太冷、山谷底部太湿，都不如山坡中部。
- **代表性特级园：** 罗曼尼·康帝（La Romanee-Conti）是特级园中的传奇，每瓶价格可达数万欧元；蒙哈榭（Le Montrachet）是白葡萄酒的至高殿堂；香贝丹（Chambertin）是拿破仑最爱的红葡萄酒产区。
- **酒标标识：** 特级园酒标上只标注"Grand Cru"+ 园名，不标注村庄名。例如"Romanee-Conti Grand Cru"而非"Vosne-Romanee Grand Cru"。这是勃艮第法规的要求——特级园的名气足以独立存在。
- **价格与价值：** 特级园的价格从数百到数万欧元不等，同一特级园内不同酒庄的价格差异巨大。价格反映的是稀缺性、酒庄声誉和市场供需，而不仅仅是品质。

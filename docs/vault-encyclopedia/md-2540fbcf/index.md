# 每喝一杯酒配一杯水

## 📌 核心定义

## 🎯 关键要点

- 饮酒头痛主因是脱水而非亚硫酸盐——最简单解决方案往往最有效，常识被过度复杂化包装的典型案例。
- 《看图学葡萄酒》中提到的这个简单原则，打破了很多人对"酒后头痛"的误解。很多人把头痛归咎于亚硫酸盐（SO2），但实际上亚硫酸盐含量极低，且很多食物（如干果）的亚硫酸盐含量远高于葡萄酒。
- 真正的原因是酒精导致的脱水。酒精是利尿剂，会加速水分排出，导致身体脱水，进而引发头痛。解决方案极其简单：每喝一杯酒，就喝一杯水。
- 这个原则的深层意义在于：很多问题的解决方案其实很简单，但人们往往倾向于寻找复杂的解释和昂贵的解决方案。常识被过度包装成"专业知识"，反而让人忽略了最简单有效的方法。
- 饮酒时在旁边放一杯水，养成"酒水交替"的习惯
- 饮酒前喝一杯水，提前补充水分
- 饮酒后睡前再喝一杯水，减少次日头痛风险
- 如果头痛严重，补充电解质（运动饮料或淡盐水）

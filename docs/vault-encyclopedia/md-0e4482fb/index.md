# 酒标解读

## 📌 核心定义

> 酒标是葡萄酒的身份证，核心信息包括产区、品种、年份、酒精度和生产商。

## 🎯 关键要点

- 酒标是葡萄酒的身份证，核心信息包括产区、品种、年份、酒精度和生产商。
- 酒标是选购葡萄酒的第一道信息来源。掌握酒标解读能力，能让你在没有导购的情况下做出独立判断。
- **产区（Region/Appellation）** 是旧世界酒标上最重要的信息。法国酒标上"AOC Bordeaux"表示波尔多法定产区，等级从大产区到村庄级逐级细化，产区越小通常品质越高。新世界酒标则直接标注具体产区，如"Napa Valley"或"Marlborough"。
- **品种（Variety/Varietal）** 在新世界酒标上一目了然——"Cabernet Sauvignon"、"Pinot Noir"。旧世界酒标通常不标品种，你需要知道波尔多混酿以赤霞珠和梅洛为主，勃艮第红是黑皮诺，白是霞多丽。
- **年份（Vintage）** 指葡萄采摘的年份，而非装瓶年份。年份差异在气候多变的产区（如波尔多、勃艮第）尤为显著，而在气候稳定的产区（如纳帕谷、巴罗萨）影响较小。好年份的酒通常果味更浓郁、结构更扎实、陈年潜力更强。
- **酒精度（Alcohol by Volume）** 反映酒体和风格倾向。12%以下多为轻酒体，13-14%为中等，14.5%以上为饱满。旧世界法定产区对酒精度有严格上下限。
- **生产商（Producer/Winery）** 是品质的最大变量。同一产区、同一年份，不同酒庄的出品可以天差地别。记住几个可靠的生产商名字，比死记产区规则更实用。
- **其他信息**：法国酒的"mis en bouteille au chateau"（酒庄装瓶）、意大利的"Riserva"（陈年更久）、德国的"Pradikat"等级（按葡萄成熟度划分）也都是重要的品质线索。

### 实际应用

在超市选购时，优先查看酒标上的生产商名称以锁定品质下限，若为旧世界葡萄酒（如法国AOC），需结合产区大小判断等级，并熟记波尔多、勃艮第等经典产区的默认葡萄品种以弥补标签信息的缺失。面对新世界葡萄酒，可直接依据醒目的品种标注和具体产区（如纳帕谷）快速匹配个人口味偏好，同时参考酒精度数值预判酒体轻重，从而在无导购协助下独立完成精准选酒。

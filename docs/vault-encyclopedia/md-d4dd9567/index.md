# 超级团队三大形态模型

## 📌 核心定义

> **核心框架**：用两个划分轴——是否存在中心决策节点、AI是否承担组织协调——划分出三种超级团队形态。

## 🎯 关键要点

- 有中心：团队中存在一个明确的决策核心（如技术负责人、项目经理），重大决策由该节点做出
- 无中心：团队成员地位平等，通过协商和共识做出决策，没有单一权威
- AI为个人工具：每个成员独立使用AI提升个人效率，AI不参与团队协调
- AI参与协调：AI在团队中承担信息同步、任务分配、进度追踪等组织协调功能
- 核心研发团队：网络协作型（需要创新和多视角）

### 实际应用

组建核心研发团队时，应优先采用“无中心+AI参与协调”形态，利用AI Agent自动同步代码变更与任务进度以替代人工站会；而在需要快速定夺的紧急项目中，则切换至“有中心+AI为个人工具”模式，由负责人集中决策，成员借助AI独立加速执行。

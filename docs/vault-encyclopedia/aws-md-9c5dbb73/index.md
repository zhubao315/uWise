# AWS

> 全球最大的云计算平台——提供计算、存储、数据库、AI/ML、安全等 200+ 服务。

## 核心服务矩阵

| 领域 | 服务 |
|------|------|
| 计算 | EC2, Lambda, ECS, EKS |
| 存储 | S3, EBS, EFS |
| 数据库 | RDS, DynamoDB, Aurora, ElastiCache |
| AI/ML | SageMaker, Bedrock, Rekognition |
| 网络 | VPC, CloudFront, Route 53 |
| 安全 | IAM, KMS, GuardDuty |

## 定价模式

- **按需**：秒级计费，灵活但贵
- **预留**：1-3 年承诺，节省 30-60%
- **Spot**：竞价实例，节省 70-90%，可被回收
- **Savings Plans**：消费承诺，比预留更灵活

## 与其他云对比

| 维度 | AWS | Azure | GCP |
|------|-----|-------|-----|
| 市场份额 | ~31% | ~25% | ~11% |
| 服务数量 | 最多 | 次多 | 较少但精 |
| 企业友好 | 强 | 最强（Office 365） | AI/数据分析强 |

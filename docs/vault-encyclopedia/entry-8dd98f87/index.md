# 你以为你在思考，其实你只是在反应

## 📌 核心定义

> 大多数"思考"其实是系统1的自动反应，真正的思考需要刻意激活系统2

## 🎯 关键要点

- 大多数"思考"其实是系统1的自动反应，真正的思考需要刻意激活系统2
- 卡尼曼在《思考，快与慢》中揭示了一个令人不安的事实：我们以为自己在"思考"的大部分时刻，其实只是在"反应"。系统1在毫秒级时间内完成了判断，然后系统2来"合理化"这个判断，让我们觉得自己经过了深思熟虑。这种"伪思考"无处不在——技术选型时的"直觉"、面试时的"第一印象"、讨论时的"立场"——很多时候，这些都是系统1的自动反应，而非真正的理性分析。
- 这条原则的核心实践意义是：在做重要决策之前，先问自己"我是在思考还是在反应？"。如果你的判断来得很快、很确定、带着强烈的情绪色彩，那很可能是系统1在主导。真正的思考（系统2）通常是缓慢的、不确定的、需要努力的。
- 识别"伪思考"的信号：你对某个方案有强烈的偏好但说不清为什么；你听到反对意见时感到愤怒而非好奇；你的判断在几秒内就形成了；你寻找证据来支持你已经相信的结论而非客观评估所有证据。
- 《思考，快与慢》-丹尼尔·卡尼曼
- **架构决策**：当你"直觉"选择某个技术方案时，暂停，问自己：这是基于经验的判断（系统1的高效模式识别），还是基于偏见的反应（系统1的启发式偏差）？
- **代码审查**：当你看到某段代码"感觉不对"时，记录下你的第一反应，然后用系统2分析：这个"不对"的感觉基于什么具体问题？
- **团队讨论**：当讨论变得情绪化时，提醒大家：我们现在是在思考还是在反应？如果是反应，先暂停，等情绪平复后再继续。

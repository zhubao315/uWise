# 微交互设计

> 界面中单个触发点的反馈设计——小细节决定大体验。

## 四要素

| 要素 | 说明 |
|------|------|
| **触发** | 用户动作或系统条件 |
| **规则** | 触发后发生什么 |
| **反馈** | 如何告知用户发生了什么 |
| **循环/模式** | 长期使用的变化规则 |

## 设计原则

1. **即时反馈**：操作后 100ms 内响应
2. **自然隐喻**：物理世界的行为映射
3. **有意义的动画**：不是装饰，是信息
4. **可感知的状态变化**：按钮/图标/颜色

## 经典案例

- 点赞动画（心形放大+粒子效果）
- 下拉刷新的物理回弹
- 开关切换的滑动反馈

# 偏斜度与非对称收益

## 📌 核心定义

> 偏斜度与非对称收益模型由纳西姆·塔勒布在《随机漫步的傻瓜》中提出，描述了收益分布的不对称性特征：小概率大收益（正偏斜）与大概率小损失（负偏斜）的分布格局。传统金融理论假设收益服从正态分布（对称），但塔勒布指出真实市场的收益分布具有"肥尾"特征——极端事件发生的概率远高于正态分布的预测，且正负两端的偏斜度不同。

## 🎯 关键要点

- **正偏斜策略**：押注小概率大收益事件，大多数时候小亏，但偶尔大赚。塔勒布本人的"深度虚值期权"策略就是典型——平时持续支付期权费（小损失），黑天鹅来临时获得巨额收益
- **负偏斜陷阱**：看似稳定盈利的策略（如卖出深度虚值期权），平时持续赚小钱，但一次极端事件就可能清零。这是"捡硬币推土机前面"的隐喻
- **均值vs中位数**：在偏斜分布中，均值和中位数可能差距巨大。一个投资者的平均收益可能是正的，但大多数人实际亏损——少数巨赚拉高了均值
- **遍历性问题**：即使期望值为正，如果路径上的波动导致破产（被"爆仓"），也无法实现长期收益。生存是第一前提

### 实际应用

- 策略设计：优先选择正偏斜（有限损失、无限收益）的策略，避免负偏斜（有限收益、无限损失）的策略
- 仓位管理：在正偏斜机会上用小仓位博大收益，确保即使全部亏损也不影响整体组合生存
- 风险评估：不只看期望收益，更要看收益分布的偏斜度和尾部风险
- 生涯规划：选择具有正偏斜特征的职业方向——失败代价可控，成功回报巨大

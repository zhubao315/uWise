### 实际应用

按烹饪方式和口味类型匹配酒款：

1. **清蒸/白灼类**（清蒸鱼、白灼虾、白切鸡）
   → 长相思（Sauvignon Blanc）或雷司令（Riesling）
   - 理由：清爽酸度能提鲜，不掩盖食材本味

2. **红烧/酱烧类**（红烧肉、酱牛肉、东坡肉）
   → 梅洛（Merlot）或赤霞珠（Cabernet Sauvignon）
   - 理由：中等至饱满酒体搭配酱汁浓郁感，单宁解腻

3. **麻辣/香辣类**（麻辣火锅、水煮鱼、辣子鸡）
   → 德国雷司令半甜（Riesling Spatlese）或琼瑶浆（Gewurztraminer）
   - 理由：微甜口感中和辣感，低酒精不会加重灼烧感

4. **酸甜类**（糖醋排骨、咕噜肉、松鼠鱼）
   → 黑皮诺（Pinot Noir）或佳美（Gamay）
   - 理由：轻酒体不抢味，果味与酸甜酱汁相得益彰

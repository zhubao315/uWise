# 三宝——慈俭不争

## 📌 核心定义

> "我有三宝，持而保之：一曰慈，二曰俭，三曰不敢为天下先。" ——《道德经》第67章

## 🎯 关键要点

- **慈（慈爱）**："慈故能勇"——真正的勇气来自对他人的慈爱，而不是好斗争狠。为保护所爱之人而战斗的力量，远大于为争强好胜而战斗的力量。
- **俭（俭约）**："俭故能广"——少消耗、少占有，反而能走得更远。这不是吝啬，而是"资源利用效率的最大化"。
- **不敢为天下先（谦退）**："不敢为天下先，故能成器长"——不抢第一，反而能成为众望所归的领袖。这不是胆怯，而是一种"让别人先受益，自己后得利"的领导智慧。

# 好清单只列杀手项

## 📌 核心定义

> 清单不是把所有步骤都写上去——那是操作手册。清单只写"漏了会出大事"的关键步骤（Killer Items）。5-9项，一页纸，3秒扫完。清单的敌人不是遗漏，而是冗长——没人看的清单等于没有清单。

4. **用动词开头**（"确认XX""检查XX"，而非"注意XX"）
5. **执行后迭代**（每次执行记录：有无新杀手项？有无冗余项？）

### 案例

**出门清单**（3项 vs 15项）：
- ✅ 好版本：手机、钥匙、钱包
- ❌ 坏版本：手机、钥匙、钱包、身份证、充电器、雨伞、水杯、笔记本、笔、纸巾、口罩、耳机、手表、零钱、口红

**投资决策清单**（5项 vs 30项）：
- ✅ 好版本：能说清楚公司吗？有护城河吗？管理层诚信吗？估值便宜吗？愿意持有5年吗？

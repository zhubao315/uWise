# 水浒式团队

## 📌 核心定义

> 赵玉平以《水浒传》108将解析多元异质团队的管理智慧。梁山好汉各怀绝技又性格迥异，宋江的核心能力不是"改造人"而是"识人用人"——发现每个人的独特价值，将不同禀赋的人放到最合适的位置上，通过互补而非标准化来构建团队合力。

## 🎯 关键要点

- **识人先于改造**：管理者的首要能力是识别每个人的独特性，而非试图把人变成统一模板
- **互补而非同质**：团队的力量来自差异性互补，而非整齐划一
- **位置决定价值**：同一个人放在不同位置上价值差异巨大，关键在匹配

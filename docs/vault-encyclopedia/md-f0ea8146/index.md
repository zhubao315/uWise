# 社会认同理论

## 📌 核心定义

> 社会认同理论是一个重要的知识概念。

## 🎯 关键要点

- 内群体偏好：人们倾向于偏爱自己所属的群体。
- 外群体偏见：人们倾向于贬低不属于自己的群体。
- 去个性化：在群体中，个人身份感消失——更容易做出极端行为。
- 理解偏见：偏见往往源于群体认同——"我们vs他们"。
- 减少偏见：增加不同群体之间的接触——接触假说。

## 📖 详细说明

### 概念解释
来源：《社会心理学》（迈尔斯）
**社会认同理论**：人们通过群体成员身份来定义自己——"我是XX群体的人"。


### 实际应用

- **理解偏见**：偏见往往源于群体认同——"我们vs他们"。
- **减少偏见**：增加不同群体之间的接触——接触假说。
- **团队建设**：建立共同的团队认同——增强凝聚力。

# 路西法效应

## 📌 核心定义

> **定义**：好人变成恶魔，往往只需要一个特定的情境。菲利普·津巴多提出的核心社会心理学概念，揭示情境力量如何压倒个人品格与道德。

## 🎯 关键要点

- <!-- AI辅助丰富：基于读书笔记提炼 -->
- **定义**：好人变成恶魔，往往只需要一个特定的情境。菲利普·津巴多提出的核心社会心理学概念，揭示情境力量如何压倒个人品格与道德。
- 路西法效应源于 1971 年的**斯坦福监狱实验**。24 名身心健康的大学生被随机分配为"狱卒"和"囚犯"，仅 6 天后实验被迫叫停——狱卒变得残暴施虐，囚犯陷入崩溃顺从，连津巴多本人作为"监狱长"也陷入角色、对暴行视而不见。这不是特殊人格的结果，而是**情境力量**压倒个性的证明。该效应后来被用于解释阿布格莱布监狱虐囚、纳粹大屠杀等现实暴行。
- 1. **去个性化** — 制服、编号、匿名使道德约束消失
- 2. **盲目服从权威** — 米尔格拉姆效应：普通人会服从权威指令伤害他人
- 3. **非人化** — 将对方标签化（编号/畜生），消除伤害的心理负担
- 4. **系统默许** — 坏苹果（个人）放入坏桶（情境）会变坏，坏桶由坏系统制造
- "通往地狱的道路，往往是由善意铺成的" — 来源：《路西法效应》-菲利普·津巴多

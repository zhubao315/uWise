# 先看「是什么」，再问「为什么」

## 📌 核心定义

> 面对复杂问题时，**先用数据观察相关性（是什么），再深挖因果（为什么）**，而非一开始就试图建立完美的因果解释。

## 🎯 关键要点

- **分析问题时：** 不要先入为主地建理论框架，先跑数据看相关性
- **做决策时：** 当因果链不清晰时，高质量的相关性数据已经能支撑决策
- **学习新领域时：** 先大量接触案例（是什么），再总结规律（为什么）

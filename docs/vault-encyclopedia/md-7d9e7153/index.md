# 户外运动规划

户外运动规划是对户外活动进行系统准备的方法。规划要素：路线评估、装备清单、体能评估、风险预案、团队分工。与跑步训练的协同：有氧基础为户外运动提供体能储备，户外运动为跑步训练增加趣味性和场景变化。
## 规划五要素

### 1. 路线评估
- 距离、海拔、地形
- 路况标识、补给点
- 撤退路线

### 2. 装备清单
- 基础：鞋、衣、水、食物
- 安全：急救包、头灯、哨子
- 导航：地图、GPS、指南针

### 3. 体能评估
- 当前训练水平
- 活动强度匹配
- 团队最弱环节

### 4. 风险预案
- 天气变化应对
- 受伤处理方案
- 紧急联络人

### 5. 团队分工
- 领队、收队、医疗
- 通信协议

# 善意陷阱识别法——初衷与结果的二元判断框架

## 📌 核心定义

> 面对任何以"善意"为名的提议或政策，**必须将"意图"与"结果"拆开独立评估**。善意的初衷不构成接受提议的理由，只有可预期的良好结果才构成。这不是冷血，而是对善意的真正负责——只有好结果才能证明善意没有被辜负。

## 🎯 关键要点

- 感动陷阱：被倡议者的眼泪和故事打动，忘记了追问机制
- 权威陷阱：因为他身份高、声望好，就相信结果一定好
- 紧迫陷阱："现在不做就来不及了"——越是紧急越要冷静分析机制
- 道德绑架：质疑者被扣上"冷血""自私"的帽子，被迫放弃追问

## 📖 详细说明

### 概念解释
面对任何以"善意"为名的提议或政策，**必须将"意图"与"结果"拆开独立评估**。善意的初衷不构成接受提议的理由，只有可预期的良好结果才构成。这不是冷血，而是对善意的真正负责——只有好结果才能证明善意没有被辜负。


### 实际应用

1. **剥离意图包装**：先把"为了XX好"这类表述放到一边，只看机制本身——这个方案具体怎么运作？
2. **追踪权力流向**：这个方案实施后，谁获得了更多权力？权力增加了哪些具体手段？这些手段有没有被滥用的可能？
3. **模拟失败场景**：假设执行者是平庸的、甚至恶意的，这个机制还能产生好结果吗？好的制度应该对坏人也有约束力。
4. **检验可逆性**：如果结果不如预期，这个方案能轻易撤回吗？很多"善意政策"的危险在于其不可逆性——一旦上马就回不去了。
5. **寻找替代路径**：同样的善意目标，有没有不集中权力、不依赖"好人执行"就能实现的自发机制？

# 损失厌恶

## 📌 核心定义

> 损失厌恶（Loss Aversion）是前景理论的核心发现，指等量损失带来的心理痛苦约为等量收益带来的快乐的2倍。赫什·舍夫林在《超越恐惧和贪婪》中将损失厌恶视为投资者行为偏差的基石，它直接解释了"处置效应"——投资者倾向于过早卖出盈利股票、过久持有亏损股票。来源：《超越恐惧和贪婪》（赫什·舍夫林，2000年）；《思考，快与慢》（卡尼曼，2011年）。

## 🎯 关键要点

- **2:1的痛苦-快乐比率**：卡尼曼和特沃斯基的前景理论实验证明，失去100元的痛苦强度约为得到100元快乐的2倍。这意味着投资者需要至少200%的潜在收益，才愿意承担100%的潜在损失。
- **参考点依赖**：损失厌恶不是对绝对值的反应，而是对"参考点"偏离的反应。投资者的心理参考点通常是买入价格，因此浮亏被视为"损失"，浮盈被视为"收益"，即使企业的内在价值与买入价无关。
- **处置效应**：损失厌恶最直接的投资表现是处置效应——投资者卖出盈利股票的速度比卖出亏损股票快1.5倍。这导致投资组合中"赢家早走、输家长留"，系统性地拖低了整体收益。
- **风险偏好的反转**：在收益区间，投资者表现为风险厌恶（选择确定的小收益）；在损失区间，投资者表现为风险偏好（选择不确定的大损失）。这解释了为什么投资者愿意"赌一把"等亏损股票回本，而不是及时止损。

## 📖 详细说明

### 概念解释
损失厌恶（Loss Aversion）是前景理论的核心发现，指等量损失带来的心理痛苦约为等量收益带来的快乐的2倍。赫什·舍夫林在《超越恐惧和贪婪》中将损失厌恶视为投资者行为偏差的基石，它直接解释了"处置效应"——投资者倾向于过早卖出盈利股票、过久持有亏损股票。来源：《超越恐惧和贪婪》（赫什·舍夫林，2000年）；《思考，快与慢》（卡尼曼，2011年）。


### 实际应用

- **止损纪律**：在买入前设定明确的止损位（如亏损10%或20%），并在触发时严格执行。止损纪律是对抗损失厌恶的最有效工具——它将"主观判断"转化为"机械执行"。
- **参考点重置**：定期将投资组合的参考点从"买入价"重置为"当前市场价值"。问自己："如果今天重新选择，我还会以当前价格买入这只股票吗？"如果答案是否定的，就应该卖出。
- **心理账户管理**：将投资组合视为一个整体而非单只股票。即使某只股票亏损，只要整体组合表现良好，就应该接受个别亏损作为投资的正常成本。

## 💡 个人理解

斯多葛哲学的"premeditatio malorum"（预设失去）是损失厌恶的天然脱敏训练：当你提前想象失去一切的场景，2:1 的痛苦比率就被"脱敏"了。投资中的止损纪律，本质上就是斯多葛式的"预设失去"——在买入前就接受"可能亏损20%"的现实，损失发生时就不会被情绪劫持。

## 🔧 调用示例

> **场景 1：投资中的止损纪律**
> 当你买入一只股票时：
> 1. 在买入前设定止损位（如亏损10%）
> 2. 写下来："如果跌到X元，我无条件卖出"
> 3. 触发止损时 → 机械执行，不要犹豫
> 4. **注意**：止损是"预设失去"——提前接受亏损的可能性

> **场景 2：谈判中的损失厌恶利用（边界场景）**
> 当你想让对方接受你的条件：
> 1. 强调"不接受会失去什么"（而非"接受会得到什么"）
> 2. 例如："如果不现在签，下个月价格会涨20%"
> 3. **注意**：这是利用对方的损失厌恶——道德上需要谨慎

## ⚠️ 边界约束

- **适用范围**：投资止损、谈判策略、消费决策、习惯改变
- **不适用**：
  - 长期价值投资（短期亏损是正常的，不应因损失厌恶而卖出）
  - 保险购买（损失厌恶反而鼓励人们买保险——这是正面的）
- **前置条件**：需要能识别自己是否在"卖赢留亏"
- **风险提示**：
  - 处置效应：过早卖出盈利股、过久持有亏损股 → 系统性降低收益
  - 后悔厌恶：害怕后悔 → 不做决策 → 错过机会

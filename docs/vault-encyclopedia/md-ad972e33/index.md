# 姿势跑法三要素

## 1. 核心精要

跑步动作被解构为三个原子要素的周期性循环：**Pose → Fall → Pull**。

**Pose（姿势）**：S形单腿站立，支撑脚落在重心正下方前脚掌，膝盖微弯，另一脚拉至臀下。这是动作的稳态基点——重力和弹性能量在此"就绪"。

**Fall（落下）**：从脚踝处整体前倾，重力产生向前的分力（F = mg·sinθ）接管推进。身体越过支撑点，进入短暂的"有控制的跌倒"。**这是跑步推进力的真正来源**。

**Pull（拉起）**：腘绳肌快速将脚从地面拉起至臀下，最小化触地时间（目标 < 200ms），最大化弹性势能回收。**拉起不是为了"抬脚"，而是为了释放弹性能量并回归 Pose**。

## 2. 系统演化图景

**正反馈（效率飞轮）**：
```
正确 Pose → 有效 Fall → 快速 Pull → GCT↓ → 弹性效率↑ → 回归 Pose 更轻松
```

**负反馈（伤病螺旋）**：
```
过度跨步 → 脚跟落地 → 弹性耗散 → GRF↑ → 微损伤累积 → 炎症 → 跑姿变形补偿 → 新区域损伤
```

**临界点**：
- 步频 ≥ 180 spm：过度跨步的物理可能性被消除
- GCT < 200ms：弹性回收效率突破 0.65 高效阈值
- 着地点在重心正下方：制动力趋近于零

## 3. 跨域依赖与关联

- **对跑步经济性**：三要素执行质量直接决定跑步经济性（每公里耗氧量）
- **对伤病预防**：90%+ 跑步伤病可追溯到三要素中至少一个的错误执行
- **对运动技能习得**：姿势跑法是"将本能动作技术化"的范式，适用于游泳、自行车
- **对系统设计**：复杂系统的关键在于找到"最小可控原子"并优化其循环效率
- **对投资**：类比"借势"——找到系统自带的驱动力，而非用蛮力对抗趋势

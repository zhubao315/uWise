## 📖 详细说明

### 概念解释
**一句话**：Agent = 工具调用 + 记忆机制 + 任务规划，三者缺一不可，共同构成自主智能体的最小可行架构。
大语言模型本身只是一个文本生成器——给定输入，产生输出。要让它成为真正能"做事"的Agent，需要在LLM之上叠加三层关键能力：**工具调用**让它与外部世界交互，**记忆机制**让它积累经验和上下文，**任务规划**让它能分解复杂目标并有序执行。

这一模型来自《大语言模型应用开发》中的Agent设计范式，其理论基础是Yao等人2022年提出的ReAct框架（Reasoning + Acting）。


### 实际应用

### 1. 工具调用（Tool Use / Function Calling）

LLM自身无法访问互联网、执行代码、查询数据库。工具调用赋予Agent"手"的能力：

- **工具注册**：将每个工具的名称、描述、参数schema注册到系统提示中，让模型知道"有哪些工具可用"
- **意图识别**：模型根据用户请求，判断是否需要调用工具、调用哪个工具、传什么参数
- **结果整合**：将工具返回的结果纳入上下文，生成面向用户的自然语言回答

典型工具包括：搜索引擎、代码解释器、数据库查询、API调用、文件操作等。

### 2. 记忆机制（Memory）

没有记忆的Agent是"金鱼脑"——每次对话都从零开始。记忆机制分为两层：

- **短期记忆（Working Memory）**：当前对话的上下文窗口，包含最近的消息历史。受限于模型的上下文长度（如128K tokens）。
- **长期记忆（Long-term Memory）**：跨对话持久化的信息。实现方式包括：
  - 向量数据库存储历史对话摘要，通过语义检索召回
  - 结构化知识库（如本知识库），通过文件系统访问
  - 用户偏好文件，记录长期习惯和设定

记忆让Agent能够：记住用户之前说过什么、从过去的失败中学习、维护跨会话的任务状态。

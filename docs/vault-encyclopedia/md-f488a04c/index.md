# 个人商业模式

## 📌 核心定义

> ![](https://qncdn.n.cn/so/image/902aa684e171d548b3f4dcfea98b8b0a.png?w=1179&h=1569)

## 🎯 关键要点

- 包括的对象：家人、朋友、同学、同事、同行、老师等能够给予帮助的人。
- 主要行为：提供产品、提供服务、提供平台、创新需求、性能改善、优化服务、节约成本、控制风险等。
- 价值体现：创新需求、性能改善、物美价廉、优化服务、节约时间、提高效率等。
- 建立方式：私人关系、自助服务、与客户协作。
- 各类群体：都市白领、职场新人、单身贵族、家庭主妇、老年群体、享乐一族、企业组织等。

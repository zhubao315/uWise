# 阴阳辩证

## 📌 核心定义

> 道家与易经的核心思维方式，认为任何事物都内在地包含对立统一的两个方面。曾仕强将其发展为管理辩证法：管理中没有脱离情境的"最优方案"，只有契合"当时、当位"的"最合理方案"。好与坏、对与错在时间轴上可以互转，管理者需要的是动态判断力而非固定标准。

## 🎯 关键要点

- **对立统一**：正反两面同时存在于一个事物之中，不能只看一面
- **时位决定合理性**：一个方案是否正确取决于时机和位置，脱离情境的判断没有意义
- **动态权衡**：管理是不断在两极之间寻找平衡的艺术，而非执行固定公式的科学

# 侍酒温度

## 📌 核心定义

> 不同类型葡萄酒有各自的最佳饮用温度，温度过高或过低都会显著影响风味表达。

## 🎯 关键要点

- 不同类型葡萄酒有各自的最佳饮用温度，温度过高或过低都会显著影响风味表达。
- 侍酒温度是影响葡萄酒品鉴体验的关键变量，却常被忽略。温度过低会封闭香气、压抑风味展开；温度过高则让酒精感刺鼻、酒体松散、酸度失衡。
- **红葡萄酒**的理想侍酒温度为14-18°C，远低于许多人以为的"室温"。传统欧洲酒窖的室温约15-16°C，而中国北方冬季室内暖气可达25°C以上。酒体轻盈的红葡萄酒（如黑皮诺、佳美）适合14-16°C，酒体饱满的（如赤霞珠、巴罗萨设拉子）适合16-18°C。
- **白葡萄酒**的理想侍酒温度为7-12°C。轻盈清爽的白葡萄酒（如长相思、灰皮诺）适合7-9°C，酒体饱满的白葡萄酒（如勃艮第霞多丽、陈年雷司令）适合10-12°C。过低的温度会让复杂白葡萄酒的层次感消失。
- **桃红葡萄酒**适合8-12°C，介于红白之间。起泡酒（香槟、卡瓦）适合6-8°C，低温有助于保持气泡的细腻度。甜酒（如托卡伊、苏玳）适合6-8°C，低温平衡甜腻感。
- 实用原则：当你不确定时，**宁凉勿热**——红葡萄酒可以冰镇15分钟，白葡萄酒从冰箱取出放5分钟。酒在杯中会自然升温，所以略低的起始温度给了你更多享受的时间窗口。

### 实际应用

开瓶前根据酒款类型调整温度：红葡萄酒若室温偏高，可放入冰箱冰镇15分钟；白葡萄酒从冷藏室取出后在室温下放置5分钟再饮用。遵循“宁凉勿热”原则，略低的起始温度能利用杯中自然升温的过程延长最佳风味窗口，避免酒精感刺鼻或香气封闭。

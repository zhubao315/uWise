# 习惯系统

## 📌 核心定义

> 习惯系统是指通过建立自动化的行为回路（提示→渴望→反应→奖励），将有意行为转化为无意识执行的认知模型。源自查尔斯·杜希格《习惯的力量》和詹姆斯·克利尔《掌控习惯》。

## 🎯 关键要点

- **习惯回路**：提示（Cue）→ 惯常行为（Routine）→ 奖励（Reward）→ 信念（Belief）
- **四大定律**：让它显而易见、让它有吸引力、让它简单易行、让它令人愉悦
- **身份驱动**：最持久的习惯改变来自身份层面（"我是跑步者"而非"我要跑步"）
- **1%法则**：每天进步1%，一年后提升37倍；习惯的效果具有复利特性

# 专注-发散双模式切换法

## 📌 核心定义

> 💡 不要迷信"苦功"——大脑需要休息来整合信息。最高效的学习节奏是"专注-放松-专注-放松"的交替，而不是"连续专注3小时然后崩溃"。

## 🎯 关键要点

- **专注模式是"聚光灯"**: 聚焦于具体问题，依赖已有知识框架做逻辑推理，适合理解新概念、解决熟悉类型的问题。此时大脑前额叶皮质活跃，神经元按固定路径连接。
- **发散模式是"探照灯"**: 大脑处于放松状态时（散步、睡觉、洗澡），不聚焦于具体问题，神经元自由连接，适合产生灵感、突破思维瓶颈、建立跨领域联想。
- **切换是核心能力**: 番茄工作法（25分钟专注 + 5分钟休息）的科学基础正是双模式切换。遇到瓶颈超过30分钟，应主动切换到发散模式，而非硬撑。
- **"顿悟"发生在发散模式**: 很多"灵光一现"的时刻（阿基米德的浴缸、凯库勒的蛇咬尾巴梦）都发生在放松的发散模式中，因为此时大脑在后台持续处理问题。

### 实际应用

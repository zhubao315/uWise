  3. 建立“信息黑名单”：主动屏蔽情绪煽动型账号、无营养短视频、重复推送的同质化内容，减少算法推荐的干扰；
  4. 每日“信息复盘”：晚上花5分钟回顾“今天接收了哪些有效信息？浪费了多少时间在无效信息上？”，逐步优化筛选标准。

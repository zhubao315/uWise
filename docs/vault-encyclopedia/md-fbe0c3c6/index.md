# 情绪与健康

## 📌 核心定义

> 来源：《情商》（戈尔曼）《身体从未忘记》（范德考克）

## 🎯 关键要点

- 长期压力：皮质醇水平升高→免疫功能下降→更容易生病。
- 负面情绪：焦虑、愤怒、悲伤→心血管疾病、消化问题、免疫功能下降。
- 积极情绪：快乐、感恩、满足→增强免疫功能、降低炎症。
- 心身一体：心理和身体不是分离的——情绪直接影响身体。
- 情绪管理是健康管理：管理情绪就是管理健康。

## 📖 详细说明

### 概念解释
来源：《情商》（戈尔曼）《身体从未忘记》（范德考克）
情绪不仅影响心理状态，还直接影响身体健康：

- **长期压力**：皮质醇水平升高→免疫功能下降→更容易生病。
- **负面情绪**：焦虑、愤怒、悲伤→心血管疾病、消化问题、免疫功能下降。
- **积极情绪**：快乐、感恩、满足→增强免疫功能、降低炎症。


### 实际应用

- **情绪管理**：通过正念、运动、社交等方式管理情绪。
- **身体觉察**：觉察身体信号——心跳加速、肌肉紧张可能是情绪的表现。
- **压力管理**：减少长期压力——压力是健康的最大威胁之一。

# 研究驱动原则

## 📌 核心定义

> 张磊在《价值》中提出的投资方法论原则：通过深度、独立、系统的研究，在投资决策前建立对行业和企业的超额认知（informational edge），用研究的确定性对抗市场的不确定性。高瓴资本的核心竞争力不是信息优势，而是研究深度带来的认知优势。

## 🎯 关键要点

- **研究是投资的根基**：不研究清楚不投资，宁可错过也不盲从。每一笔投资都应建立在对行业格局、竞争壁垒、管理层能力、财务状况的深入理解之上。
- **"疯狂的超额研究"**：在做出投资决策前，投入远超市场平均水平的研究时间和精力。高瓴团队在投资某家公司前，往往会访谈数十位行业专家、供应商、客户和竞争对手。
- **第一性原理思考**：不依赖市场共识和二手信息，从最基础的事实和逻辑出发，独立推导结论。
- **行业研究**：理解行业的商业模式、价值链结构、竞争格局、增长驱动力和潜在风险。
- **企业研究**：深入分析企业的竞争优势、管理层质量、财务健康度、战略方向和执行力。

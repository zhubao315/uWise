# 相关不等于因果

## 📌 核心定义

> 来源：《对伪心理学说不》（斯坦诺维奇）《心理学与生活》（津巴多）

## 🎯 关键要点

- 混淆变量：一个未被测量的变量同时影响两个相关变量——这才是真正的"原因"。
- 方向性问题：A和B相关，可能是A导致B，也可能是B导致A。
- 第三变量问题：A和B相关，可能是C同时导致了A和B。
- 评估研究：看到"研究表明……"时，问自己——"有没有混淆变量？"
- 做决策：不要因为两件事同时发生就认为一个导致了另一个。

## 📖 详细说明

### 概念解释
来源：《对伪心理学说不》（斯坦诺维奇）《心理学与生活》（津巴多）
**相关不等于因果**：两个变量相关，不代表一个导致另一个。

**例子**：冰淇淋销量和溺水率正相关——但冰淇淋不导致溺水（真正原因是夏天）。


### 实际应用

- **评估研究**：看到"研究表明……"时，问自己——"有没有混淆变量？"
- **做决策**：不要因为两件事同时发生就认为一个导致了另一个。
- **科学思维**：用实验法验证因果关系——而不是靠相关法猜测。

# 文以载道

## 📌 核心定义

> "文以载道"是中国文学批评的核心命题，由宋代周敦颐明确提出："文所以载道也。"其含义是：**文章的价值在于承载和传达"道"（思想、道德、真理），而非单纯的辞藻华丽。**

这一思想可以追溯到孔子的"辞达而已矣"（言辞能表达意思就够了）和韩愈的"文以贯道"。它强调文学的社会功能和道德责任。

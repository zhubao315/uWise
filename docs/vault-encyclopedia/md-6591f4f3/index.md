# 摄影的加减法

摄影创作的核心思维模型：**减法做审美，加法做叙事**。初学者的进阶之路往往是从「什么都想拍」到「知道该舍弃什么」。

## 减法美学（摄影的入门与成熟期）

取景框的本质是**切除**——从混乱的世界中切出一个有序的框。

- **排除视觉干扰**：取景前扫视四角和背景，移除或规避分散注意力的元素
- **减少色彩数量**：一张照片的主色调不超过3种
- **减少信息层级**：主体只有一个，其他都是衬托
- **减少不必要细节**：过于丰富的细节会分散情感注意力

> 摄影要的不是更多，而是更少。——布列松

## 加法叙事（摄影的进阶期）

当减法做到极致，画面可能干净但空洞——这时候需要**往画面里加信息**。

- **加入前景**：增加纵深感，引导视线进入画面
- **加入叙事元素**：能说明时间、地点、事件背景的小物件
- **加入人物**：有人物的风景比纯风景更容易引发共情
- **加入对比关系**：大小对比、新旧对比、冷暖对比

## 实践框架

1. 取景时先做减法——去掉一切可以去掉的东西
2. 按下快门前问自己：「这张照片的核心信息是什么？」
3. 如果画面太干净但没意思——考虑加什么能增强叙事

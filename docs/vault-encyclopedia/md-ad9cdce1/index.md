# 工作是为了活着不是活着为了工作

## 📌 核心定义

> 中村恒子在《人间值得》中提出了一个被现代社会遗忘的常识：工作是为了活着，不是活着为了工作。工作是维持生活的手段，而不是人生的全部目的。当工作成为人生的唯一意义时，一旦退休或失业，人就会陷入虚无。

## 🎯 关键要点

- 不要把自我价值完全绑定在工作成就上
- 培养工作之外的兴趣和社交关系
- 接受工作的"足够好"，不必追求极致
- 保持生活的多样性，让工作只是生活的一部分

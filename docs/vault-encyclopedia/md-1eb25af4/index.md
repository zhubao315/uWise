# 无形资产投资

## 📌 核心定义

> 在长寿时代，无形资产比有形资产更重要。无形资产决定了你能否在 100 年人生中保持活力和竞争力。

## 🎯 关键要点

- 有形资产会贬值：货币会通胀，资产会折旧
- 无形资产会增值：技能会提升，关系会深化，认知会扩展
- 有形资产可以被夺走：经济危机、政策变化
- 无形资产永远属于你：你的知识、技能、健康无法被夺走

|------|------|---------|

1. **生产力资产**：每年学习一个新领域，保持专业竞争力
2. **活力资产**：坚持运动、健康饮食、维护社交网络
3. **转型资产**：培养自我认知、适应能力、学习能力

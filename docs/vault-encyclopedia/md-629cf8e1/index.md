# 估值分析

> 评估企业或资产内在价值的系统方法——投资决策的核心基础。

## 常用方法

| 方法 | 适用场景 |
|------|---------|
| **DCF** | 现金流稳定的成熟企业 |
| **PE 估值** | 盈利稳定的上市公司 |
| **PB 估值** | 重资产行业（银行/地产） |
| **PS 估值** | 高增长但未盈利的公司 |
| **可比公司** | 行业内横向对比 |

## DCF 三要素

1. **未来自由现金流**：预测 5-10 年
2. **折现率（WACC）**：反映风险
3. **终值**：永续增长模型

## 常见误区

- ❌ 过度依赖单一估值方法
- ❌ 增长假设过于乐观
- ❌ 忽视行业周期性
- ❌ 安全边际不够

# 风险≠波动率

## 📌 核心定义

> 霍华德·马克斯在《投资最重要的事》中提出的核心模型：真正的投资风险不是价格波动率（volatility），而是永久性资本损失的概率。传统金融学用波动率衡量风险（如标准差、Beta值），但马克斯认为这是根本性的错误——波动只是暂时的账面损失，而永久性损失是不可逆的本金侵蚀。

## 🎯 关键要点

- **波动不是风险**：股价从100跌到70再涨回120，波动率很高但没有风险。真正的风险是股价从100跌到70，然后公司破产，本金归零
- **永久性损失才是风险**：风险是"实际结果低于预期结果的可能性"，尤其是"本金永久性损失的可能性"
- **波动率被广泛误用**：现代投资组合理论（MPT）用波动率衡量风险，导致很多投资者回避波动大的资产，反而错过了真正的机会
- **高波动≠高风险，低波动≠低风险**：在牛市中，低波动的资产可能隐藏着巨大风险（如2008年前的次贷产品）

## 📖 详细说明

### 概念解释
霍华德·马克斯在《投资最重要的事》中提出的核心模型：真正的投资风险不是价格波动率（volatility），而是永久性资本损失的概率。传统金融学用波动率衡量风险（如标准差、Beta值），但马克斯认为这是根本性的错误——波动只是暂时的账面损失，而永久性损失是不可逆的本金侵蚀。


### 实际应用

- **资产选择**：不要因为某资产波动大就回避它，要评估永久性损失的概率
- **风险管理**：不要依赖VaR等量化指标，要用情景分析和压力测试
- **仓位管理**：对永久性损失概率高的资产，降低仓位；对概率低但波动大的资产，可以增加仓位
- **逆向思考**：问自己"在什么情况下我会永久性损失本金"，然后避免那些情况

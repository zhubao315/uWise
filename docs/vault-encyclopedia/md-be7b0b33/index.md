# 创伤的代际传递

## 📌 核心定义

> 来源：《身体从未忘记》（范德考克）《超越原生家庭》（理查森）

## 🎯 关键要点

- 依恋模式传递：你的依恋类型影响你孩子的依恋类型。
- 行为模式传递：未处理的创伤会以行为模式的方式传递——如焦虑、回避、攻击。
- 可以打破循环：通过觉察和处理创伤，可以打破代际传递。
- 觉察创伤来源：问自己——"这个行为模式是从哪里来的？"
- 处理创伤：通过心理治疗、身体练习等方式处理创伤。

## 📖 详细说明

### 概念解释
来源：《身体从未忘记》（范德考克）《超越原生家庭》（理查森）
创伤不仅影响经历创伤的人，还会传递给下一代——通过依恋模式、家庭系统、行为模式。


### 实际应用

- **觉察创伤来源**：问自己——"这个行为模式是从哪里来的？"
- **处理创伤**：通过心理治疗、身体练习等方式处理创伤。
- **打破循环**：有意识地选择不同的反应方式——不把创伤传递给下一代。

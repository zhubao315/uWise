# 阅读环境设计四原则

## 📌 核心定义

> 💡 阅读环境是被忽视的变量——改变空间，就能改变阅读的质量和深度。

## 🎯 关键要点

- **减少干扰因素**: 手机静音、关闭通知、选择安静空间
- **提供舒适座椅**: 合适的椅子和桌面让身体放松，注意力集中在文字上
- **充足光线**: 自然光最佳，阅读灯次之，避免眼睛疲劳
- **营造仪式感**: 固定时间、固定地点、一杯茶/咖啡，建立阅读的心理暗示

## 📖 详细说明

### 概念解释
阅读效果不仅取决于读什么，更取决于在哪里读。减少干扰、舒适座椅、充足光线、营造仪式感——四原则共同塑造深度阅读体验。

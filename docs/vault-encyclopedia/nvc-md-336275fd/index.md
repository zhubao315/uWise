# NVC四要素——非暴力沟通框架

## 📌 核心定义

> |------|------|------|

## 🎯 关键要点

- 观察不加评判：区分"观察"和"评论"——"你总是迟到"是评论，"这周你迟到三次"是观察。
- 感受源于需要：所有负面感受都源于某个未被满足的需要。
- 请求而非命令：请求允许对方说"不"，命令不允许。
- 家庭沟通：用NVC处理家庭冲突——观察→感受→需要→请求。
- 职场反馈：用NVC给出建设性反馈——不评判行为，只描述影响。

## 📖 详细说明

### 概念解释
来源：《非暴力沟通》（卢森堡）
非暴力沟通（NVC）的核心是四个步骤：

| 步骤 | 内容 | 示例 |
|------|------|------|
| **观察** | 客观描述发生了什么，不加评判 | "这周你有三次在9点之后到达" |
| **感受** | 表达自己的真实感受 | "我感到失望和担心" |
| **需要** | 说出感受背后的需要 | "因为我需要被尊重和重视" |
| **请求** | 提出具体的、可操作的请求 | "你能否在明天9点前到达？" |


### 实际应用

- **家庭沟通**：用NVC处理家庭冲突——观察→感受→需要→请求。
- **职场反馈**：用NVC给出建设性反馈——不评判行为，只描述影响。
- **自我对话**：用NVC和自己对话——觉察自己的感受和需要。

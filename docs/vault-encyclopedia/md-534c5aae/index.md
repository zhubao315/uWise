# 时间视角切换术

## 📌 核心定义

> 💡 时间管理的本质不是"做更多事"，而是在正确的时刻用正确的视角，做值得做的事。

## 🎯 关键要点

- **五种时间视角各有适用场景**：
- 积极过去视角：从过往成功中汲取信心和经验
- 消极过去视角：适度反思错误（但不可沉溺）
- 享乐主义视角：休息放松、享受当下美好时刻
- 宿命论视角：接受不可控因素，放下执念

### 实际应用

1. **五种时间视角各有适用场景**：
   - 积极过去视角：从过往成功中汲取信心和经验
   - 消极过去视角：适度反思错误（但不可沉溺）
   - 享乐主义视角：休息放松、享受当下美好时刻
   - 宿命论视角：接受不可控因素，放下执念
   - 未来视角：规划目标、延迟满足、为未来投资
2. **场景匹配原则**：工作规划用未来视角，社交聚会用享乐视角，复盘总结用积极过去视角
3. **警惕单一视角陷阱**：总是未来视角→焦虑；总是享乐视角→荒废；总是消极过去→抑郁
4. **收益半衰期辅助决策**：在选择做什么时，优先高收益+长半衰期的事（如学习技能），减少低收益+短半衰期的事（如无目的刷手机）

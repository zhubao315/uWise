# 风土（Terroir）

## 📌 核心定义

> 风土是影响葡萄酒特性的自然与人文因素的总和，涵盖气候、土壤、地形和人文传统四大维度。

## 🎯 关键要点

- 风土是影响葡萄酒特性的自然与人文因素的总和，涵盖气候、土壤、地形和人文传统四大维度。
- 风土（Terroir）源自法语"terre"（土地），是葡萄酒世界最核心也最难翻译的概念。它不是单一变量，而是一个多维度的系统，决定了某个地块出品的葡萄酒为何具有不可替代的个性。
- **气候维度**包括宏观气候（产区纬度、大陆性或海洋性影响）、中气候（山谷走向、湖泊调节）和微气候（单株葡萄树周围的温湿度）。同一纬度上，山坡朝阳面与背阴面的温差可造就截然不同的酒风。
- **土壤维度**涵盖石灰�ite、黏土、砂岩、花岗岩、火山�ite等不同基岩。土壤影响排水性、矿物质供给和根系深度。勃艮第人相信同一山坡上不同土层的葡萄酒有明显差异，这是"climat"概念的基石。
- **地形维度**包括海拔、坡度、坡向和水体反射。高海拔昼夜温差大，有利于酸度保留；河流和湖泊能调节极端温度，如德国摩泽尔河谷的陡坡朝南，最大化阳光接收。

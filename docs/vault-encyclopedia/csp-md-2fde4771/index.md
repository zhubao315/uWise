# 有意识消费计划CSP

## 📌 核心定义

> Conscious Spending Plan：固定成本50-60%、投资储蓄、热爱事项20-35%无 guilt 花掉——预算不是苦行，是优先级。

## 🎯 关键要点

- 固定成本压到 50-60%，超了先砍房/车/订阅
- 投资＋储蓄自动划走，剩下的才是可花
- 热爱事项大方花，讨厌事项砍到零
- 每月只看一次，不记流水账
- CSP 是自动化的预算前提

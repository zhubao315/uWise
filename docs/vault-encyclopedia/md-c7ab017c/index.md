# 城市规划伦理

## 📌 核心定义

> 城市规划伦理，是指城市规划决策过程中应遵循的伦理原则与价值准则。它要求规划者超越单纯的技术效率和经济利益考量，将公共利益、代际公平、文化传承、社会公正等价值维度纳入决策框架。

在北京城市规划的历史实践中，规划伦理的缺失造成了深刻教训。1950年代将行政中心设在旧城、拆除城墙、改造胡同等决策，虽然有其当时的现实考量，但从伦理角度审视，存在多重问题：未充分尊重历史文化遗产的内在价值，未充分考虑决策的不可逆后果，未充分保障受影响群体的知情权和参与权，未充分平衡当代人需求与后代人权益。

城市规划伦理的核心在于承认：城市空间不仅是经济资产，更是文化容器和社会纽带。一座城市的街道、建筑、广场承载着几代人的集体记忆，是城市文化认同和精神归属的物质载体。规划者对这些空间的处置，本质上是在行使一种伦理权力。

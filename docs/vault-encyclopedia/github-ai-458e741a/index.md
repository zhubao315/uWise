## 📖 项目详解

### 🥇 OpenMontage — AI 视频生产流水线

首个开源的 agentic 视频生产系统，文本描述→完整视频一站式完成：
- 全流程自动化：调研 → 写脚本 → 生成素材 → 剪辑 → 成片
- 从免费素材库检索真实运动镜头（非静态图片）
- 制作成本极低，几乎无需人工干预

### 🥈 daily_stock_analysis — AI 股票分析师

大模型驱动的多市场股票智能分析工具：
- 覆盖 A 股、港股等多市场
- 每日生成评分/买卖点/风险警报决策仪表盘
- 支持微信、飞书、Telegram 多渠道推送
- 通过 GitHub Actions 定时运行，零成本部署

### 🥉 voicebox — 本地 AI 语音工作室

集成两大语音巨头功能，强调本地优先和隐私保护：
- 集成 ElevenLabs（合成）+ WisprFlow（听写）
- 声音和录音全程本地处理，数据不出本机
- 内置 7 个 TTS 引擎，支持 23 种语言

### 4. penpot — 开源设计平台

Figma 的真正替代品，主打"设计即代码"：
- 可完全自托管设计基础设施
- 设计稿可直接翻译成代码，原生支持 Design Tokens
- 支持插件系统，工作区可被程序和 AI 调度

### 5. agent-native — 人机协作开发框架

打通 Agent 与 UI 的开发框架：
- 一份 action 代码可同时被界面/Agent/HTTP/CLI 等六个入口调用
- 人与 Agent 共享数据库，状态实时同步
- 附带录屏、视觉规划、幻灯片等开箱即用模板

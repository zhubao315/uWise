# 创造性资本主义

## 📌 核心定义

> 比尔·盖茨在 2008 年达沃斯世界经济论坛上提出的概念：资本主义需要一次"创造性"的升级——将市场力量、商业效率导向于服务最贫困的人群。企业可以在盈利的同时解决社会问题——不是 CSR 的装饰，而是把穷人纳入市场体系。

## 🎯 关键要点

- **问题诊断**：纯市场的利润驱动让资本只流向有支付力的人群，最需要帮助的穷人被系统性地忽略
- **解决路径**：通过机制设计（如疫苗预购承诺、社会影响力债券）让服务穷人变为可盈利的业务
- **核心理念**：不是反对资本主义，而是让资本主义变得更完整——让 40 亿穷人从"被援助对象"变为"市场参与者"

# 液态活检与多维生物标志物在癌症超早期筛查中的量化应用

## 📌 核心定义

## 🎯 关键要点

- 核心定义：液态活检（Liquid Biopsy）是通过检测血液中的循环肿瘤 DNA（ctDNA）、循环肿瘤细胞（CTC）、外泌体等生物标志物，实现癌症超早期筛查与动态监测的非侵入性诊断技术。其核心价值在于将癌症发现窗口提前 3-5 年，在无症状的亚临床阶段实现干预。
- ctDNA 甲基化检测：癌细胞死亡后会释放携带异常甲基化模式的 DNA 片段进入血液。GRAIL 平台的 Galleri 检测可识别 50 余种癌症的 ctDNA 甲基化特征，并精确定位肿瘤组织来源。
- 多癌症早筛（MCED）：一次抽血同时筛查多种癌症，突破传统「一癌一查」的低效模式。
- 信号溯源：不仅能判断「是否有癌」，还能追踪信号的组织来源，大幅减少不必要的后续侵入性检查。

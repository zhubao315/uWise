# Stay Hungry, Stay Foolish

## 📌 核心定义

> 乔布斯 2005 年斯坦福大学毕业演讲的核心口号，也是他一生奉行的行动原则。"Stay Hungry"意味着永不满足于已经取得的成就，始终像饥渴的人一样追求更多；"Stay Foolish"意味着始终保持"初学者"的心态，敢于尝试看似愚蠢、不被理解的事情。

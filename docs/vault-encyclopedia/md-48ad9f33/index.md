# 心理学的科学方法

## 📌 核心定义

> 来源：《心理学与生活》（津巴多）《对伪心理学说不》（斯坦诺维奇）

## 🎯 关键要点

- 相关不等于因果：两个变量相关，不代表一个导致另一个。
- 可证伪性是科学的标志：不能被证伪的理论不是科学。
- 心理学是科学：不是读心术或常识，而是基于实证研究的科学学科。
- 评估研究：问自己——"样本量多大？有没有对照组？有没有混淆变量？"
- 识别伪科学：问自己——"这个说法可以被证伪吗？"

## 📖 详细说明

### 概念解释
来源：《心理学与生活》（津巴多）《对伪心理学说不》（斯坦诺维奇）
心理学是一门**研究行为和心理过程的科学**——使用科学方法来理解人类行为。


### 实际应用

阅读心理学研究时，主动核查样本量、对照组设置及潜在混淆变量，以区分相关关系与因果关系。面对声称能改变行为或提升能力的理论（如某些性格测试或潜能开发课程），先判断其核心主张是否具备可证伪性，从而快速识别并规避伪科学陷阱。

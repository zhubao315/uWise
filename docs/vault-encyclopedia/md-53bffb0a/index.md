# 明心见性

## 📌 核心定义

> "明心见性"是禅宗的核心修行目标。"明心"指明了自己的心；"见性"指见到自己的本性（佛性）。

六祖慧能在《坛经》中提出"直指人心，见性成佛"——不需要通过繁琐的经典学习和仪式修行，直接观照自己的心，就能见到本性，顿悟成佛。

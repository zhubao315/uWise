# 般若智慧

## 📌 核心定义

> "般若"（bō rě）是梵语Prajñā的音译，意为"超越的智慧"。般若智慧不是普通的聪明才智，而是**洞见事物本质（空性）的智慧**。

《金刚经》是般若经典的核心，其核心教义是"应无所住而生其心"——不执着于任何事物，而生起清净心。般若智慧的要点是：一切有为法如梦幻泡影，不应执着。

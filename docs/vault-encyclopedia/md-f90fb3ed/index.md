# 心理边界

## 📌 核心定义

> 来源：《超越原生家庭》（理查森）《被讨厌的勇气》（岸见一郎）

## 🎯 关键要点

- 课题分离是建立心理边界的工具：区分自己的课题和别人的课题。
- 自我分化需要心理边界：在保持连接的同时拥有独立性。
- 心理边界不是冷漠：不是"不管别人"，而是"尊重边界"。
- 学会说"不"：不是不爱家人，而是保护自己的心理空间。
- 区分感受：问自己——"这是'我的'感受，还是'别人投射给我的'感受？"

## 📖 详细说明

### 概念解释
来源：《超越原生家庭》（理查森）《被讨厌的勇气》（岸见一郎）
**心理边界**是保护自己心理空间的界限——区分"我的感受"和"别人的感受"，"我的责任"和"别人的责任"。


### 实际应用

- **学会说"不"**：不是不爱家人，而是保护自己的心理空间。
- **区分感受**：问自己——"这是'我的'感受，还是'别人投射给我的'感受？"
- **承担责任**：承担自己的责任，不替别人承担。

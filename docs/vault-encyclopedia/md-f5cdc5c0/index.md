# 自成目标

## 📌 核心定义

> 自成目标（Autotelic）是契克森米哈赖在《心流》中提出的概念，源自希腊语"auto"（自我）和"telos"（目的），指**活动本身就是目的，不需要外在奖励来维持动机**。

## 🎯 关键要点

- 自成目标（Autotelic）是契克森米哈赖在《心流》中提出的概念，源自希腊语"auto"（自我）和"telos"（目的），指**活动本身就是目的，不需要外在奖励来维持动机**。
- 自成目标体验的本质是：**做这件事本身就是最大的回报**。你画画不是为了卖钱，而是因为画画本身让你快乐。你编程不是为了工资，而是因为解决问题的过程让你着迷。你跑步不是为了减肥，而是因为奔跑的感觉本身就是奖赏。
- 契克森米哈赖发现，心流体验几乎总是自成目标的——当人进入心流状态时，活动本身就变成了目的，外在奖励变得无关紧要。
- 心理学研究发现，**过度的外在奖励反而会削弱内在动机**——这就是"过度理由效应"。本来喜欢画画的孩子，如果开始为奖励而画画，失去奖励后就不再喜欢画画了。
- 契克森米哈赖研究了大量自成目标型人格，发现了共同特征：
- **强烈的好奇心**：对世界保持开放和探索的态度。
- **持久的毅力**：遇到困难不轻易放弃。
- **低自我中心**：不把注意力放在自己身上，而是专注于任务。

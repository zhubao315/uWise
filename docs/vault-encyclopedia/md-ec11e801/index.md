# 事以密成：藏状态与行事主动权

## 📌 核心定义

> **状态是一种信息；状态被人看透，就容易被拿捏。** 不诉苦、不炫耀、不泄计划，把力气花在暗处，掌握行事的**主动权**。

## 🎯 关键要点

- **不诉苦**：80% 的人不关心，剩下 20% 的人听了会高兴。
- **不炫耀成功**：大量的人见不得别人比自己好。
- **不泄计划**：事成后让结果说话；计划没落地就嚷嚷，外部期待一高，稍有反复就成了笑话，内部行动力也随之消散。
- **藏 ≠ 装**：藏不是做假，而是**不把还没成的事亮出来**。
- **底牌不外露**：真实收入、家庭财务、真实报价、对别人的真实评价——一旦敞开，被用来对付你的点就越多。
- **熟人不如生人**：熟人知道你的过去，你被"定义"了；陌生人没有历史包袱。

## 📖 详细说明

### 理论依据

- **《论持久战》**："主动性，说的是军队行动的自由权……行动自由是军队的命脉，失了这种自由，军队就接近于被打败或被消灭。"——**主动权即命脉**。
- **《韩非子》**："**事以密成，语以泄败**。"——事情因保密而成，因泄露而败。

### 实践方法

- 有人问"最近咋样"，回一句"**还行，老样子**"。
- 不诉苦、不炫耀、不解释。
- **少说一句，就多一分主动；多沉默一次，就多一分分量。** 说话的分量，从选择沉默的次数开始增长。
- 把力气花在暗处，在没人注意的地方，把事做成。

# 复盘方法论

## 核心定义

复盘（After Action Review, AAR）源自美军经验学习法，是通过结构化回顾来提炼经验教训的方法论。

## 复盘四步法

| 步骤 | 问题 | 目的 |
|------|------|------|
| **1. 回顾目标** | 当初要做什么？ | 对齐预期 |
| **2. 评估结果** | 实际发生了什么？ | 建立共识 |
| **3. 分析原因** | 为什么会有差距？ | 深挖根因 |
| **4. 总结规律** | 下次如何做更好？ | 提炼方法 |

## 复盘类型

| 类型 | 触发时机 | 侧重点 |
|------|----------|--------|
| **项目复盘** | 项目结束 | 全流程经验 |
| **里程碑复盘** | 阶段性节点 | 偏差分析 |
| **个人复盘** | 每周/每月 | 成长与反思 |
| **战略复盘** | 季度/年度 | 方向校准 |

## 常见误区

1. **变成追责会**：复盘是为了学习，不是为了惩罚
2. **流于形式**：没有深入分析根因
3. **缺乏行动**：复盘完了没有跟进措施
4. **只看结果**：忽略过程中的学习

# 知识-经验-直觉的三角转化

## 📌 核心定义

> 知识、经验与直觉三者之间相互转化的动态模型：知识通过实践内化为经验，经验通过反复验证凝结为直觉，直觉又能指导新知识的获取。

## 🎯 关键要点

- 知识→经验：通过实践、试错、反馈将显性知识转化为隐性能力
- 经验→直觉：大量重复实践后形成的自动化判断能力（专家直觉）
- 直觉→知识：将直觉判断显性化、结构化，形成可传授的知识体系
- 三角循环：三者不断螺旋上升，每一层都比上一层更深刻

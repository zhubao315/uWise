### 幻觉的本质

**什么是LLM幻觉**：
LLM幻觉是指模型生成的内容看起来合理、流畅、有说服力，但实际上与事实不符、与上下文矛盾、或者完全是编造的。

**为什么幻觉是必然的**：
1. **概率采样**：LLM基于概率分布生成下一个token，即使概率很低的token也可能被选中
2. **训练目标**：模型的训练目标是最大化下一个token的预测概率，而非确保事实正确性
3. **知识截止**：模型的知识来自训练数据，有时间截止点，无法获取最新信息
4. **泛化压力**：模型需要泛化到未见过的输入，这必然会导致一些错误的推断

### 幻觉的类型

**事实性幻觉**：
- 生成与现实世界不符的事实
- 例如："爱因斯坦在1921年获得了诺贝尔化学奖"（实际是物理学奖）

**忠实性幻觉**：
- 生成与输入上下文不符的内容
- 例如：在摘要任务中添加原文没有的信息

**逻辑性幻觉**：
- 生成逻辑上不一致的内容
- 例如：自相矛盾的陈述

**引用性幻觉**：
- 引用不存在的文献、数据或来源
- 例如：编造一个不存在的论文引用

### 为什么不能完全消除幻觉

**技术层面**：
- 概率模型的本质决定了不可能100%准确
- 训练数据不可能覆盖所有知识
- 模型需要泛化能力，这必然引入不确定性

**哲学层面**：
- "正确"本身是模糊的概念，很多问题

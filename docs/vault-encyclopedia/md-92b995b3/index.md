# 人格类型

## 📌 核心定义

> 来源：《荣格自传》（荣格）《安静》（凯恩）

## 🎯 关键要点

- 内向不是缺陷：内向是一种有独特优势的性格特质。
- 内向者的大脑更敏感：对外界刺激更敏感——需要更少的刺激就能达到最佳状态。
- 自由特质理论：在必要时可以"扮演"外向者，但需要在之后恢复独处时间。
- 理解自己：了解自己的人格类型——选择与之匹配的工作和生活方式。
- 尊重差异：不是所有人都需要外向才能成功。

## 📖 详细说明

### 概念解释
来源：《荣格自传》（荣格）《安静》（凯恩）
荣格提出人格的两个基本态度：

| 态度 | 特征 | 能量来源 |
|------|------|----------|
| **外向** | 关注外部世界——社交、行动 | 外部刺激 |
| **内向** | 关注内部世界——思想、感受 | 独处 |

**四种心理功能**：思维、情感、感觉、直觉——每个人都有主导功能。


### 实际应用

- **理解自己**：了解自己的人格类型——选择与之匹配的工作和生活方式。
- **尊重差异**：不是所有人都需要外向才能成功。
- **创造平衡**：内向者需要独处来恢复能量——这不是"不合群"。

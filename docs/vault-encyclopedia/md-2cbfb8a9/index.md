# 无条件养育

## 📌 核心定义

> 无条件养育（Unconditional Parenting）是阿尔菲·科恩提出的育儿理念，主张父母对孩子的爱不应附加任何条件，不以行为表现作为爱的前提。

## 🎯 关键要点

- **无条件的爱**：不以成绩、行为、表现为条件给予爱和关注
- **反思传统奖惩**：奖励和惩罚都是有条件的关注，损害内在动机
- **关注需求**：理解孩子行为背后的需求，而非只看表面行为
- **共同决策**：让孩子参与规则制定，培养自主性

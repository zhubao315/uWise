### 实际应用

### 场景1：决策审查
在做重要决策后，花15分钟写一份"解释审查"：
1. 我做出这个决策的**核心解释**是什么？（一句话）
2. 这个解释能被**证伪**吗？什么样的结果会推翻它？
3. 如果结果出了意外，我**什么时候**会知道？
4. 有没有什么**我只愿意接受、不愿意检验**的假设？

### 场景2：学习新知识时
每接触一个新概念，问自己：
- 这个解释能预测什么具体现象？
- 如果这个解释是错的，最可能的原因是什么？
- 它的"远达性"在哪里——能否用它解释其他领域的现象？

### 场景3：与人讨论时
当有人说"这就是原因"时，练习追问：
- "这个解释能预测什么？"
- "如果这个解释不成立，会怎样？"
- 不是为了刁难，而是为了共同获得更好的解释

### 场景4：面对失败时
失败后最容易接受"懒惰解释"（"运气不好""市场不行"）。更有效的做法：
1. 承认："我当时的解释是不充分的"
2. 追问："我当时的解释中，哪个假设被事实推翻了？"
3. 升级："新的事实需要什么样的更好解释？"

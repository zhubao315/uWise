# 默读式会议

> 亚马逊的会议创新——先默读文档，再讨论，提升会议质量。

## 流程

```
1. 主持人提前分发 6 页备忘录
2. 会议开始：全员默读 15-20 分钟
3. 讨论：基于文档内容深入讨论
4. 决策：当场做出决定
```

## 优势

| 传统会议 | 默读式会议 |
|---------|-----------|
| 发言权被声音大的人垄断 | 每个人平等获取信息 |
| 讨论容易跑题 | 基于文档聚焦讨论 |
| 信息不对称 | 所有人在同一页面 |

## 适用场景

- 需要深度讨论的决策会
- 需要全面理解背景的评审会
- 跨部门对齐会

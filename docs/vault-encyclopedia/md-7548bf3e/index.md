# 幂次法则

> 自然界和社会中普遍存在的非线性分布现象——少数个体占据大部分结果。

## 核心公式

```
Y = X^α（α ≠ 1 时即幂律分布）
```

## 经典案例

| 领域 | 幂律表现 |
|------|---------|
| **投资** | 极少数股票贡献大部分回报 |
| **知识** | 少数核心概念支撑大部分理解 |
| **财富** | 少数人持有大部分财富 |
| **互联网** | 少数平台聚集大部分流量 |
| **创业** | 少数公司获得大部分利润 |

## 实践应用

1. **投资**：不要试图预测哪只股票是赢家，而是广泛持有
2. **学习**：找到 20% 的核心知识，覆盖 80% 的应用场景
3. **时间管理**：识别 20% 的高价值活动
4. **产品**：聚焦核心功能，不做大而全

## 与正态分布的区别

| 维度 | 正态分布 | 幂律分布 |
|------|---------|---------|
| 形状 | 钟形曲线 | 长尾 |
| 极端值 | 几乎不存在 | 频繁出现 |
| 例子 | 身高 | 收入 |

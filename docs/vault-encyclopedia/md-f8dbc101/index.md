# 逆向思维断言

## 定义
蒙田怀疑论在投资场景的物化应用：当市场形成唯一笃定的一致预期时，强制执行逆向思维审计，用客观概率分布对撞群体情绪。

## 核心机制

**触发条件：**
- 市场出现非理性概念爆炒（如 FOMO 驱动的单边行情）
- 权威机构给出绝对化预测（"必涨" / "必跌"）
- 自身持仓产生强烈的恐惧或贪婪情绪

**执行协议：**
1. 识别当前市场的一致预期叙事
2. 用 Tushare/Pandas 调出历史相似场景的胜率分位数
3. 若胜率 < 60%，将一致预期信息权重强制设为 50%
4. 列出该叙事不成立的 3 种可能路径

**边界条件：**
- 逆向思维 ≠ 永远反向押注
- "依照规则生活"——行动上遵循资产配置纪律
- "依照理性思考"——认知上拒绝任何绝对看多/看空

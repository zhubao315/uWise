# 以当下能力训练，而非目标训练

## 📌 核心定义

> 训练强度应基于当前实际能力(用近期比赛成绩确定VDOT)，而非期望达到的目标成绩。按目标训练必然导致过度训练或受伤。

## 🎯 关键要点

- 训练强度应基于当前实际能力(用近期比赛成绩确定VDOT)，而非期望达到的目标成绩。按目标训练必然导致过度训练或受伤。

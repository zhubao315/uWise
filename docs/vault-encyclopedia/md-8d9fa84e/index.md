# 投资的熵增现象

## 📌 核心定义

> 投资组合如同封闭系统，若不主动管理，必然走向混乱和贬值——这就是投资中的熵增定律。

## 🎯 关键要点

- **自然贬值**：资产不管理就会自然贬值（通胀、技术迭代、竞争）
- **信息熵增**：市场信息越来越多，噪音越来越大，决策越来越难
- **组合熵增**：投资组合不调整就会偏离最优配置
- **反熵增**：通过主动管理、持续学习、定期再平衡来对抗熵增

### 实际应用

每季度执行一次组合再平衡，将偏离目标权重的资产类别调整回预设比例，以消除因市场波动导致的配置漂移。建立年度资产检视机制，剔除受技术迭代或竞争加剧影响而基本面恶化的标的，并重新评估信息噪音对决策的干扰程度，通过主动管理输入负熵维持组合秩序。

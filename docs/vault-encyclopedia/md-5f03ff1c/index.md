# 以治驭术

## 📌 核心定义

> 源自中国传统管理智慧的"道法术"三级框架：道是根本原则和价值观，法是制度规则和流程体系，术是具体技巧和操作手段。赵玉平强调管理必须"以道驭术"——用根本原则驾驭具体方法，避免陷入只讲究技巧而迷失方向的"有术无道"困境。

## 🎯 关键要点

- **道为根**：组织的使命愿景和核心价值观，是最底层的第一性原理
- **法为干**：制度和流程将"道"转化为可执行的规则体系
- **术为叶**：具体的管理技巧和操作手段，必须服务于"道"和"法"

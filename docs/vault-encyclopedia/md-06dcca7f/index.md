# 终身成长方法论

## 📌 核心定义

> 源自 《终身成长》-卡罗尔·德韦克 的核心理念：人的基本能力可以通过努力来培养。

## 🎯 关键要点

- **成长型思维** vs 固定型思维：相信能力可发展，而非天生注定
- **过程导向**：关注学习过程而非结果评价
- **拥抱挑战**：将困难视为成长机会而非威胁
- **从批评中学习**：反馈是进步的燃料

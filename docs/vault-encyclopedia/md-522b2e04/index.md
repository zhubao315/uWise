# 在线思维

> 区分「在线/离线」是数字时代最底层的分界线。数据产生的瞬间就被计算，而非攒批处理。

## 核心要点

- **原理**：在线不是"连上网"，而是一种生存状态——数据实时流动、计算实时发生
- **方法**：审视业务流程，识别哪些环节仍停留在"离线思维"（攒批处理），哪些已实现"在线思维"（实时流式）
- **案例**：阿里云"飞天"系统——从设计之初就是在线架构，数据产生即被调度计算

## 在线 vs 离线

| 维度 | 离线思维 | 在线思维 |
|------|----------|----------|
| 数据处理 | 攒一批再处理 | 产生即处理 |
| 决策方式 | 历史数据分析 | 实时数据驱动 |
| 系统架构 | 批处理管道 | 流式计算 |
| 商业模式 | IT 支撑部门 | 业务核心引擎 |

## 跨领域应用

- 架构师：设计系统时区分批处理架构和实时流式架构，前者是离线思维产物，后者才是在线思维
- 投资人：评估公司是否真正数字化，不看有没有数据系统，而看数据能否实时驱动决策
- 学习者：学习过程中的"在线思维"——实时反馈（做题即知对错）比攒批复习（期末突击）更有效

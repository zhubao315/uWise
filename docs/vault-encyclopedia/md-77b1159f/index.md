# 人类误判心理学

## 📌 核心定义

> 查理·芒格原创的心理学框架，识别出 25 种系统性心理倾向，揭示理性人在哪些场景下会集体走向非理性。

## 🎯 关键要点

- 激励类：奖励/惩罚超级反应倾向——驱动行为的底层元
- 认知保守类：避免怀疑倾向、避免不一致性倾向——匆忙做决定、拒绝认错
- 社会类：社会认同倾向、权威错误影响——盲目随大流、盲信专家
- 损失类：被剥夺超级反应倾向——损失厌恶，引发疯狂反扑

## 📖 详细说明

### 概念解释
查理·芒格原创的心理学框架，识别出 25 种系统性心理倾向，揭示理性人在哪些场景下会集体走向非理性。
人类的理性是有边界且脆弱的。大脑在进化中固化了大量"认知快捷键"（启发式策略），在现代高维金融与复杂社会中，这些快捷键往往沦为致命的误判。


### 实际应用

在投资决策前，主动对照“激励超级反应”与“社会认同”倾向进行自检，警惕因追求短期回报或盲目跟随市场热点而做出的非理性交易；在日常沟通与管理中，利用“避免不一致性倾向”识别对方拒绝认错的防御机制，通过引入第三方视角或重构问题框架来打破僵局，从而提升决策质量。

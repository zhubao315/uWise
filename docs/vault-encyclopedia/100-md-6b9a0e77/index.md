# 100小时时间审计法

## 📌 核心定义

> 在你抱怨"时间不够"之前，先证明你知道自己的时间去了哪里。

## 🎯 关键要点

- 第一次审计：通常会发现深度工作占比远低于预期（多数人<25%）
- 持续审计：记录行为本身就会改变行为（霍桑效应），深度工作占比自然提升
- 长期效果：建立起对时间的精确感知力，不需要持续记录也能高效管理时间

## 📖 详细说明

### 概念解释
在你抱怨"时间不够"之前，先证明你知道自己的时间去了哪里。
柳比歇夫56年的时间记录揭示了一个残酷真相：**人对自身时间分配的感知误差高达50%以上**。你以为自己"一直在工作"，但数据会告诉你，大量时间被无意识地浪费在上下文切换、无效社交和信息焦虑中。

**100小时时间审计法**是将柳比歇夫方法现代化的最小可行实验：用连续一周（约100小时清醒时间）的精确记录，揭开你的时间黑洞。

### 实际应用

### 第一步：准备（5分钟）
1. 选择一个记录工具（Toggl/纸笔/备忘录/手机计时器）
2. 将活动分为三类：
   - 🔴 **第一类**：创造性深度工作（写代码、写作、思考战略、学习新技能）
   - 🟡 **第二类**：辅助性工作（邮件、会议、整理、行政事务）
   - ⚪ **第三类**：生活杂事（吃饭、通勤、刷手机、闲聊）

### 第二步：记录（持续7天）
- 每次切换活动时记录：**活动名 + 开始时间 + 结束时间**
- 关键原则：**只记事实，不记感受**（不写"今天效率很低"，写"14:00-15:30 刷微博"）
- 碎片时间也要记录（等车10分钟、排队5分钟）

### 第三步：审计（第8天，30分钟）
1. 汇总7天数据，计算：
   - 第一类工作总时长 / 168小时 = **深度工作占比**
   - 碎片时间总时长
   - 最大的3个时间黑洞
2. 画出时间分配饼图
3. 诚实面对数据

### 第四步：设计改进实验
- 从最大的时间黑洞中选1个
- 设计一个7天的改进实验
- 下周再做一次100小时审计，对比数据

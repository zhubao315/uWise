## 📖 详细说明

### 概念解释
"知足者富。" ——《道德经》第33章
"祸莫大于不知足，咎莫大于欲得。" ——《道德经》第46章
"知足者富"——真正的富足不是"拥有更多"，而是"满足于已有的"。四个字拆穿了消费主义的全部幻觉。

"不知足"是最大的灾祸来源——战争、经济危机、环境破坏，根源都是"不知足"。

# 费曼学习法

## 📌 核心定义

> 费曼学习法的核心理念：**通过教授他人来验证自己是否真正理解**。理查德·费曼的名言——"如果你不能用简单的语言解释，说明你没有真正理解"——揭示了学习的终极检验标准不是考试分数，而是能否用最朴素的语言让外行人听懂。

这不是一种记忆技巧，而是一种**认知校验机制**。它强迫学习者从"自以为懂了"的幻觉中走出来，暴露知识结构中的模糊地带和逻辑漏洞。

## 🎯 关键要点

- **四个步骤**：选择概念 → 用简单语言教别人 → 发现卡壳的地方 → 回去重新学习 → 再次尝试解释
- **卡壳是关键信号**：如果你在解释时需要用术语、比喻含糊带过、或说"总之就是这样"，说明你在这个点上并未真正理解
- **简单不等于肤浅**：费曼能把量子电动力学讲得让本科生听懂，这不是简化，而是穿透了复杂性之后抵达的本质
- **对抗"熟悉度幻觉"**：反复阅读会产生"我懂了"的错觉，但只有输出才能检验输入的有效性
- **费曼本人的实践**：他在巴西教学时发现学生能背诵所有公式却完全不理解物理意义，由此提出"教育的全部目的就是训练人们不理解东西时也能说出答案"的讽刺

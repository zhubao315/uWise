# 视觉重心与构图平衡

构图不是规则集——它是画面中各元素的**重量分配**。每个元素（亮度、色彩、纹理、人脸、文字）都有视觉重量，摄影构图的任务是安排这些重量达到动态平衡。

## 影响视觉重量的因素

| 因素 | 重量感大 | 重量感小 |
|------|---------|---------|
| 亮度 | 高光区域 | 暗部区域 |
| 色彩 | 红色、饱和色 | 蓝色、低饱和色 |
| 元素 | 人脸、文字 | 空白、纹理 |
| 位置 | 边缘（张力大） | 中心（稳定） |
| 清晰度 | 清晰对焦区域 | 虚化区域 |

## 常见平衡策略

- **对称平衡**：左右镜像，庄重正式——适合建筑、倒影
- **非对称平衡**：左侧一个大元素 ↔ 右侧两个小元素，动态而有层次
- **色彩平衡**：一块暖色 ↔ 一大片冷色（互补色平衡）
- **负空间平衡**：主体偏向一侧，大面积留白制造呼吸感

## 三分法不是法则，是起点

三分法把画面切为九宫格，把主体放在交叉点上。这是最简单的平衡入门工具，但不是最优解——真正出色的构图往往恰好违背三分法（中心对称、边缘构图、极简留白）。

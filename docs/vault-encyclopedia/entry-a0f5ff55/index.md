# 经验晶体 个人也有文明周期成功后必须反骄奢复盘

## 📌 核心定义

> 个人成长遵循与文明兴衰相同的"挑战→应战→成功→骄奢→腐化→衰亡"周期律。取得阶段性成功后，人最容易陷入舒适区，停止学习，放纵欲望，最终能力退化、认知僵化。**突破的关键是在每次成功后，主动设置"反骄奢复盘期"，而非进入享乐模式**。

## 🎯 关键要点

- 职业晋升后：不沉浸在喜悦中，立即思考下一个能级需要什么新能力
- 创业成功后：避免"创始人膨胀"，保持对市场变化的敏感度
- 投资获利后：不因短期收益而放松风控纪律，警惕"这次不一样"的幻觉
- 个人项目完成后：总结经验教训，将知识沉淀为可复用的方法论

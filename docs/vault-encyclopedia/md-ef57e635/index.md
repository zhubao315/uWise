# 性善论与性恶论

## 📌 核心定义

> **性善论**（孟子）：人性本善，人天生具有"四端"——恻隐之心（仁之端）、羞恶之心（义之端）、辞让之心（礼之端）、是非之心（智之端）。善是本性，恶是后天环境蒙蔽。

**性恶论**（荀子）：人性本恶，人的自然欲望（好利、疾恶、耳目之欲）会导致争夺和混乱。善是后天"化性起伪"（通过礼义教化改造本性）的结果。

## 🎯 关键要点

- **性善论**（孟子）：人性本善，人天生具有"四端"——恻隐之心（仁之端）、羞恶之心（义之端）、辞让之心（礼之端）、是非之心（智之端）。善是本性，恶是后天环境蒙蔽。
- **性恶论**（荀子）：人性本恶，人的自然欲望（好利、疾恶、耳目之欲）会导致争夺和混乱。善是后天"化性起伪"（通过礼义教化改造本性）的结果。
- 孟子的"性善"不是说人不会做恶，而是说人有向善的潜能
- 荀子的"性恶"不是说人不能为善，而是说善需要后天努力
- 两者殊途同归：都强调修养和教化的重要性
- 告子主张"性无善无不善"，是第三种立场

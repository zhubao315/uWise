# 止损的哲学

> 在投资中何时认错离场的智慧——止损不是认输，是保存实力。

## 止损逻辑

| 逻辑 | 说明 |
|------|------|
| **保存本金** | 亏 50% 需涨 100% 才回本 |
| **机会成本** | 死扛的机会成本 > 止损代价 |
| **情绪管理** | 避免越亏越焦虑的恶性循环 |

## 止损方法

- **固定比例**：跌破买入价 X% 止损
- **技术位**：跌破关键支撑位
- **基本面**：投资逻辑被证伪
- **时间止损**：持有 N 个月无起色

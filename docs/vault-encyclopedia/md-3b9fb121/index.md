# 主人道德与奴隶道德

## 📌 核心定义

> 尼采在《论道德的谱系》中区分了两种根本对立的道德类型：主人道德以自我肯定为核心——"我做的是好的，因此我是好的"；奴隶道德以否定他者为核心——"你做的事是坏的，因此你是坏的"。尼采认为基督教是奴隶道德的最高形式，用"谦卑""怜悯""平等"取代了古典世界的贵族的自我肯定精神。

## 🎯 关键要点

- **主人道德**：自我肯定、积极创造，"好/坏"的区分源于自身
- **奴隶道德**：否定他者、怨恨驱动，"善/恶"的区分源于对他者的仇视
- **历史反转**：基督教以奴隶道德征服了主人道德，重新估价一切价值

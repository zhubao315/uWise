# 控制错觉

## 📌 核心定义

> 控制错觉：我们倾向于相信自己能够控制或影响某些东西，就算这种东西客观上无法被控制或被影响。

## 🎯 关键要点

- 控制错觉：我们倾向于相信自己能够控制或影响某些东西，就算这种东西客观上无法被控制或被影响。
- 比如心理学实验：有个安慰剂按钮，我们就更能忍受噪音，因为我们以为可以通过按钮控制噪音减小，其实完全没用。
- 这告诫我们，要将注意力和精力，放在真正能被我们控制的事情上，尽人事听天命。

# 自动思维

## 📌 核心定义

> 自动思维是一个重要的知识概念。

## 🎯 关键要点

- 自动思维是无意识的：你可能意识不到自己在想什么。
- 自动思维影响情绪：不是事件导致情绪，而是对事件的解释导致情绪。
- 自动思维可以被识别和挑战：通过CBT技术可以识别和改变自动思维。
- 识别自动思维：觉察"我此刻在想什么？"
- 评估证据：支持这个想法的证据是什么？反对的证据是什么？

## 📖 详细说明

### 概念解释
来源：《认知行为疗法》（贝克）
**自动思维**是大脑对事件的自动解释——它发生得很快，我们通常意识不到。

**例子**：领导没回你消息 → 自动思维："他对我有意见" → 情绪：焦虑。
**实际**：领导可能只是在忙。


### 实际应用

- **识别自动思维**：觉察"我此刻在想什么？"
- **评估证据**：支持这个想法的证据是什么？反对的证据是什么？
- **生成替代想法**：有没有更平衡的解释？

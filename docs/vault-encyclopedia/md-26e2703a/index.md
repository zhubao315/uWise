# 身份先于行为——从「尝试跑步」到「我是跑者」

## 📌 核心定义

> 宾利的洞察：当一个人开始说"我是一个跑者"而不是"我在尝试跑步"时，行为改变才真正内化。身份认同的转变是习惯养成的关键拐点。

## 🎯 关键要点

- 宾利的洞察：当一个人开始说"我是一个跑者"而不是"我在尝试跑步"时，行为改变才真正内化。身份认同的转变是习惯养成的关键拐点。

# CPO共封装光学

> Co-Packaged Optics——将光学组件直接封装到交换芯片封装体内的技术，解决 AI 数据中心带宽瓶颈。

## 核心价值

| 问题 | CPO 方案 |
|------|---------|
| 可插拔光模块功耗高 | 光学组件紧贴芯片，减少电信号传输距离 |
| 带宽密度不足 | 更多光通道并行，支持 51.2T+ 交换容量 |
| 散热挑战 | 集成化设计优化热管理 |

## 技术路线

```
传统：芯片 → PCB → 连接器 → 可插拔光模块 → 光纤
CPO：  芯片 ← 光学引擎（直接封装）→ 光纤
```

## 产业链参与者

- **芯片**：Broadcom（Memory 总线 CPO）、NVIDIA
- **光学**：Intel、Ranovus、Ayar Labs
- **封装**：日月光、长电科技

## 时间线

- 2024-2025：样品验证
- 2026-2027：规模部署

# 家族相似性

## 📌 核心定义

> 维特根斯坦在《哲学研究》中提出的概念：语言中的范畴并非靠"共同本质"定义，而是靠一系列重叠交叉的相似性网络来维持。如同一个家族——成员A与B鼻子像，B与C眼睛像，C与D性格像——不存在所有成员共享的单一特征。以"游戏"为例：棋类游戏、球类游戏、儿童游戏之间没有共同本质，只有一张复杂的相似性之网。

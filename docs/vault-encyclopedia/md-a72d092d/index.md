# 精益创业

## 📌 核心定义

> 精益创业（Lean Startup）是由埃里克·莱斯提出的创业方法论，核心是通过"构建-度量-学习"的快速循环来验证商业假设，减少浪费。

## 🎯 关键要点

- MVP（最小可行产品）：用最少资源构建可测试核心假设的产品
- 构建-度量-学习循环：快速构建→度量用户反馈→学习并调整方向
- 验证式学习（Validated Learning）：用数据验证假设，而非凭直觉
- 转型（Pivot）：当假设被证伪时，果断改变方向

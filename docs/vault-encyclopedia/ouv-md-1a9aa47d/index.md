# 世界遗产的OUV标准

## 📌 核心定义

> OUV（Outstanding Universal Value，杰出普遍价值）是联合国教科文组织《世界遗产公约》中评估一处文化遗产是否应被列入《世界遗产名录》的核心标准框架。OUV意味着一处遗产具有超越国家界限的、对全人类 present 和 future generations 都具有重要意义的文化或自然价值。

OUV的评估标准包含十条（文化遗产六条、自然遗产四条），候选遗产需满足至少一条方可列入。文化遗产的六条标准包括：(i) 代表人类创造性天才的杰作；(ii) 展示人类价值观的重要交流；(iii) 见证已消失文明的独特或稀有证据；(iv) 代表一种建筑类型或景观的杰出范例；(v) 代表传统人类居住方式的杰出范例；(vi) 与具有突出普遍意义的事件、传统、信仰直接相关。

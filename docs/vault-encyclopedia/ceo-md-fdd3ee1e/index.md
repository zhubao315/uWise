# CEO决策框架

> 企业最高决策者的系统化决策方法论——在信息不完备时做出高质量、可追溯的战略决策。

## 四维评估模型

| 维度 | 核心问题 |
|------|---------|
| **战略对齐** | 这个决策是否符合公司 3-5 年愿景？ |
| **信息完备性** | 关键假设是否已验证？数据缺口在哪？ |
| **风险承受** | 最坏情况是否可承受？有无回滚方案？ |
| **执行可行性** | 团队能力是否匹配？资源是否到位？ |

## 决策矩阵

```
高确定性 + 高影响 → 快速决策，立即执行
高确定性 + 低影响 → 委托执行，不必亲自管
低确定性 + 高影响 → 小步验证，降低不确定性后再决
低确定性 + 低影响 → 忽略或最小化投入
```

## CEO 特有的决策陷阱

- **信息过载**：等待「完美信息」导致错失窗口
- **锚定效应**：被第一个方案锚定，忽略替代选项
- **沉没成本**：因为已投入而继续错误方向
- **群体思维**：团队一致同意时反而要警惕

## 实践建议

1. 重大决策设「决策日志」，记录假设和推理过程
2. 定期「预验尸」：假设项目已失败，倒推可能原因
3. 建立「反对派」角色，专门挑战主流意见

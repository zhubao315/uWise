# 记忆的三阶段模型

## 📌 核心定义

> 来源：《心理学与生活》（津巴多）《认知心理学》（索尔所）

## 🎯 关键要点

- 艾宾浩斯遗忘曲线：学习后遗忘速度先快后慢——及时复习是最有效的记忆策略。
- 记忆是重新建构：不是"录像机"，而是每次都在"重新建构"。
- 多感官编码：看+听+写比只看更有效。
- 间隔复习：学完后1天、3天、7天、30天各复习一次。
- 多感官编码：同时用眼看、耳听、手写来学习。

## 💡 个人理解

我的理解：记忆是编码、储存、提取的三段流水线，每一段都可能掉链子——遗忘不全是没记住，更多是没编码好或提取线索失效，所以复习要练提取而不是重读。

# 逻辑谬误

## 📌 核心定义

> 来源：《思考的艺术》（拉吉罗）《对伪心理学说不》（斯坦诺维奇）

- 逻辑谬误无处不在：广告、政治宣传、日常对话中都充满了逻辑谬误。
- 识别谬误是批判性思维的核心：了解这些谬误是识别它们的第一步。
- 不要被"听起来有道理"迷惑：一个论证听起来有道理，不代表它逻辑上成立。
- 评估论证：检查论证中是否有逻辑谬误。
- 避免使用谬误：在自己的论证中避免使用逻辑谬误。

## 📖 详细说明

### 概念解释
来源：《思考的艺术》（拉吉罗）《对伪心理学说不》（斯坦诺维奇）
**逻辑谬误**是论证中的逻辑错误——让论证看起来有道理，但实际上不成立。

| 谬误 | 含义 | 例子 |
|------|------|------|
| **人身攻击** | 攻击人而不是论证 | "你不是专家，你的观点不值一提" |
| **滑坡谬误** | 假设一个事件会导致极端后果 | "如果允许A，就会导致Z" |
| **虚假二分法** | 只给两个选项 | "你要么支持我们，要么反对我们" |
| **诉诸权威** | 用权威代替证据 | "专家说的，所以一定对" |
| **诉诸情感** | 用情感代替逻辑 | "想想孩子们！" |
| **稻草人谬误** | 歪曲对方观点 | "你居然支持XXX！" |


### 实际应用

- **评估论证**：检查论证中是否有逻辑谬误。
- **避免使用谬误**：在自己的论证中避免使用逻辑谬误。
- **识别操控**：广告和政治宣传经常使用逻辑谬误——了解它们可以更好地防御。

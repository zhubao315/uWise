# 游戏叙事设计

> 通过游戏机制、环境、角色讲述故事的设计方法——区别于传统线性叙事。

## 叙事类型

| 类型 | 特点 |
|------|------|
| **线性叙事** | 固定剧情走向 |
| **分支叙事** | 玩家选择影响剧情 |
| **涌现叙事** | 玩家行为产生故事 |
| **环境叙事** | 场景细节讲述故事 |

## 设计原则

1. **展示而非讲述**：用游戏体验传递信息
2. **玩家主动性**：让玩家参与故事构建
3. **节奏控制**：紧张与放松交替
4. **一致性**：世界观/角色行为逻辑统一

# 橡木桶陈酿

## 📌 核心定义

> 橡木桶陈酿通过添氧、萃取单宁和赋予香草烘烤香气三个机制，深刻影响葡萄酒的风格和品质。

## 🎯 关键要点

- 橡木桶陈酿通过添氧、萃取单宁和赋予香草烘烤香气三个机制，深刻影响葡萄酒的风格和品质。
- 橡木桶陈酿是葡萄酒酿造中最古老也最昂贵的工艺之一。一个225升的法国橡木桶价格可达数千欧元，使用寿命仅3-5年。酿酒师选择橡木桶陈酿，是因为它同时提供了三个维度的改变。
- **第一，添氧（Micro-oxygenation）。** 橡木是半透性材质，微量氧气通过桶壁缓慢渗入酒中。这种极其微量的氧气接触促进了单宁的聚合反应——小分子单宁结合成大分子，口感从粗糙变得柔顺。同时，氧气还稳定了酒的颜色（花色苷与单宁的聚合物更不易褪色），并发展出更复杂的三类香气。这个过程在不锈钢罐中无法自然发生。
- **第二，萃取单宁。** 橡木本身含有丰富的单宁（主要是鞣花单宁），在陈酿过程中缓慢释放到酒中，增加了酒的结构感和陈年潜力。法国橡木（阿列省、特隆赛等）的单宁细腻优雅，美国橡木的单宁较粗犷但甜香更突出。
- **第三，赋予风味化合物。** 橡木在烘烤成桶的过程中会产生大量的风味化合物——香草醛（香草味）、内酯（椰子味）、呋喃类（焦糖和烘烤味）、丁香酚（丁香味）。烘烤程度越深，烟熏和咖啡的风味越浓。
- **关键变量：** 新桶vs旧桶（新桶风味贡献大，旧桶几乎只提供添氧效果）、法国橡木vs美国橡木（前者细腻后者奔放）、烘烤程度（轻/中/重）、陈酿时间（6个月到36个月不等）。
- 并非所有酒都适合橡木桶陈酿——清新果味型的酒（如莫斯卡托、长相思）用橡木桶反而会掩盖品种特性。

### 实际应用

酿酒师在酿造黑皮诺或赤霞珠等需要陈年潜力的红葡萄酒时，会选用法国新橡木桶进行12至24个月的陈酿，以利用微量氧气柔化单宁并赋予香草香气；而对于长相思等追求清新果味的白葡萄酒，则应严格避免使用新橡木桶，仅采用不锈钢罐或旧桶发酵储存，以防烘烤风味掩盖其原本的纯净特质。

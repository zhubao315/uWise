# 2-20收费模式

## 📌 核心定义

> 巴顿·比格斯（Barton Biggs）在《对冲基金风云录》中深入剖析的对冲基金行业标准收费结构：管理人收取管理资产规模的2%作为固定管理费（Management Fee），另加20%的投资利润作为业绩提成（Performance Fee）。这一模式在创造激励的同时，也产生了深刻的结构性矛盾。

## 🎯 关键要点

- **2%管理费**：无论基金盈亏，管理人每年按管理资产规模（AUM）收取2%的固定费用。对于10亿美元规模的基金，管理费收入为2000万美元，足以覆盖运营成本并产生利润。
- **20%业绩提成**：基金实现正收益后，管理人提取利润的20%作为业绩报酬。这是管理人收入的主要来源，也是激励优秀投资表现的核心机制。
- **高水位线条款（High Water Mark）**：基金净值必须超过前期高点后才能再次收取业绩提成，防止管理人在亏损后靠反弹重复收费。
- **规模优先 vs 回报优先**：管理费与规模挂钩，管理人有动机做大AUM而非优化回报。规模增长直接增加管理费收入，但可能稀释投资回报。
- **风险偏好扭曲**：20%的业绩提成使管理人倾向于承担高风险——赢了拿20%，亏了不退钱（有限合伙制下）。这创造了不对称的风险收益激励。

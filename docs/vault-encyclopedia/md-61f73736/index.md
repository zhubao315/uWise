# 自我觉察

## 📌 核心定义

> 来源：《情商》（戈尔曼）《蛤蟆先生去看心理医生》（戴博德）

## 🎯 关键要点

- 自我觉察是情商的基石：如果你不知道自己在感受什么，就无法管理它。
- 自我觉察是改变的第一步：觉察到自己的模式，才能改变它。
- 自我觉察可以训练：通过正念、情绪日记、反思等方式可以提高自我觉察。
- 正念冥想：每天10-15分钟——觉察自己的想法和感受。
- 情绪日记：每天记录自己的情绪变化——提高情绪觉察能力。

## 📖 详细说明

### 概念解释
来源：《情商》（戈尔曼）《蛤蟆先生去看心理医生》（戴博德）
**自我觉察**是识别自己的情绪、想法和行为模式的能力——是情商的基石，也是心理成长的基础。


### 实际应用

- **正念冥想**：每天10-15分钟——觉察自己的想法和感受。
- **情绪日记**：每天记录自己的情绪变化——提高情绪觉察能力。
- **定期反思**：问自己——"我此刻在想什么？我的感受是什么？我的行为模式是什么？"

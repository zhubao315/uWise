# 难者不会，会者不难

## 📌 核心定义

> 某个东西是一个难点，如果我觉得他难，那么我就不会。如果我会了，就会觉得这个东西其实很简单。

## 🎯 关键要点

- 某个东西是一个难点，如果我觉得他难，那么我就不会。如果我会了，就会觉得这个东西其实很简单。

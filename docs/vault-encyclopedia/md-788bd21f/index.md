# 意识流

## 📌 核心定义

> 20世纪初现代主义文学的核心技法，被福克纳、普鲁斯特、伍尔夫等共享使用：以人物内心联想的流动结构取代传统的情节推进。不按客观时间线叙述，而是按意识的自然跳跃——一个感官印象触发一段回忆，一段回忆又勾起一种情绪——自由行进。

## 🎯 关键要点

- **联想的逻辑**：意识流动有自己内在的连结方式，不再是因果关系，而是情感、意象、声音的共振
- **内外的融合**：外部事件通过人物的感知过滤后才进入叙事，内外世界的边界被取消
- **时间的消解**：意识流中的过去、现在、未来共存于同一文本表面，不服从时钟的线性秩序

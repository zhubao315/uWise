# 周期定位比预测更重要

## 📌 核心定义

> "周期定位比预测更重要"是霍华德·马克斯在《周期》中的核心洞察，指投资者不需要（也无法）准确预测周期转折点的精确时间和幅度，但可以通过观察当前处于周期的哪个位置，来调整自己的风险敞口。马克斯认为，预测是"知道会发生什么"，定位是"知道现在在哪里"——前者极难，后者可行。这一洞察的深刻之处在于：你不需要知道冬天何时结束，但如果你知道现在是冬天，就应该穿棉衣。

## 🎯 关键要点

- **预测的徒劳性**：没有人能持续准确预测市场走向。经济学家的预测准确率不比掷硬币好多少。依赖预测做投资决策，长期来看必然失败
- **定位的可行性**：虽然无法预测转折点，但可以通过多种信号判断当前位置——估值水平、信贷标准、市场情绪、杠杆率等指标组合起来，能给出相对可靠的"温度计"
- **概率思维**：定位的意义不在于"确定"当前处于什么阶段，而在于"调整概率"——如果处于周期后期，下跌的概率大于上涨，就应该降低风险
- **行动的差异**：预测要求精确（"明天会跌"），定位只需要方向（"现在偏高估"）。后者更容易做到，也更有投资价值

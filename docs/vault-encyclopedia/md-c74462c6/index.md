# 皮亚杰认知发展阶段

## 📌 核心定义

> 来源：《发展心理学》（费尔德曼）《婴儿、儿童和青少年》（伯克）

## 🎯 关键要点

- 发展的阶段性：每个阶段有其独特的能力——不能跳过。
- 建构性：儿童通过与环境的互动主动建构知识。
- 个体差异：不同儿童到达各阶段的时间不同。
- 理解孩子：前运算期的孩子"不讲道理"不是"不听话"，而是发展阶段的限制。
- 教育设计：教学内容应该与孩子的认知发展阶段匹配。

## 📖 详细说明

### 概念解释
来源：《发展心理学》（费尔德曼）《婴儿、儿童和青少年》（伯克）
皮亚杰提出认知发展有四个阶段：

| 阶段 | 年龄 | 核心能力 | 特征 |
|------|------|----------|------|
| **感知运动期** | 0-2岁 | 通过感官和动作认识世界 | 客体永久性 |
| **前运算期** | 2-7岁 | 符号思维，但缺乏逻辑 | 自我中心 |
| **具体运算期** | 7-11岁 | 逻辑思维，但限于具体事物 | 守恒概念 |
| **形式运算期** | 11岁+ | 抽象思维、假设推理 | 假设演绎 |


### 实际应用

- **理解孩子**：前运算期的孩子"不讲道理"不是"不听话"，而是发展阶段的限制。
- **教育设计**：教学内容应该与孩子的认知发展阶段匹配。
- **耐心等待**：不要强迫孩子理解超出其发展阶段的内容。

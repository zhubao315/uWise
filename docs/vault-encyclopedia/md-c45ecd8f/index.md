# 太极思维

## 📌 核心定义

> 源自易经的思维范式，认为万事万物都由阴阳两极构成且相互转化，不存在绝对的对错黑白。曾仕强将其引入管理领域，主张管理者不执着于寻找"唯一正确答案"，而是在动态变化中寻求当时、当位、当境的最合理方案。

## 🎯 关键要点

- **阴阳互涵**：任何事物都包含对立统一的两面，阴中有阳、阳中有阴
- **动态转化**：事物状态不是固定的，吉凶祸福可以相互转化，关键在于把握时机
- **不执绝对**：放弃"非对即错"的二元思维，在矛盾中寻找动态平衡点

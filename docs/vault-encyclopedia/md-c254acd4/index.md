# 旁观者效应

## 📌 核心定义

> 来源：《心理学与生活》（津巴多）《改变心理学的40项研究》（霍克）

## 🎯 关键要点

- 责任分散：当有很多人在场时，每个人都觉得"别人会帮忙"——结果没人帮忙。
- 从众：看到别人不帮忙，自己也不帮忙——"可能情况没那么严重"。
- 多元无知：每个人都在看别人的反应来判断情况——结果所有人都在观望。
- 紧急情况：指定具体的人提供帮助——"你，穿红衣服的，请拨打120！"
- 团队合作：明确指定责任人——责任分散时没人会主动行动。

# 行为先于态度

## 📌 核心定义

> **"态度紧随行为。"** —— 戴维·迈尔斯《社会心理学》

## 🎯 关键要点

- **"态度紧随行为。"** —— 戴维·迈尔斯《社会心理学》
- 行为改变 → 认知失调 → 态度自动调整
- **不是：** 有动力 → 去行动 → 获得结果
- **而是：** 先行动 → 产生动力 → 态度改变 → 持续行动
- 1. **认知失调：** 当行为与态度不一致时，大脑会自动调整态度来匹配行为（"我既然做了，说明我应该是喜欢的"）
- 2. **登门槛效应：** 答应小请求后，态度改变，更愿意答应大请求
- 3. **斯坦福监狱实验：** 穿上制服（行为改变）后，普通人的自我认知和态度彻底改变

# 伤病是身体的信号，不是需要克服的障碍

> 伤病不是敌人，是身体的预警系统——忽视信号只会让问题恶化，理解信号才能根本解决。

## 核心理念

传统思维：「疼就忍，继续练」→ 结构性损伤
新思维：「疼是信号，找到原因」→ 根因修复

## 伤病信号分类

| 信号类型 | 含义 | 处理方式 |
|---------|------|---------|
| **肌肉酸痛（DOMS）** | 正常训练反应 | 恢复即可 |
| **关节锐痛** | 可能有结构性问题 | 立即停止，就医 |
| **持续隐痛** | 过度使用/炎症 | 降低强度，排查原因 |
| **代偿性疼痛** | 其他部位过度补偿 | 矫正动作模式 |

## 常见误区

- ❌ 「痛就是弱，练强就不痛了」→ 痛是信号，不是原因
- ❌ 「休息是浪费时间」→ 恢复是训练的一部分
- ❌ 「止痛药能解决一切」→ 掩盖症状，延误治疗

## 实践建议

1. **疼痛日志**：记录疼痛位置、程度、触发动作
2. **专业评估**：持续 2 周以上的疼痛应就医
3. **预防优于治疗**：热身、拉伸、渐进负荷
4. **恢复训练**：伤后按「无痛范围」逐步恢复

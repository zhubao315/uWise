# 沟通即社会

## 📌 核心定义

> 卢曼的激进社会学命题：社会不是人的集合，而是沟通的网络。"沟通"不是人在说话，而是一个自组织的三合一操作——信息（说什么）、传达（怎么说）、理解（被接收）——三者同时成立才构成一次沟通。每一次沟通都触发下一次沟通，构成社会系统的持续运作。

## 🎯 关键要点

- **去人类中心**：不是"人在社会里"，而是"沟通在社会里"——人被置于社会系统的环境中，而非系统内部
- **沟通的三位一体**：信息、传达、理解三者缺一不可——没有理解的传达不是沟通，只是噪音
- **理论后果**：这意味着社会系统不能"对话"人的意识（心理系统），两个系统各自封闭运行，仅通过"结构耦合"互相刺激

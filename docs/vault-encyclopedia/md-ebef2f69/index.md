# 信贷周期模型

## 📌 核心定义

> 信贷周期模型（Credit Cycle Model）由霍华德·马克斯在《周期》中系统阐述，描述了信贷市场的周期性波动：信贷扩张→资产泡沫→信贷收缩→金融危机→信贷再扩张的循环。马克斯认为信贷周期是所有经济周期中最重要的驱动力——信贷的松紧直接决定了资产价格的涨跌和经济的繁荣衰退。这一模型的核心洞察是：周期的根源在于人性的贪婪与恐惧在信贷决策中的交替主导。

## 🎯 关键要点

- **扩张阶段**：经济向好→银行愿意放贷→企业容易融资→投资增加→经济更好→银行更愿意放贷。正反馈循环推动信贷不断扩张
- **泡沫阶段**：信贷标准持续下降，"这次不一样"的故事盛行。次贷危机前的零首付、无收入证明贷款就是典型案例
- **收缩阶段**：一笔大额违约触发恐慌→银行收紧信贷→企业融资困难→经济放缓→更多违约→银行更收紧。负反馈循环加速衰退
- **危机与重生**：信贷收缩到极端时，资产价格跌至远低于内在价值，为下一轮扩张创造了条件

### 实际应用

- 周期定位：观察信贷标准的变化（贷款利率、审批门槛、杠杆倍数）来判断当前处于周期的哪个阶段
- 逆向操作：在信贷极度收缩、无人敢放贷时加大配置；在信贷极度扩张、人人都能贷到款时收缩风险

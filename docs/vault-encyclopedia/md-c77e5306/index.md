# 自我中心思维

## 📌 核心定义

> 自我中心思维是批判性思维的最大障碍，因为你无法改进你看不见的东西。

## 🎯 关键要点

- 确认偏误：只关注支持自己观点的信息
- 可得性偏误：用容易想到的例子做判断
- 锚定效应：被第一个信息过度影响
- 从众效应：跟随大多数人的判断

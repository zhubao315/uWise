# 心即理

## 📌 核心定义

> "心即理也。天下又有心外之事、心外之理乎？" —— 王阳明

## 🎯 关键要点

- 心的本体就是天理：天理不在外部事物中，而在人心之中
- 对朱熹的批判：朱熹认为天理在外部事物中，需要"格物穷理"；王阳明认为这是"支离"的
- 实践意义：道德判断的最终依据不是外部规范，而是内心的良知

## 📖 详细说明

### 概念解释

### 实际应用

1. **反求诸己**：遇到问题先向内看，而不是向外找原因
2. **倾听良知**：在做决定时，倾听内心的声音
3. **相信自己**：每个人都有良知，都可以做出正确判断
4. **不假外求**：不需要向外寻求答案，答案在心中

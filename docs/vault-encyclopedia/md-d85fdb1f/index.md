# 永远不要连续两天不跑步

## 📌 核心定义

> 一天不跑是休息，两三天不跑就会失去状态。训练的连续性比单次强度更重要，保持节奏是长期进步的关键。

## 🎯 关键要点

- 一天不跑是休息，两三天不跑就会失去状态。训练的连续性比单次强度更重要，保持节奏是长期进步的关键。
- 即使状态不好也要出门慢跑10-15分钟;出差/旅行时找时间跑15-20分钟;把跑步视为像刷牙一样的日常习惯而非可选活动。

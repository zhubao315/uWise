# 跑者力量训练周期化模型

## 📌 核心定义

## 🎯 关键要点

- 跑者力量训练周期化模型将力量训练分为适应期(自重)、发展期(增加负荷)、转化期(跑步专项)、维持期(赛前减量)四个阶段，与跑步训练周期同步。

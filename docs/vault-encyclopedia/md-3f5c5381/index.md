# 品酒四步法

品酒四步法是葡萄酒品鉴的标准化流程：观色（观察酒液颜色、清澈度、挂杯）→ 闻香（识别一级香气果香、二级香气发酵香、三级香气陈年香）→ 品味（感受甜度、酸度、单宁、酒体）→ 回味（评估余味长度和复杂度）。

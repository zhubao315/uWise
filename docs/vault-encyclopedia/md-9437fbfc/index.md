# 责任归因切换法

## 📌 核心定义

> **当你从"谁该为此负责"切换到"我能做什么"时，你不是在认输，而是在拿回行动的主导权。**

## 🎯 关键要点

- **当你从"谁该为此负责"切换到"我能做什么"时，你不是在认输，而是在拿回行动的主导权。**
- 受害者模式 = 外部归因 → 等待 → 无力感 → 更多抱怨
- 责任者模式 = 内部归因 → 行动 → 掌控感 → 更多行动
- **注意力决定现实**：你关注什么就会放大什么——关注外部阻碍，阻碍就会变大；关注自己能做的事，行动空间就会变大
- **控制圈理论**：只有在你控制范围内的事才值得投入精力，而你的行动永远在你的控制范围内
- **行动-情绪正循环**：行动 → 掌控感 → 积极情绪 → 更多行动，而抱怨 → 无力感 → 消极情绪 → 更多抱怨
- 😤 工作中遇到"不合理"的要求或变化时
- 😞 人际关系中感到"都是对方的问题"时

### 三步切换法

| 步骤 | 动作 | 示例 |
|------|------|------|
| **① 暂停外归因** | 当你想说"都是因为……"时，先停3秒 | "项目延期是因为需求老变……" → 暂停 |
| **② 问"我能做什么"** | 把问题重构成"在当前条件下，我的最优行动是？" | "在需求可能变的情况下，我能做什么减少影响？" |
| **③ 立即执行最小行动** | 不等完美方案，先做一个能做的小动作 | "今天先和PM确认接下来一周的需求冻结" |

### 为什么有效

1. **注意力决定现实**：你关注什么就会放大什么——关注外部阻碍，阻碍就会变大；关注自己能做的事，行动空间就会变大
2. **控制圈理论**：只有在你控制范围内的事才值得投入精力，而你的行动永远在你的控制范围内
3. **行动-情绪正循环**：行动 → 掌控感 → 积极情绪 → 更多行动，而抱怨 → 无力感 → 消极情绪 → 更多抱怨

### 每日责任审计三问

| 问题 | 目的 |
|------|------|
| 今天哪些事我推责给了别人或环境？ | 觉察外归因惯性 |
| 如果100%由我负责，我会怎么做？ | 激活内部归因 |
| 明天我可以主动承担的一件小事是什么？ | 从思考转向行动 |

### 反模式警告

| ❌ 错误做法 | ✅ 正确做法 |
|------------|------------|
| "都是领导/同事/市场的问题" | "在这些条件下，我能做什么" |
| 等环境变好了再行动 | 先行动让环境变好 |
| 认为"负责"就是"认错" | 负责是"拿回改变的权力" |
| 把所有责任都揽到自己身上 | 负责≠自责，而是聚焦于可控的行动 |

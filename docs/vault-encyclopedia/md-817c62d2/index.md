# 荒诞哲学

## 📌 核心定义

> 荒诞哲学是阿尔贝·加缪思想体系的核心概念。"荒诞"不是指世界是荒谬的或可笑的，而是指一种根本性的冲突：人类本能地渴望意义、秩序和目的，但世界本身并不提供这些。世界是沉默的、无目的的、不关心人类的。这种渴望与沉默之间的冲突，就是荒诞。

加缪的关键洞察是：面对荒诞，人有三种可能的回应。第一种是自杀——既然没有意义，那就结束生命。加缪拒绝这种选择，认为它是对荒诞的投降。第二种是"哲学自杀"——通过宗教或形而上学，虚构一个超越的意义来逃避荒诞。加缪也拒绝这种选择，认为它是自欺。第三种是反抗——接受荒诞的事实，但不放弃对意义的追求。在明知世界没有内在意义的情况下，仍然创造自己的意义、过自己的生活、爱自己的所爱。这才是真正的勇气。

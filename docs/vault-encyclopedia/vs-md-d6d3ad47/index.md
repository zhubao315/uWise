# 创造模式vs解决问题模式

## 📌 核心定义

> 创造者总是在塑造结果，解决问题的人总是在应对症状。

## 🎯 关键要点

- 问题导向：注意力集中在问题上，而不是结果上
- 改变症状：只是应对症状，不是改变根本结构
- 回到平衡：解决问题后，系统会回到原来的状态
- 个人成长：不要问"我有什么问题"，问"我想要成为什么样的人"
- 职业发展：不要问"我的工作有什么问题"，问"我想要什么样的职业"

## 📖 详细说明

### 概念解释
创造者总是在塑造结果，解决问题的人总是在应对症状。
| 维度 | 解决问题模式 | 创造模式 |
|------|------------|---------|
| 起点 | 问题（你不想要什么） | 结果（你想要什么） |
| 注意力 | 集中在问题上 | 集中在结果上 |
| 行动 | 应对症状 | 塑造结构 |
| 结果 | 回到原来的状态 | 创造新的状态 |
| 心态 | 被动、防御 | 主动、创造 |


### 实际应用

- **个人成长**：不要问"我有什么问题"，问"我想要成为什么样的人"
- **职业发展**：不要问"我的工作有什么问题"，问"我想要什么样的职业"
- **投资**：不要问"我的投资有什么问题"，问"我想要什么样的财务状况"

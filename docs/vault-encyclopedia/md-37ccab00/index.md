# 人力资本与金融资本再平衡

> 你最大的资产不是银行账户里的数字，而是你未来几十年赚钱的能力——把它纳入投资组合的考量，才能做出真正最优的资产配置。

## 核心要点

- **原理**：一个人的终身财富 = 当前金融资本 + 人力资本（未来收入折现值）。年轻时金融资本极小、人力资本极大；年老时人力资本耗尽、金融资本达到峰值。最优投资策略要求你在整个生命周期中保持总财富中股票的比例不变——这意味着年轻时必须用金融资产加杠杆来覆盖人力资本无杠杆的部分。
- **方法**：将人力资本视为类债券资产（稳定的工资收入近似于债券利息），计算你的"终身投资组合"中股票的占比。如果目标是50%，你年轻时的金融资产可能只有总财富的5%，意味着你需要用2:1杠杆才能让金融资本中的股票占比达到名义总财富的10%（5%×2=10%，仍远低于50%）。
- **案例**：25岁，存款2万，未来40年退休储蓄折现100万。如果最优股票比例为50%，应持有50万股票。用2:1杠杆可持有4万——虽然离50万还很远，但已是无杠杆时的2倍效果。

## 跨领域应用

- **架构师**：将"潜在技术债"视为系统中的"人力资本"——即使当前系统干净（金融资本），未来的修改需求（人力资本）必然会带来技术债。需要提前设计中长期可扩展性来"对冲"。
- **投资人**：评估一个人/公司的实际杠杆水平时，必须把收入稳定性（人力资本波动率）考虑进去——体制内人员可以承受更高金融杠杆，自由职业者则不行。
- **学习者**：年轻时学习新领域的成本低、回报期长（时间杠杆大），中年后应转为深度积累——这是知识版图的人力资本配置。
- **艺术家**：创作生涯中，前期大量尝试多种风格（人力资本最"激进"），后期聚焦成熟风格（人力资本"转化"为作品资产）。

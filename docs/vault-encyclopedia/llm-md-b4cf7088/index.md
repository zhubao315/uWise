# LLM概率生成模型

## 📌 核心定义

> 大语言模型（LLM）本质上是一个基于前文预测下一个 token 的概率分布模型。它不"理解"语言，不"思考"问题，而是根据给定的上下文序列，计算词汇表中每个 token 作为下一个词出现的概率，然后按照某种采样策略从中选择一个 token 输出。

## 🎯 关键要点

- BPE（Byte Pair Encoding）：GPT 系列使用，从字符级别开始，反复合并最高频的相邻对。
- WordPiece：BERT 使用，类似 BPE 但合并策略基于似然最大化。
- SentencePiece：LLaMA 等使用，支持无空格语言（如中文），直接在原始文本上训练。
- T → 0：分布趋向 one-hot，几乎总是选择概率最高的 token（确定性、保守、重复）。
- T = 1：保持原始训练得到的概率分布（标准行为）。

## 📖 详细说明

### 概念解释
大语言模型（LLM）本质上是一个基于前文预测下一个 token 的概率分布模型。它不"理解"语言，不"思考"问题，而是根据给定的上下文序列，计算词汇表中每个 token 作为下一个词出现的概率，然后按照某种采样策略从中选择一个 token 输出。
### 概率生成的本质

LLM 的核心数学表达：

```
P(token_t | token_1, token_2, ..., token_{t-1})
```

给定前文（prompt + 已生成的所有 token），模型输出词汇表上每个 token 的概率分布。例如输入"今天天气"，模型可能输出：

- "很" → 0.35
- "不错" → 0.20
- "真" → 0.12
- "预报" → 0.08
- ...（词汇表中数万个 token 各有概率）

这个概率分布来自模型在海量文本上的训练——它学习到了语言的统计规律：在"今天天气"之后，"很"这个词出现的频率最高。

### Token 化（Tokenization）

LLM 不直接处理文字，而是处理 token——文本被切分为子词单元：

- **BPE（Byte Pair Encoding）**：GPT 系列使用，从字符级别开始，反复合并最高频的相邻对。
- **WordPiece**：BERT 使用，类似 BPE 但合并策略基于似然最大化。
- **SentencePiece**：LLaMA 等使用，支持无空格语言（如中文），直接在原始文本上训练。

**关键特性**：
- 同一个词在不同上下文中可能被切分为不同的 token。
- 中文通常一个字占 1-2 个 token，英文一个词占 1-3 个 tok

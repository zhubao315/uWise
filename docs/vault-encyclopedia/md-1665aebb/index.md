# 基因与环境的交互作用

## 📌 核心定义

> 基因与环境的交互作用是一个重要的知识概念。

## 🎯 关键要点

- 基因影响环境：有某种基因倾向的人会主动寻求特定的环境。
- 环境影响基因表达：环境可以"打开"或"关闭"某些基因。
- 交互作用：基因×环境的交互作用比单独的基因或环境效应更重要。
- 不是"基因vs环境"：是"基因×环境"。
- 承认人性不等于为不公正辩护：理解人性是为了更好地应对它。

## 📖 详细说明

### 概念解释
来源：《白板》（平克）
基因和环境不是对立的，而是交互作用的：

- **基因影响环境**：有某种基因倾向的人会主动寻求特定的环境。
- **环境影响基因表达**：环境可以"打开"或"关闭"某些基因。
- **交互作用**：基因×环境的交互作用比单独的基因或环境效应更重要。


### 实际应用

- **理解个体差异**：接受个体差异是真实存在的——不是教育的失败。
- **避免极端思维**：不是"基因决定一切"，也不是"环境决定一切"。
- **教育启示**：教育应该适应个体差异——不是所有孩子都一样。

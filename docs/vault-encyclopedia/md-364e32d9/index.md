# 六种说服原理

## 📌 核心定义

> |------|------|------|

## 🎯 关键要点

- 自动化反应：这些原理利用了大脑的"自动化反应"——系统1的捷径。
- 可以被利用：营销、广告、政治宣传都在利用这些原理。
- 也可以被防御：了解这些原理后，可以更好地抵抗它们。
- 营销：利用互惠、社会认同、稀缺等原理。

## 📖 详细说明

### 概念解释
来源：《影响力》（西奥迪尼）
西奥迪尼提出六种基本的说服原理：

| 原理 | 含义 | 例子 |
|------|------|------|
| **互惠** | 别人给你好处，你会想回报 | 免费试用后更可能购买 |
| **承诺和一致** | 一旦做出承诺，会保持一致 | 小承诺导致大承诺 |
| **社会认同** | 看别人怎么做来决定自己怎么做 | "100万人的选择" |
| **喜好** | 更容易被喜欢的人说服 | 名人代言 |
| **权威** | 更容易被权威说服 | 专家推荐 |
| **稀缺** | 越稀缺越想要 | "仅剩最后3件" |


### 实际应用

- **营销**：利用互惠、社会认同、稀缺等原理。
- **谈判**：利用承诺和一致、互惠等原理。
- **防御**：识别这些原理的使用——问自己"我是在被操控吗？"

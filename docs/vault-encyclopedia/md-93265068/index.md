# 上瘾：让用户养成使用习惯

## 📌 核心定义

> 《上瘾》（Hooked）是尼尔·埃亚尔的著作，提出了让用户形成产品使用习惯的四步模型（Hook Model）。

## 🎯 关键要点

- **触发（Trigger）**：外部触发（通知、邮件）→ 内部触发（情绪、习惯）
- **行动（Action）**：最小行为，降低门槛（如点赞、滑动）
- **多变的酬赏（Variable Reward）**：不确定的奖励创造期待（社交酬赏、猎物酬赏、自我酬赏）
- **投入（Investment）**：用户投入越多，越难离开（数据、关系、声誉）

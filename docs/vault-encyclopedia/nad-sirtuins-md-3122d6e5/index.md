# NAD+代谢通路与去乙酰化酶Sirtuins的抗衰老机理

## 📌 核心定义

> NAD+ 水平下降 → Sirtuins 失活 → DNA 修复停滞

## 🎯 关键要点

- 核心定义：NAD+（烟酰胺腺嘌呤二核苷酸）是细胞能量代谢的核心辅酶，Sirtuins（去乙酰化酶）是依赖 NAD+ 运转的「基因守护者」蛋白家族。两者构成的代谢通路是细胞衰老调控的底层枢纽——NAD+ 水平随年龄断崖式下跌，是导致 Sirtuins 失活、基因修复停滞、线粒体功能障碍的核心诱因。
- Sirtuins 去乙酰化酶：被称为「长寿蛋白」，负责 DNA 损伤修复、表观遗传调控、抑制炎症通路、增强线粒体生物合成。需 NAD+ 作为燃料才能发挥功能。
- NAD+ 辅酶：细胞内能量代谢的通用货币，参与 ATP 合成、DNA 修复（PARP 酶）、钙信号调控。25 岁后每 20 年约下降 50%，到 50 岁时可能仅剩青年期的一半。
- NAD+ 前体补充：烟酰胺核糖（NR）、烟酰胺单核苷酸（NMN）等前体物质可在体内转化为 NAD+，临床研究显示可部分恢复 NAD+ 水平。
- 激活 Sirtuins：间歇性禁食、热量限制、运动可天然激活 Sirtuins 通路；白藜芦醇等植物多酚是 Sirt1 激活剂。

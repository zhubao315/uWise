# 文化基因库

## 📌 核心定义

> 文化基因库（Cultural Gene Pool）是一个将文化遗产类比为生物基因库的分析框架。它认为，一个民族或城市的非物质文化遗产——包括表演艺术、手工技艺、民俗节庆、传统医药等——构成了该文化的完整"基因库"。每一项非遗都是一个"文化基因片段"，承载着特定的知识、技能、价值观和世界观。正如生物基因库的多样性决定了物种的适应能力，文化基因库的丰富程度决定了一个文化的创造力和生命力。

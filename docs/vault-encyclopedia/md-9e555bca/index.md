# 广告账户审计

> 全面检查广告账户结构、投放效果和优化空间的系统方法。

## 审计维度

| 维度 | 检查点 |
|------|--------|
| **账户结构** | 广告组划分是否合理 |
| **受众设置** | 定向是否精准/过窄/过宽 |
| **出价策略** | 出价方式是否匹配目标 |
| **素材表现** | CTR/CVR 趋势 |
| **预算分配** | 是否向高效广告组倾斜 |

## 审计流程

```
数据导出 → 指标分析 → 问题定位 → 优化建议 → 执行验证
```

## 常见问题

- ❌ 广告组过多导致预算分散
- ❌ 受众重叠造成内部竞争
- ❌ 素材疲劳未及时更换
- ❌ 转化追踪不完整

# 胖东来文化道德观

> 胖东来内部核心文化准则，以"自由·爱"为终极价值导向，是国内极具特色的人本主义商业文化范本。

## 道德观核心

**尊重 · 平等 · 自由 · 博爱**

## 道德观十三条

### 正向标准（4条）

1. **自由高于一切**
2. **人人拥有平等的尊严和人格**
3. **发自内心的喜欢**——所有选择、相处遵从内心真实喜好，拒绝勉强
4. **成人之美**——秉持成人之美的善意，主动成全他人

### 负面红线（9条"不道德"）

5. 束缚自己、束缚他人，不道德
6. 依附他人，不道德
7. 虚伪，不道德
8. 自卑，不道德
9. 过度嫉妒，不道德
10. 过度贪婪，不道德
11. 利用他人、伤害他人，不道德
12. 不快乐，不道德
13. 为他人而活，不道德

**底部标语：自由·爱 FREEDOM & LOVE**

## 核心理念

| 维度 | 要点 |
|------|------|
| **以人为本** | 罕见将"不快乐"判定为违背道德，精神幸福优先 |
| **独立人格** | 反对依附他人、为别人活，先自我独立再善待他人 |
| **双向约束** | 既不束缚伤害别人，也不自我压抑、自我贬低 |
| **终极价值** | 自由与爱的平衡——个体自由 + 人与人之间的善意博爱 |

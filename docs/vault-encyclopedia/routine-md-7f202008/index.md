# 常规routine设计

## 📌 核心定义

> 把精要装进固定 routine：天才在 routines 里，靠系统不靠意志，routine 越固定，执行越省电。

## 🎯 关键要点

- 晨间 routine：前 90 分钟只做精要
- 晚间 routine：复盘＋准备明日唯一要事
- 触发器设计：固定时间地点动作链
- routine 从小：先 15 分钟版本跑两周
- 破坏 routine 的安排一律后置

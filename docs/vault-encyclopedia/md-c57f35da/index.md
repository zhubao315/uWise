# 渐进超负荷

> 训练的核心原则——逐步增加训练刺激，迫使身体持续适应和进步。

## 超负荷方式

| 方式 | 说明 |
|------|------|
| **增加重量** | 最直接的方式 |
| **增加次数** | 同重量下多做几次 |
| **增加组数** | 增加总训练量 |
| **缩短休息** | 增加代谢压力 |
| **放慢速度** | 增加肌肉张力时间 |

## 增加节奏

- **新手**：每次训练增加 2.5kg（上肢）/ 5kg（下肢）
- **中级**：每周增加 1-2 次重复
- **高级**：周期化训练，波动增加

## 常见误区

- ❌ 每次都增加重量（应该循序渐进）
- ❌ 忽视恢复（超负荷+恢复=进步）
- ❌ 超过 10% 规则（周增量不超过 10%）

# 三大竞争战略

## 📌 核心定义

> 迈克尔·波特（Michael Porter）在《竞争战略》中提出的企业获取竞争优势的三种基本战略：成本领先（Cost Leadership）、差异化（Differentiation）和聚焦（Focus）。波特强调，企业必须明确选择其中一种，试图同时追求多种战略的企业将陷入"夹在中间"（Stuck in the Middle）的困境。

## 🎯 关键要点

- **核心逻辑**：通过规模效应、流程优化、技术投入或低成本要素获取，使总成本低于竞争对手，从而在相同价格下获得更高利润，或以低价抢占市场份额。
- **适用条件**：行业产品标准化程度高、价格竞争激烈、买方对价格敏感。
- **风险**：技术变革可能使过去的成本优势归零；过度关注成本可能忽视产品创新和市场需求变化。
- **典型案例**：沃尔玛（供应链效率）、Costco（极致低毛利+会员制）、比亚迪（垂直整合降本）。
- **核心逻辑**：提供被客户广泛认为独特的、有价值的产品或服务，从而获得溢价能力。差异化可体现在品牌、技术、功能、服务、渠道等多个维度。

## 📖 详细说明

### 概念解释
迈克尔·波特（Michael Porter）在《竞争战略》中提出的企业获取竞争优势的三种基本战略：成本领先（Cost Leadership）、差异化（Differentiation）和聚焦（Focus）。波特强调，企业必须明确选择其中一种，试图同时追求多种战略的企业将陷入"夹在中间"（Stuck in the Middle）的困境。


### 实际应用

- **投资选股**：识别企业采取哪种竞争战略，评估该战略在当前行业格局下是否可持续。
- **竞争优势分析**：判断企业的竞争优势是否清晰，警惕"夹在中间"的企业。
- **行业比较**：同一行业内不同战略的企业可能共存，但需关注各自的护城河深度。

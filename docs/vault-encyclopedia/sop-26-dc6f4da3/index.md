### 实际应用

### 🔄 日循环：反馈学习 (Daily Feedback)

**执行时机**：每日晚间复盘后自动触发

**流程**：
```
1. 数据采集
   └─ 读取今日复盘数据（完成率、能量、洞察）

2. 即时分析
   └─ 对比计划vs实际，标记偏差

3. 次日优化
   └─ 将洞察注入明日计划生成逻辑
```

**输出**：更新 `history.json`，优化建议注入次日计划

---

### 📈 周循环：模式优化 (Weekly Pattern)

**执行时机**：每周日进化日

**流程**：
```
1. 周数据聚合
   └─ 汇总7天完成率、能量曲线、洞察清单

2. 模式识别
   ├─ 成功模式：哪些日子表现最好？有什么共同特征？
   ├─ 失败模式：哪些日子表现差？是什么阻碍了执行？
   └─ 能量模式：能量曲线与任务完成的相关性

3. 流程调整
   ├─ 任务数量调整（完成率低则减少）
   ├─ 时间安排优化（匹配能量曲线）
   └─ 习惯微调（强化有效习惯）
```

**输出**：周回顾文档 + 系统参数调整建议

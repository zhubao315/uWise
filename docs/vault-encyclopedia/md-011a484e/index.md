# 建筑即文化表达

## 📌 核心定义

> 建筑即文化表达是一种理解建筑的视角，它认为建筑不仅仅是遮风避雨的物质结构，更是一个文明的价值观、审美趣味和宇宙观的物质化表达。每一座建筑都不是孤立的存在，而是特定文化观念的具象化呈现——天坛建筑体现"天人关系"，紫禁城体现"礼制秩序"，四合院体现"家族伦理"。

裴丽珠在《北京纪胜》中反复强调这一观点。她指出，紫禁城的"前朝后寝"格局体现了中国传统政治中"公"与"私"的严格分界；三大殿沿中轴线依次排列，既是建筑的秩序，也是权力的秩序。她特别注意到，紫禁城的每一处设计——从屋顶琉璃瓦的颜色到台阶的级数——都有严格的等级含义，是中国礼制思想的物质化表达。

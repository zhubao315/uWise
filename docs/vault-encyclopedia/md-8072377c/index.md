# 极度透明

## 📌 核心定义

> 极度透明是瑞·达利欧在桥水基金推行的管理原则，也是《原则》一书中最具争议性的观点之一。其核心主张是：**真相，尤其是残酷的真相，是做出好决策的前提**。而要获得真相，就必须建立一种让所有人都能坦诚表达、所有信息都公开透明的文化。

## 🎯 关键要点

- 所有会议录音：公司内部的几乎所有会议都被录音，任何人都可以回听。这消除了背后议论和政治操作的空间。
- 所有反馈公开：对同事的评价不是私下进行的，而是当面、公开地给出。每个人都会收到直接、有时甚至令人不适的反馈。
- 所有错误被记录：错误不是被掩盖的，而是被系统性地记录、分析，转化为组织学习的素材。

# 经验晶体 选择包容性环境制度比个人能力更重要

## 📌 核心定义

> 个人发展不仅取决于自身能力，更取决于所在环境的制度设计。在"榨取性"环境（权力垄断、论资排辈、关系网主导）中，再优秀的能力也难以发挥；在"包容性"环境（公平竞争、机会平等、创新鼓励）中，普通人也能获得成长。**选择比努力重要——优先选择包容性环境，比在榨取性环境中拼命努力更有价值。**

- 职业选择：评估目标公司的制度环境，而非只看薪资和头衔
- 团队管理：设计包容性制度（员工参与决策、利润共享、创新激励）
- 创业选址：选择制度环境友好、法治健全的地方创业
- 投资判断：分析一个国家/地区的制度质量，作为长期投资参考
- 教育选择：为孩子选择鼓励多元思维、尊重个性的教育环境

## 📖 详细说明

### 概念解释

具体方法：(1) 评估当前环境：是否存在公平竞争机会？创新是否被鼓励？努力能否获得相应回报？(2) 若环境高度榨取且无法改变，果断"用脚投票"迁移至更包容的环境；(3) 若暂时无法迁移，在局部创造包容性空间（如跨部门协作、内部创新项目）；(4) 在自己的团队中推行包容性设计——分权、透明、公平激励。

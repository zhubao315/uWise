# 认知重构

## 📌 核心定义

> 1. **识别自动思维**：觉察"我此刻在想什么？"

## 🎯 关键要点

- 不是事件导致情绪，而是对事件的解释导致情绪：改变认知就能改变情绪。
- 认知重构不是"正能量"：不是用"积极想法"替代"消极想法"——而是用更平衡的想法替代扭曲的想法。
- 行为实验比认知重构更有效：用行动验证想法——比在头脑中"想通"更有效。
- 识别自动思维：觉察"我此刻在想什么？"
- 挑战认知扭曲：问自己——"支持这个想法的证据是什么？反对的证据是什么？"

### 实际应用

1. **识别自动思维**：觉察"我此刻在想什么？"
2. **评估证据**：支持这个想法的证据是什么？反对的证据是什么？
3. **生成替代想法**：有没有更平衡的解释？
4. **测试新想法**：用行为实验验证新想法。

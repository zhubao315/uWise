# 逆向思维做决策：先想怎么死，再决定怎么活

## 📌 核心定义

> "如果我知道我会死在哪里，那我永远都不会去那个地方。" ——芒格

## 🎯 关键要点

- 面对任何重要决策，不要问"怎么成功"，先问"怎么失败"，然后把所有失败路径逐一堵死——剩下的就是正确答案。
- 正向思维容易陷入"我该怎么做"的迷茫，选项太多无从下手
- 逆向思维把问题变成"我该避免什么"，答案通常少且明确
- 人类对"损失"的敏感度远高于"收益"（损失厌恶），利用这个本能更容易驱动行动

- 2. **列出"这件事怎么搞砸"的所有可能**（至少写10条）
- **逐条打分**：可能性（1-5）× 杀伤力（1-5）= 风险分

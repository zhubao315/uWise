# 存在性风险

## 📌 核心定义

> 存在性风险（Existential Risk）是指可能导致人类文明永久终结或严重倒退的风险类型。这一概念由牛津大学哲学家尼克·博斯特罗姆（Nick Bostrom）在2002年系统化提出，此后成为长期主义和AI安全研究的核心议题。

## 🎯 关键要点

- 存在性风险（Existential Risk）是指可能导致人类文明永久终结或严重倒退的风险类型。这一概念由牛津大学哲学家尼克·博斯特罗姆（Nick Bostrom）在2002年系统化提出，此后成为长期主义和AI安全研究的核心议题。
- 存在性风险具有三个独特属性：（1）不可逆性——一旦发生，无法恢复；（2）全球性——影响范围覆盖整个人类文明，而非局部地区；（3）永久性——终结的不仅是一代人，而是所有未来世代的潜在存在。一次普通的自然灾害可能造成巨大损失，但文明可以恢复；存在性风险则是"终局性的"，没有第二次机会。
- 博斯特罗姆和其他研究者识别出的存在性风险包括：核战争（尤其是全面核冬天）、超级智能失控（AI系统的目标与人类利益不一致）、生物武器（合成生物学使病原体工程化成为可能）、气候变化极端情景（虽然单独引发灭绝概率较低，但与其他风险叠加可能产生灾难性后果）、以及小行星撞击等自然风险。
- 在有效利他主义（Effective Altruism）的框架下，存在性风险被列为最高优先级议题。其逻辑是：如果人类文明有潜力延续数百万年，那么保护这一潜力的"期望价值"远超任何当下的慈善行为。即使存在性风险发生的概率极低，其巨大的负面后果也使其值得投入大量资源去预防。
- 批评者指出，过度关注存在性风险可能导致资源从当下紧迫问题（如贫困、疾病）转移。TESCREAL框架的批评者认为，"拯救未来"可能成为忽视当下的精英主义借口。如何在当下苦难与未来风险之间取得平衡，是长期主义面临的根本伦理挑战。

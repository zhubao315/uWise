# 叙事谬误

## 📌 核心定义

> 叙事谬误（Narrative Fallacy）由纳西姆·塔勒布在《随机漫步的傻瓜》中系统阐述。指人类大脑天生倾向于为随机事件编织因果故事，将本来无关的巧合赋予逻辑关系，从而产生一种虚假的理解感和预测能力。这一倾向根植于人类进化过程中对"模式识别"的依赖——在原始环境中，快速建立因果联系有助于生存，但在复杂随机系统中却成为认知陷阱。

## 🎯 关键要点

- **因果幻觉**：大脑无法接受"无原因"的结果，总要为随机事件找到解释。股票涨了是因为"业绩好"，跌了是因为"政策利空"——事后看都合理，但这些解释往往是事后诸葛亮
- **信息越多越自信**：获取的信息越多，叙事越丰富，人们对自己的判断越有信心，但预测准确率并未提高。塔勒布引用实验表明，给分析师更多信息反而使其过度自信
- **历史的后见之明**：历史事件在发生后总显得"必然"，但事前几乎无人预见。这种后见之明偏差让我们低估世界的随机性
- **简化陷阱**：叙事将复杂现实压缩为简单故事，丢失了关键的不确定性和随机性维度

### 实际应用

- 投资复盘：区分"结果好是因为决策好"还是"决策差但运气好"，避免将随机收益归因于能力
- 媒体素养：对财经新闻中的因果解释保持警惕，问自己"这个事件是否真的有因果关系，还是只是相关？"
- 决策审计：记录决策时的推理过程，而非只看结果，以识别叙事谬误对自己的影响
- 风险管理：不因为"这次不一样"的故事而放松风控纪律

# 创意择优

## 📌 核心定义

> 创意择优（Idea Meritocracy）是瑞·达利欧在桥水基金建立的决策机制。其核心原则是：**最好的想法胜出，不论它来自谁**。这不是一句口号，而是一套有具体实施方法的制度设计。

## 🎯 关键要点

- 不是一人一票：民主投票中每个人的意见权重相同，但在复杂决策中，一个有20年投资经验的人的判断显然比一个实习生的判断更有参考价值。
- 按可信度加权：每个人的意见权重取决于他们在相关领域的经验和过往记录。在某个领域有过多次成功经验的人，其意见权重更高。
- 不是独裁：虽然权重不同，但每个人都有表达意见的权利和义务。最终决策是所有加权意见的综合结果。

### 实际应用

创意择优要有效运作，需要两个前提条件：

1. **极度透明**：所有人都能看到所有信息，否则加权投票的信息基础就不成立。
2. **坦诚的文化**：人们必须愿意表达真实想法，而不是迎合上级或多数人的意见。

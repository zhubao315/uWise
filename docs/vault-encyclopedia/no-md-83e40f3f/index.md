# No导向问题设计

## 📌 核心定义

> 把问题设计成让对方说“不”的样子（“你是不是已经放弃这个项目了？”），安全感让人开口说真话。

## 🎯 关键要点

- “愿意/同意吗”逼人防御，“是不是放弃”给人掌控
- No 之后必跟开放问题接真话
- 用于破冰、探底线、重启僵局
- 配合镜像使用效果翻倍
- 本质是把“被要求”变成“我选择”

## 📖 详细说明

### 出处
第 1 章“让对方说不”，全书开门技术。

### 应用
下次想问“行不行”时，改写成 No 导向版再问。

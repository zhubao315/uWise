# 非暴力抵抗

## 📌 核心定义

> 梭罗开创的社会变革方法论：通过拒绝合作、不服从、不使用武力的方式对抗不义制度。改变制度的前提是改变自己——先让自己的行为合乎良知，然后以自我改变的事实感染他人。甘地受此影响发展为"Satyagraha"（坚持真理），马丁·路德·金将其应用于美国民权运动。

## 🎯 关键要点

- **不合作即力量**：拒绝参与不义制度（不纳税、不遵守歧视性法律）本身就是一种行动
- **手段与目的统一**：非暴力不是策略选择而是道德原则——暴力的手段不能带来和平的目的
- **从个体到集体**：非暴力抵抗的起点永远是个人良知的觉醒，然后通过个人的道德示范扩散为社会运动

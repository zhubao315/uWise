# 文化市场生态学

## 📌 核心定义

> 文化市场生态学是研究文化商品交易市场的内部结构、运作机制和生态平衡的分析框架。它将文化市场视为一个有机的生态系统，其中各类参与者（买家、卖家、中间人、鉴定者、制作者）形成复杂的共生关系，共同维持市场的运转和文化的流通。

# 被看见本身就是治愈

## 📌 核心定义

> 来源：《也许你该找个人聊聊》（戈特利布）

## 🎯 关键要点

- 被看见：有人真正理解你，这本身就是治愈。
- 安全空间：一个不评判、不指责、只是倾听的空间。
- 新体验：在咨询关系中体验到健康的互动模式，可以迁移到其他关系中。
- 创造"被看见"的体验：找一个信任的人，分享你真实的感受——不是为了得到建议，只是为了"被看见"。
- 成为"看见"他人的人：真正的倾听——放下自己的判断和建议，专注于对方的感受。

# 竞技心理韧性

竞技心理韧性是指在高压、逆境、连败中保持决策质量和执行力的能力。在高分段，**心态 > 操作 > 意识 > 反应**——操作再好，心态崩了就没法赢。

## 连败的应对机制

1. **三连败停止排位**：连续输三把就关游戏或者换模式——大脑进入「急于翻盘 → 决策急躁 → 越打越差」的恶性循环
2. **复盘最后一局**：不是复盘操作失误，而是复盘「我在哪一刻做了情绪化的决定」
3. **重置心态**：深呼吸 30 秒，喝杯水，提醒自己上一局的队友和对手都不是这一局的人

## 队友冲突的处理

- **屏蔽是最高效的**：队友喷人 → 屏蔽 → 专注自己操作。争论只会分散你的注意力
- **不要试图教育队友**：你不可能在一局 15 分钟的比赛里改变任何人的习惯
- **「我错了」是最高级的策略**：即使不是你的错，承认「我这一波可以处理得更好」能降低团队火药味

## 心流状态的进入

- **赛前热身**：先打一把训练营或匹配，把手感和肌肉记忆激活
- **单排时只听能让自己放松的音乐**：熟悉的、节奏稳定的背景音
- **输赢不是目标，进步才是**：每一局结束问自己「这局我在哪个决策上做得比上一局好」

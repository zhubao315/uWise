## 📖 详细说明

### 概念解释
来源：《思考，快与慢》（卡尼曼）《对伪心理学说不》（斯坦诺维奇）
认知偏差是系统1的系统性错误——它们是可预测的、普遍存在的。

| 偏差 | 含义 | 例子 |
|------|------|------|
| **锚定效应** | 先看到的数字影响后续判断 | 房产中介先带你看贵的房子 |
| **可得性启发** | 越容易想到的事情越认为它发生概率高 | 飞机失事新闻让人高估飞行风险 |
| **代表性启发** | 根据刻板印象做判断 | "沉默寡言"的人更可能是图书管理员 |
| **损失厌恶** | 失去的比得到的更让人在意 | 不愿卖出亏损的股票 |
| **确认偏误** | 只看到想看到的证据 | 星座效应 |
| **后见之明偏差** | 事后觉得"我早就知道了" | "我早就预测到了" |
| **过度自信** | 以为自己知道的比实际多 | 高估自己的能力 |
| **框架效应** | 同一问题不同表述导致不同选择 | "90%存活率"vs"10%死亡率" |

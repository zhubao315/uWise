# 俄罗斯轮盘赌决策

## 📌 核心定义

> 俄罗斯轮盘赌决策（Russian Roulette Decision）是纳西姆·塔勒布《随机漫步的傻瓜》的核心隐喻：一把 6 发左轮装 1 颗子弹，扣一次扳机不死就赚 1000 万——**赚钱（结果）不能证明开枪（决策）正确**。评估决策只看过程，不看结果。

## 🎯 关键要点

- **结果 ≠ 过程**：好决策可能坏结果（运气差），坏决策可能好结果（运气好）——两者在随机性高的领域都常见
- **唯一正确的评估问题**："给定当时的认知与信息，我的决策过程是否合理？"——合理则即使亏钱也是好决策
- **识别俄罗斯轮盘赌式成功**：短期暴利 + 承担毁灭性风险 + "连续成功"记录 = 大概率是子弹还没响（马克案例：连续三年大赚被当明星，第四年爆仓清零还欠公司钱）
- **与偏斜度的关系**：轮盘赌结构 = 极端负偏斜（一次输 = 出局）
- **过程评估三问**：(1) 当时的信息支持这个决策吗？(2) 最坏情况我承受得起吗？(3) 去掉运气因素，这个决策还站得住吗？

## 📖 详细说明

### 概念解释

俄罗斯轮盘赌隐喻针对的是"结果论"评价系统：业绩排名、成功学叙事、明星基金经理的加冕——在随机性高的领域，这些系统把"子弹还没响"误读为"枪法准"。

塔勒布的交易室案例：激进交易员马克连续三年大赚，住豪宅开跑车；保守交易员约翰表现平平被嘲笑。第四年暴跌，马克一夜清零还倒欠，约翰毫发无损还抄底获利。**马克的三年"成功"本质是连续三次没碰到那颗子弹**——我们只看到三年的成功记录，看不到平行宇宙中"第一年就爆仓的马克们"（幸存者偏差）。

### 实际应用

1. **决策日志**：每个重大决策记录"过程三问"答案——事后用过程而非结果评价自己
2. **识别他人**：看到"连续成功 + 高波动 + 暴利"的组合，先假设是轮盘赌，直到看到风险结构证据
3. **识别自己**：我的"连续成功"（如 8 月提纯节奏）里，哪些是"子弹还没响"的部分？（单点依赖/未压力测试的假设）
4. **生活迁移**：职业/健康/关系中的"一直没事"决策同样过三问——去掉运气，过程还站得住吗？

### 实际应用

### 识别"英雄主义陷阱"
当你发现自己或团队在依赖以下模式时，就是英雄主义陷阱在起作用：

```
危险信号：
  → "这件事只有老王能做"（单点故障）

```

### 用系统替代英雄的四步法
1. **识别关键流程**：哪些事情反复做？哪些出错后果严重？
2. **提取杀手项**：从经验中提炼出"漏了会出大事"的关键步骤
3. **固化为清单/流程**：把隐性知识显性化，不依赖记忆
4. **赋予执行纪律**：清单是纪律不是建议——必须执行，不可跳过

### 权力下放：让系统赋能弱者
葛文德在手术清单中加入"所有人自我介绍"这一项后，护士和麻醉师在发现问题时更敢于开口。清单的本质是**权力下放**——它让最基层的人也有权暂停流程。真正的系统不是命令链，而是安全网。

### 团队实践
- 在项目启动时建立**沟通清单**（所有人自我介绍、明确角色）
- 在关键节点设置**检查清单**（不依赖任何一个人的记忆）
- 在复盘时**迭代清单**（每次出错后问："这个错误能用清单拦截吗？"）

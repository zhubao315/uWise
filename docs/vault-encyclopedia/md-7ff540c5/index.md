# 视野博弈

视野是 MOBA 游戏中最重要的隐形资源——**你看到对方，对方没看到你，你就拥有信息和决策的绝对优势**。

## 视野的价值

- **安全信息**：知道对方打野位置 → 决定推线/控线/撤退
- **先手权**：先看到对方的人可以在草丛埋伏、在转角预判技能
- **目标控制权**：在龙/主宰区域有视野的一方拥有开团主动权

## 视野的三个层次

| 层次 | 行为 | 战术价值 |
|------|------|---------|
| 被动视野 | 插眼在常规位置（河道草丛、龙坑） | 基础安全，但容易被排 |
| 主动视野 | 入侵对方野区插深眼（对方蓝Buff、F6） | 掌握对方打野路线和动向 |
| 视野压制 | 排掉对方的眼，让对方陷入黑暗 | 制造心理压迫——对方不知道你在哪 |

## 视野置换法则

*想要龙坑视野 → 先推中线 → 对方被迫守塔 → 你安全布置龙坑视野*

视野不是免费获得的——任何视野的建立都必须以兵线压力为前提。没有兵线优势就去插眼，等于送给自己被埋伏的机会。

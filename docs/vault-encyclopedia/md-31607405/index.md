# 五大金钱法则

## 📌 核心定义

> 刻在泥板上的钱之来去铁律：钱亲近存它的人、听智者话的人，远离赌运气、听外行、追暴利的人。

## 🎯 关键要点

- 法则一：存下十分之一以上的人，钱会到来
- 法则二：为钱找到可盈利的雇主（让钱工作），钱会繁衍
- 法则三：听从智者建议守护钱财，钱得保全
- 法则四：投不熟悉的生意，钱会溜走
- 法则五：被暴利诱惑、强求不可能，钱必遭报复
- 核心是“守”：增值与防损同等重要

## 📖 详细说明

### 出处
泥板智慧章，对应当代 P2P、杀猪盘、高息诱饵等全部变体。

### 应用
任何投资先过五法则：存了吗？钱在工作吗？问过懂行的人吗？我懂吗？是暴利幻想吗？

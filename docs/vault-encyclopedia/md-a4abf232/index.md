# 跨界方法论

## 📌 核心定义

> 冯唐从医生→麦肯锡咨询顾问→作家→投资人四次跨界所提炼的心法：不是从零开始学每个新领域，而是找到不同领域底层的共通能力——逻辑分析、表达沟通、判断决策——然后将这些核心能力迁移复用。跨界不是换赛道，是用同一套引擎跑不同的路。

## 🎯 关键要点

- **底层能力的识别**：所有领域的表层知识不同，但底层能力相通——逻辑推理、信息整合、说服表达、风险判断、人性洞察
- **迁移而非从零**：每次跨界不是"放弃已有去学新的"，而是"把已有的核心能力装进新领域的外壳"——80% 的能力不变，20% 的领域知识新增
- **叠加效应**：跨界的价值在于单一领域专家无法产生的连接——医学+文学+商业+投资的四重视角产生了独特的洞察

# 地方政府竞争模式

## 📌 核心定义

> 兰小欢在《置身事内》中提出的中国地方政府行为模型。与西方市场经济中政府主要扮演"裁判员"角色不同，中国地方政府是经济的深度参与者——它们像企业一样竞争，通过招商引资、基础设施建设、政策优惠等手段争夺资源和经济增长。这种"地方政府竞争"是中国经济奇迹的核心制度动力之一。

## 🎯 关键要点

- **政府不是裁判，是运动员**：中国地方政府不仅制定规则，还深度参与经济活动。它们拥有土地、国有企业、金融机构等大量资源，可以直接影响经济走向
- **竞争驱动发展**：各地方政府之间存在激烈的竞争关系——争投资、争项目、争人才、争排名。这种竞争推动了基础设施建设和经济增长
- **GDP锦标赛**：长期以来，地方官员的晋升与当地GDP增长高度相关，形成了"GDP锦标赛"机制。这既推动了经济增长，也带来了过度投资、地方债务等问题
- **制度演变**：从改革开放初期的乡镇企业，到1994年分税制后的土地财政，再到近年来的创新驱动转型，地方政府的竞争模式在不断演变

# 苦难叙事

## 📌 核心定义

> 余华小说的核心主题：将个体苦难置于中国现代史的大背景中，揭示普通人在历史洪流中的挣扎与坚韧。苦难不是抽象概念，而是具体的身体经验——饥饿、疾病、暴力、死亡，通过这些极端处境拷问人性的底线。

- **历史中的个体**：将小人物的苦难与中国现代史（土改、文革、改革开放）紧密交织，个人命运即历史缩影。

- **苦难中的温情**：在极端困境中保留人性微光，如《活着》中福贵与老牛的相依为命。

# 从0到1

## 📌 核心定义

> "从0到1"是彼得·蒂尔用来描述创新本质的框架。0到1代表创造全新的事物——从无到有；1到N代表复制已有的事物——从一到多。这两种进步形式有本质区别，却经常被混淆。

## 🎯 关键要点

- "从0到1"是彼得·蒂尔用来描述创新本质的框架。0到1代表创造全新的事物——从无到有；1到N代表复制已有的事物——从一到多。这两种进步形式有本质区别，却经常被混淆。
- **垂直进步（0到1）——科技创新**：用新技术创造前所未有的东西。硅谷是这种进步的典型代表——从芯片到互联网到人工智能，每一次技术革命都是从0到1的过程。垂直进步需要的是独立思考和创造力。
- **水平进步（1到N）——全球化**：把已经被验证的模式复制到更多地方。中国过去四十年的高速增长很大程度上是1到N——把西方成熟的工业模式、商业模式搬到中国，用更大的市场规模实现增长。水平进步需要的是复制能力和执行力。
- 蒂尔认为，1到N的竞争最终会把利润压到零。当所有人都在复制同一模式时，差异化无从谈起，最终只能陷入价格战。而0到1的创新者有机会建立垄断，获得持续的超额回报。
- 这并不意味着1到N没有价值——全球化让数十亿人脱离了贫困。但从投资和创业的角度看，0到1的机会才是真正的"黑天鹅"，才能产生非线性回报。
- 问自己一个关键问题：**你是在创造新事物，还是在复制已有事物？** 如果你在做的事情已经有100个人在做，那你就是在1到N。这不一定是坏事，但你需要意识到你面对的是完全竞争的逻辑。如果你在做的事情前所未有，那你就是在0到1——风险更高，但回报可能是指数级的。

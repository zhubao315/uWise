# 人优先级-人产品利润的管理铁律

## 📌 核心定义

> 利润 = f(产品质量) → 产品质量 = f(人才质量) → 因此 利润 = f(人才质量)

## 🎯 关键要点

- 错误做法：先做产品，有收入再招人
- 正确做法：先找到联合创始人和核心团队，再启动产品
- 具体行动：花60%的时间在招聘上，面试20个人才录1个

### 实际应用

### 场景1：创业初期的人才投资
- **错误做法**：先做产品，有收入再招人
- **正确做法**：先找到联合创始人和核心团队，再启动产品
- **具体行动**：花60%的时间在招聘上，面试20个人才录1个

### 场景2：快速增长期的人才瓶颈
当业务增长超过团队能力时：
1. 立即暂停业务扩张，先补齐关键岗位
2. 对现有团队做一次"战时评估"：谁是A级、谁是B级、谁是C级
3. C级员工要么升级要么离开，不能让平庸者拖累优秀者
4. 外部引入关键高管，CEO亲自参与每一个高管招聘

### 场景3：解雇决策的正确方式
霍洛维茨的经验：
- 发现错误招聘后，不要等到下一个review周期，立即行动
- 谈话时诚实但尊重，说明原因，给出合理补偿
- 对留下的团队解释（不点名），消除不确定性和恐惧
- 让被裁的人带走尊严——他们会成为你的口碑

### 场景4：培训作为CEO的最高杠杆
- CEO每周花时间亲自培训核心骨干
- 培训不是"上课"，是带着做、即时反馈、手把手带
- 培训10个人 → 这10个人各影响10人 = 影响100人
- 培训的内容是思维方式和决策能力，不是具体技能

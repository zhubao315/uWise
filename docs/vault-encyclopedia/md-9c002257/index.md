# 记录即拯救

## 📌 核心定义

> 记录即拯救是一种文化保护理念，它认为在文化消失之前，用文字、影像、口述历史等方式将其完整记录下来，本身就是一种有效的保护行动。即使物质形态最终无法保存，文字和影像中的记忆可以跨越时间，让后人了解曾经存在过的文化面貌。

裴丽珠的写作是"记录即拯救"的典范。面对20世纪初北京的急速变迁，她以文字和照片保存了大量即将消失或已经消失的文化信息。她的写作体现了一种紧迫的文化使命感——在旧世界消逝之前，尽可能完整地记录下它的面貌。林语堂赞誉她的作品为"关于北京的最全面的英文著作"，正是因为她在一个关键的历史节点上，以系统而深入的方式记录了北京的文化景观。

这一理念的核心洞察在于：记录不是被动的旁观，而是主动的参与。一个认真记录的人，其文字可以成为跨越百年的文化财富。当城墙被拆除、胡同被推倒、老字号关门歇业，那些曾经被记录下来的文字和影像，就成为后人了解这些文化遗产的唯一窗口。

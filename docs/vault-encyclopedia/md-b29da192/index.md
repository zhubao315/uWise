# 认知偏差演化根源

## 1. 核心精要

**第一性原理**：人类的悲观主义倾向不是对现实的准确反映，而是进化遗留的认知偏差。杏仁核对负面信息的敏感性在原始匮乏环境中具有生存优势，但在现代社会被媒体无限放大，导致系统性悲观。

**演化动力学**：负面新闻比正面新闻更吸引注意力（进化优势），信息过载超出认知处理能力（邓巴数限制），两者叠加形成"世界正在变糟"的错觉。

## 2. 系统演化图景

### 认知偏差形成路径

```
原始环境(匮乏) → 杏仁核进化(负面敏感) → 现代媒体(放大负面) → 系统性悲观
```

### 三大偏差来源

| 来源 | 机制 | 现代影响 |
|------|------|----------|
| 杏仁核偏好 | 负面信息更易引发警觉 | 焦虑决策、风险规避过度 |
| 邓巴数限制 | 社交圈上限150人 | 无法直观理解全球数据 |
| 媒体放大 | 负面新闻更吸引眼球 | 信息环境系统性偏负面 |

### 正反馈抑制机制

```
负面新闻 → 注意力捕获 → 传播扩散 → 更多负面新闻 → 系统性悲观
     ↑                                              ↓
     └──────────── 认知偏差强化 ←──────────────────────┘
```

## 3. 跨域依赖与关联

**对决策科学的启示**：
- 悲观不是现实，是认知偏差的产物
- 需要主动构建"基于证据的乐观主义"
- 信息过滤是理性决策的前提

**对心智进化的启示**：
- 乐观是可以训练的技能
- 数据比直觉更可靠
- 主动寻找反例是打破偏差的有效方法

**对投资的启示**：
- 市场恐慌往往是认知偏差的产物
- 长期视角可以过滤短期噪音
- 逆向投资需要对抗本能的悲观倾向

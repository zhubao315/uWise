# 正则化思维——剔除噪声抓住规律是通用的决策框架

## 📌 核心定义

> **模型过拟合是"记住噪声而非规律"，人过拟合是"被细节淹没而抓不住本质"。正则化不是削弱能力，而是引导注意力聚焦到真正重要的模式上——这对AI和人生同样适用。**

## 🎯 关键要点

- 信息过载 = 没有正则化的输入层：每天接触海量信息，如果不筛选，大脑会被噪声填满，无法形成有效判断

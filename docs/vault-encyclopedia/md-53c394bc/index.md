# 象数思维

## 📌 核心定义

> 《周易》的认知方法——通过"象"（卦象、物象）和"数"（数理关系）来理解世界，是中国传统思维的核心范式之一。

## 🎯 关键要点

- 《周易》的认知方法——通过"象"（卦象、物象）和"数"（数理关系）来理解世界，是中国传统思维的核心范式之一。
- "象"是《周易》认知世界的基本单位。"圣人立象以尽意"——用具体的形象来表达抽象的道理。卦象不是精确的数学模型，而是一种象征性的表达方式。例如，乾卦象征天、刚健、进取；坤卦象征地、柔顺、承载。通过类比和象征，将复杂的世界简化为可理解的模式。
- "数"不是精确的数学计算，而是数理关系和规律的把握。阴阳的二元结构、八卦的八种基本状态、六十四卦的六十四种组合，构成了一个理解世界的数理框架。数字在这里不是用来精确测量的，而是用来分类和关联的。
- 象数思维类似于"用隐喻理解抽象概念"的认知方式。认知语言学研究表明，人类理解抽象概念很大程度上依赖于隐喻——我们用"时间是金钱"来理解时间的价值，用"人生是旅程"来理解人生的方向。象数思维正是这种隐喻认知的系统化应用。
- 象数思维的优势在于：它不追求精确（因为精确往往意味着简化），而是追求关联（因为关联意味着丰富）。在面对复杂、模糊、多变量的现实问题时，象数思维提供的不是精确答案，而是理解框架。

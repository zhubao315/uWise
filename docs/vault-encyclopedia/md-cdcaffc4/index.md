# 医学的疆与界

## 核心定义

> 医学的疆与界是一个深刻且全面的概念，它涉及医学的多个方面。根据刘东博士的观点，一个完整的医学链条应该包括预防、保健、诊断、治疗、康复这五个环节。刘东博士在北京安贞医院工作22年，专注于心脏手术，但他发现很多病人手术后难以得到正确的康复，这让他意识到医学的局限性。

## 关键要点

- 刘东博士在北京安贞医院工作22年，专注于心脏手术，但他发现很多病人手术后难以得到正确的康复，这让他意识到医学的局限性。
- 在他的TEDxCEIBS 2019演讲中，刘东博士强调了预防的重要性，认为预防应始终大于治疗。他指出，大多数病患的现状是病前无预防，术后难康复。为了改变这一现状，他提倡将医学的疆界扩展到无疆的境地，将医学与社会学、社会支持系统融合起来，形成一个完整的社会支持系统。这样的系统不仅包括医疗、教育、心理、安全、社会融入、志愿者、政策、法律等方面，而且致力于帮助患者形成正确的生活方式，提高他们的依从性。
- 慢性病已成为国民健康的头号威胁。据《"十四五"国民健康规划》，慢性病导致的死亡已占到中国总死亡的85%，疾病负担占总疾病负担的70%。因此，强化个人健康责任，提高全民健康素养，形成自主自律的健康生活方式和疾病管理模式变得尤为重要。
- 刘东博士的这些观点不仅揭示了当前中国医疗体系的局限性，也为我们指出了医学发展的新方向，即更加注重预防、保健和康复，形成一个更全面、更有效的医学链条。

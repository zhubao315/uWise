# 存量与流量

## 📌 核心定义

> 存量（Stocks）是系统在任一时刻的积累（水池中的水、银行存款、组织能力、认知资产）；流量（Flows）是随时间进入或离开存量的物质或能量（流入量与流出量）。系统的动态变化完全由流量对存量的调控决定。

## 🎯 关键要点

- **存量(t) = 存量(t₀) + ∫(流入 − 流出)dt**
- **存量有惯性**：流量改变需时间才能体现在存量上 → 时滞（Delays）是误判之源
- **存量是缓冲垫**：吸收外界波动，但也掩盖变化
- **看系统先看存量**：判断系统健康度，看存量趋势而非单次流量快照
- **AI 时代警示**：AI 加速"流量"，却可能在无声中消耗"存量"（分析能力、独立判断）
- **留白即蓄能**：休息=给认知存量补流入、断消耗流量的转嫁负担回路

## 📖 详细说明

### 概念解释

存量与流量是德内拉·梅多斯《系统之美》中系统分析的核心工具。存量是系统"家底"——专业知识、判断力、人脉、直觉，这些积累五年十年。流量是"进出"——每天的产出量、处理的信息量、完成的任务数。

梅多斯强调存量具有惯性：流入量与流出量的改变需要时间才能体现在存量变化上。这种非线性时滞，正是人类对复杂系统产生误判（反应过度或反应不足）的根源。**存量既是缓冲垫，也是掩盖问题的帷幕**——它吸收波动，让人看不清真实的消耗速率。

### 实际应用

1. **系统体检**：面对反复出现的问题，先列出核心存量，标出流入/流出量与时滞
2. **守存量**：AI 代写/代思考是"流量加速 + 存量消耗"，要为核心能力设硬规则
3. **补流入**：深度阅读、结构化复盘、留白休息 = 给认知存量补流入
4. **看趋势**：判断系统健康度，看存量变化趋势，而非单次流量快照

# 把自己作为方法

## 📌 核心定义

> 用自身经验作为理解世界的切入点，而非依赖抽象理论

## 🎯 关键要点

- 用自身经验作为理解世界的切入点，而非依赖抽象理论
- 项飙提出"把自己作为方法"，意味着用个人的具体经验、困惑和观察作为理解世界的起点，而非从抽象的理论框架出发。这不是鼓励自恋或自我中心，而是一种认识论上的诚实——所有的认知都是从某个具体位置出发的，承认这一点比假装客观更接近真相。
- 这一原则的核心逻辑是：抽象理论之所以有力量，是因为它能帮助我们理解具体经验；但如果理论脱离了具体经验，它就变成了空洞的教条。把自己作为方法，就是不断在理论与经验之间来回穿梭，用经验检验理论，用理论照亮经验。
- 与传统的"客观研究"不同，这种方法承认研究者的主体性。你不是一面透明的镜子，你带着自己的偏见、经验和位置去观察世界。与其假装中立，不如清楚地意识到自己的位置，然后把这个位置当作理解的起点。项飙自己的人类学研究就是如此——从温州的全球化商人到北京的"北漂"社区，他始终从自己能触及的经验出发，逐步扩展理解的边界。

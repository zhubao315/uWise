# 民族秘史

## 📌 核心定义

> 《白鹿原》的核心定位：巴尔扎克说"小说是一个民族的秘史"，陈忠实以此为创作纲领。通过白鹿两家半个世纪的命运沉浮，展示中国社会从清末到建国初期的深层变迁——不是官修正史的宏大叙事，而是被正史遮蔽的民间记忆与人性真实。

## 🎯 关键要点

- **秘史而非正史**：关注被官方历史叙述忽略的个体命运、民间伦理和文化冲突。
- **家族即民族**：白、鹿两家的恩怨情仇是20世纪中国社会矛盾的微型剧场。
- **文化冲突**：儒家宗法伦理、革命意识形态、个体欲望三者的剧烈碰撞。

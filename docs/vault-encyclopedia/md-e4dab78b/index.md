# 化性起伪

## 📌 核心定义

> "化性起伪"是荀子修养论的核心概念。"化性"指改造人的本性；"起伪"指兴起人为的努力（"伪"在古汉语中指"人为"，不是"虚伪"）。

荀子认为人性本恶，但人可以通过后天的学习、教化和礼义规范来改造本性，达到善的境界。"人之性恶，其善者伪也。"——人的本性是恶的，善是后天人为努力的结果。

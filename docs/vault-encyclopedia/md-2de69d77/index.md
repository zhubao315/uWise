# 中隐智慧——在世俗中保持闲心

## 📌 核心定义

> 💡 大隐隐于市——不必逃离世俗，在日常中建构你的'闲心空间'。

## 🎯 关键要点

- **小隐 vs 中隐**: 小隐隐于山林，中隐隐于市朝。在世俗中保持闲心比逃离更难也更有价值
- **闲心 ≠ 无所事事**: 闲心是心灵有余裕，能感受生命的丰富，而非空闲不做事
- **媒介建构法**: 通过具体的'媒介'（琴、酒、云、书、茶）帮助自己进入闲心状态

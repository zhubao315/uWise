# 内部触发识别与设计法

## 📌 核心定义

> 内部触发是习惯的终极标志——当用户在某种情绪或情境下自动想到你的产品，无需任何外部提示就主动使用，这就是内部触发建立成功的证明。

## 🎯 关键要点

- 不要强行创造触发：：内部触发来自真实用户需求，不能凭空设计
- 情绪绑定需要时间：：通常需要 2-4 周的重复才能建立条件反射式关联
- 负面情绪触发有伦理风险：：利用焦虑、恐惧、孤独设计的产品可能对用户造成伤害
- 检验标准：：问自己"如果去掉所有推送通知，用户还会回来吗？"如果答案是不会，内部触发尚未建立
- 习惯的力量是双向的：：既可以用于好习惯的培养，也可以用于有害行为的设计，需谨慎使用

### 实际应用

### 识别内部触发的步骤

**1. 用户情绪地图**
- 列出目标用户的核心情绪痛点：无聊、孤独、焦虑、不确定、失落、好奇、FOMO
- 用"当用户感到____时，他们需要____"句式描述每个触发场景
- 选择最频繁、最强烈的情绪作为核心内部触发

**2. 验证触发强度**
- 做用户访谈时问："你上次使用这个产品之前在想什么/感受什么？"
- 如果回答是"我也不知道，就是想看看"，说明内部触发已建立
- 如果回答是"收到了推送通知"，说明仍停留在外部触发

**3. 设计从外部到内部的桥梁**
- 第一阶段：用外部触发（通知、邮件）引导用户体验核心价值
- 第二阶段：将产品与特定场景/情绪反复关联（通过时间和重复）
- 第三阶段：减少外部触发频率，观察用户是否仍主动回来
- 第四阶段：如果用户在无外部提示时仍主动使用，内部触发已建立

### 个人习惯养成的应用
- 想养成阅读习惯？将阅读与"午休后"这个内在线索绑定，而非设闹钟提醒
- 想养成写作习惯？将写作与"早起后喝咖啡时"绑定，形成情境-行为关联
- 关键：选择一个已有的高频内部触发（如某个情绪或时间点），嫁接新行为

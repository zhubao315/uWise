# 致良知

## 📌 核心定义

> "致良知"是王阳明心学的核心概念。"良知"指人天生具有的道德直觉（知善知恶）；"致"指推致、扩充、实现。

王阳明认为，良知是人人本有的，不需要向外求取。"致良知"就是通过去除私欲的遮蔽，让良知自然显现，从而在每一件事上都能做出正确的判断和行动。

# 前额叶与杏仁核

## 📌 核心定义

> 来源：《情商》（戈尔曼）《身体从未忘记》（范德考克）

## 🎯 关键要点

- 杏仁核劫持：强烈的情绪会让杏仁核"劫持"前额叶——理性被关闭。
- 创伤让杏仁核过度活跃：创伤会改变大脑结构——杏仁核对威胁过度敏感，前额叶功能减弱。
- 情商的核心是管理前额叶与杏仁核的博弈：在情绪爆发和行为之间创造"暂停"。
- 暂停6秒：杏仁核劫持持续约6秒——暂停让前额叶重新上线。
- 深呼吸：腹式呼吸能激活副交感神经系统——降低杏仁核的活跃度。

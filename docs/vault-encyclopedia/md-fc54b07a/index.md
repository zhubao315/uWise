# 代码审查

代码审查（Code Review）是通过同行评审提升代码质量的工程实践。审查维度：正确性（逻辑是否正确）、可读性（命名/结构/注释）、性能（有无明显瓶颈）、安全性（OWASP Top 10）、测试覆盖（是否需要新增测试）。最佳实践：小批量提交（<400 行）、异步审查、建设性反馈。

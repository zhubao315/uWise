# 知识分子的勇气

## 📌 核心定义

> 李敖对知识分子本质的重新定义：知识分子不只是掌握知识的人，更是有勇气为真理发声、即使在威权压力下也不妥协的人。知识赋予能力，勇气赋予尊严。没有勇气的"知识分子"只是知识容器——有知识而无风骨。

## 🎯 关键要点

- **知识+勇气**：知识是必要条件但不是充分条件——博士学者很多，有勇气的知识分子很少
- **代价意识**：说真话有代价——被排挤、被禁言、被调查——勇气就是明知有代价仍然选择发声
- **不妥协**：知识分子的勇气不在于"适当的时候说适当的话"，而在于"什么时候都说不适当的话"——独立是知识分子的立身之本

# 理财规划

## 📌 核心定义

> 将个人财务目标转化为可执行方案的落地过程——量化目标、盘点现状、配置资产、设定节奏、定期复盘，是把 [个人理财](../md-2999c127/) 的战略落到战术的桥。

## 🎯 关键要点

- **SMART 目标**：目标须可量化（如"40 岁前积累 X"）、有时限、与人生阶段匹配
- **现状盘点**：净资产 = 资产 - 负债；收支结余率决定积累速度
- **资产配置**：按风险承受力与期限把资金分配到现金 / 保险 / 固收 / 权益
- **节奏纪律**：定投 / 定期复盘固化节奏，对抗情绪化决策
- **税务与效率**：合法节税与工具费率优化是规划的一部分

## 📖 详细说明

### 概念解释
理财规划是把"希望"转译为"计划"的过程。它强调端到端：目标定义 → 现状盘点 → 配置方案 → 执行节奏 → 年度复盘，任何一环缺失都会让规划流于口号。与个人理财的全局视角不同，它聚焦"如何分步实现"。

### 实际应用

- **年度财务计划**：年初设目标（储蓄率 / 收益率），年中对账
- **配置再平衡**：每季度检查权益/固收比例是否漂移，回归目标配比
- **生命周期调整**：临近大额支出（购房 / 教育）时下调风险暴露
- **纳税优化**：将合法节税动作纳入年度节奏

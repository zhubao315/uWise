# 旧世界葡萄酒

## 📌 核心定义

> 以法国、意大利、西班牙为代表的欧洲传统产酒国，强调风土含蓄内敛的风格表达。

## 🎯 关键要点

- 以法国、意大利、西班牙为代表的欧洲传统产酒国，强调风土含蓄内敛的风格表达。
- 旧世界（Old World）葡萄酒指来自欧洲传统产区的葡萄酒，核心产区包括法国（波尔多、勃艮第、香槟）、意大利（托斯卡纳、皮埃蒙特）、西班牙（里奥哈、里贝拉德尔杜罗）、德国（摩泽尔、莱茵高）以及葡萄牙、奥地利等。
- 旧世界风格的核心哲学是"风土优先"。酒庄追求的是让葡萄园的个性在酒中自然流露，而非人为塑造某种口味。这种理念体现在几个方面：酒标以产区而非品种命名（如"Chablis"而非"Chardonnay"），法律对种植密度、产量上限、陈年时间有严格规定，酿造手法偏向克制——较少使用重度烘烤的新橡木桶，不追求过熟的果味，保留酸度和矿物感。
- 旧世界葡萄酒的典型特征是：含蓄、内敛、层次复杂。果味不会一入口就炸开，而是逐步展开；结构感强，适合陈年；酸度明亮，与食物搭配时表现出色。它们常常需要耐心等待——无论是瓶中陈年还是杯中醒酒。
- 当然，"旧世界"这个标签正在变得模糊。许多欧洲新一代酿酒师在借鉴新世界的技术和理念，而传统产区内部也有大胆创新的酒庄。旧世界与新世界的界限，正从地理概念演变为一种风格倾向的光谱。

### 实际应用

选购波尔多或勃艮第等旧世界葡萄酒时，应依据酒标上的产区名称（如 Chablis）而非葡萄品种来预判风味，并预留 30 分钟以上的醒酒时间以释放其含蓄的层次。在餐饮搭配中，利用其高酸度和矿物感特征，将其与海鲜、白肉或结构复杂的菜肴结合，能有效平衡食物油腻感并提升整体味觉体验。

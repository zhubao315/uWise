# 法术势

## 📌 核心定义

> "法术势"是韩非子法家思想的三大支柱：

- **法**：公开的法律制度，明确赏罚标准（"法者，编著之图籍，设之于官府，而布之于百姓者也"）
- **术**：君主驾驭臣下的权术，不可示人（"术者，藏之于胸中，以偶众端而潜御群臣者也"）
- **势**：君主的权势地位，是推行法令的基础（"势者，胜众之资也"）

韩非子认为，三者缺一不可：有法无术则臣下欺瞒，有术无法则百姓无所适从，有法有术无势则令不行禁不止。

# 自然人的道德直觉

## 📌 核心定义

> 卢梭在《忏悔录》及其哲学体系中提出的核心观点：人在自然状态下拥有天然的道德直觉——良心。这种直觉先于理性、先于社会规范，是判断善恶的内在指南针。社会的虚伪和文明的扭曲，往往遮蔽了这种天然的道德感。

## 🎯 关键要点

- **自然状态**：人在未被社会污染前，拥有天真的善良和道德直觉
- **良心先于理性**：道德判断不依赖复杂的逻辑推理，而源于内心深处的直觉感受
- **社会的腐蚀**：文明社会的虚荣、攀比、伪装，扭曲了人的天然善良
- **回归真实**：通过自我反省和坦诚，可以重新连接被遮蔽的道德直觉

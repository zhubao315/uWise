# 50%缓冲排期法

## 📌 核心定义

> 任何计划预留一半冗余：估算耗时 ×1.5 排进日历，意外发生时依然从容。

## 🎯 关键要点

- deadline 失守多因估算乐观而非执行懒
- 每天第一个时间块只给精要事项
- 周五下午设缓冲时段消化溢出
- 缓冲不是摸鱼额度，是风险准备金
- 对外承诺用缓冲后的日期

## 📖 详细说明

### 出处
执行章“缓冲”：为最坏情况留白。

### 应用
本周三个 deadline 全部 ×1.5 重排，对外只报缓冲后的时间。

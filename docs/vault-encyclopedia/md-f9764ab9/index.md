# 饮要少但要好

## 📌 核心定义

> 与其喝很多便宜酒，不如少喝一点喝好一点——有品质有节制的饮酒方式。

## 🎯 关键要点

- 与其喝很多便宜酒，不如少喝一点喝好一点——有品质有节制的饮酒方式。
- "Drink less but better"是杰西斯·罗宾逊在《24堂大师课》中反复强调的核心理念。这条原则反对两种极端：一是酗酒式的大饮量，二是盲目追求昂贵名酒的虚荣消费。
- 真正的葡萄酒爱好者应该追求的是：每一杯酒都值得认真品味，每一次饮酒都是一次感官体验。当你把注意力集中在品质而非数量上，你会发现少量好酒带来的愉悦远超大量平庸之酒。这不是关于价格——一瓶200元的好酒可能比一瓶2000元的名庄更适合你。
- 这条原则的核心在于：饮酒是一种享受，不是一种任务。
- 每次饮酒控制在1-2杯，专注于品味而非灌醉
- 选择自己经济能力范围内最好的酒，而非最贵的
- 宁可一周喝一瓶好酒，也不要每天喝劣质酒
- 买酒时关注性价比而非品牌光环

# 鉴于往事有资于治道

## 📌 核心定义

> "鉴于往事，有资于治道"是宋神宗为《资治通鉴》所赐书名的含义。"资"指资助、帮助；"治道"指治理国家的方法。

这句话的含义是：**从历史事件中吸取经验教训，为当下的治理提供借鉴。** 这体现了司马光写作《资治通鉴》的目的：不是为历史而历史，而是为现实服务。

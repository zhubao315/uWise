# 建筑叙事法

## 📌 核心定义

> 建筑叙事法，是指通过建筑空间、构件细节、历史变迁来讲述历史故事的方法论。它将建筑视为一种特殊的"文本"，通过"阅读"建筑的空间布局、装饰细节、修缮痕迹和周边环境，还原出与建筑相关的历史事件、人物命运和文化变迁。

张克群在《北京古建筑物语》中示范了这种方法：她不从抽象的建筑理论出发，而是从具体的建筑故事入手——一座庙宇的兴衰、一座城门的拆除、一座四合院的易主——通过建筑的命运折射时代的变迁。书名中的"物语"二字，正暗示了这种方法的核心：建筑不是沉默的物质，而是会"说话"的历史见证者。

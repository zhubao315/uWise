# 诗言志

## 📌 核心定义

> "诗言志"出自《尚书·尧典》，是中国诗学的开山纲领。其含义是：**诗歌是表达内心志向、情感和思想的工具。**

"志"有多重含义：志向（抱负）、情感（喜怒哀乐）、意念（想法）。"诗言志"确立了中国诗歌"抒情言志"的传统，与西方诗歌的"叙事模仿"传统形成对比。

### 实际应用

在诗歌创作中，可依据“志”的多重内涵明确写作意图：若抒发个人抱负（如杜甫《望岳》），侧重意象的宏大与气骨；若宣泄喜怒哀乐（如李煜词作），则注重情感的细腻与真挚。在文学批评时，运用此理论分析作品需区分其是偏向“言志”（社会理想）还是“缘情”（个人情感），例如解读屈原《离骚》时需兼顾其政治志向与身世之悲，避免将“志”狭隘地仅理解为严肃的政治宣言。

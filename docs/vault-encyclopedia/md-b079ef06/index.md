# 没有绝对规则只有指导原则

## 📌 核心定义

> 酒食搭配最终是个人体验，规则是出发点不是终点——最重要的是个人喜好。

## 🎯 关键要点

- 酒食搭配最终是个人体验，规则是出发点不是终点——最重要的是个人喜好。
- 《酒食圣经》在介绍各种搭配规则后，反复强调这一点：所有规则都是"指导原则"，不是"绝对法则"。
- "红酒配红肉，白酒配白肉"是很好的出发点，但不是铁律。如果你特别喜欢用清爽的长相思搭配牛排，而且你觉得好吃，那就大胆搭配。规则是前人经验的总结，能帮助初学者避免明显错误，但不应该成为束缚创造力的牢笼。
- 这条原则的深层含义是：在任何领域，规则都是工具，不是目的。当你真正理解了规则背后的原理，你就有资格打破它。
- 初学者先学习基本规则，建立搭配基础
- 有经验后大胆尝试"违规"搭配，可能会有惊喜
- 关注搭配的"为什么"而非"是什么"，理解原理比记住规则更重要
- 最终以自己的味蕾为准，不盲从权威

## 🎯 关键要点

- TESCREAL框架是由哲学家埃米尔·格布鲁（Émile Torres）和蒂姆·格布鲁（Timnit Gebru）提出的批判性分析框架，用以描述七种相互关联的意识形态。这七种意识形态的首字母缩写构成了"TESCREAL"一词。
- TESCREAL代表：（1）Transhumanism（超人类主义）——通过技术增强人类身体和认知能力；（2）Extropianism（反熵主义）——追求无限进步，对抗宇宙熵增；（3）Singularitarianism（奇点主义）——相信技术奇点即将到来；（4）Cosmism（宇宙主义）——追求人类文明扩展至整个宇宙；（5）Rationalism（理性主义）——强调用逻辑和概率推理指导决策；（6）Effective Altruism（有效利他主义）——用证据最大化善行效益；（7）Longtermism（长期主义）——认为我们对未来世代负有重大道德责任。
- 格布鲁认为，这七种意识形态并非独立发展，而是共享一套深层假设：（1）技术进步本质上是好的；（2）人类可以通过理性设计出更好的未来；（3）当代人有权利（甚至有义务）决定人类文明的长期方向。这一思想谱系可以追溯到启蒙运动，经由20世纪的超人类主义运动，最终在硅谷技术精英中找到了最肥沃的土壤。

- 格布鲁提出TESCREAL框架的目的是批判性的。她认为这些意识形态存在以下问题：（1）精英主义——少数技术精英自认为有权决定全人类的未来；（2）殖民主义思维——将西方理性主义价值观普世化；（3）优生学历史关联——超人类主义与20世纪优生学运动有思想渊源。

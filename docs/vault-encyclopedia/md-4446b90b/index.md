# 视觉节奏

视觉节奏是画面中元素的**重复与变化**产生的韵律感。就像音乐中的节拍，视觉节奏引导观者的视线在画面中有序流动，产生阅读的快感。

## 节奏的类型

| 类型 | 特征 | 摄影应用 |
|------|------|---------|
| 重复节奏 | 完全相同的元素连续出现 | 拱门、柱子、路灯序列 |
| 渐变节奏 | 元素规律变化（大小/疏密/明暗） | 透视收缩的铁轨、渐远的树木 |
| 交替节奏 | ABABAB 模式交替 | 明—暗—明—暗的条纹光影 |
| 自由节奏 | 不规则重复但有内在秩序 | 自然场景中的石头、树叶 |

## 节奏的打断

连续节奏的**打断点**就是画面的视觉锚点——一行柱子中缺失的那一根、一排窗户中亮着灯的那一扇。没有打断的节奏是单调的背景，打断才是主体出现的位置。

## 节奏在摄影中的常见运用

- **引导线节奏**：栏杆、铁轨、墙沿形成视线引导
- **光影节奏**：阳光透过百叶窗投下的条纹阴影
- **色彩节奏**：红—白—红—白的排列
- **负空间节奏创建**：在空旷背景中有规律地摆放元素

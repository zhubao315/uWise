# Obsidian Canvas

> 重建笔记（08-22 断链补建，4x 引用）：正文已含功能说明与典型用法。

Obsidian 的无限画布功能：以卡片（笔记/文本/图片/文件）为节点自由连线，用于思维导图、白板推演与可视化知识组织。`.canvas` 为 JSON 格式文件，可版本控制。

## 典型用法

- 概念关系推演（节点=笔记，连线=关系）
- 项目白板 / 会议协作画布
- 与 wikilink 互补：线性链接 vs 空间布局

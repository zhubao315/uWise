# 三种自我状态

## 📌 核心定义

> 来源：《蛤蟆先生去看心理医生》（戴博德）

## 🎯 关键要点

- 大部分心理问题源于"卡在"儿童自我或父母自我状态中：无法进入成人自我状态。
- 人生脚本：每个人在童年时期就写好了自己的"人生脚本"——关于"我是谁""世界是什么样的"的核心信念。
- 心理游戏：人们会无意识地重复有预设结局的人际互动模式。
- 觉察自己的状态：问自己——"我现在处于哪种状态？"
- 切换到成人自我：当发现自己处于儿童自我或父母自我时，有意识地切换到成人自我。

## 📖 详细说明

### 概念解释
来源：《蛤蟆先生去看心理医生》（戴博德）
人的三种自我状态：

| 状态 | 特征 | 表现 |
|------|------|------|
| **儿童自我状态** | 顺从、讨好、叛逆、情绪化 | 童年时期形成的行为模式 |
| **父母自我状态** | 批评、控制、说教 | 内化了父母的声音 |
| **成人自我状态** | 理性、客观、自主 | 最健康的状态 |


### 实际应用

- **觉察自己的状态**：问自己——"我现在处于哪种状态？"
- **切换到成人自我**：当发现自己处于儿童自我或父母自我时，有意识地切换到成人自我。
- **改写人生脚本**：觉察童年写好的核心信念，用新的信念替代它。

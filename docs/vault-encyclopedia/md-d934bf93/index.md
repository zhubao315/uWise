# 情绪管理方法

## 📌 核心定义

> 识别、理解、调节和表达情绪的系统性操作方法。区别于"情绪管理"作为一种通用模型，本概念聚焦于具体可执行的技术——认知重评、正念觉察、情绪日记、呼吸调节等。这些方法是将心理学理论转化为日常情绪掌控力的桥梁。

## 🎯 关键要点

- **认知重评为核心**：改变对事件的解读框架，而非压制情绪本身。同样的刺激经不同解读会产生完全不同的情绪反应。
- **正念为觉察工具**：不评判地观察情绪的生灭，打破"情绪→自动反应"的惯性链条，在刺激和反应之间创造选择空间。
- **情绪日记为校准手段**：记录情绪触发事件、强度、持续时间和应对方式，长期积累后可发现个人情绪模式并提前干预。

# 防御型与进取型投资者

## 📌 核心定义

> 格雷厄姆将投资者分为两类：防御型（Defensive）追求安全省心、接受市场平均回报；进取型（Enterprising）投入大量时间研究、追求超越市场平均。这是投资者自我定位的基本框架。

## 🎯 关键要点

- **防御型**：用纪律代替判断、分散代替精选、耐心代替聪明；股债平衡（25%-75%，核心 50/50）+ 蓝筹/指数
- **进取型**：用深研代替分散、安全边际代替估值纪律；烟蒂股、困境反转、特殊情形
- **进取型门槛远高于防御型**：大多数自称"进取型"的投资者，实际只是"投机型"
- **自我定位**：诚实评估自己的时间、能力、心理素质，再决定类型
- **防御型选股量化标准**：PE<15 · PB<1.5 · PE×PB<22.5 · 流动比率≥2:1 · 10年连续正盈利 · 20年不间断分红

## 📖 详细说明

### 概念解释

格雷厄姆将投资者分为两类，这一分类至今仍是投资者自我定位的基本框架：

**防御型投资者（Defensive Investor）**：不愿花费大量时间和精力研究股票，追求安全和省心，能接受市场平均回报。策略是建立股债平衡的组合，买入大型、知名、财务稳健、有长期分红记录的公司，或直接购买指数基金。核心逻辑：用纪律代替判断，用分散代替精选，用耐心代替聪明。

**进取型投资者（Enterprising Investor）**：愿意投入大量时间研究，具备财务分析能力，追求超越市场平均的回报。可以投资"烟蒂股"（股价低于净流动资产）、困境企业、特殊情形（并购、分拆等）。核心逻辑：用深度研究代替分散化，用安全边际代替估值纪律，用耐心等待代替频繁交易。

### 实际应用

1. **自我定位**：诚实评估自己的时间投入能力、财务分析能力、心理素质，再决定选防御型还是进取型
2. **防御型执行**：股债平衡（50/50）+ 宽基指数/蓝筹 + 定投 + 每年再平衡
3. **进取型执行**：只在有充分时间与能力时才选择；否则宁可选择防御型
4. **警惕伪装**：多数自称"进取型"者实为投机型——用防御型纪律兜底

## 💡 个人理解

防御型与进取型的分类，本质是"诚实面对自己的能力圈"。**大多数人高估了自己的"进取"能力**——以为投入时间就能超越市场，实则既没时间也没心理素质，最终沦为投机。对我而言，最诚实的定位是：在没有充分时间与财务分析能力之前，用防御型的纪律（股债平衡+分散+长期）兜底，再逐步向进取型演进。**先做防御型，再谈进取型，是普通人最安全的成长路径。**

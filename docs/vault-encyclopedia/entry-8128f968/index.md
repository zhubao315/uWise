### 实际应用

**每季度做一次"社交圈审计"：**

1. **内圈（≤5人）**：核心家人、伴侣、最亲密的朋友
   - → 投入最多时间和情感，主动联系，不等对方找你
2. **中圈（≤15人）**：好朋友、重要合作伙伴、mentor
   - → 定期维护，每月至少一次有意义的交流
3. **外圈（其余所有人）**：普通朋友、同事、网友
   - → 礼貌回应但不主动投入，敢于说"不"

**关键原则：**
- 内圈的人值得你为他们打破规则
- 外圈的人应该用规则来管理（而非人情）
- 不要用对内圈的标准要求外圈的人（会失望）
- 不要用对外圈的敷衍对待内圈的人（会失去他们）

# SkillOpt技能优化

> 基于 Deliberate Practice（刻意练习）原则的技能提升框架——定位弱点、设计练习、获取反馈、迭代改进。

## 四步循环

```
1. 诊断 → 找出当前最大的技能瓶颈
2. 设计 → 针对瓶颈设计专项练习
3. 执行 → 专注练习，收集反馈数据
4. 评估 → 对比前后数据，确认进步
```

## 与普通练习的区别

| 维度 | 普通练习 | SkillOpt |
|------|---------|----------|
| 目标 | 重复已会的 | 攻克不会的 |
| 反馈 | 模糊感觉 | 量化指标 |
| 难度 | 舒适区 | 学习区边缘 |
| 时长 | 越长越好 | 高质量短时段 |

## 实践要点

1. **一次只练一个子技能**：避免多线程分散注意力
2. **设置明确的成功标准**：「做到 X 算过关」
3. **记录练习日志**：每次练习的条件、结果、感受
4. **寻求外部反馈**：教练/同行/录像回放

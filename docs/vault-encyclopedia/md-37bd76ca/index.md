# 魔幻现实主义叙事

## 📌 核心定义

> 魔幻现实主义（Magical Realism）是马尔克斯在《百年孤独》中运用的标志性叙事技术。它的核心特征不是"在现实中添加魔幻元素"，而是以一种完全平静、理性的语气叙述超自然事件，仿佛这些事件和吃饭、睡觉一样平常。

马尔克斯的名言是："我外祖母讲故事的时候，无论多离奇的事，她都讲得不动声色，好像那是她亲眼所见。"这种叙述方式创造了一种独特的阅读体验：读者无法区分哪些是"真实的"，哪些是"魔幻的"，因为叙述者自己也不区分。美人蕾梅黛丝抓着床单飞上天空，和香蕉公司屠杀三千人——在马尔克斯的笔下，它们具有同等的叙事权重。

这个概念的技术核心在于"语气的一致性"。当叙述者以同样的平静语气讲述现实和魔幻时，读者被迫接受魔幻是现实的一部分。这不是逃避现实，而是以一种更丰富的维度呈现现实——拉丁美洲的现实本身就充满了常理无法解释的事物。

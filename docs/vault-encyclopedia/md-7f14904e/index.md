# 职业燃料四要素

## 📌 核心定义

> 💡 职业燃料的核心逻辑：不要问"我现在能赚多少"，要问"我的燃料储备是否在增长"。

## 🎯 关键要点

- **可迁移技能**：沟通、解决问题、项目管理等跨岗位通用能力，是职业转换时的硬通货——它决定你能在多少个领域生存。
- **有意义的经验**：独特项目、跨文化经历、危机处理等差异化经历，构成你的职业故事线——它决定你能获得什么级别的机会。
- **持久的关系**：导师、同行、下属等长期信任网络，是信息和机会的放大器——它决定你能触达多远的资源。
- **学习敏捷性**：快速学习新领域、适应变化、从失败中提取教训的能力——它决定你的燃料能用多久，是唯一不会贬值的燃料。

## 📖 详细说明

### 概念解释
职业生涯的持久竞争力不取决于单一技能或一时机遇，而是由四种"燃料"持续供给：可迁移技能、有意义的经验、持久的关系、学习敏捷性。这四者像汽车的燃油系统，缺任何一项都会在职业长跑中抛锚。关键是定期盘点、主动补给，而非等到危机时才匆忙加油。

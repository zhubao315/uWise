# 围城困境

## 📌 核心定义

> 《围城》的核心隐喻：城外的人想进去，城里的人想出来。婚姻、职业、人生选择无不如此——欲望的本质是不满足。这一困境揭示了人类永恒的生存悖论：我们追求的目标一旦实现就失去吸引力，而我们永远在追逐下一个目标。

## 🎯 关键要点

- **欲望的悖论**：人对"未得到"的渴望驱动一切选择，但得到之后渴望即消退，形成永恒的追逐循环。
- **普适的人生困境**：不止于婚姻——留学/归国、体制内/体制外、单身/恋爱，一切人生选择都是围城。

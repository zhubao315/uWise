# Datadog

> 云原生可观测性平台——统一 APM、日志、基础设施监控、安全分析。

## 核心产品

| 产品 | 功能 |
|------|------|
| APM | 分布式追踪、服务拓扑、性能分析 |
| Logs | 日志采集、解析、告警 |
| Infrastructure | 服务器/容器/云资源监控 |
| RUM | 真实用户监控（前端性能） |
| Security | 运行时安全检测（CIEM/CSPM） |

## 竞品对比

| 平台 | 优势 | 劣势 |
|------|------|------|
| Datadog | 开箱即用、集成丰富 | 成本高、数据量大时贵 |
| Grafana | 开源、灵活、便宜 | 需自行搭建运维 |
| New Relic | 免费额度大、全栈 | 查询语言学习曲线 |

## 典型使用场景

- 微服务架构的链路追踪
- Kubernetes 集群健康监控
- 多云环境统一仪表盘
- SLO/SLA 自动化追踪

# 黑人民族认同

## 📌 核心定义

> 哈莱姆文艺复兴的核心主题，休斯是其最有力的诗人代言人：黑人不能以白人的审美和标准定义自己，必须从黑人自身的历史、文化传统、日常生活和语言中建立自豪的身份认同。休斯的宣言非常清晰——"黑人"不是一个需要被克服的缺陷，而是一个值得被歌唱的身份。

## 🎯 关键要点

- **拒绝白化**：不模仿、不迎合、不寻求白人的认可——黑人的美和力量来自自己的传统
- **文化的根部**：非洲的音乐、节奏、叙事传统、宗教经验是黑人身份的深层来源
- **自尊的政治**：身份认同运动首先是心理解放——在被贬低了几个世纪后重建对自己的骄傲

# 欲望预算冷静期

## 📌 核心定义

> 欲望无穷，预算是缰绳：非必要支出设 72 小时冷静期，冲动多半自行熄灭。

- 先区分“必要”与“想要”，想要一律进清单

- 预算不是苦行，是给欲望排优先级

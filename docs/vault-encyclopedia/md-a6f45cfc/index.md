# 增强回路起点法

## 📌 核心定义

> 关键洞见：一天中最初的选择（如起床后的第一个行为）会像多米诺骨牌一样影响后续所有行为的方向。在意志力最充沛的起点做正确的事，成本最低、收益最大。

## 🎯 关键要点

- **起点选择决定方向**：增强回路的起点是一天中最关键的决策时刻。起床后刷手机→信息过载→注意力碎片化→一天低效；起床后阅读/运动→精神集中→正向循环→一天高效。同样的意志力，用在起点的效果远大于用在中途。
- **降低启动难度是核心策略**：不要依赖意志力去对抗本能脑和情绪脑，而是通过环境设计让"正确的选择"变成"最容易的选择"。提前准备好所有启动条件——运动衣放在床头、书翻开在桌上、文档打开在屏幕上——让开始变得毫不费力。
- **正向反馈驱动自动增强**：增强回路需要反馈来维持。在习惯启动后，设计即时的正向反馈（记录完成、打勾标记、小小奖励），让情绪脑感受到"这样做很爽"，从而推动它主动重复这个行为。
- **警惕负向回路的陷阱**：负向增强回路同样存在——一次放纵→自我否定→更多放纵→更深的自我否定。识别负向回路的起点，用一个微小的正向行为打断它，比试图用意志力硬扛要有效得多。

## 📖 详细说明

### 概念解释
在增强回路的起点做出正确选择，消耗的意志力最小。行为一旦进入增强回路，就会自动向正向或负向不断放大。因此，**关键不在于过程中如何坚持，而在于起点如何选择。** 设计好习惯的启动环节，让本能脑和情绪脑成为助力而非阻力。

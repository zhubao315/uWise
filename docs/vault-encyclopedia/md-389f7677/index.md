# 择偶策略的进化

## 📌 核心定义

> 进化心理学发现，男性和女性在择偶策略上有系统性差异——源于"亲代投资理论"。

## 🎯 关键要点

- 亲代投资理论：投资更多的一方（通常是女性）在择偶时更挑剔。
- 嫉妒的进化功能：嫉妒是"伴侣守护"机制——提醒注意潜在威胁。
- 理解不等于辩护：进化心理学解释行为的起源，但不意味着这些行为是"好的"。
- 理解择偶行为：从进化角度理解男女择偶差异——不是"肤浅"，而是进化出来的偏好。
- 管理嫉妒情绪：理解嫉妒的进化功能——它是保护关系的机制，但不要让它控制行为。

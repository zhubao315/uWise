# 去个性化

## 📌 核心定义

> 来源：《乌合之众》（勒庞）《社会心理学》（迈尔斯）

## 🎯 关键要点

- 匿名性：在匿名环境中（如网络、群体），更容易出现极端行为。
- 责任分散：在群体中，个人责任感降低——"不是我一个人做的"。
- 情绪传染：情绪在群体中快速传播——一个人的恐慌可以瞬间传染给所有人。
- 网络暴力：匿名性导致去个性化——更容易攻击他人。
- 群体骚乱：在群体中，个人身份感消失——更容易做出极端行为。

来源：《乌合之众》（勒庞）《社会心理学》（迈尔斯）

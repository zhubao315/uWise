# 储蓄先行原则

## 📌 核心定义

> 先储蓄，再消费。不是收入 - 支出 = 储蓄，而是收入 - 储蓄 = 支出。

## 🎯 关键要点

- **传统思维**：收入 - 支出 = 储蓄（月底看看剩多少）
- **正确思维**：收入 - 储蓄 = 支出（先存起来，用剩下的生活）

## 核心流程

```
建模 → 材质/纹理 → 灯光 → 相机 → 动画 → 交互 → 优化
```

## 性能优化要点

- **LOD（Level of Detail）**：远距离用低模
- **遮挡剔除**：不可见物体不渲染
- **纹理压缩**：使用 ASTC/ETC2 格式
- **实例化渲染**：相同模型一次 Draw Call

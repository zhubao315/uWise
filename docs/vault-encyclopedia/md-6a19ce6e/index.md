# 杜邦分析法

## 📌 核心定义

> 杜邦分析法（DuPont Analysis）由美国杜邦公司于20世纪20年代首创，是将净资产收益率（ROE）分解为三个驱动因素的综合财务分析框架：ROE = 净利率 × 资产周转率 × 权益乘数。唐朝在《手把手教你读财报》中将其作为理解企业盈利能力的核心工具。

## 🎯 关键要点

- **净利率（Net Profit Margin）**= 净利润 / 营业收入。衡量企业每单位收入能转化为多少利润，反映定价权和成本控制能力。高净利率通常意味着品牌溢价或垄断优势。
- **资产周转率（Asset Turnover）**= 营业收入 / 总资产。衡量企业运用资产创造收入的效率，反映管理层运营能力。高周转率常见于零售、快消等行业。
- **权益乘数（Equity Multiplier）**= 总资产 / 股东权益。衡量企业的财务杠杆水平，反映负债经营程度。权益乘数越高，杠杆越大，风险也越大。
- **高净利率型**：如白酒、奢侈品行业，靠品牌和定价权取胜，核心护城河在于品牌壁垒。
- **高周转型**：如沃尔玛、Costco，靠薄利多销取胜，核心护城河在于供应链效率和规模效应。

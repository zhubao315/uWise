# 幂律法则

## 📌 核心定义

> 幂律法则（Power Law）描述的是这样一种分布规律：少数极端事件贡献了大部分结果。在风险投资领域，这意味着一只基金的最好投资回报往往超过其他所有投资的总和。这不是比喻，而是经过大量数据验证的统计事实。

## 🎯 关键要点

- 不要追求投资组合的"分散化"：。如果你投了20个"还不错"的项目，你大概率会获得平庸的回报。
- 要集中到少数"可能改变世界"的项目：。宁可投1个有潜力产生1000倍回报的项目，也不要投10个有望产生10倍回报的项目。
- 不要用平均回报来评估基金：。一只基金的中位数投资可能是亏损的，但只要有一笔大赢家就够了。

### 实际应用

在构建投资组合时，应放弃追求“分散化”的平庸策略，将资金集中配置于少数具备颠覆性潜力的项目，以博取可能覆盖整体亏损的极端回报。评估基金或项目绩效时，需摒弃基于平均值的线性思维，转而关注头部项目的爆发力，接受中位数投资亏损的现实，只要有一笔大赢家即可实现整体盈利。

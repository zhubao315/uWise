# 历史地理学的空间叙事

## 📌 核心定义

> 历史地理学的空间叙事是一种研究方法和叙事策略，其核心理念是：历史不是发生在"空中"的，而是发生在具体的山川河流之间。通过将历史事件还原到其所处的地理空间中，可以发现许多在传统线性时间叙事中被忽略的深层逻辑。刘东黎在《北京当历史成为地理》中将这一方法发展为"空间-时间"双轴分析框架：用空间换时间，从地理角度重读历史。

这一方法的核心命题是"地理是历史的容器，历史是地理的注释"。地理环境提供了人类活动的舞台和约束条件，而人类活动又不断改造和重塑地理空间。北京的历史不是线性的时间堆积，而是地理空间与人类活动的双向塑造——每一次城址迁移、每一处建筑布局，都是对地理条件的回应与超越。

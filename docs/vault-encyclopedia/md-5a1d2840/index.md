# 闲聊法调研框架

## 📌 核心定义

> 闲聊法（Scuttlebutt Method）由菲利普·费雪提出，指通过与企业的竞争对手、供应商、客户、前员工、行业专家等进行非正式交谈，获取关于企业真实经营状况的第一手信息。费雪认为，这种方法比单纯阅读财务报表更能揭示企业的竞争优势和管理质量。来源：《怎样选择成长股》（菲利普·费雪，1958年）。

## 🎯 关键要点

- **信息不对称的破解**：财务报表是企业希望你看到的信息，而竞争对手和客户的评价往往更客观、更真实。闲聊法的核心价值在于从多个独立信源交叉验证企业的真实竞争力。
- **关键访谈对象**：竞争对手（了解对手如何看待这家企业）、供应商（了解付款信用和采购量趋势）、客户（了解产品满意度和替代意愿）、前员工（了解企业文化和管理问题）、行业专家（了解行业格局和技术趋势）。
- **渐进式深入**：先从公开信息建立初步假设，再通过闲聊验证或推翻假设，最后形成对企业"护城河"的独立判断。费雪强调，好的投资决策来自于对企业长期前景的深刻理解，而非短期财务数据的精确计算。
- **质量重于数量**：与其泛泛调查100家公司，不如深入调研5家公司。费雪一生只投资了少量股票，但每一只都经过了极为深入的调研。

## 📖 详细说明

### 概念解释
闲聊法（Scuttlebutt Method）由菲利普·费雪提出，指通过与企业的竞争对手、供应商、客户、前员工、行业专家等进行非正式交谈，获取关于企业真实经营状况的第一手信息。费雪认为，这种方法比单纯阅读财务报表更能揭示企业的竞争优势和管理质量。来源：《怎样选择成长股》（菲利普·费雪，1958年）。


### 实际应用

- **成长股筛选**：当你发现一家高增长企业时，先不要急着看财务数据，而是打电话给它的客户，问"如果有一款替代产品，你会换吗？"客户的犹豫程度就是护城河的深度。
- **行业研究**：进入一个新行业时，先拜访3-5家供应商，了解谁是他们的最佳客户、谁的付款最准时、谁的采购量在增长，这些信息比任何行业报告都更有价值。
- **管理层评估**：通过与前员工交谈，了解管理层是否言行一致、是否真正重视长期发展而非短期股价。

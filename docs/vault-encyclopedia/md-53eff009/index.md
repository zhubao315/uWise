# 什么是执行力

## 📌 核心定义

## 💬 一句话浓缩

> **执行力，是允许起步不完美，先行动，在过程中学习、调整、沉淀、精进。**

## 要点拆解

- **共同骨架**：每条路径都是「先粗后细、先动后精」——拒绝"准备完美再出发"。
- **启动优先**：第一步的价值不在于正确，而在于让反馈循环转起来。
- **迭代闭环**：行动 → 复盘 → 优化，是让结果逐步逼近目标的引擎。

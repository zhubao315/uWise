# 长期主义投资原则

## 📌 核心定义

> "最好的持有期限是永远。" —— 沃伦·巴菲特

## 🎯 关键要点

- **时间是朋友**：复利需要时间来发挥作用
- **忽略短期波动**：短期市场是投票机，长期是称重机
- **持有优质资产**：只买你愿意持有 10 年的资产
- **减少交易**：每次交易都有成本（手续费、税费、时间）

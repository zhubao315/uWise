# 数据分区

## 📌 核心定义

> 数据分区（Data Partitioning，也称分片Sharding）是将大数据集拆分到多个节点的技术，是构建可扩展分布式系统的核心手段。

## 🎯 关键要点

- 优势：支持高效的范围查询（"查询ID在100-200之间的所有用户"）。
- 劣势：如果键分布不均匀，容易产生热点。例如按时间戳分区时，所有写入都集中在最新的分区上。
- 优势：数据分布均匀，避免热点问题。
- 劣势：丧失键的顺序信息，范围查询需要扫描所有分区。

## 📖 详细说明

### 概念解释
数据分区（Data Partitioning，也称分片Sharding）是将大数据集拆分到多个节点的技术，是构建可扩展分布式系统的核心手段。
### 按键范围分区

将数据按键的连续范围分配到不同节点。例如用户ID 1-1000在节点A，1001-2000在节点B。

- **优势**：支持高效的范围查询（"查询ID在100-200之间的所有用户"）。
- **劣势**：如果键分布不均匀，容易产生热点。例如按时间戳分区时，所有写入都集中在最新的分区上。

### 按哈希分区

对键取哈希值，按哈希值分配节点。相同哈希值的数据落在同一节点。

- **优势**：数据分布均匀，避免热点问题。
- **劣势**：丧失键的顺序信息，范围查询需要扫描所有分区。

# 白板说

## 📌 核心定义

> 白板说是一个重要的知识概念。

## 🎯 关键要点

- 行为遗传学：基因对人格和智力有显著影响（约50%）。
- 进化心理学：人类有进化出来的心理机制。
- 跨文化研究：某些行为模式在所有文化中都存在。
- 基因和环境交互作用：不是对立的，而是相互影响的。
- 承认人性不等于为不公正辩护：理解人性是为了更好地应对它。

## 📖 详细说明

### 概念解释
来源：《白板》（平克）
**白板说**认为：人类心灵在出生时是"空白"的，完全由环境塑造。

**平克的反驳**：
- **行为遗传学**：基因对人格和智力有显著影响（约50%）。
- **进化心理学**：人类有进化出来的心理机制。
- **跨文化研究**：某些行为模式在所有文化中都存在。


### 实际应用

- **理解个体差异**：接受个体差异是真实存在的——不是教育的失败，而是基因的影响。
- **避免极端思维**：不是"基因决定一切"，也不是"环境决定一切"——是两者的交互。
- **教育启示**：教育应该适应个体差异——不是所有孩子都一样。

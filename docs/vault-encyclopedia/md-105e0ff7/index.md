# 路径依赖

## 📌 核心定义

> 路径依赖（Path Dependence）指历史路径对当前结果的决定性影响——当前状态不仅取决于当前条件，更取决于到达此处的特定序列。塔勒布在《随机漫步的傻瓜》中强调，随机事件的序列效应使得"最终赢家"未必是最有能力的人，而可能是路径上碰巧获得早期优势的人。这一概念最早由经济学家保罗·大卫（Paul David）在QWERTY键盘研究中提出，后被布莱恩·阿瑟（W. Brian Arthur）发展为正反馈理论。

## 🎯 关键要点

- **序列依赖**：相同的事件以不同顺序发生，会导致完全不同的结果。A→B 与 B→A 的效果可能截然相反
- **正反馈锁定**：早期的微小优势通过正反馈机制被放大，最终形成不可逆转的锁定效应。QWERTY键盘、VHS vs Betamax都是经典案例
- **能力与运气的混淆**：在路径依赖的世界里，成功者往往被高估——他们的成功可能只是早期随机优势的累积放大，而非持续能力的体现
- **不可逆性**：一旦进入特定路径，转换成本极高，即使发现更优路径也难以切换

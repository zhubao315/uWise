# 偏差-方差权衡模型

## 📌 核心定义

> **核心原理**：模型的泛化误差可以分解为偏差、方差和噪声三个部分，降低偏差往往增加方差，降低方差往往增加偏差，两者的平衡是模型调优的核心。

## 🎯 关键要点

- **核心原理**：模型的泛化误差可以分解为偏差、方差和噪声三个部分，降低偏差往往增加方差，降低方差往往增加偏差，两者的平衡是模型调优的核心。
- **泛化误差 = 偏差² + 方差 + 不可约噪声**
- 定义：模型预测的期望值与真实值之间的差距
- 来源：模型假设过于简化，无法捕捉数据的真实模式
- 表现：系统性偏离，无论训练数据如何变化都会存在
- 高偏差 → 欠拟合（Underfitting）
- 典型场景：用线性模型拟合非线性数据
- 定义：模型预测值在不同训练数据集上的变化程度

## 📖 详细说明

### 概念解释
**核心原理**：模型的泛化误差可以分解为偏差、方差和噪声三个部分，降低偏差往往增加方差，降低方差往往增加偏差，两者的平衡是模型调优的核心。
泛化误差的分解公式：

**泛化误差 = 偏差² + 方差 + 不可约噪声**

### 组成部分

#### 偏差（Bias）
- 定义：模型预测的期望值与真实值之间的差距
- 来源：模型假设过于简化，无法捕捉数据的真实模式
- 表现：系统性偏离，无论训练数据如何变化都会存在
- 高偏差 → 欠拟合（Underfitting）
- 典型场景：用线性模型拟合非线性数据

#### 方差（Variance）
- 定义：模型预测值在不同训练数据集上的变化程度
- 来源：模型过于复杂，对训练数据中的噪声过度敏感
- 表现：在不同训练集上训练出的模型差异很大
- 高方差 → 过拟合（Overfitting）
- 典型场景：用高阶多项式拟合少量数据点

#### 噪声（Noise）
- 定义：数据本身的随机误差，任何模型都无法消除
- 来源：数据采集误差、内在随机性
- 是泛化误差的下界，决定了模型性能的理论上限

### 权衡关系

| 模型复杂度 | 偏差 | 方差 | 总误差 |
|-----------|------|------|--------|
| 低（简单模型） | 高 | 低 | 高（欠拟合） |
| 中（适当模型） | 中 | 中 | 低（最佳平衡） |
| 高（复杂模型） | 低 | 高 | 高（过拟合） |


### 实际应用

- 模型选择时，判断应该用更简单还是更复杂的模型
- 模型调优时，诊断当前问题是偏差还是方差导致的
- 评估模型改进方向时，确定是增加模型复杂度还是增加训练数据
- 理解集成学习（Bagging 降方差、Boosting 降偏差）的原理

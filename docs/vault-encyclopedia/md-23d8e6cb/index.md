# 价值链分析模型

## 📌 核心定义

> 价值链分析模型（Value Chain Analysis）由迈克尔·波特在《竞争优势》和《竞争战略》中提出，将企业的经营活动分解为一系列创造价值的环节，通过分析每个环节的成本结构和价值贡献，识别企业的竞争优势来源和改进空间。

## 🎯 关键要点

- **内部物流（Inbound Logistics）**：原材料接收、存储和分配。高效的库存管理和供应链协调可降低成本。
- **生产运营（Operations）**：将投入转化为最终产品。制造效率、质量控制和技术水平直接影响产品竞争力。
- **外部物流（Outbound Logistics）**：产品的收集、存储和配送。物流网络的覆盖范围和效率影响客户体验。
- **市场与销售（Marketing & Sales）**：产品推广、定价、渠道管理。品牌建设和客户获取能力是关键。
- **服务（Service）**：售后支持、维修、客户关系维护。服务质量和客户满意度影响复购和口碑。

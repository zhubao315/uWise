# 身心健康管理

## 📌 核心定义

> 以系统性方法管理身体和心理健康的整体框架。不只关注"不生病"，而是主动优化精力水平、情绪稳定性和长期健康寿命。睡眠、营养、运动、压力管理和心理健康监测是五大支柱，它们的协同效应远大于各自独立作用之和。

## 🎯 关键要点

- **五维协同**：睡眠是恢复基础、营养是燃料质量、运动是硬件维护、压力管理是系统减负、心理监测是早期预警。任一维度塌陷都会拖累整体。
- **量化为前提**：不可衡量则不可管理。睡眠时长与质量、心率变异性(HRV)、体脂率、情绪评分等指标构成健康仪表盘。
- **长寿逃逸速度的基础层**：在基因决定约30%寿命上限的前提下，生活方式管理是普通人掌控70%寿命变量的唯一手段。

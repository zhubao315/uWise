# 客户成功与扩展

> 确保客户实现预期价值并驱动增购/续约的系统方法。

## 核心指标

| 指标 | 公式 |
|------|------|
| **NRR**（净收入留存率） | (期初收入+增购-流失-降级) / 期初收入 |
| **NPS**（净推荐值） | 推荐者% - 贬损者% |
| **健康评分** | 使用频率+功能覆盖+支持互动 |

## 客户生命周期

```
签约 → 交付 → 激活 → 采用 → 扩展 → 续约
```

## 扩展策略

1. **使用量扩展**：用量增长自然带动付费增长
2. **功能升级**：高级功能解锁更高套餐
3. **席位扩展**：更多团队成员使用
4. **交叉销售**：购买其他产品线

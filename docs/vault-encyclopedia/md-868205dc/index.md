# 舒适区理论

## 📌 核心定义

> 人的心理状态分为舒适区、学习区和恐慌区三个区域，成长发生在学习区。

## 🎯 关键要点

- **舒适区**：熟悉的、无压力的区域，不产生成长
- **学习区**：适度挑战的区域，最佳学习发生在此
- **恐慌区**：超出能力范围的区域，导致焦虑和退缩
- **扩展舒适区**：通过持续在学习区练习，舒适区逐渐扩大

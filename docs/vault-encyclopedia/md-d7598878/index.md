# 信贷周期

## 📌 核心定义

> 信贷周期（Credit Cycle）是霍华德·马克斯《周期》中经济与市场周期的放大器：信贷扩张期，银行放松贷款标准、杠杆上升、资产价格被推高；信贷收缩期，标准收紧、去杠杆、资产价格被压低。**信贷周期的转折点往往是市场周期的转折点。**

## 🎯 关键要点

- **信贷扩张期**：贷款标准放松 → 融资成本↓ → 杠杆↑ → 资金追逐资产 → 价格↑ → 信心↑ → 风险偏好↑（增强回路）
- **信贷收缩期**：反向恶性循环——融资困难 → 被迫去杠杆 → 抛售资产 → 价格↓ → 信心↓
- **四条传导机制**：融资成本 / 杠杆水平 / 资产价格 / 信心水平
- **观测指标**：信用利差（高收益债-国债利差，收窄=风险偏好高）、IPO 数量与首日涨幅、整体杠杆水平、VIX
- **顶底信号**：信贷扩张极限≈市场顶部；信贷收缩极限≈市场底部
- **政策关系**：低利率/量化宽松可以推迟收缩，但积累更大泡沫（"这次不一样"的温床）

## 📖 详细说明

### 概念解释

信贷是周期家族的"油门与刹车"：它不创造周期，但决定周期的**摆幅**。经济周期是基础层，盈利周期用经营杠杆/财务杠杆放大经济波动，信贷周期则同时放大两者——因为信贷既影响实体（企业融资/投资），又影响市场（投资者杠杆/资金供给）。

典型案例是 2008 年：危机前银行放松标准发放次级贷款 → 房地产与金融市场快速上涨；违约率上升 → 标准收紧、信贷快速收缩 → 市场暴跌。理解信贷周期的投资者在危机前降杠杆、危机中配置优质资产，获得超额回报。

### 实际应用

1. **利差监测**：把"信用利差分位"加入周期定位仪表盘——利差收窄至极值=风险偏好极端（顶部信号），扩大至极值=底部信号
2. **杠杆自检**：个人/组合杠杆水平与信贷周期对齐——收缩期主动降杠杆（不等市场逼你降）
3. **系统迁移**：任何依赖"外部供给"的系统都有信贷周期——知识库依赖"输入供给"（新书/新信息），供给过剩期囤积、供给稀缺期消化，节奏同构

# 柳比歇夫时间统计

> 苏联科学家柳比歇夫的时间记录方法——通过精确记录时间使用，实现时间感知的质变。

## 核心方法

```
每天记录：做了什么 + 用了多长时间
每周/月/年：统计各类时间占比
对比分析：时间分配 vs 产出
```

## 记录格式

```
1982年3月7日
分类工作 — 5小时15分
看报 — 25分
散步 — 1小时30分
...
合计：8小时30分
```

## 为什么有效

1. **量化感知**：知道自己时间花在哪
2. **减少浪费**：意识到低效活动
3. **优化分配**：调整时间投入比例
4. **长期积累**：年度统计揭示模式

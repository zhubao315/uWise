# 自住房与居住成本

## 📌 核心定义

> 把房租变成资产：自住房是有利投资，但前提是持有成本低于租房且不透支未来。

## 🎯 关键要点

- 原意是降低刚性居住成本，不是鼓励加杠杆
- 结合《通往财富的简单之路》4% 公式：年租÷房价≥4% 才考虑买
- 持有成本（物业＋维修＋利息）超租金 1.5 倍就租
- 首付挤占全部流动性＝把城墙拆了盖房子
- 居住决策先算账，后谈情怀

## 📖 详细说明

### 出处
七法则之五，现代版见买房租房公式。

### 应用
看房前先算 rent-price 比与持有成本，算不过就安心租＋差额定投。

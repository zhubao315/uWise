# 香气演化时间轴

## 📌 核心定义

> 葡萄酒的香气随时间推移从品种香→工艺香→陈年香依次演化，三类香气此消彼长，构成完整的风味生命周期。

## 🎯 关键要点

- 葡萄酒的香气随时间推移从品种香→工艺香→陈年香依次演化，三类香气此消彼长，构成完整的风味生命周期。
- **核心因果链：** 时间是驱动香气演化的关键变量。新鲜饮用时以一类香为主，中期（3-10年）二类香整合，长期陈年（10年+）三类香逐渐主导。
- 1. **判断饮用时机：** 一款酒如果一类香（果香）已明显衰退但三类香尚未发展出来，说明正处于"封闭期"，不宜此时饮用。
- 2. **配酒策略：** 年轻酒配轻盈菜肴突出果香；中期酒配烤肉突出工艺复杂度；老年份酒配蘑菇/松露菜呼应陈年香。
- 3. **品酒训练：** 品尝同一酒庄不同年份垂直品鉴，体会三类香气的时间演化规律。

# 未来自我

## 📌 核心定义

> Nick Milo 的知识管理时间维度概念：现在写的每一篇笔记，都是给未来的自己留下的礼物。写作时需要想象——未来的自己在什么情境下、遇见了什么问题、会需要这条信息？用这个视角写笔记，笔记才具有跨越时间的价值。

## 🎯 关键要点

- **时间思维**：今天的你写笔记时精力充沛、情境清晰；未来的你读到它时可能疲惫、遗忘、处于不同上下文
- **可发现性**：笔记必须让未来的自己"能找到"——标题清晰、标签准确、连接充分，而非藏在一堆文件夹深处
- **可复用性**：笔记不是一次性消费品，而应该是可以反复在不同情境下被激活的"思维资产"

# 三脑协调驾驭法

## 📌 核心定义

> 理智脑不是本能脑和情绪脑的敌人，而是它们的引导者。——周岭

## 🎯 关键要点

- 理智脑不是本能脑和情绪脑的敌人，而是它们的引导者。——周岭
- **大脑由三层结构组成，成长的本质是让理智脑学会"驾驭"而非"压制"本能脑和情绪脑。**
- **关键洞察**：骑手（理智脑）的力量远不如两匹马（本能+情绪），硬拉缰绳只会两败俱伤。聪明的做法是**理解马的习性，顺势引导**。

- **用情绪脑造势**：想象完成任务后的成就感和画面，让情绪脑成为助力而非阻力
- **用元认知做旁观者**：练习在情绪涌起时"暂停3秒"，让理智脑有机会介入
- ❌ 靠意志力硬抗 → 理智脑很快耗尽，必然失败

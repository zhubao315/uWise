# 获客提案与优惠设计

> 设计有吸引力的获客方案和优惠策略，降低获客成本。

## 获客漏斗

```
曝光 → 点击 → 注册 → 激活 → 付费 → 留存
```

## 优惠类型

| 类型 | 特点 |
|------|------|
| **新客专享** | 首单折扣/免费试用 |
| **限时优惠** | 制造紧迫感 |
| **裂变优惠** | 邀请返利/拼团 |
| **会员权益** | 长期价值锁定 |

## 设计原则

1. **锚定效应**：展示原价和现价对比
2. **损失厌恶**：「错过即损失」比「获得」更有效
3. **互惠原则**：先给予再索取
4. **社会证明**：已有 N 人参与

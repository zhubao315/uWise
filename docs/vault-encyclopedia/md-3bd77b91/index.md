# 混合笔记法

## 📌 核心定义

> zsolt 提倡的笔记策略：文字、视觉、结构三种表达方式混合使用，互不替代。每种信息类型都有最适合的表达媒介——逻辑论证适合文字，空间关系适合图表，层次关系适合结构布局。

## 🎯 关键要点

- **多种媒介**：不要一切信息都用纯文字或纯图表——叙事用文字、流程用箭头、层次用缩进、对比用表格
- **媒介匹配**：选择媒介的原则是"让信息的结构自然显现"——如果你在文字中用三句话描述一个空间关系，不如画出来
- **互不替代**：图表不能替代文字的解释功能，文字不能替代图表的空间呈现功能——二者互补而非竞争

# 中央电视台电视文化中心

中央电视台电视文化中心，英文简称**TVCC（Television Cultural Center）**，俗称「央视北配楼」，是中央电视台总部建筑群的核心组成部分，与南侧的央视总部主楼（俗称「大裤衩」）共同构成北京CBD的标志性传媒综合体，也是总台线下文化活动、节目录制、展览展陈的核心承载空间。

## 项目定位与规划缘起

央视总部园区整体定位为全球顶级的广播电视传媒综合体，由两部分功能互补：

- 南侧主楼：核心办公、新闻制播、节目生产中枢，属于内部核心工作区，管理严格；
- 北侧配楼（电视文化中心）：**传媒文化对外窗口**，承担公共文化展演、节目录制、大型活动、配套服务功能，是央视面向公众、对接行业的文化界面。

项目由荷兰OMA事务所（雷姆·库哈斯团队）统一设计，延续了解构主义建筑风格，与主楼环形倾斜的造型形成视觉呼应，共同组成完整的城市地标群落。

## 建设历程：从奠基到波折

1. **启动奠基**：2004年9月，央视新址项目整体奠基开工，电视文化中心与主楼同步建设，原计划2008年北京奥运会前全面投用，承担奥运赛事转播配套、新闻发布等功能。
2. **建筑参数**：建筑高约159米，地上30层、地下3层，总建筑面积约11万平方米，内部涵盖剧场、演播厅、录音棚、展览空间、酒店、会议中心等多元业态。
3. **功能分区**
   - 地下层：设备机房、地下停车场；
   - 低区（1-8层）：1500座专业剧场、大型演播厅、多间录音棚、展览展厅、新闻发布厅、文创与配套商业；
   - 中区：会议中心、节目制播技术配套用房；
   - 高区：高端接待酒店与配套服务。

## 2009年火灾事件

这是配楼历史上最受关注的节点，也推动了国内建筑防火规范的升级。

1. **事发经过**：2009年2月9日（农历正月十五元宵节），央视新址建设部门违规在园区内燃放A级大型烟花，火星引燃建筑外墙的挤塑板保温材料，火势沿外立面快速蔓延，造成严重火灾。
2. **事故后果**：建筑外立面、内部装修与机电设备大面积损毁；经检测主体结构完好，未受根本性破坏；事故造成消防人员伤亡，相关责任人被依法追责。
3. **行业影响**：该事件成为国内建筑防火规范收紧的标志性事件，直接推动了全国公共建筑外墙保温材料防火标准的全面升级。

## 修复复建

火灾后经过一年多的方案论证，2010年修复工程正式启动，核心原则是**保留原建筑设计外观，全面升级安全标准**：

- 全部拆除原有外墙体系，更换为A级防火标准的幕墙与保温材料，全楼升级消防喷淋、智能火灾报警与疏散系统；
- 内部空间按原功能定位重新设计装修，优化安全动线与技术配置；
- 外观上与原设计几乎完全一致，最大程度保留了OMA的原始建筑设计理念。

2012年底修复工程全面完工，2013年起逐步投入使用，重新成为央视文化活动与节目制作的重要阵地。

## 现状与运营

1. **核心功能**：如今是中央广播电视总台重要的线下文化空间，承接各类书画展、艺术展、文化论坛、节目录播、发布会等活动，也是总台「思想+艺术+技术」融合传播的实体落地场景。
2. **管理规则**：不面向普通散客自由开放，需凭活动预约、内部通行权限进入。
3. **文化价值**：它不仅是一座传媒建筑，也承载了北京CBD的城市记忆——从地标建筑的建设波折，到如今常态化的文化输出，见证了中国传媒行业与城市建设的发展历程。

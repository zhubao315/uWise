# 活态遗产

## 📌 核心定义

> 活态遗产（Living Heritage），是指那些至今仍在使用、仍在参与当代生活的文化遗产。与静态遗址（如庞贝古城、殷墟遗址）不同，活态遗产的特征在于其功能的延续性和文化的有机性——它不仅是历史的见证，更是当代生活的有机组成部分。

北京中轴线是活态遗产的典型范例。从元代的商业街区到明清的皇家禁地，从近代的政治中心到当代的市民空间，中轴线的功能在不断演变，但其空间骨架和文化精神保持了惊人的连续性。天安门广场从皇家空间转变为人民广场，故宫从皇宫转变为博物馆，钟鼓楼从报时中心转变为文化地标——每一处遗产都在与当代生活对话中获得新的意义。

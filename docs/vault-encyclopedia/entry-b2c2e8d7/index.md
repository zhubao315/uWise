# 终身学习的芒格模式

## 📌 核心定义

> 芒格模式是一种以**跨学科阅读**为核心、以**普世智慧（Worldly Wisdom）** 为目标的终身学习框架。芒格本人一生保持每天阅读5-6小时的节奏，他称自己见过的所有聪明人"没有一个不是每天阅读的——没有，一个都没有。"

与碎片化学习或应试学习不同，芒格模式强调：
1. **覆盖数学、物理、生物、心理、历史、经济等基础学科**
2. **提取每个学科最底层的核心模型（而非全部细节）**
3. **将模型互联成格栅，用于解决现实世界的问题**

## 🎯 关键要点

- 阅读前：写下自己对该问题的现有理解
- 阅读中：寻找反直觉的事实和竞争性解释
- 阅读后：用书中的模型重新分析一个自己的实际案例
- 明确知道自己知道什么（核心优势区）
- 更清楚知道自己不知道什么（盲区）

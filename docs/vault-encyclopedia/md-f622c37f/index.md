# 团队协作

## 📌 核心定义

> 多个个体为共同目标而协调行动的过程，涉及沟通、信任、角色分工和冲突管理。

## 🎯 关键要点

- **明确目标**：团队成员对目标有共识
- **角色分工**：基于能力互补的分工（贝尔宾团队角色）
- **沟通机制**：定期同步、信息透明、反馈及时
- **信任建设**：可靠性 + 透明度 + 能力 + 善意
- **冲突管理**：建设性冲突促进创新，破坏性冲突需要干预

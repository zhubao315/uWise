# 酸度是搭配灵魂

## 📌 核心定义

> 酸度是最通用的搭配武器，可以平衡食物的油腻感、甜味和咸味——在酒食搭配中比单宁更重要。

## 🎯 关键要点

- 酸度是最通用的搭配武器，可以平衡食物的油腻感、甜味和咸味——在酒食搭配中比单宁更重要。
- 《酒食圣经》中反复强调的核心观点。很多人在酒食搭配时过度关注单宁与蛋白质的匹配，却忽略了酸度这个真正的"万能钥匙"。
- 切断油腻感：一口红烧肉后喝一口高酸的酒，口腔立刻清爽
- 平衡甜味：甜腻的甜点需要高酸度的酒来解腻
- 提升鲜味：适度酸度能让食物的鲜味更加突出
- 清洁味蕾：酸度就像味蕾的"重置按钮"，让你为下一口做好准备
- 相比之下，单宁只在搭配红肉时有明显作用，而酸度几乎适用于所有食物。
- 不确定配什么酒时，选择酸度高的酒通常不会错

## 📖 详细说明

### 概念解释
酸度是最通用的搭配武器，可以平衡食物的油腻感、甜味和咸味——在酒食搭配中比单宁更重要。
- 不确定配什么酒时，选择酸度高的酒通常不会错
- 油腻食物（烤肉、奶酪）配高酸白酒或轻盈红酒
- 甜点配高酸甜酒（如雷司令晚收）
- 清淡食物配中等酸度的酒，避免酸度掩盖食物风味
- 如果酒的酸度不够，可以稍微冰镇来提升口感

# 街拍伦理

街头摄影在不经许可的情况下拍摄陌生人，天然涉及隐私、尊严与权力的伦理张力。伦理不是法律——法律是底线，伦理是摄影师自己选择的高度。

## 核心原则

- **尊严优先于图像**：一张精彩的照片不值得以牺牲被摄者的尊严为代价
- **弱势群体保护**：流浪者、醉酒者、儿童——这些人在公共空间也需要额外的保护
- **知情权**：如果可以，拍摄后给对方留一张名片或展示照片——把被摄者当合作者而非素材

## 实践中遇到的问题

| 场景 | 思考 |
|------|------|
| 街拍路人肖像 | 对方发现后敌对怎么办？微笑、展示照片、删除——三者选一 |
| 拍摄社会边缘群体 | 你的照片能给他们带来什么？还是只是你的审美投射？ |
| 灾难/冲突现场 | 记录还是侵入？「该不该拍」比「能不能拍」更优先 |
| 发表与传播 | 把照片发到社交媒体前，问自己：如果被摄者看到会怎么想？ |

## 摄影师的自我校准

- **三问法**：快门之前问——(1) 我为什么要拍这张？(2) 被摄者会怎么看待这张照片？(3) 如果我是被摄者，我愿意被这样拍吗？
- **拒绝也是答案**：对方拒绝后立即停止拍摄，删除已拍的——这是信任的底线

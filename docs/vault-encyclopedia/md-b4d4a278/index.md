# 重力驱动运动模型

## 1. 核心精要

跑步前进的主动力来自重力，而非肌肉推蹬。当身体从脚踝处前倾角度 θ 时，重力产生向前的分力 F = mg·sinθ 推动身体运动。肌肉的核心功能是**维持 θ 角度**（姿态伺服）与**触发弹性回收**（Pull），而非产生推进力。

**关键推论**：
- 重力做功的边际成本恒为零——无论跑多快多远
- 肌肉做功的边际收益严格递减——疲劳时维持相同推进力需要指数级能量增长
- 精英跑者"毫不费力"的真相：将肌肉从"推进引擎"降级为"姿态伺服器"

**公式化**：
```
传统认知（错误）：F = F_muscle × cos(α)  ← 肌肉蹬地产生推进力
姿势跑法（正确）：F = mg·sin(θ) + E_elastic  ← 重力 + 弹性释放
```

## 2. 系统演化图景

**正反馈**：高效利用重力 → 肌肉做功↓ → 疲劳延缓 → 更长时间维持正确姿态 → 重力利用效率维持

**负反馈（崩溃路径）**：疲劳 → 姿态崩溃 → θ↓ → 重力分力↓ → 需要更多肌肉做功 → 加速疲劳

**临界点**：θ < 2° 时，重力分力趋近于零，跑者进入"纯肌肉驱动"低效模式——此时每增加 1km 距离，能量消耗呈超线性增长。

## 3. 跨域依赖与关联

- **对跑步经济性**：重力利用效率是跑步经济性的物理基础
- **对投资/系统设计**：借势原则——利用系统自带的趋势力量，而非对抗它
- **对认知进化**：最小阻力路径——找到系统中最省力的驱动方式
- **对组织管理**：推动变革时，找到组织的"自然前倾方向"比强行推动更有效

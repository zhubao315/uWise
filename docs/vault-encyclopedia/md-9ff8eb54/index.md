# 自我效能感

## 📌 核心定义

> 来源：《心理学与生活》（津巴多）

## 🎯 关键要点

- 自我效能感影响行为：相信自己能做到的人更可能去尝试，也更可能坚持。
- 自我效能感可以培养：通过小的成功积累、观察他人、获得鼓励。
- 自我效能感≠自尊：自尊是"我有价值"，自我效能感是"我能做到"。
- 从小的成功开始积累：每次成功都会增强"我能做到"的信念。
- 找到榜样：看到和你相似的人成功了——你也会相信自己能做到。

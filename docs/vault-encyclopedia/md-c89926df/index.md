# 庄周梦蝶

## 📌 核心定义

> "昔者庄周梦为胡蝶，栩栩然胡蝶也，自喻适志与！不知周也。俄然觉，则蘧蘧然周也。不知周之梦为胡蝶与，胡蝶之梦为周与？周与胡蝶，则必有分矣。此之谓物化。"——《庄子·齐物论》

## 🎯 关键要点

- "昔者庄周梦为胡蝶，栩栩然胡蝶也，自喻适志与！不知周也。俄然觉，则蘧蘧然周也。不知周之梦为胡蝶与，胡蝶之梦为周与？周与胡蝶，则必有分矣。此之谓物化。"——《庄子·齐物论》
- 庄周梦见自己变成蝴蝶，翩翩飞舞，快乐自得，完全忘记了自己是庄周。醒来后，发现自己分明是庄周。于是产生了一个根本性的疑问：究竟是庄周梦见了蝴蝶，还是蝴蝶梦见了庄周？
- 我们如何确定自己对现实的认知是真实的？庄子提出的这个问题，两千多年后依然是哲学的核心议题。从柏拉图的洞穴隐喻，到笛卡尔的"我思故我在"，到《黑客帝国》的虚拟现实，都在追问同一个问题：我们感知的现实是否就是真实？
- 卡尼曼提出的WYSIATI（What You See Is All There Is，眼见即为实）描述了人类认知的一个深层偏见：我们倾向于认为自己所看到的就是全部的真相。庄子质疑的恰恰是"眼见即为实"的可靠性——你在梦中看到的蝴蝶栩栩如生，当时你怎么知道那不是真实的？
- 保持认知的谦逊：我们对现实的理解可能只是众多可能的解读之一。在做重要决策时，提醒自己"我看到的可能不是全部"，主动寻求不同的视角和信息来源，是克服WYSIATI偏见的有效方法。

# 人生三件事

## 📌 核心定义

> 阿德勒个体心理学中描述人一生必须面对的三大课题，也称为"人生三大任务"。这三件事涵盖了所有人类关系的基本形式：工作（职业合作——在分工社会中谋生并贡献价值）、交友（社会合作——建立和维持友谊与社交网络）、爱（亲密合作——建立平等的伴侣关系并养育下一代）。完成这三件事即完成人生任务，任何心理问题都可追溯到某一课题的逃避或失败。

## 🎯 关键要点

- **工作**：职业合作，在社会分工中找到位置并贡献价值
- **交友**：社会合作，建立友谊和社交关系网络
- **爱**：亲密合作，平等的伴侣关系，是最高难度的人际关系课题

# 机会成本

## 📌 核心定义

> 某种东西的成本是为了得到它所放弃的东西。 —— 曼昆

## 🎯 关键要点

- 会计成本：你实际付出的钱
- 机会成本：你放弃的最佳替代方案的价值
- 真正的成本：机会成本才是真正的成本
- 上大学的成本：不只是学费，还包括 4 年工作的工资
- 持有现金的成本：不是 0，而是放弃的投资回报

## 📖 详细说明

### 概念解释
某种东西的成本是为了得到它所放弃的东西。 —— 曼昆

### 实际应用

1. 列出所有可选方案
2. 评估每个方案的收益
3. 选择机会成本最低的方案
4. 不要考虑沉没成本（已经付出的、无法收回的成本）

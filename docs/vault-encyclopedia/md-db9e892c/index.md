# 镜头语言与焦段选择

焦段决定视角，视角决定**摄影师与世界的距离**——这种距离不仅是物理的，更是心理的。

## 焦段与叙事语言

| 焦段 | 视角 | 叙事效果 | 典型场景 |
|------|------|---------|---------|
| 超广角（≤24mm） | 114°+ | 夸张远近感，强调环境压迫感 | 建筑、星空、街拍大场景 |
| 广角（28–35mm） | 75–90° | 环境+主体兼顾，带入感强 | 街头摄影、纪实 |
| 标准（50mm） | 46° | 人眼等效视角，最自然 | 全场景通用 |
| 中长焦（85–135mm） | 15–28° | 压缩空间，突出主体，虚化背景 | 人像 |
| 长焦（≥200mm） | ≤12° | 强烈压缩感，压缩空间距离 | 体育、野生动物、街拍偷拍 |

## 焦段的选择策略

- **新手易犯的错误**：用长焦逃避构图——以为拉近就能拍好。其实广角难拍但容易出彩
- **Zoom with your feet**：变焦靠走——改变物理距离比转动变焦环更能理解构图
- **定焦训练**：一个月只用一支定焦头（推荐 35mm 或 50mm），逼迫自己用身体变焦

## 压缩效应

长焦的「空间压缩」让远处的物体看起来和近处的一样大。这可以用来制造有趣的视觉错位——把太阳和人物拉近到同一个画面中。

# ASO应用商店优化

> 提升 App 在应用商店搜索排名和转化率的系统方法。

## 核心要素

| 要素 | 优化方向 |
|------|---------|
| **标题** | 包含核心关键词，30 字以内（iOS） |
| **副标题** | 补充长尾关键词，30 字以内 |
| **关键词字段** | 100 字符，逗号分隔，无空格 |
| **截图/预览** | 前 3 张决定转化率，突出核心功能 |
| **评分/评论** | 4.0+ 是门槛，积极回复差评 |

## 关键指标

- **搜索可见度**：目标关键词排名
- **下载转化率**：曝光 → 下载比例（行业均值 25-35%）
- **自然下载占比**：越高说明 ASO 效果越好

## 优化流程

1. 关键词研究（工具：AppTweak, Sensor Tower, 七麦）
2. 竞品分析（标题/截图/评分策略）
3. A/B 测试（Google Play 支持 Store Listing Experiments）
4. 数据追踪与迭代

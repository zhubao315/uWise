# 致富与守富

## 📌 核心定义

> 致富与守富（Getting Wealthy vs. Staying Wealthy）是摩根·豪泽尔《金钱心理学》的核心区分：**致富需要冒险和乐观，守富需要谦卑和偏执——这是两种截然不同的技能，需要完全不同的目标函数。不要用致富的方法去守富。**

## 🎯 关键要点

- **致富模式**：冒险 + 乐观 + 杠杆 + 进攻——目标函数=增长最大化，拥抱不确定性
- **守富模式**：谦卑 + 节俭 + 冗余 + 防守——目标函数=归零概率最小化
- **换挡信号**：收入/资产跨过阈值后，必须从"增长最大化"切换到"归零概率最小化"
- **换挡失败=破产**：利弗莫尔 1929 做空赚数十亿（今天口径），无法切换到守富模式，1940 自杀
- **守富四原则**：保持节俭（支出不同步增长）/ 保持谦卑（承认成功的运气成分）/ 保持偏执（假设最坏随时发生）/ 保持冗余（现金储备+保险+低杠杆）
- **过去的成功经验可能成为未来的陷阱**：致富的直觉（进攻/加杠杆）在守富期是毒药

## 📖 详细说明

### 概念解释

致富与守富的互斥性解释了为什么许多成功者最终破产：创业/投资阶段的卓越表现（冒险+判断力）是致富能力的证明，但**同样的性格特质在守富期变成风险**——进攻型人格会不断寻找新的增长机会，而守富需要的是"无聊的防守"。

与"复利不中断"的关系：守富的第一要务是**避免归零**——复利公式里任何乘以 0 的过程都让此前积累归零。致富追求凸性（向上空间），守富防御凹性（向下风险）。

### 实际应用

1. **识别自己的模式**：当前处于致富期还是守富期？目标函数匹配吗？
2. **换挡清单**：进入守富期时执行——降杠杆/增冗余/减扩张/排查永久损失点
3. **系统迁移**：知识库爆发月（致富）之后进入治理期（守富）——守富期禁止用冲刺方法运营
4. **人生阶段**：年轻时容错空间大（可致富模式），接近财务目标后逐步切换（守富权重上升）

# 自性化

## 📌 核心定义

> 1. **面对阴影**：承认自己不愿面对的部分。

## 🎯 关键要点

- "向外看的人在做梦，向内看的人醒着。"：真正的觉察是观察自己的内心。
- "你意识不到的东西会变成你的命运。"：未被觉察的无意识内容会影响你的生活。
- "与其做好人，我宁愿做一个完整的人。"：追求"好"意味着压抑"坏"，追求"完整"意味着接纳全部的自己。
- 觉察阴影：对某人有强烈的反感？问自己——"这个人身上让我反感的特质，是否也存在于我身上？"
- 开始内在探索：写日记、做梦的记录、冥想、艺术表达。

## 📖 详细说明

### 概念解释
来源：《荣格自传》（荣格）
**自性化**是荣格心理学的核心目标——整合意识与无意识，成为一个完整的、独特的个体。


### 实际应用

1. **面对阴影**：承认自己不愿面对的部分。
2. **整合对立面**：意识与无意识、理性与感性、男性与女性。
3. **实现自性**：达到心灵的完整与和谐。

# 齐物论

## 🎯 关键要点

- 《庄子》核心篇目，论述万物齐一的哲学，是庄子认识论和本体论的集中表达。
- "天地与我并生，万物与我为一"——消解是非、善恶、大小、美丑的对立。在道的层面上，万物本质上是平等的、统一的，所有差异和对立都是人为的分别心造成的。
- "彼亦一是非，此亦一是非"——每个立场都有其道理，没有绝对的是与非。你认为对的，在另一个视角下可能是错的；你认为大的，在另一个尺度下可能是小的。这不是相对主义的虚无，而是对认知局限性的深刻觉察。

- **齐是非**：跳出二元对立思维，不执着于自己的立场，看到事物的多面性。
- **齐生死**：生与死是自然变化的不同阶段，不必执着于生，也不必恐惧于死。

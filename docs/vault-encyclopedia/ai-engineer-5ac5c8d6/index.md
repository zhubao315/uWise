# AI Engineer角色

## 📌 核心定义

> AI Engineer（AI 工程师）是专注于将基础模型（Foundation Models）集成为应用组件的工程师角色。与传统的 ML Engineer 不同，AI Engineer 不训练模型，而是将预训练好的大语言模型（LLM）等基础模型通过工程手段组装成可用的产品和系统。

## 🎯 关键要点

- 不是训练模型的人：，而是**使用模型构建产品的人**。

## 📖 详细说明

### 概念解释
AI Engineer（AI 工程师）是专注于将基础模型（Foundation Models）集成为应用组件的工程师角色。与传统的 ML Engineer 不同，AI Engineer 不训练模型，而是将预训练好的大语言模型（LLM）等基础模型通过工程手段组装成可用的产品和系统。
### 角色定义与定位

AI Engineer 是随着 GPT-3.5/4、Claude、Gemini 等基础模型的普及而兴起的新兴角色。其核心定位：

- **不是训练模型的人**，而是**使用模型构建产品的人**。
- 工作重心从"模型开发"转向"应用集成"——如何将一个通用模型通过工程手段变成解决具体问题的产品。
- 需要同时理解 AI 能力边界和软件工程最佳实践。

### 核心技能栈

| 技能领域 | 具体内容 | 重要性 |
|----------|----------|--------|
| **Prompt Engineering** | 设计有效的提示词模板、系统提示、Few-shot 示例，控制模型输出质量 | 核心 |
| **RAG（检索增强生成）** | 构建向量检索管道、文档分块策略、重排序、上下文注入 | 核心 |
| **Agent / 工具调用** | 设计 Agent 架构、函数调用、工具链编排、多 Agent 协作 | 核心 |
| **评估与可观测性** | 建立 LLM 输出评估框架、A/B 测试、延迟/成本监控、Hallucination 检测 | 核心 |
| **模型选型与编排** | 根据任务选择合适的模型（成本/延迟/能力权衡）、模型路由、Fallback 策略 | 高 |
| **应用框架** | LangChain、Lla

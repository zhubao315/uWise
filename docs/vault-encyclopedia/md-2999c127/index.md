# 个人理财

## 📌 核心定义

> 对个人或家庭的资金进行以目标为导向的规划与配置——现金流管理、风险保障、消费储蓄与投资，核心是让钱服务人生目标，而非追逐收益本身。

## 🎯 关键要点

- **先目标后方案**：理财首先澄清"钱用来做什么"（稳健 / 增值 / 保障），再设计工具组合
- **现金流为基**：收入 - 支出 = 储蓄，健康理财始于正向结余，投资是结余的放大器非来源
- **风险分层**：应急金（流动性）→ 保障（保险）→ 长期增值（投资）三层递进，先保底再进取
- **与投资区分**：理财是总体规划，投资是其中执行层——见 [理财规划](../md-fcae9cb1/) 的落地动作
- **长期复利**：时间在慢变量中胜出，频繁交易常是费率的吞噬者

## 📖 详细说明

### 概念解释
个人理财不是"买什么理财"，而是对终身的财务决策做系统性管理。它把抽象的人生目标（体面养老、孩子教育、购房）转化为量化的现金流安排，是用财务工具为人生目标服务的过程。切记账、预算、储蓄、保险、投资的组合布局。

### 实际应用

- **记账分类**：识别现金流出向，找到可优化项
- **三层钱包**：应急金留足（3-6 月支出）→ 保费覆盖风险 → 闲置资金做长期配置
- **自动化**：发薪即定投，让"先储蓄后消费"成为默认而非意志力
- **月度复盘**：对照目标检查实际与计划偏离，动态调整

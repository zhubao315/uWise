# 风土决定风格

## 📌 核心定义

> 每个产区的风土不可复制，葡萄酒风格本质是风土的味觉表达——理解风土是理解葡萄酒的核心。

## 🎯 关键要点

- 每个产区的风土不可复制，葡萄酒风格本质是风土的味觉表达——理解风土是理解葡萄酒的核心。
- 《世界葡萄酒地图》和《智利葡萄酒全书》都强调"风土"（Terroir）这个概念。风土是一个综合概念，包括气候、土壤、地形、海拔、朝向、微生物环境等所有影响葡萄生长的自然因素。
- 为什么同一品种的葡萄，在不同产区会呈现截然不同的风格？勃艮第的黑皮诺优雅细腻，新西兰的黑皮诺果香浓郁，俄勒冈的黑皮诺结构感强——差异的根源就是风土。
- 风土是不可复制的。你可以复制酿酒技术，可以移植葡萄品种，但无法复制一个产区千百年来形成的独特风土。这也是为什么葡萄酒如此丰富多彩——世界上没有两片完全相同的风土。
- 学习葡萄酒时，先了解产区风土，再了解品种特性
- 同一品种在不同产区对比品鉴，感受风土差异
- 关注酒标上的产区信息，它比品种名更能预示风格
- 理解"旧世界"（欧洲）和"新世界"（其他地区）的风土哲学差异

| 指标 | 公式 | 健康值参考 |
|------|------|-----------|
| CPC | 总花费 / 点击数 | 行业差异大 |

| CVR | 转化数 / 点击数 | > 2% |
| ROAS | 收入 / 广告花费 | > 3.0 |
| Quality Score | 关键词质量分（1-10） | ≥ 7 |

```
1. 选词 → 关键词研究（长尾词优先）

```

### 实际应用

按智利四大产区风格分类，有针对性地品鉴：

1. **沙漠风土区**（阿塔卡马、科金博）
   → 重点试饮：长相思、西拉
   - 特点：昼夜温差极大，白葡萄保留高酸清新，红葡萄果味集中

2. **中央山谷**（迈坡谷、卡恰布谷、空加瓜谷）
   → 重点试饮：赤霞珠、佳美娜（Carmenere）
   - 特点：智利经典产区，赤霞珠是王牌，佳美娜是智利标志性品种

3. **高海拔区**（安第斯山麓地块）
   → 重点试饮：赤霞珠、西拉
   - 特点：海拔带来的强紫外线使葡萄皮更厚，单宁结构感更强，风味浓缩

4. **巴塔哥尼亚**（南部凉爽产区）
   → 重点试饮：黑皮诺、霞多丽
   - 特点：冷凉气候，优雅风格，酸度明亮，适合喜欢勃艮第风格的饮家

# 酒体

## 📌 核心定义

> 酒体是葡萄酒在口中的重量感和质地，可用从水到牛奶的连续光谱来类比理解。

## 🎯 关键要点

- 酒体是葡萄酒在口中的重量感和质地，可用从水到牛奶的连续光谱来类比理解。
- 酒体（Body）是品酒中最直观却最常被误解的维度。它不是味道，不是香气，而是酒液在口腔中产生的"重量感"和"浓郁度"——类似于水、果汁和牛奶在口中厚薄不同的感受。
- 影响酒体的因素是多方面的。**酒精度**是最主要的决定因素——酒精比水更黏稠，15%酒精度的酒体明显比12%的更厚重。**残糖量**也增加酒体，甜型葡萄酒往往比干型更饱满。**萃取程度**——浸皮时间长、压榨力度大的酒含有更多甘油和酚类物质，酒体更浓。**橡木桶陈酿**通过微氧化和甘油酯化进一步增加酒体。
- 用光谱来理解酒体：轻酒体如黑皮诺、灰皮诺，口感接近水或脱脂牛奶；中等酒体如梅洛、桑娇维塞，类似全脂牛奶；饱满酒体如赤霞珠、巴罗萨设拉子、马尔贝克，接近奶油的厚实感。
- 酒体本身没有优劣之分——一款轻盈的莫斯卡托和一款厚重的赤霞珠各有其美。关键在于**平衡**：酒体应与其他要素（酸度、单宁、果味浓度）协调。酒体厚重但酸度不足的酒会显得沉闷；酒体轻盈但单宁过重的酒会显得空洞。
- 品鉴酒体时，试着让酒液在舌面上停留几秒，感受它的"重量"。

### 实际应用

选购葡萄酒时，可根据个人口味偏好匹配酒体：喜欢清爽口感者宜选黑皮诺等轻酒体品种，偏爱浓郁厚重感者则适合赤霞珠或巴罗萨设拉子。品鉴时让酒液在舌面停留数秒以感知其“重量”，并检查酒体是否与酸度、单宁平衡，避免选择因酒体过重而缺乏酸度支撑的沉闷酒款。

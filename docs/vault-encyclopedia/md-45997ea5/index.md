# 禅修基础

## 📌 核心定义

> 禅修是通过专注、觉察和冥想等练习来训练心智、培养内在平静与洞察力的修行方法。

## 🎯 关键要点

- 核心方法：止（专注一个对象）、观（觉察身心变化）、止观双运
- 基础练习：数息观（关注呼吸）、慈心观（培养善意）、身体扫描
- 禅修层次：从散乱→专注→轻安→定→慧
- 现代应用：正念减压（MBSR）、正念认知疗法（MBCT）、企业正念项目

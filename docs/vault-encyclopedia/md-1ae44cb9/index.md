# 先进封装

> 超越传统引线键合的芯片封装技术——通过更紧密的互联提升性能、降低功耗。

## 主流技术

| 技术 | 特点 | 代表 |
|------|------|------|
| **2.5D 封装** | 芯片并排放置，硅桥/硅中介层互联 | Intel EMIB |
| **3D 封装** | 芯片垂直堆叠，TSV 互联 | AMD 3D V-Cache |
| **Fan-Out** | 晶圆级封装，无基板 | 台积电 InFO |
| **Chiplet** | 多小芯片组合成大芯片 | AMD EPYC |

## 为什么重要

- **摩尔定律放缓**：先进制程推进变慢，封装成为新性能来源
- **良率提升**：小芯片比大芯片良率高
- **成本优化**：不同芯片用不同工艺，混合搭配
- **异构集成**：CPU+GPU+HBM 封装在一起

# 群体心理

## 📌 核心定义

> 群体心理是一个重要的知识概念。

## 🎯 关键要点

- 去个性化：在群体中，个人身份感消失——更容易做出平时不会做的事情。
- 情绪传染：情绪在群体中快速传播——一个人的恐慌可以瞬间传染给所有人。
- 群体极化：群体讨论会让观点更极端——原来温和的观点变得更激进。
- 暗示性：在群体中，人更容易被暗示——领袖的口号比逻辑更有力量。
- 警惕群体压力：在群体中保持独立思考。

## 📖 详细说明

### 概念解释
来源：《乌合之众》（勒庞）
**群体心理**（勒庞）：当个体融入群体后，智力水平会下降，情绪会传染，行为会变得非理性。


### 实际应用

- **警惕群体压力**：在群体中保持独立思考。
- **识别去个性化**：匿名环境（如网络）中更容易出现极端行为。
- **理解群体事件**：群体骚乱、金融泡沫等都可以用群体心理来解释。

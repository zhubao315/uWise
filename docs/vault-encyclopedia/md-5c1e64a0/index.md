# 斯坦福监狱实验的启示

## 📖 详细说明

### 概念解释
来源：《心理学与生活》（津巴多）《路西法效应》（津巴多）
斯坦福监狱实验（1971）证明：**正常人在特定情境下会表现出极端行为——情境比人格更能预测行为。**

- 实验中，正常的大学生在"狱警"角色下变得残忍。
- 实验被迫提前终止——因为"狱警"的行为变得过于暴力。
- 津巴多本人也陷入了"监狱长"角色——情境的力量甚至影响了研究者。


### 实际应用

- **不要高估自己的抵抗力**：你可能在权威面前也会服从。
- **创造好的情境**：如果你想改变行为，改变环境比改变意志力更有效。
- **警惕角色的力量**：你扮演的角色会改变你的行为。

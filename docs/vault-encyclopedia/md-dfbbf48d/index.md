# 佳美娜

## 📌 核心定义

> 佳美娜（Carmenere）是智利的国宝级葡萄品种，以黑樱桃、甜椒和巧克力风味为典型特征。

## 🎯 关键要点

- 佳美娜（Carmenere）是智利的国宝级葡萄品种，以黑樱桃、甜椒和巧克力风味为典型特征。

## 📖 详细说明

### 概念解释
佳美娜（Carmenere）是智利的国宝级葡萄品种，以黑樱桃、甜椒和巧克力风味为典型特征。
佳美娜原产于法国波尔多，曾是梅多克混酿的重要组成部分。1867年根瘤蚜虫灾后，佳美娜在法国几乎灭绝，却阴差阳错地在智利扎根存活——由于其叶片与梅洛极为相似，长期以来被智利人误认为梅洛种植。直到1994年，法国DNA鉴定才确认智利的"梅洛"中有相当一部分其实是佳美娜。

这段失而复得的历史让佳美娜成为智利独有的"身份符号"。如今全球95%以上的佳美娜种植在智利，它已成为智利葡萄酒的标志性品种。

佳美娜的典型风味是**黑樱桃和红醋栗**的果香，辅以**甜椒和青椒**的草本气息，以及来自橡木桶陈酿的**巧克力、咖啡和烟草**味。完全成熟时展现出黑莓果酱和香料的浓郁；未完全成熟时，青椒和草本味会过于突出，这是佳美娜酿造的关键挑战。

佳美娜需要充足的热量和漫长的成长季来达到完全成熟。中央山谷的佩谷和拉佩尔谷是其最佳产区，安第斯山脉的日照和昼夜温差帮助葡萄缓慢积累糖分和风味复杂度。

酿造上，智利酿酒师逐渐摸索出减少草本味的方法：推迟采收、降低产量、控制浸皮时间。优质的佳美娜酒体中等至饱满，单宁柔顺，带有标志性的甜椒和巧克力余韵。


### 实际应用

选购智利葡萄酒时，若酒标标注为佳美娜（Carmenere），可重点寻找带有黑樱桃、甜椒及巧克力风味的酒款，并优先选择产自中央山谷佩谷或拉佩尔谷的年份以规避未成熟时的生青味。在侍酒环节，建议将酒杯温度控制在16-18℃，搭配红肉料理或硬质奶酪，以突出其柔顺单宁与标志性的草本余韵。

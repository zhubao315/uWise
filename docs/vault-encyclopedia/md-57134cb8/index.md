# 决定性瞬间

亨利·卡蒂埃-布列松提出的摄影哲学概念：摄影是在**几分之一秒内**同时识别事件的意义和形式的精准组织。核心主张是「构图必须在取景瞬间完成，而非后期裁剪」。

## 核心理念

- **形式与内容的合一**：最好的照片是几何结构（构图）和情感意义（内容）在瞬间同时达到峰值
- **预判而非运气**：决定性瞬间不是碰巧拍到的——摄影师需要预判事件即将到来的高潮位置，提前站在那里
- **不干预原则**：不导演、不摆拍、不裁剪——尊重场景本身的完整性

## 实践方法

- **预测动作轨迹**：观察人物的运动方向和速度，提前在交汇点等待
- **几何框架预建**：先用环境中的线条、门窗、阴影搭好构图框架，等主体走入
- **超焦距对焦**：预设对焦距离，不用对焦直接拍摄，缩短反应时间

## 争议与发展

- 当代摄影批评认为该理论过度强调「单张决定性」，忽视了系列照片的整体叙事能力
- 罗伯特·弗兰克在《美国人》中用「非决定性瞬间」对抗布列松——不完美、模糊、构图上失衡的照片反而更真实

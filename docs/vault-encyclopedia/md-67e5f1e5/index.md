# 情绪钟摆

## 📌 核心定义

> 情绪钟摆（Emotional Pendulum）是霍华德·马克斯《周期》的核心模型：市场情绪像钟摆一样在"极度乐观（贪婪）"与"极度悲观（恐惧）"两个极端之间摆动，**很少停留在理性中点**——大部分时间市场要么被高估、要么被低估。

## 🎯 关键要点

- **七阶段**：乐观 → 兴奋 → 狂热 → 极度乐观（顶）→ 焦虑 → 恐惧 → 极度恐惧/投降（底）
- **不对称性**：乐观→恐惧的切换比恐惧→乐观更快（恐惧是更强烈的情绪）
- **自我强化性**：上涨吸引资金→更涨；下跌迫使离场→更跌（增强回路）
- **顶底标志**：顶部 = "风险已消失"论调；底部 = "风险无处不在"论调
- **四偏差燃料**：锚定效应 / 从众心理 / 损失厌恶 / 过度自信
- **定位而非择时**：钟摆给出的是"区间"（我现在在哪一端），不是"时点"（明天何时转折）

## 📖 详细说明

### 概念解释

钟摆理论与格雷厄姆的"市场先生"同构：市场先生是情绪化的交易对手（人格化），钟摆是情绪的运动规律（动力学化）。关键洞见在于：**钟摆摆向极端不是信息错误，是参与者的情绪共振**——每个参与者单独看都"理性"（追涨有追涨的理由，杀跌有杀跌的理由），加在一起就是极端。

因此，对抗钟摆不能靠"比别人聪明"，只能靠**纪律**：在极端区域执行与直觉相反的操作（顶部信号区禁止加仓、底部信号区分批买入），且这些规则必须在情绪到来**之前**写死。

### 实际应用

1. **周度定位**：用估值/情绪/信贷/杠杆/供给/利差六维矩阵给市场打分（0-100），>80=顶部信号区，<20=底部信号区
2. **民间指标**：身边不投资的人开始谈论投资=顶部信号；优质资产"便宜到没人要"=底部信号
3. **生活迁移**：个人精力/情绪同样是钟摆——冲刺期与低谷期交替是正常摆动，低谷期不做重大决策
4. **情绪免疫**：知道"钟摆必然摆动"的人，对极端情绪的杀伤力天然减半

## 🔧 调用示例

> **场景 1（投资定位·正例）**
> 面对市场剧烈涨跌时：
> 1. 不先问"买还是卖"，先问"我在钟摆的哪一端"；
> 2. 用估值/情绪/信贷/杠杆/供给/利差六维打分（>80 顶部区，<20 底部区）；
> 3. 执行事先写死的纪律（顶部禁加仓、底部分批买入），而非临场凭感觉。

> **场景 2（生活迁移·边界场景）**
> 把钟摆用于个人精力/情绪时：
> 1. 承认冲刺与低谷交替是正常摆动，不把低谷当失败；
> 2. 低谷期不做重大决策、不否定长期方向；
> 3. **注意**：钟摆给出的是"区间"不是"时点"——它不能预测明天几时转折，别拿它当择时工具。

## ⚠️ 边界约束

- **适用范围**：市场情绪定位、逆向投资纪律、个人情绪与精力的周期管理。
- **不适用**：精确择时（它只定位区间）；把它当短期交易信号；用"必然回归"安慰自己不设风控。
- **前置条件**：需有可量化的定位指标（估值/情绪/信贷等）与事先写好的纪律，否则只是事后感慨。
- **风险提示**：**钟摆宿命论**——认为极端后必然立刻反转，忽视"更极端"的可能；**借钟摆加仓**——把"在底部"当成无风险买入理由。

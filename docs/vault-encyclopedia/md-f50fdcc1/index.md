# 心流状态激活

> 进入完全沉浸、高效产出的心理状态——最优体验的触发条件和维持方法。

## 心流触发条件

| 条件 | 说明 |
|------|------|
| **明确目标** | 知道要做什么 |
| **即时反馈** | 知道做得怎么样 |
| **挑战匹配** | 难度略高于能力（110%） |
| **专注环境** | 无干扰 |

## 激活方法

1. **仪式感**：固定的时间/地点/音乐
2. **消除干扰**：手机静音/关闭通知
3. **热身**：从简单任务过渡
4. **番茄钟**：25 分钟专注时段

## 阻碍因素

- 任务太简单 → 无聊
- 任务太难 → 焦虑
- 外部干扰 → 注意力分散
- 缺乏反馈 → 失去动力

# 客观描述优于主观评价

## 📌 核心定义

> 反对用"好喝""不好喝"评价葡萄酒，鼓励用具体词汇描述颜色、香气、口感、余味——客观描述让不同人之间可以有效交流。

## 🎯 关键要点

- 反对用"好喝""不好喝"评价葡萄酒，鼓励用具体词汇描述颜色、香气、口感、余味——客观描述让不同人之间可以有效交流。
- 《品酒练习册》强调的核心方法论之一。当你喝到一杯酒说"好喝"，别人无法从这两个字获得任何有用信息。但如果你说"这款酒呈深宝石红色，有黑醋栗和雪松的香气，单宁柔顺，余味中等"，即使没有品尝的人也能大致想象这款酒的风格。
- "好喝"和"不好喝"是主观判断，取决于个人偏好和场合。而客观描述是事实陈述，具有可交流性。这也是为什么专业酒评总是用描述性语言而非简单的评分——评分只是总结，描述才是内容。
- 这条原则的价值不仅限于品酒：它是一种思维方式，教你区分"我觉得"和"它是什么"。
- 品酒时按颜色、香气、口感、余味四个维度逐一描述
- 使用具体词汇：不说"香"，说"有青苹果和柠檬的香气"
- 避免使用"好喝""难喝""一般"等模糊词汇
- 与他人交流时先描述再评价，让对方有判断依据

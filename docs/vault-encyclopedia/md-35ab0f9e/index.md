# 公民不服从

## 📌 核心定义

> 梭罗政治哲学的核心：当法律与国家行为背离正义时，公民有道德义务以非暴力方式拒绝服从。个人良知高于国家意志——梭罗本人因拒绝缴纳支持奴隶制的税收而入狱，以此事件写就《公民不服从》。深刻影响了甘地的非暴力运动和马丁·路德·金的民权斗争。

## 🎯 关键要点

- **良心的优先性**：个人道德判断高于法律权威；不合正义的法律没有道德约束力
- **非暴力的行动**：不服从不是暴动或革命，而是拒绝合作、拒绝纳税、拒绝遵守——用和平的不合作施加压力
- **承担后果**：真正的公民不服从者愿意为自己的选择付出代价（入狱、罚款），而不是逃避惩罚

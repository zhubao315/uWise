# 道德记账法——每次只追踪一个变量是最小阻力的习惯养成路径

## 📌 核心定义

> 人试图同时改变多个习惯时，几乎100%会失败。富兰克林的道德记账法揭示了一个反直觉的真理：**不是你意志力不够，而是你同时操控的变量太多。** 解决方案不是"更努力"，而是"更聚焦"——每周只盯一个美德，其他犯错只记录不纠正，13周一个循环。

## 🎯 关键要点

- 认知带宽有限：人每天的自控力是消耗性资源（Roy Baumeister的意志力损耗理论），同时改变多个习惯会快速耗尽带宽
- 单变量实验法：科学实验的黄金法则——一次只改一个变量，才能确定因果关系。习惯养成同理
- 正反馈循环：只盯一个目标时，你更容易体验到进步→进步带来信心→信心强化行动→行动巩固习惯
- 容错设计：其他美德犯错只打黑点不纠正，降低了心理负担，避免了"全有或全无"的完美主义陷阱
- 不追求完美：富兰克林本人也从未全部达标，他说"虽然我从未达到我所追求的完美境界，但我通过努力成了一个比原来更好更快乐的人"

### 实际应用

1. **列出**你想培养的3-7个核心习惯/品质
2. **排序**：选出最基础、最紧迫的1个作为第一周的焦点
3. **设计追踪表**：横轴=习惯项，纵轴=每天，用✅/❌记录
4. **每周轮换**：下周转到第2个焦点，前一个变成"维护模式"（犯错才打点）
5. **13周复盘**：一个循环结束后，审视数据，调整习惯清单和优先级

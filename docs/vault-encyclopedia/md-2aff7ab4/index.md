# 明确的乐观主义

## 📌 核心定义

> 彼得·蒂尔对未来的分类框架中的一种态度：对未来乐观，但乐观必须有具体的蓝图和行动计划，而不是模糊的信心。"明确的乐观主义者"有路线图、有阶段性目标、有具体执行的意志——如 1960 年代的登月计划。

## 🎯 关键要点

- **四种未来态度**：明确乐观（有蓝图+行动）、模糊乐观（有信心无规划）、明确悲观（有计划无希望）、模糊悲观（既无计划也无希望）
- **时代诊断**：美国从 1950-60 年代的"明确乐观"（登月、州际公路）滑入"模糊乐观"（相信进步但不做具体规划）
- **行动指南**：真正的乐观不是"一切都会好的"的安慰，而是"我知道要去哪里，这是路线图，现在出发"

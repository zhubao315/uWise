# 骆驼商人还债公式

## 📌 核心定义

> 欠一屁股债的达巴希尔翻身公式：收入的十分之七养家、十分之二按比例还债、十分之一自存。

## 🎯 关键要点

- 70% 生活，20% 还债，10% 照常自存
- 20% 按欠款比例分配给各债权人，而非先还小额图爽
- 持续还款让债权人愿意协商展期
- 还债期间储蓄不断，翻身后直接进入积累期
- 本质是现金流纪律，不是收入奇迹

## 📖 详细说明

### 出处
骆驼商人达巴希尔的十四块泥板还债记录。

### 应用
列出全部债务与债权人，每月固定 20% 按比例分配；同时保留 10% 储蓄，守住习惯。

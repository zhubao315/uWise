# 感知的建构性

## 📌 核心定义

> 感知不是被动接收信息——大脑会主动"建构"我们看到的世界。

## 🎯 关键要点

- 自下而上加工：从感觉输入到知觉——数据驱动。
- 自上而下加工：从知识到知觉——概念驱动。
- 知觉恒常性：无论角度如何变化，我们知道门是长方形的。
- 感知是主动建构：大脑根据有限的信息"猜测"世界的样子。
- 注意力有限：你只能注意到有限的信息——不能同时注意所有东西。

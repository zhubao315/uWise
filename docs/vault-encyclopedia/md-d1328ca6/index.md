# 定位：争夺用户心智

## 📌 核心定义

> 《定位》（Positioning）是艾·里斯和杰克·特劳特的营销经典，提出品牌要在消费者心智中占据一个独特位置。

## 🎯 关键要点

- **心智阶梯**：消费者心智中每个品类只有 2-3 个品牌位置
- **成为第一**：第一个进入心智的品牌最有优势
- **聚焦法则**：品牌应聚焦一个核心概念
- **对立定位**：找到领导者的对立面
- **品类创新**：开创新品类比在现有品类竞争更有效

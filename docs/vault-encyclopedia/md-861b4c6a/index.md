# 把自己产品化——专长×杠杆是普通人逆袭的唯一公式

## 📌 核心定义

> 💡 不要问"我怎么赚更多钱"，要问"我的专长是什么，以及如何用杠杆把它放大1000倍"。

## 🎯 关键要点

- **专长不可培训**：如果一项能力能被培训出来，它就能被别人替代。真正的专长来自你的好奇心、热情和性格，是无法被批量复制的。
- **三种杠杆选第三种**：劳动力杠杆（管理难）、资本杠杆（需要本金）、**零边际成本杠杆**（代码+媒体，普通人唯一选择）。
- **复利效应**：专长一旦被产品化，就能在你不工作时继续产生价值，形成"睡后收入"的复利增长。
- **行动检验**：回想你小时候废寝忘食的事，那就是你的专长线索。

## 📖 详细说明

### 概念解释
财富不是靠出租时间获得的，而是靠**专长×杠杆**的乘积效应。专长是你独特的能力——对你来说是玩耍、对别人来说是工作的事；杠杆是放大器——用零边际成本的方式（代码、媒体）把专长卖给全世界。普通人的逆袭路径只有一条：找到你的专长，然后用代码或媒体把它产品化。

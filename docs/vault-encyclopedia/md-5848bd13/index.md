# 物理只是最赚钱的爱好

## 📌 核心定义

> 费曼获得诺贝尔奖后对朋友说："物理只是我最赚钱的爱好。" 这句话揭示了一个深刻的人生哲学：**真正有趣的人不被专业边界束缚**。

## 🎯 关键要点

- **跨域不是不专注**：费曼在物理学上投入了毕生精力，但他从未把其他兴趣视为"不务正业"。跨域探索反而为物理学研究提供了新的思维模型
- **兴趣是认知的杠杆**：费曼学习打鼓的节奏感帮助他理解了量子力学中的振动模式；画画培养的观察力帮助他在生物学实验中注意到细节
- **业余精神的价值**：业余（amateur）的词根是"爱"（amare）。业余精神意味着纯粹出于热爱而做，没有功利压力，反而更容易产生突破性想法
- **T型人才的极端形态**：费曼是"T"的竖线极深（物理学）、横线极宽（几乎所有他感兴趣的事物）的极端案例
- **好奇心驱动的学习**：费曼从不制定"学习计划"，他只是对自己不理解的东西感到好奇，然后去弄明白

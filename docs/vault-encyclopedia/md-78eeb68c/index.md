## 归因模型

| 模型 | 逻辑 |
|------|------|
| **首次触点** | 100% 归功于第一次接触 |
| **末次触点** | 100% 归功于最后一次 |
| **线性归因** | 平均分配给所有触点 |
| **时间衰减** | 越近的触点权重越高 |
| **数据驱动** | 算法自动分配权重 |

# 选择权

## 1. 核心精要

选择权（Optionality）是反脆弱性的核心数学表达，指**拥有选择权但无义务的不对称状态**。其本质是构建"损失有限、收益无限"的结构，使决策者在不确定性中获益。

**第一性原理**：反脆弱性的秘密在于：你不需要知道发生了什么，你只需要知道自己会在好事发生时获益。选择权思维颠覆了"预测准确"的传统决策模式。

**关键特征**：
- **损失有限性**：最大损失已知且可承受（如期权费）
- **收益无限性**：潜在收益无上限或远大于损失
- **波动性朋友**：波动越大，选择权越有价值
- **非预测性**：不需要预测方向，只需要非对称性

## 2. 系统演化图景

### 输入变量
- 选择权成本（已知损失）
- 潜在收益空间（未知收益）
- 波动性水平
- 决策次数

### 状态转换
1. **构建阶段**：以有限成本获取选择权（购买期权、启动实验）
2. **暴露阶段**：承受波动，允许小损失发生
3. **收获阶段**：波动触发非对称收益，大赚覆盖多次小亏
4. **复利阶段**：收益再投资于新选择权，形成正反馈

### 正负反馈网络
- **正反馈**：选择权成功→收益放大→购买更多选择权→更多成功机会
- **负反馈**：选择权失败→损失有限→调整策略但不危及生存

### 临界点
- 当选择权成本超过可承受阈值时，系统从反脆弱转为脆弱
- 当决策次数不足时，选择权优势无法显现

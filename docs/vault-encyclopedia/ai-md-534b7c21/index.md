# 语音AI集成

> 将语音识别（ASR）、语音合成（TTS）、语音理解集成到应用中的技术方案。

## 技术栈

| 技术 | 代表 |
|------|------|
| **ASR（语音识别）** | Whisper, Paraformer, Azure Speech |
| **TTS（语音合成）** | VITS, Bark, ElevenLabs |
| **NLU（语义理解）** | LLM + Prompt |
| **对话管理** | 有限状态机 / LLM 驱动 |

## 集成流程

```
音频输入 → ASR 转文本 → LLM 理解 → 生成回复 → TTS 输出音频
```

## 应用场景

- **智能客服**：语音交互式客服
- **语音助手**：日程/查询/控制
- **内容创作**：播客/有声书制作
- **辅助功能**：无障碍交互

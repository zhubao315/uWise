# 可选择性

## 📌 核心定义

> 可选择性（Optionality）由纳西姆·塔勒布推广，指拥有多条可选路径但无需承担下行风险的非对称优势。核心思想：当你有更多选择权时，不确定性反而成为你的朋友。

## 🎯 关键要点

- **非对称性**：上行空间无限，下行风险有限（"反脆弱"的底层逻辑）
- **期权思维**：用小额成本获取大量潜在机会，让"黑天鹅"事件为你工作
- **杠铃策略**：将90%资源投入极度安全领域，10%投入极度高风险领域，避免中间地带
- **凸性收益**：可选择性越高，波动带来的收益越大

# 4%法则与25倍线

## 📌 核心定义

## 🎯 关键要点

- 25 倍＝年支出 ×25，是独立线的数学定义
- 4% 是上限不是目标，保守者可用 3.5%
- 通胀已包含在回测里，无需另算
- 独立后仍建议保留 1-2 年现金缓冲
- 这是 FIRE 的终点线，也是起点线

# 财商教育

## 📌 核心定义

> 传统教育系统不教授财商，这是最大的失败。财商是实现财务自由的基础能力。

## 🎯 关键要点

- 资产 vs. 负债：资产把钱放进口袋，负债从口袋拿走钱
- 现金流：关注现金流方向，而非账面利润
- 被动收入：不需要工作就能获得的收入
- 财务报表：用资产负债表和损益表看世界

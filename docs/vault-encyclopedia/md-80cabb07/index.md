# 指控审计开场白

## 📌 核心定义

> 开场先替对方说出最坏的指控（“你们肯定觉得我们就是来宰客的……”），敌意先泄一半。

## 🎯 关键要点

- 把对方可能的所有恶意猜测列全
- 开场 60 秒内主动说出来
- 说完接标注，等对方纠正/接话
- 越是弱势方开场，效果越强
- 配合深夜 DJ 语调使用

## 📖 详细说明

### 出处
全书开场技术，劫案谈判“先认怂再控场”。

### 应用
下次难缠会议开场，先替对方把难听话说了。

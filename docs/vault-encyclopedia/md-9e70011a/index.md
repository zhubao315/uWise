# 关键点位理论

## 📌 核心定义

> 杰西·利弗莫尔（Jesse Livermore）在《股票大作手回忆录》中提出的核心交易概念：价格运动中存在一些关键的价格点位（Pivotal Points），这些点位标志着趋势的反转或延续。识别并正确应对关键点位，是利弗莫尔交易体系的基石。

## 🎯 关键要点

- **反转关键点**：价格在经历一段趋势后，出现方向性转折的价格区域。通常伴随着成交量的显著放大和价格形态的明确变化。反转关键点标志着旧趋势的终结和新趋势的开始。
- **延续关键点**：在趋势运行过程中，价格经过整理后继续沿原方向突破的价格区域。延续关键点确认趋势仍在有效运行中，是加仓的信号。
- **整数关口的心理效应**：如100元、50元等整数价格往往具有心理意义，突破或跌破这些关口可能引发加速运动。
- **成交量确认**：真正的关键点位突破通常伴随着成交量的显著放大，缩量突破往往是假突破。
- **时间确认**：突破关键点位后，需要一定时间（通常2-3天）来确认突破的有效性，避免被假突破欺骗。

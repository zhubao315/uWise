# 设定虚拟时薪——用价格杠杆过滤低价值决策

## 📌 核心定义

> 💡 你的时间价值不是市场决定的，而是你对自己的定价。定价越高，你越会珍惜它。

## 🎯 关键要点

- **核心公式**：任务价值 < 虚拟时薪 × 耗时 → 外包/自动化/放弃
- **不是偷懒，是杠杆思维**：把省下来的时间用于发展专长、构建资产、深度思考——这些才是能产生复利的活动
- **心理阻力**：最大的障碍是"我能做得更好"的控制欲。接受"80分就够了"，把时间花在只有你能做到100分的事上
- **渐进式执行**：从最容易外包的任务开始（家务、数据搬运、格式化），逐步扩展到更多领域

## 📖 详细说明

### 概念解释
给自己设定一个远高于市场水平的"虚拟时薪"（如5000元/小时），然后用这个价格作为决策过滤器：任何可以用低于这个价格外包或自动化的任务，都不值得你亲自做。这不是傲慢，而是**强制将时间从低价值维护活动重新分配到高价值创造活动**的系统方法。纳瓦尔说："依靠出租时间是永远发不了财的。"

### 实际应用

先通过时间审计找出每周重复性最高的低价值任务（如邮件整理、数据录入），设定一个高于当前时薪5-10倍的虚拟价格，若该任务外包成本低于此价则立即执行外包或自动化。针对“我能做得更好”的心理阻力，强制规定非核心领域只需达到80分标准，将节省出的整块时间专门用于构建可复利的专长资产或深度思考，而非填补琐碎事务。

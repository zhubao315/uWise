# 认知扭曲

## 📌 核心定义

> |------|------|------|

## 🎯 关键要点

- 认知扭曲是可识别的：了解这些扭曲是克服它们的第一步。
- 认知重构：识别扭曲→评估证据→生成替代想法。
- 行为实验：用行动验证想法——比认知重构更有效。
- 识别扭曲：觉察自己的自动思维——问自己"我此刻在想什么？"
- 挑战认知扭曲：问自己——"支持这个想法的证据是什么？反对的证据是什么？"

## 📖 详细说明

### 概念解释
来源：《认知行为疗法》（贝克）
**认知扭曲**是自动思维中常见的系统性错误：

| 扭曲 | 含义 | 例子 |
|------|------|------|
| **全或无思维** | 非黑即白 | "如果做不到完美，就是失败" |
| **灾难化** | 预测最坏结果 | "最坏的情况一定会发生" |
| **读心术** | 假设知道别人想什么 | "他一定觉得我很蠢" |
| **情绪推理** | 把感受当事实 | "我感到焦虑，所以一定有危险" |
| **过度概括** | 从一件事推广到所有事 | "我这次失败了，我永远都会失败" |
| **个人化** | 把所有事情归咎于自己 | "都是我的错" |


### 实际应用

- **识别扭曲**：觉察自己的自动思维——问自己"我此刻在想什么？"
- **挑战认知扭曲**：问自己——"支持这个想法的证据是什么？反对的证据是什么？"
- **生成替代想法**：有没有更平衡的解释？

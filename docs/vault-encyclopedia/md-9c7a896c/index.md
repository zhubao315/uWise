# 光质与光位

摄影本质上是「用光线作画」。光质（软硬）和光位（方向）决定了画面的情绪、立体感和质感。

## 光质：软光 vs 硬光

| 类型 | 特征 | 效果 | 产生条件 |
|------|------|------|---------|
| 硬光 | 阴影边缘锐利，过渡急剧 | 戏剧性、强烈、质感突出 | 小光源（晴天正午、裸灯） |
| 软光 | 阴影边缘柔和，过渡渐变 | 柔和、包容、肤色好看 | 大光源（阴天、柔光箱、窗户光） |

**黄金时间**：日出后1小时和日落前1小时的光线既有方向性（硬），又经过大气层散射（软），是软硬兼得的最佳窗口。

## 光位：方向决定立体感

| 光位 | 效果 | 使用场景 |
|------|------|---------|
| 顺光（正面） | 平坦无阴影 | 证件照、产品展示（少用） |
| 侧光（90°） | 强烈立体感，一半亮一半暗 | 强调纹理、情绪人像 |
| 侧逆光（135°） | 轮廓光，立体且富有氛围 | 人像、产品边缘高光 |
| 逆光（180°） | 剪影、轮廓光 | 日出日落、氛围感 |
| 顶光 | 眼窝深陷，不讨喜 | 一般回避，或用于戏剧化效果 |

## 实用原则

- **先找光，再构图**：进入一个场景先观察光线方向和性质
- **眼神光点就是灵魂**：人像中确保眼睛有反光点
- **阴影比高光更说明问题**：阴影的软硬和位置决定了光线的质量

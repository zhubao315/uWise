# 跑步技术

## 📌 核心定义

> 跑步的生物力学、姿势、步频、步幅等技术要素的系统性方法。

## 🎯 关键要点

- **姿势**：身体微前倾，肩膀放松，手臂自然摆动，核心收紧
- **步频**：理想步频 180 步/分钟，减少触地时间
- **步幅**：自然步幅，避免过度跨步（overstriding）
- **着地方式**：前掌或中掌着地，避免脚跟先着地
- **呼吸**：腹式呼吸，节奏与步频协调（3:2 或 2:1）

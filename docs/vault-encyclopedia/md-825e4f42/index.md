# 均值回归的力量

## 📌 核心定义

> 均值回归（Mean Reversion）是约翰·博格在投资领域的重要洞察：主动管理基金的长期表现会回归市场均值，扣除成本后，大多数主动基金的净收益低于市场指数。这不仅是统计规律，更是数学必然——因为主动管理者的总和就是市场，扣除成本后必然落后。来源：《约翰·博格的投资50年》（约翰·博格，1994年）。

## 🎯 关键要点

- **数学必然性**：主动管理是一个零和博弈（扣除成本前）和负和博弈（扣除成本后）。所有主动管理者的总收益就是市场收益，但他们的总成本（管理费+交易成本+税费）使得主动管理投资者的平均净收益必然低于市场指数。这不是概率问题，而是数学恒等式。
- **短期超额收益的幻觉**：短期内，确实有少数主动基金能战胜市场，但这往往是运气而非技能。博格引用的研究显示，过去10年表现优异的基金，在下一个10年的表现与随机选择无异。短期的超额收益是均值回归的起点，不是能力的证明。
- **时间是主动管理的敌人**：随着时间推移，均值回归的力量越来越强。1年期看，约40%的主动基金能战胜指数；5年期看，约25%能胜出；10年期看，只有约10%能胜出；20年期看，几乎无人能持续胜出。
- **幸存者偏差**：我们看到的基金业绩排行榜只包含现存基金，那些因表现不佳而清盘的基金被排除在外。这使得主动管理的平均表现看起来比实际更好。

### 实际应用

- **选基策略**：不要追逐过去几年表现最好的基金，因为均值回归意味着它们未来很可能表现平庸。相反，应选择长期费率最低、策略最透明的基金。
- **择时的陷阱**：试图通过择时来规避市场下跌，本质上是在与均值回归对抗。研究表明，错过市场最好的10个交易日，长期收益将大幅缩水。被动投资的"永远在场"策略，反而能捕获这些关键交易日。
- **对"明星经理"的警惕**：任何声称能持续战胜市场的基金经理，都需要面对均值回归的检验。博格建议，与其追逐明星经理，不如接受市场平均回报。

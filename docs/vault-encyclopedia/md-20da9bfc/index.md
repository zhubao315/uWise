# 图像史料学

## 📌 核心定义

> 图像史料学是将视觉图像（古地图、老照片、复原图、绘画、版画等）作为历史研究的一手资料进行系统收集、整理、解读和利用的方法论。它不是将图像视为文字史料的"配图"或"插图"，而是将其视为与文字史料同等重要的独立证据来源。岳升阳在《图说北京古城变迁史》中系统运用了这一方法，通过古地图、老照片和城市复原图来呈现北京古城的空间变迁。

图像史料的价值在于它能提供文字史料无法传达的信息。一张古地图可以呈现一个城市在某个历史时刻的空间全貌——街道的走向、建筑的布局、水系的分布——这些信息用文字描述往往冗长且不精确，而一张地图可以在瞬间传达。一张老照片可以捕捉到已经消失的建筑、街道和生活方式的真实面貌，这种视觉信息是任何文字描述都无法替代的。

# 语言游戏

## 📌 核心定义

> 维特根斯坦后期哲学核心概念，见于《哲学研究》。语言的意义不在于指称对象或心理意象，而在于具体使用方式——如同棋子的意义在于走法规则而非其材质。不同"生活形式"有不同的语言游戏（命令、提问、讲故事、开玩笑等），它们彼此之间仅通过"家族相似性"关联。

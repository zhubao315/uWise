# 年龄债券配比

## 📌 核心定义

> 年轻人 100% 股票吃满成长，随年龄加纯债平滑波动；债券是减震器不是发动机。

## 🎯 关键要点

- 30 岁前可全股票，波动用时间熨平
- 40 岁后逐步加纯债/国债至 20-40%
- 再平衡是最好的低买高卖纪律
- 熊市里债券是加仓股票的子弹
- 本土化用国债＋纯债基金实现

## 📖 详细说明

### 出处
债券与年龄章（glidepath）。

### 应用
生日当天做一次比例体检，偏离超 5% 即再平衡。

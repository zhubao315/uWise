# 训练即教育原则

## 📌 核心定义

> "训练不是折磨自己，而是教育自己。" ——保罗·威德

## 🎯 关键要点

- **训练是学习，不是惩罚**：带着觉知去训练，关注动作质量而非数量
- **动作是技能**：每个动作都有技术要点，需要刻意练习才能掌握
- **渐进是课程表**：从简单到复杂，从易到难，这是学习的自然规律
- **耐心是学费**：掌握一个动作可能需要数月甚至数年，这是正常的

> 城市身份跃迁是指一座城市在历史进程中经历的重大身份转变——从一种城市类型跃升为另一种城市类型，伴随着城市功能、文化面貌、政治地位的全面升级。北京的城市身份经历了四次重大跃迁，每一次跃迁都深刻改变了城市的面貌和命运。

# 梁陈方案

## 📌 核心定义

> 梁陈方案，全称《关于中央人民政府行政中心区位置的建议》，是1950年2月由建筑学家梁思成与城市规划师陈占祥联合提出的城市规划方案。其核心主张是：为保护北京旧城的完整格局，应在旧城西侧（今西郊公主坟一带）建设新的中央行政中心，将行政功能与旧城的居住、文化功能分离，形成"新旧并存"的城市格局。

方案基于这样的理念：北京旧城是人类城市规划史上的杰作，其完整的中轴线、棋盘式道路系统、胡同四合院体系以及壮丽的城墙城门，构成了一个有机统一的整体，具有不可替代的历史文化价值。任何对旧城的大规模改造都将造成不可逆转的破坏。

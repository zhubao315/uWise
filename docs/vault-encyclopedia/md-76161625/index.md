# 英雄池构建策略

英雄池不是「会玩的英雄数量」，而是**在当前版本能稳定上分的英雄组合**。广而不精比精而不广更致命。

## 理想英雄池结构

| 深度层级 | 数量 | 要求 | 用途 |
|---------|------|------|------|
| 本命英雄 | 1-2 个 | 任何阵容/任何对位都能拿 | 冲分主力 |
| 补位英雄 | 2-3 个 | 在主力被 ban/被抢时拿 | 稳住下限 |
| 版本英雄 | 1-2 个 | 当前版本强势，随时可练 | 利用版本红利 |
| 扩展池 | 不限 | 匹配/娱乐练习 | 为下赛季储备 |

## 核心原则

- **不要雨露均沾**：同时练超过 3 个新英雄 = 一个都练不好
- **输不是因为英雄不对**：低分段换英雄不如提升对这个英雄的理解
- **英雄理解 > 操作熟练度**：知道这个英雄的斩杀线、强势期、弱势对位比会一套连招更重要

## 版本适应

- 新赛季第一周不排位：观察哪些英雄被加强/削弱、新装备的影响
- 每月检查一次英雄胜率榜：只看高分/职业胜率，不看全段位胜率
- 版本强势英雄不需要练到本命水平——练到能补位的程度即可吃版本红利

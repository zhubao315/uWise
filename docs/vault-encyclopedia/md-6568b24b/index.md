# 认知偏误

## 📌 核心定义

> 认知偏误（Cognitive Bias）是人类在信息处理过程中系统性偏离理性判断的思维模式，由大脑的启发式捷径导致。

## 🎯 关键要点

- **确认偏误**：倾向于寻找支持自己观点的信息，忽视反面证据
- **锚定效应**：过度依赖第一个接收到的信息作为判断基准
- **可得性启发**：根据信息的易获得程度判断事件概率
- **损失厌恶**：对损失的敏感度约为等量收益的 2 倍
- **框架效应**：同一信息的不同表述方式导致不同决策

# 迷你退休计划

## 📌 核心定义

> 把 30 年后的退休拆成穿插人生的 3-6 个月长假：现在就过想要的生活，而不是 65 岁。

## 🎯 关键要点

- 一次 1-3 个月，去生活成本低但体验高的地方
- 带着一个项目去（学语言/写书/徒步），不是纯躺
- 回来后复盘：哪些体验要常态化
- 攒钱目标从“退休金”变成“下一次迷你退休”
- 35 岁前至少执行一次

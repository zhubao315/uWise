# 行为实验

## 📌 核心定义

> 1. **识别自动思维**：觉察"我此刻在想什么？"

## 🎯 关键要点

- 行为实验比认知重构更有效：想通了再行动不如通过行动来验证想法。
- 实验是安全的：设计的小实验风险可控——即使失败也不会有大问题。
- 实验提供直接证据：实际结果比任何认知重构都有效。
- 社交焦虑：想法："如果我发言，大家会笑话我。"实验：在会议上发言一次，观察实际结果。
- 恐惧症：想法："如果我坐飞机，一定会出事。"实验：先坐一次短途飞机。

## 📖 详细说明

### 概念解释
来源：《认知行为疗法》（贝克）
**行为实验**是CBT的独特技术——不是"想通了再行动"，而是"通过行动来验证想法"。


### 实际应用

1. **识别自动思维**：觉察"我此刻在想什么？"
2. **设计实验**：设计一个小实验来验证这个想法。
3. **执行实验**：按照设计执行。
4. **评估结果**：实际结果与预期一致吗？

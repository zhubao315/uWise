# 标注技术：说出情绪让情绪减半

## 📌 核心定义

> “听起来像是……”句式命名对方情绪：说出负面情绪将其消解，说出正面情绪将其强化。

## 🎯 关键要点

- 以“听起来/看起来像是”开头，不用“我觉得”
- 标错了也没关系，对方会纠正你——纠正本身就是信息
- 负面标注泄压，正面标注加固
- 标注后闭嘴，让对方接话
- 可对自己用：焦虑命名后写下来

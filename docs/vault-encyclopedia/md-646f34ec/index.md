# 创造力的神经基础

## 📌 核心定义

> 创造力并非"右脑专属"或某些天才的天赋，而是大脑默认模式网络（DMN）与执行控制网络（ECN）协同运作的结果——发散联想与聚敛筛选交替，共同完成从"灵光"到"成品"的转化。

## 🎯 关键要点

- **默认模式网络（DMN）**：走神 / 松弛时活跃，负责发散联想——灵感多诞生于放空、沐浴、散步时
- **执行控制网络（ECN）**：专注、评估、聚敛——负责把发散的想法筛选、打磨成有价值的输出
- **交替而非二选一**：创造力 = 发散进入 + 聚敛退出，两个网络动态切换
- **环境可塑**：无聊与独处滋养 DMN，深度聚焦激活 ECN——两种状态都要刻意安排

## 📖 详细说明

### 概念解释
过去误以为创造力是单一脑区的天赋，现代神经科学发现它取决于大脑两个网络的动态平衡：DMN 负责"无中生有"的联想，ECN 负责"去伪存真"的评估。真正的创作过程是二者反复交替的振荡——先发散涌现，再收敛判断。

### 实际应用

- **创作节奏**：构思阶段安排散步 / 洗碗（DMN），输出阶段安排深度块（ECN）——与 [90分钟冲刺取代马拉松式工作](../90-md-20aed0d7/) 互补
- **灵感捕获**：走神往往是 DMN 在生成，及时记录而非打断
- **环境设计**：允许"无聊"的时段进入日程，保护发散空间（呼应 [深度工作-注意力护城河](../md-9b177e14/)）
- **判断分离**：创作时先全量发散不评判，进入修改阶段再聚敛——防止 ECN 过早掐灭灵感

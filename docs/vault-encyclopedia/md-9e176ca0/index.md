# “就是这样”确认信号

## 📌 核心定义

> 对方亲口说 That's right＝确认被理解，防御解除；说 You're right 只是在打发你。

## 🎯 关键要点

- 没听到“就是这样”就不算真正理解
- 拿到信号后才进入让步/成交阶段
- 用“总结＋标注”去钓这句话
- 听到“You're right”要警觉：回去重做共情
- 它是信任账户到账的短信通知

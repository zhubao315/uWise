# 代表性启发式与基础概率忽视

## 📌 核心定义

> 用人与类别原型的相似程度替代严谨统计概率，直觉上彻底忽视先验基础概率与样本规模。

## 🎯 关键要点

- 史蒂夫实验：内向描述→判图书管理员，无视农民基数数十倍
- 迪克实验：70/30 与 30/70 样本池下评估均锚定 50%
- 本质是属性替代：概率计算被模式匹配替换
- 小样本必然具总体特征即“小数法则”错觉
- 对策：先调历史客观成功率，再用贝叶斯校准直觉

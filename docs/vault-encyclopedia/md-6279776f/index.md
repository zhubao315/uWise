# 新闻伦理

## 📌 核心定义

> 新闻伦理是关于新闻从业者在追求真相过程中应遵循的道德准则的思考。柴静在《看见》中对新闻伦理的反思，核心在于一个张力：新闻的目的是呈现真相，但呈现真相的过程不可避免地涉及人——而人是有情感、有尊严、有痛苦的。如何在不伤害人的前提下接近真相，如何在不遮蔽真相的前提下保持同情，这是新闻伦理的核心问题。

柴静的思考不是从抽象原则出发的，而是从具体的采访经历中提炼的。她采访过非典患者、虐猫事件的当事人、征地拆迁的农民、药家鑫案的家属——每一次采访都让她面对同一个问题：我是在记录真相，还是在消费苦难？我的镜头是打开了理解，还是加深了偏见？

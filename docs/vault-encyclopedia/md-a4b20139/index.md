# 余闲缓冲区

## 📌 核心定义

> 主动保留20%的时间和金钱作为余闲，是防止稀缺陷阱的最有效策略。

## 🎯 关键要点

- 主动保留20%的时间和金钱作为余闲，是防止稀缺陷阱的最有效策略。
- 稀缺会占据心智带宽，导致短视决策和恶性循环。当你的日程或财务被填满到100%，任何小意外（一次加班、一笔意外支出）都会引发连锁反应，让你陷入被动应对的状态。余闲（Slack）就像缓冲垫，让你在面对不确定性时仍有选择的余地。研究表明，没有余闲的人更容易做出"借用未来"的决策，而这正是稀缺陷阱的核心机制。
- 日程管理：每天保留2小时空白时间，不安排任何任务
- 财务管理：每月收入10-20%自动转入应急基金，视为"不存在"
- 项目管理：deadline提前20%设置，留出真正的缓冲时间
- 决策场景：重要决策前确保自己不在稀缺/疲惫状态
- 1. 审计当前状态：计算你的"满载率"——时间利用率、财务支出占比
- 2. 设定余闲比例：选择一个可承受的比例（建议起步10-20%）

# 阿米巴经营

## 📌 核心定义

> 稻盛和夫创立的管理模式：把公司分成小的独立核算单元，让每个员工都有经营者意识。

## 🎯 关键要点

- 小集体独立核算：把大公司分成小的"阿米巴"
- 全员经营：每个员工都是经营者，不只是执行者
- 透明经营：每个阿米巴的收入和支出都公开透明
- 培养人才：通过经营实践培养经营者

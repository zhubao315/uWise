# 品酒四S法

## 📌 核心定义

> 品酒四S法：观色（Sight）、摇杯（Swirl）、闻香（Smell）、品尝（Sip），是英文世界的品酒标准流程。

## 🎯 关键要点

- 品酒四S法：观色（Sight）、摇杯（Swirl）、闻香（Smell）、品尝（Sip），是英文世界的品酒标准流程。
- 四S法是英语世界最流行的品酒口诀，与中文语境的"品酒四步法"（看闻尝总结）高度重叠但各有侧重。四S法特别强调了"摇杯"作为独立步骤的重要性。
- **Sight（观色）。** 将酒杯倾斜45度置于白色背景前。观察酒液中心到边缘的色调渐变——红葡萄酒从深紫到浅红，暗示年龄和品种；白葡萄酒从无色到深金，暗示酿造风格和陈年程度。澄清度反映过滤工艺；气泡暗示二次发酵或瑕疵。
- **Swirl（摇杯）。** 这是四S法区别于其他品酒法的独特步骤。将酒杯放在桌上画小圈摇晃，让酒液沿杯壁旋转。摇杯的目的是增大酒液与空气的接触面积，释放封闭的香气。摇杯后观察"酒腿"——缓慢流下的液柱暗示较高的酒精度或残糖量。初学者可以在桌上练习，熟练后可以单手持杯在空中摇晃。
- **Smell（闻香）。** 先将鼻子探入杯口但不触碰酒液，轻嗅最挥发性的花果香（一类香气）；再深入杯口，嗅取更深层的工艺香和陈年香。闻香时用短促的浅呼吸，避免嗅觉疲劳。记住：人类的嗅觉可以训练，但需要有意识地建立风味记忆库。
- **Sip（品尝）。** 含一小口酒，让酒液在口中"翻滚"——用舌头搅动酒液，让其接触口腔的每个角落。评估甜度、酸度、单宁、酒体和酒精五个维度。注意入口、中段和收尾三个阶段的风味变化。余味的长度是品质的重要指标。
- 四S法的精髓是：每个步骤都为下一步做准备——观色设定预期，摇杯释放香气，闻香建立风味框架，品尝验证和补充。

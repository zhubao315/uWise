# 考古二重证据法

## 📌 核心定义

> 考古二重证据法是指将考古发掘获得的地下实物资料（如遗址、器物、铭文等）与传统文献记载（如史书、方志、碑刻等）进行交叉验证，以重建更可靠历史事实的研究方法。这一方法的核心理念是：文献可能缺失或带有偏见，地下文物则以"物证"的方式提供更客观的历史信息；而脱离文献的考古发现也难以被完整解读，二者结合才能最大限度地还原历史真相。

该方法的学术渊源可追溯至王国维1925年提出的"二重证据法"——"吾辈生于今日，幸于纸上之材料外，更得地下之新材料。由此种材料，我辈固得据以补正纸上之材料，亦得证明古书之某部分全为实录。"在北京建城史研究中，这一方法得到了淋漓尽致的体现：琉璃河西周燕都遗址出土的堇鼎与克罍铭文，直接印证了文献中"燕国始封都城"的记载，将北京建城史从文字记载的"模糊推测"变为有精确断代的"实证历史"。

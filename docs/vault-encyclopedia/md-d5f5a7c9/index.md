# 价值投资

## 📌 核心定义
> 价值投资是一种基于公司**内在价值**进行投资决策的策略，通过寻找市场价格低于内在价值的股票，等待价值回归获利。

## 🎯 关键要点
- **核心思想**：买股票就是买公司的一部分
- **安全边际**：以显著低于内在价值的价格买入
- **长期持有**：价值回归需要时间
- **能力圈**：只投资自己理解的企业
- **逆向思维**：在市场恐慌时买入

## 📖 详细说明

### 概念解释
价值投资由本杰明·格雷厄姆创立，后经沃伦·巴菲特发扬光大。其核心理念是：

1. **市场先生理论**：市场短期是投票机，长期是称重机
2. **安全边际**：买入价格要显著低于内在价值
3. **护城河**：选择具有持续竞争优势的企业

### 核心要素

#### 1. 内在价值评估
- **现金流折现法**：预测未来现金流并折现
- **相对估值法**：PE、PB、PS等指标对比
- **资产价值法**：清算价值、重置成本

#### 2. 安全边际
- **定义**：买入价格与内在价值的差距
- **建议**：至少30%以上的安全边际
- **作用**：保护投资者免受估值错误和市场波动影响

#### 3. 护城河分析
- **品牌优势**：如茅台、可口可乐
- **成本优势**：如沃尔玛、西南航空
- **转换成本**：如微软、Adobe
- **网络效应**：如腾讯、Visa

### 实际应用

#### 投资决策流程
```
1. 寻找候选企业 → 2. 分析内在价值 → 3. 评估安全边际 → 4. 检查护城河 → 5. 决策买入/卖出
```

#### 经典案例
- **巴菲特投资可口可乐**：1988年买入，持有至今
- **段永平投资网易**：2002年互联网泡沫后买入
- **张磊投资腾讯**：早期发现并长期持有

## 💡 个人理解

价值投资不仅是一种投资方法，更是一种**思维方式**：

1. **长期主义**：关注长期价值而非短期波动
2. **独立思考**：不被市场情绪左右
3. **持续学习**：不断扩大能力圈
4. **知行合一**：严格执行投资纪律

> 价值投资的精髓在于：**用合理的价格买入优秀的公司，而不是用便宜的价格买入平庸的公司。**

## 🔧 调用示例

> **场景 1：个股估值决策**
> 当你想判断一只股票是否值得买入时：
> 1. 用 DCF 模型估算内在价值（输入：未来5年自由现金流预测 + 折现率10%）
> 2. 对比当前股价，计算安全边际
> 3. 如果安全边际 ≥30%，且护城河分析通过 → 可以买入
> 4. 如果安全边际 <10% → 等待回调或放弃

> **场景 2：投资组合检视（反例/边界）**
> 你持有10只股票，想用价值投资框架检视：
> 1. 逐一检查：是否仍符合"内在价值 > 市场价格"？
> 2. 如果某只股票安全边际已消失（涨到接近内在价值）→ 考虑减仓
> 3. 如果某只股票基本面恶化（ROE连续下降）→ 不再是价值投资标的，应卖出
> 4. **注意**：不要用价值投资框架为亏损持仓找借口（"长期持有"≠"死扛"）

## ⚠️ 边界约束

- **适用范围**：基本面稳定、现金流可预测的成熟企业（消费品、金融、公用事业）
- **不适用**：
  - 高速成长股（现金流为负，无法用 DCF 估值）
  - 强周期股（盈利波动大，内在价值难以估算）
  - 财务造假公司（数据不可信，估值无意义）
  - 你不懂的企业（超出能力圈）
- **前置条件**：需要基本的财务分析能力（读懂三张报表）、估值能力（DCF/PE/PB）
- **风险提示**：
  - 价值陷阱：便宜的股票可能继续跌（基本面恶化的公司）
  - 时间成本：价值回归可能需要数年，期间资金被锁定
  - 估值主观性：内在价值的估算高度依赖假设，不同假设得出不同结论

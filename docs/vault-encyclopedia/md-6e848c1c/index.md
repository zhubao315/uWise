# 现金流比净利润更真实

## 📌 核心定义

> 唐朝在《手把手教你读财报》中提出的核心洞察：利润表基于权责发生制，存在大量主观判断和操纵空间；而现金流量表记录的是真金白银的流入流出，更难造假。经营现金流与净利润的比值是衡量利润质量的关键指标。

## 🎯 关键要点

- **净利润是算出来的，现金流是数出来的**：净利润依赖会计估计（折旧、减值、收入确认时点等），管理层有较大的操纵空间；经营现金流直接反映银行账户的变动，造假难度极高。
- **经营现金流/净利润比值 > 1 为健康信号**：说明企业赚到的利润都以现金形式收回，利润质量高。长期该比值稳定在1以上的公司，通常具有较强的议价能力和良好的商业模式。
- **该比值持续 < 1 需要警惕**：可能是应收账款堆积、存货积压、或提前确认收入所致。特别是连续多年低于0.8时，利润的真实性值得怀疑。
- **警惕"利润增长但现金流萎缩"的剪刀差**：这是财务造假最常见的信号之一，意味着账面利润无法转化为真金白银。
- **不同行业有不同基准**：软件SaaS行业因预收模式，该比值可能天然高于1；而工程建设行业因结算周期长，该比值可能天然偏低，需在行业内横向比较。

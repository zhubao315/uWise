# 法律心理服务

## 📌 核心定义

> 心理学在法律领域的应用：包括刑事心理评估、证人证词可靠性分析、陪审团决策心理、调解心理学、犯罪心理画像和罪犯心理矫正。它将心理学的科学方法引入司法系统，帮助法律决策更加精准和人性化。

## 🎯 关键要点

- **证词可靠性是关键问题**：记忆的可塑性、暗示诱导、目击者偏差等认知因素会严重影响证词准确性。法律心理服务的核心任务之一就是识别并过滤这些偏差。
- **决策心理影响司法公正**：法官和陪审团的决策同样受认知偏差影响——锚定效应、框架效应、后见之明偏差等都可能在法庭上发挥作用。
- **调解心理学减少诉讼成本**：理解冲突双方的认知框架和情绪驱动因素，运用心理学技术促进和解，是法律心理服务中应用最广的领域。

# 可证伪性

## 📌 核心定义

> 来源：《对伪心理学说不》（斯坦诺维奇）

## 🎯 关键要点

- 可证伪："所有天鹅都是白色的"——只要找到一只黑天鹅就能推翻。
- 不可证伪："你的行为受潜意识驱动"——任何行为都能用"潜意识"解释，所以无法证伪。
- 识别伪科学：问自己——"这个说法可以被证伪吗？"
- 评估研究：问自己——"这个研究有没有对照组？有没有可能被推翻？"
- 批判性思维：不要因为"听起来有道理"就相信——要有证据。

# 认知错觉：假性努力与获得感陷阱

## 📌 核心定义

> |------|------|------|

## 🎯 关键要点

- 核心定义：假性努力（Pseudo-Effort）是指个体在进行低认知负荷的重复性活动时，大脑释放「已完成学习」的虚假奖励信号，造成「我在努力」的认知错觉，而实际上并未发生任何知识内化或能力提升。这是碎片化伪学习得以持续吸引用户的核心心理机制。
- 与深度学习的本质区别：
- 深度学习的核心指标：能否用自己的话复述、能否在陌生场景中应用、能否与其他知识建立连接。
- 假性努力的典型特征：听时频频点头、关掉后一片空白、一周后几乎全部遗忘。
- 卡尼曼「系统一/系统二」框架：假性努力全程停留在系统一（直觉、自动、省力）；真正的学习必须调动系统二（分析、刻意、费力）。

## 📖 详细说明

### 概念解释
1. **费曼测试**：学完后立即用最简单的话讲给别人听/写下来——讲不出来 = 没学会。
2. **输出强制**：将「学完」的标准从「看完/听完」改为「产出一份笔记/一个决策/一个行动」。
3. **间隔回顾**：利用遗忘曲线，在 1 天后、1 周后、1 月后主动提取记忆，而非重复观看。

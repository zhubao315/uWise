# 稀少性偏误

## 📌 核心定义

> 常见套路。营造出稀缺性，给人物以稀为贵的感觉。现在抖音带货主播，几乎一定会用这个套路，某款商品限量多少单，卖完就没了，和厂家周旋多少轮才给家人们争取来的福利等等。

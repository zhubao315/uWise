# 拥抱痛苦原则

## 📌 核心定义

> "当你想放弃的时候，问问自己：你是真的不行了，还是只是不舒服？" —— 蒂姆·格罗弗

## 🎯 关键要点

- **痛苦是进化的信号**，不是停止的理由
- **区分"不舒服"和"真的不行了"**：大多数人放弃是因为不舒服，不是因为真的到了极限
- **突破在痛苦之后**：成长发生在舒适区之外

### 实际应用

1. **在运动中多坚持 10%**
2. **在工作中主动承担困难任务**
3. **在学习中挑战不擅长领域**
4. **每次突破后记录感受和收获**

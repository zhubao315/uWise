# 偏差方差权衡模型

> 机器学习中模型复杂度与泛化误差的核心权衡——理解欠拟合与过拟合的根源。

## 误差分解

```
总误差 = 偏差² + 方差 + 不可约噪声
```

| 分量 | 含义 | 高时表现 |
|------|------|---------|
| **偏差（Bias）** | 模型预测值与真实值的系统偏离 | 欠拟合：太简单 |
| **方差（Variance）** | 模型对训练数据变化的敏感度 | 过拟合：太复杂 |
| **噪声** | 数据本身的随机性，不可消除 | — |

## 权衡关系

```
简单模型 → 高偏差（欠拟合） + 低方差
复杂模型 → 低偏差 + 高方差（过拟合）
```

**最优模型**：在偏差和方差之间找到总误差最小的平衡点。

## 实践指导

| 问题 | 解决方向 |
|------|---------|
| 高偏差 | 增加模型复杂度、更多特征、减少正则化 |
| 高方差 | 更多数据、减少特征、增加正则化、Dropout |

# 黑天鹅信息杠杆

## 📌 核心定义

> 永远假设每场谈判藏着三条改变格局的未知信息，用标注＋校准问题把它钓出来再成交。

## 🎯 关键要点

- 未知分三类：对方不知道你知道、你不知道对方知道、双方都不知道
- 成交前问自己：还有什么没问出来
- 标注试探＋开放问题是钓竿
- 一条黑天鹅可顶全部让步
- 贪快成交是黑天鹅的最大天敌

## 📖 详细说明

### 出处
第 10 章，全书压轴心法。

### 应用
每次成交前强制问三遍“还有什么我不知道的”。

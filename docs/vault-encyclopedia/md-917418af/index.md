## 📌 核心定义

> 大明朝堂上人人满口仁义道德，私下却行贿结党、买官鬻爵。不是没有制度，而是制度只活在纸上。当"阳"变成表演，"阴"才是真正的游戏规则。

## 🎯 关键要点

- **当一个组织的官方规则（阳）与实际操作（阴）严重脱节时，组织就进入了慢性衰败。** 表面的道德宣言越响亮，背后的潜规则就越猖獗。不要只看制度文本，要看制度在真实场景中如何被执行——执行层才是真相。

- **做法：** 不要只看规章制度写得漂不漂亮，要到一线去看——这个规则在实际中被执行了多少？执行时走了多少样？偏差的方向是什么？每月花1小时做一次"影子观察"：跟着一线员工走一遍流程，记录制度与实际的差异点。
- **原理：** 明朝从来不缺法律和制度，缺的是执行。黄仁宇指出，帝国的法律"缺乏创造性"，不是法律条文不够多，而是法律在基层被选择性执行、变通执行，最终形同虚设。制度的价值=制度文本×执行系数，执行系数为0则制度无意义。

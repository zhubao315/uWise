# 熬：主动蛰伏与积蓄力量

## 📌 核心定义

> **熬不过去，便是终点；熬得过去，便是新生。** 熬绝非被动等待，而是**主动蛰伏**——在低谷中积攒能量，等待时机，最终反击。

## 🎯 关键要点

- **熬不是死扛，而是智慧的蛰伏**：不硬碰硬，主动调整节奏，耐心等待出击时机。
- **熬住孤独**：环境不利时练就内心强大——"我们的方针是持久战"。
- **熬住煎熬**：不在逆境中迷失方向，不被短期困难打倒。
- **熬出转机**：把低谷变成养精蓄锐的机会。
- **熬不是无所作为**：每天设定一个小目标，坚持完成；借低谷期学习、健身、培养新技能。
- **从无力感到掌控感**：别人叹气时你在提升，别人焦虑时你在积累，别人放弃时你还在坚持。

## 📖 详细说明

### 战术隐喻：红军游击战

面对敌强我弱，红军没有硬碰硬，而是提出：
> **"敌进我退，敌驻我扰，敌疲我打，敌退我追。"**

要义：**主动调整节奏，耐心等待出击时机**。熬，就是默默提升自己。

### 转机案例

一位创业者在公司濒临倒闭时没有逃避，反而更加坚决地奋战；半年后具备全新竞争力，成功翻盘。

### 毛主席的话（结语）

> 不要被敌人的气势汹汹所吓倒，
> 不要被尚能忍耐的困难所沮丧，
> 不要被一时的挫折所灰心。
> 道路是曲折的，前途是光明的。
> 黑暗即将过去，曙光就在眼前。
> **有利的条件和主动的恢复，产生于再坚持一下的努力之中！**

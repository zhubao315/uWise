# 智利四大风土带

## 📌 核心定义

> 智利葡萄酒产区按地理特征可分为四大风土带：北部沙漠、中央山谷、高海拔区和巴塔哥尼亚。

## 🎯 关键要点

- 智利葡萄酒产区按地理特征可分为四大风土带：北部沙漠、中央山谷、高海拔区和巴塔哥尼亚。
- 智利的独特地理条件——西临太平洋、东倚安第斯山脉、北接阿塔卡马沙漠、南抵巴塔哥尼亚冰原——造就了四个截然不同的风土带。
- **北部沙漠风土带**以阿塔卡马和科金博产区为代表。阿塔卡马是地球上最干旱的沙漠，极端的干旱和高温迫使葡萄根系深扎数十米寻找水源。这里出产的葡萄酒矿物质感突出，浓缩度极高。利马里谷和艾尔基谷是北部最值得关注的新兴产区，昼夜温差可达20°C以上。
- **中央山谷风土带**是智利葡萄酒的心脏地带，包括迈坡谷、卡恰布谷、库里科谷和莫莱谷。迈坡谷距首都圣地亚哥最近，是智利赤霞珠的经典产区，土壤以冲积扇和黏土为主。中央山谷气候温和，受安第斯山脉下沉气流和太平洋海风双重调节，是种植波尔多品种的理想之地。
- **高海拔风土带**主要指安第斯山脉海拔600米以上的地块。高海拔带来强烈的紫外线、极大的昼夜温差和贫瘠的山坡土壤，葡萄果皮更厚、色素更深、酸度更明亮。近年来智利酒庄不断向高处探索，涌现出一批令人兴奋的高海拔佳作。
- **巴塔哥尼亚风土带**位于智利最南端，是全球最南的葡萄酒产区之一。凉爽的气候、强风和漫长的生长季赋予葡萄酒优雅的酸度和精致的花果香气。黑皮诺和长相思在这里表现出色。
- 四大风土带的多样性使智利成为世界上风格最全面的产酒国之一。

# 课题分离

## 📌 核心定义

> 来源：《被讨厌的勇气》（岸见一郎）

## 🎯 关键要点

- **不干涉别人的课题**：你可以提供帮助，但不能强迫。
- **不让别人干涉你的课题**：你可以听取建议，但决定权在你。
- **课题分离不是冷漠**：不是"不管别人"，而是"尊重边界"。

## 📖 详细说明

### 概念解释
来源：《被讨厌的勇气》（岸见一郎）
"课题分离"是阿德勒心理学最实用的工具——判断一个问题是"谁的课题"，然后不干涉别人的课题，也不让别人干涉你的课题。

**判断标准**：这个选择的后果最终由谁承担？——谁承担，就是谁的课题。


### 实际应用

- **亲子关系**：学习是孩子的课题——父母可以提供帮助，但不能强迫。
- **职场关系**：领导的评价是领导的课题——你的课题是"把工作做好"。
- **亲密关系**：伴侣的情绪是伴侣的课题——你可以支持，但不能替对方感受。

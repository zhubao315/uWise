# 关卡设计

> 游戏中构建玩家体验的核心环节——通过空间、节奏、难度曲线的设计引导玩家行为。

## 核心要素

| 要素 | 作用 |
|------|------|
| **空间布局** | 引导玩家移动路径和探索顺序 |
| **节奏控制** | 紧张→放松→高潮的循环 |
| **难度曲线** | 逐步提升挑战，避免挫败感 |
| **叙事融入** | 环境叙事，让关卡讲述故事 |
| **奖励分布** | 正反馈驱动玩家继续前进 |

## 设计原则

1. **先教学再考验**：新机制先安全环境中练习
2. **可见即可达**：玩家能看到的目标应该能到达
3. **选择有价值**：多条路径各有优势
4. **失败可恢复**：死亡/失败后快速重试，惩罚适度

## 经典案例

| 黑暗之魂 | 高难度但公平，每个死亡都有教训 |
| 塞尔达 | 开放世界中的引导式探索 |

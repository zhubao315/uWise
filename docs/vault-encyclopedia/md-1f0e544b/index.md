# 组织竞争力公式

## 🎯 关键要点

- **核心公式**：组织竞争力 = (人才密度 × AI杠杆) ÷ 组织摩擦
- 这一公式来自腾讯研究院《从超级个体到超级团队：AI时代组织变革的涌现路径》，提供了一个理解AI时代组织竞争力的简洁框架。三个变量的组合决定了组织在AI时代的实际竞争力水平。
- **定义**：组织中高能力人才的浓度和质量。不是"有多少人"，而是"有多少能与AI深度融合的人"。

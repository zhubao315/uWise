# 时间民俗学

## 📌 核心定义

> 时间民俗学是民俗学的一个分支领域，研究特定文化群体如何通过民俗活动来感知、划分、标记和组织生活时间。它关注的核心问题不是天文学意义上的时间测量，而是文化意义上的时间建构——普通人如何通过节日、仪式、禁忌、饮食等民俗行为，将抽象的时间流逝转化为可感知、可参与、可记忆的文化体验。

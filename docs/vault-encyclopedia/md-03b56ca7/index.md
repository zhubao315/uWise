# 被动投资原则

## 📌 核心定义

> 被动投资原则由约翰·博格系统阐述，核心公式为：投资者净收益 = 市场总收益 - 成本。在零和博弈的市场中，主动管理者的总收益就是市场收益，但扣除成本后，主动管理投资者的平均收益必然低于市场收益。因此，低成本被动投资是大多数投资者的最优选择。来源：《约翰·博格的投资50年》（约翰·博格，1994年）。

## 🎯 关键要点

- **成本决定论**：博格的投资哲学可以概括为一个等式：投资者收益 = 市场收益 - 成本。这个等式是数学上的必然，不是观点。主动管理的总成本（管理费+交易成本+税费）必然拉低投资者的平均回报，而低成本指数基金能最大程度保留市场收益。
- **术业有专攻的误区**：传统观点认为专业基金经理能战胜市场。博格指出，在扣除成本前，主动管理者的平均收益等于市场收益（因为他们就是市场）；扣除成本后，主动管理者的平均收益必然低于市场收益。这是一个数学恒等式，不是概率问题。
- **简单的力量**：被动投资不需要选股能力、择时能力或任何特殊技能，只需要接受市场平均回报。这种"无知"反而是一种智慧——它避免了主动管理中常见的行为偏差和过度交易。
- **长期视角**：被动投资的真正价值在长期才能显现。短期内，主动管理可能偶尔胜出，但随着时间推移，成本的复利侵蚀效应使得被动投资的优势越来越明显。

## 📖 详细说明

### 概念解释
被动投资原则由约翰·博格系统阐述，核心公式为：投资者净收益 = 市场总收益 - 成本。在零和博弈的市场中，主动管理者的总收益就是市场收益，但扣除成本后，主动管理投资者的平均收益必然低于市场收益。因此，低成本被动投资是大多数投资者的最优选择。来源：《约翰·博格的投资50年》（约翰·博格，1994年）。


### 实际应用

- **核心-卫星策略**：将投资组合的80%-90%配置于低成本指数基金（核心），剩余10%-20%用于主动投资尝试（卫星）。这样既保证了大部分资金获得市场平均回报，又保留了通过主动投资获取超额收益的可能性。
- **费率筛选**：选择指数基金时，优先考虑费率而非追踪误差。在同类指数基金中，费率最低的那只长期表现几乎总是最好的。
- **全市场配置**：不要只投资单一市场指数，而应配置全球股票指数和债券指数，实现真正的分散化。博格建议的简单配置是：年龄%的债券 + (100-年龄)%的全球股票指数。

# 人生脚本

## 📌 核心定义

> 来源：《蛤蟆先生去看心理医生》（戴博德）

## 🎯 关键要点

- 人生脚本是潜意识的：你可能意识不到自己的核心信念。
- 人生脚本是可以改写的：但首先需要觉察到它的存在。
- 心理游戏是脚本的表演：人们会无意识地重复有预设结局的人际互动模式。
- 觉察自己的脚本：问自己——"我内心深处对自己的核心信念是什么？"
- 识别心理游戏：问自己——"我在重复什么人际互动模式？"

## 📖 详细说明

### 概念解释
来源：《蛤蟆先生去看心理医生》（戴博德）
每个人在童年时期就写好了自己的"人生脚本"——一套关于"我是谁""世界是什么样的""我应该怎么做"的核心信念。

| 类型 | 核心信念 | 表现 |
|------|----------|------|
| **赢家脚本** | "我是有价值的，世界是安全的" | 自信、积极、能追求目标 |
| **输家脚本** | "我是不够好的，世界是危险的" | 自卑、焦虑、讨好他人 |


### 实际应用

- **觉察自己的脚本**：问自己——"我内心深处对自己的核心信念是什么？"
- **识别心理游戏**：问自己——"我在重复什么人际互动模式？"
- **改写脚本**：用新的信念替代旧的——"我是有价值的"替代"我是不够好的"。

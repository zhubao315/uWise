# 学习内化

## 📌 核心定义

> Johnny 学的核心概念：将外部获取的知识——读书、听课、观察——转化为个人行为习惯和思维模式的完整过程。读书不是终点，内化才是。真正学到的不是能背诵的内容，而是已经进入"肌肉记忆"、无需刻意调用就能自然运用的部分。

## 🎯 关键要点

- **从外到内的过程**：外部信息 → 理解消化 → 刻意练习 → 自动化——每一步都在减少意识的参与，增加行为的自动性
- **量化内化**：不是"读了 50 本书"，而是"改变了 3 个习惯、新增了 2 个思维框架"——用行为改变量衡量学习效果
- **刻意练习**：内化的关键环节是反复应用——一次读懂的获得感是假象，只有反复用到不需要想，才是真正的内化

# 防御型投资

## 📌 核心定义

> 防御型投资（Defensive Investing）是霍华德·马克斯的核心理念：投资的首要目标不是赚大钱，而是**避免犯大错**——橡树资本座右铭："如果我们避免了输家，赢家会自己照顾自己。"

## 🎯 关键要点

- **防御 > 进攻**："赚钱是投资的副产品，不亏钱才是投资的主产品"
- **避免输家**：先识别并排除"可能永久亏损"的标的，剩下的自然包含赢家
- **分散化**：防御型投资的核心工具——降低单点永久损失概率
- **情绪三对抗**：
  - 对抗贪婪：设定明确卖出规则与目标回报，达标严格执行；接受"别人赚钱我没参与"的不适
  - 对抗恐惧：**平静期写好"暴跌 50% 怎么办"预案**；确保组合不因流动性被迫卖出
  - 对抗从众：决策前先写分析逻辑与预期；复盘区分"独立判断 vs 从众行为"
- **预测的局限**：没有人能持续准确预测——为各种可能的未来做好准备，优于预测唯一未来
- **谦逊与运气**：短期业绩无法分离技能与运气；知道自己不知道什么比知道什么更重要

## 📖 详细说明

### 概念解释

防御型投资与进攻型投资的分野不在"买什么"，而在**目标函数**：进攻型优化"预期收益"，防御型优化"坏结果概率×幅度"。防御型投资者承认两个事实：(1) 风险不可精确度量，只能感知水平；(2) 预测会持续失败——因此不依赖预测，而依赖**规则 + 安全边际 + 分散化**构成的防御结构。

防御不是消极：它是把有限精力从"找更多好股票"转移到"排除坏结果"——因为排除一个永久输家，比多买一个中等赢家对长期复利的贡献更大（复利公式里，任何乘以 0 的过程都归零）。

### 实际应用

1. **永久损失情景卡片**：每个持仓先过"会不会永久亏"关，再谈收益
2. **平静期预案**：暴跌 50% 预案在市场平静时写好（恐慌时只能执行，不能思考）
3. **分散化纪律**：单一资产/单一逻辑的敞口设上限（如单资产 ≤30%）
4. **情绪三对抗清单**：贪婪/恐惧/从众各有具体动作（卖出规则/预案/决策日志）
5. **系统迁移**：知识库防御 = 断链/野生标签治理（永久损失=可信度损失）；"避免输家"优先于"多产出"

# 我选择语言替换

## 📌 核心定义

> 把语言里的“不得不”全部换成“我选择”：夺回主体性，忙碌从勋章变回可选项。

## 🎯 关键要点

- “我不得不加班”→“我选择加班因为＿＿”
- 说不出口的理由暴露了真正的代价
- 语言塑造认知，认知决定边界
- 每天睡前复盘三句“不得不”
- 与优雅说不对内对外配套

## 📖 详细说明

### 出处
本质章“我选择”，精要主义的心智起点。

### 应用
今天起，凡说“不得不”立刻改口并补上理由。

# 程序化广告投放

> 通过算法自动完成广告购买、投放和优化的技术方案。

## 投放模式

| 模式 | 说明 |
|------|------|
| **RTB** | 实时竞价，按展示付费 |
| **PDB** | 保价保量，优先购买 |
| **PD** | 优先交易，价格固定 |
| **PA** | 程序化合约 |

## 技术栈

```
DSP（需求方平台）→ ADX（广告交易平台）→ SSP（供应方平台）
```

## 优化方向

1. **受众定向**：DMP 数据精准画像
2. **创意优化**：A/B 测试+动态创意
3. **出价优化**：oCPC/oCPM 智能出价
4. **频次控制**：避免过度曝光

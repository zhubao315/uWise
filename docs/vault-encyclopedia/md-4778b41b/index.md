# 黑暗森林法则

## 📌 核心定义

> 刘慈欣《三体》中宇宙社会学的核心公理。两条基本定理：1）文明的第一需要是生存；2）宇宙总物质恒定。推论：任何暴露自己坐标的文明，必然被其他文明消灭——宇宙就是一座黑暗森林，每个文明都是带枪的猎人，发现即消灭。

## 🎯 关键要点

- **零和博弈的宇宙版**：资源有限 → 生存竞争 → 先发制人是最优策略。文明间不存在合作的可能性。
- **猜疑链**：两个文明之间无法确认对方的善意，也无法确认对方是否相信自己的善意，形成无限猜疑。
- **技术爆炸**：弱小文明可能在短时间内技术爆炸超越对手，因此必须在其弱小阶段消灭。

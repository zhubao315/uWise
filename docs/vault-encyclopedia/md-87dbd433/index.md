# 交叉点概念

## 📌 核心定义

## 🎯 关键要点

- **交叉点** = 投资收入 ≥ 生活支出。当你的被动收入足以覆盖日常支出时，你就达到了财务自由。
- 投资收入线：持续增长（复利效应）
- 生活支出线：逐步降低（有意识消费）

- **提高投资回报**：学习投资知识，提高被动收入
- **降低生活支出**：区分"需要"和"想要"，减少不必要的消费

# 禅与设计

## 📌 核心定义

> 乔布斯将禅宗的核心原则——直觉、专注、简约——系统性地应用于产品设计的方法论。"初学者的心"（Beginner's Mind）概念来源于铃木俊隆禅师的教导，对乔布斯的产品哲学产生了深远影响。

## 🎯 关键要点

- **直觉**：相信直觉胜过市场调研，用户不知道他们需要什么直到你拿出来
- **专注**：禅宗教导"做一件事"，对应苹果每年只推几款产品的极端聚焦策略
- **简约**：通过冥想式的反复精简，达到"空"的状态——产品只剩本质，没有多余

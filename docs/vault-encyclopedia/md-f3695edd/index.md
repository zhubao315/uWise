# 苹果酸-乳酸发酵

## 📌 核心定义

> 苹果酸-乳酸发酵（MLF）是葡萄酒酿造中的二次发酵，将尖锐的苹果酸转化为柔和的乳酸，降低酸度并增添奶油质感。

## 🎯 关键要点

- 苹果酸-乳酸发酵（MLF）是葡萄酒酿造中的二次发酵，将尖锐的苹果酸转化为柔和的乳酸，降低酸度并增添奶油质感。
- 苹果酸-乳酸发酵（Malolactic Fermentation，简称MLF）是几乎所有红葡萄酒和部分白葡萄酒经历的酿造步骤。它不是真正意义上的"发酵"（不涉及糖分转化为酒精），而是一种酸度转化过程。
- **化学原理：** 乳酸菌（Oenococcus oeni等）将葡萄酒中的苹果酸（二元酸，尖锐刺激）转化为乳酸（一元酸，柔和圆润）。这个过程同时产生少量二氧化碳和双乙酰（奶油和黄油的风味来源）。
- **对风味的影响：** MLF最直观的效果是**降低酸度**——苹果酸的酸感比乳酸强得多，转化后酒的口感变得更柔和。其次是**增添奶油和黄油的风味**——双乙酰正是黄油的主要香气成分。此外，MLF还能增加酒体的圆润感和复杂度。
- **应用场景：** 红葡萄酒几乎100%经历MLF，因为酿酒师追求柔顺的口感和复杂的层次。白葡萄酒则视风格而定——霞多丽（尤其是勃艮第风格）通常经历完全的MLF，获得奶油般的质感；长相思和雷司令则通常阻止MLF，保留清新的酸度和纯粹的果香。
- **控制手段：** 酿酒师可以通过温度控制（低温抑制乳酸菌活性）、二氧化硫添加（杀菌）和过滤（物理去除乳酸菌）来阻止MLF的发生。部分MLF则只转化一部分苹果酸，在清爽和圆润之间取得平衡。
- MLF是酿酒师塑造风格的重要工具——同一批霞多丽，是否进行MLF、进行到什么程度，直接决定了酒是"清瘦矿物"还是"丰腴奶油"。

# 人际关系优化

## 📌 核心定义

> 通过心理学原理系统化改善人际交往质量的方法论。核心思想是将人际关系视为可理解、可优化、可投资的系统，而非被动接受的命运安排。阿德勒的"共同体感觉"和戈特曼的"情感银行账户"是两个关键理论支柱。

## 🎯 关键要点

- **共同体感觉为基础**：阿德勒认为，人际关系是人生三大课题之一，健康的共同体感觉（对他人的关心与贡献感）是幸福的核心来源。
- **情感银行账户为操作框架**：戈特曼提出，每次积极互动都是存入，每次消极互动都是取出。长期关系中，5:1的正负比是健康阈值。
- **系统性而非零散化**：人际关系优化需要从沟通模式、共情能力、边界意识、冲突处理四个维度系统推进，而非孤立解决单一矛盾。

# 家庭系统理论

## 📌 核心定义

> 来源：《超越原生家庭》（理查森）

## 🎯 关键要点

- 家庭是一个系统：每个成员的行为都会影响其他成员。
- 平衡：家庭系统会自动维持平衡——如果一个人改变，其他人会试图把他"拉回来"。
- 症状携带者：家庭的焦虑往往会集中在一个人身上——这个人成为"症状携带者"。
- 理解家庭动力：问自己——"我在家庭中扮演什么角色？"
- 自我分化：在保持连接的同时拥有独立性。

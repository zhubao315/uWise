# 创新者

## 定义

推动技术、产品或商业模式突破的关键角色，具备跨领域视野和非共识判断力。

## 核心特质

1. **好奇心**：对未知领域保持探索欲
2. **跨域迁移**：将A领域的方案引入B领域
3. **容忍失败**：将失败视为学习机会
4. **非共识**：在别人看不到的地方发现机会

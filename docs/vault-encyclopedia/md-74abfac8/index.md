# 恐惧设定工作表

## 📌 核心定义

> 把想做不敢做的事做三栏分析：最坏情况 Top10、预防与补救、不做的代价——把纠结从情绪变成算术。

## 🎯 关键要点

- 写下具体行动，而非模糊愿望
- 最坏情况逐条写对策，多半可承受
- 算“不做”的代价：6 个月/1 年/3 年
- 读完当场拍板，做还是放弃
- 每年恐惧清单复盘一次

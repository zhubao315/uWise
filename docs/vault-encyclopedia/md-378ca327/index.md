# 治未病——预防医学的千年智慧

## 📌 核心定义

> "是故圣人不治已病治未病，不治已乱治未乱。夫病已成而后药之，乱已成而后治之，譬犹渴而穿井，斗而铸锥，不亦晚乎！" ——《黄帝内经·四气调神大论》

## 🎯 关键要点

- "是故圣人不治已病治未病，不治已乱治未乱。夫病已成而后药之，乱已成而后治之，譬犹渴而穿井，斗而铸锥，不亦晚乎！" ——《黄帝内经·四气调神大论》
- **未病先防**：在疾病尚未发生时，通过饮食、作息、情志的调理，增强体质。"正气存内，邪不可干。"
- **既病防变**：疾病刚刚出现时立即干预，防止向深层传变。"善治者治皮毛，其次治肌肤，其次治筋脉，其次治六腑，其次治五脏。"
- **愈后防复**：疾病治愈后，用"调养正气"的方式防止复发。
- 现代医学正逐渐向"治未病"靠拢——从"疾病医学"转向"健康医学"：
- 慢性病（高血压、糖尿病、癌症）"治"起来极其困难，但"防"起来最有效
- 世界卫生组织数据：人类65%-90%的疾病与心理压抑感有关——情志养生的重要性
- 预防医学的投入产出比远高于治疗医学

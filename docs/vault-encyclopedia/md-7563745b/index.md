# 听息法——高级冥想技术

## 📌 核心定义

## 🎯 关键要点

- 来源：《道教与养生》《仙学详述》（陈撄宁）
- 听息法是陈撄宁最著名的实修法门——在静坐时，将注意力放在"听皮肤毛孔的呼吸"上。
- **姿势**：平躺或静坐
- **意念**：闭眼，想象全身毛孔都在随呼吸开合
- **吸气**：毛孔打开，摄取能量
- **呼气**：毛孔关闭，锁住能量
- **时长**：每次15-30分钟
- 通过微细的体表感知，让大脑皮层进入深度抑制状态

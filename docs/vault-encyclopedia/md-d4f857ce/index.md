# 文学纯粹性

## 📌 核心定义

> 木心的文学信仰，也是他一生颠沛中不放弃的事：文学不为政治服务、不为市场服务、不为名利服务。文学只为美和真实服务。这种"纯粹性"不是象牙塔式的封闭——木心经历了战争、牢狱、流亡——而是即便在最黑暗的时代，仍然相信艺术有其不可被工具化的内在价值。

## 🎯 关键要点

- **反工具化**：文学不是宣传的工具、教育的工具、赚钱的工具——这些是对文学的亵渎，也是对写作者的侮辱
- **美作为最高的忠诚**：一切可以为了美而牺牲——包括舒适、安全、出名——但美本身不能被牺牲给任何其他东西
- **对抗的力量**：在一个要求所有事物都有"用"的时代，文学的"无用"恰恰是它最激进的抵抗

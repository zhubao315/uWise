# 对话即思想碰撞

## 📌 核心定义

> "对话即思想碰撞"是许知远在《十三邀》中展现的核心对话理念。与主流访谈节目追求"流畅"、"共识"、"让嘉宾舒适"不同，许知远的对话方式刻意保持张力——他不回避分歧，不掩饰困惑，甚至不害怕沉默和尴尬。他相信，真正的思想交流不是信息的平滑传递，而是不同认知框架之间的碰撞和摩擦。

这种对话方式的前提是：每个对话者都带着自己的"思想地形"——独特的经历、偏见、困惑和信念。当两个不同的地形相遇时，碰撞是必然的。许知远不试图消除这种碰撞，而是把它当作对话的核心价值。碰撞中产生的火花，比共识中产生的温暖更能照亮认知的盲区。

许知远的另一个特点是"笨拙"。他不装作什么都懂，不假装与嘉宾处于同一频率。他的问题常常暴露自己的局限性，但正是这种笨拙打开了对话的空间——当主持人放下"全知"的姿态，嘉宾也更容易放下"表演"的姿态，露出更真实的一面。

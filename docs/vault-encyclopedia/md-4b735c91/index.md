**底层逻辑：**

**7大触发器的识别信号：**

| 触发器 | 典型信号词 | 暂停问自己 |
|--------|-----------|-----------|
| 互惠 | "免费赠送""先体验" | 我是真的需要，还是因为"欠人情"？ |
| 承诺与一致 | "你之前说过""你同意了" | 我现在的想法变了吗？过去的承诺还适用吗？ |
| 社会认同 | "大家都在用""100万人选择" | 大家都这样做，不代表对我就是对的 |
| 喜好 | 对方是你的朋友/同类人 | 我是因为喜欢这个人，还是因为这个方案本身好？ |
| 权威 | "专家推荐""诺贝尔奖得主" | 这个权威在这个领域真的专业吗？ |
| 稀缺 | "限时""限量""最后3件" | 没有这个限制，我还会买吗？ |
| 联盟 | "我们是一类人""自己人" | 我们真的是"自己人"吗？还是被制造的认同感？ |

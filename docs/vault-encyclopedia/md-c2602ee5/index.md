# 校准问题清单

## 📌 核心定义

> How/What 开头、禁用 Why 的问题库，把解决问题的责任优雅推回给对方，还让他觉得方案是自己想的。

## 🎯 关键要点

- “我们怎样才能解决这个问题？”万能开场
- “这对我们有什么好处？”逼对方论证
- “是什么让你这么想？”挖真实动机
- 禁用 Why（像审问），慎用封闭问
- 问题是控制 Frame 的方式，不是陈述

## 📖 详细说明

### 出处
第 7 章“创造掌控的幻觉”。

### 应用
建自己的 10 问清单，谈判/投诉/访谈前挑 3 个备用。

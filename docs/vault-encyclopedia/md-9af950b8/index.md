# 产品思维

## 📌 核心定义

> 以用户价值为核心，通过系统化方法创造、传递和捕获价值的思维方式。

## 🎯 关键要点

- 用户洞察：理解用户的真实需求（不是用户说的需求）
- 价值主张：产品如何解决问题、创造价值
- 产品市场契合：PMF—产品满足市场需求的程度
- 商业闭环：价值创造→价值传递→价值捕获
- 用户故事地图：从用户视角梳理产品功能

# Instagram视觉运营

> 以视觉内容为核心的品牌/个人账号运营方法论——强调视觉一致性和内容美学。

## 内容形式

| 形式 | 特点 | 适合 |
|------|------|------|
| **Feed 帖** | 精修图片，长期展示 | 品牌形象、产品展示 |
| **Reels** | 15-90s 短视频，算法推荐 | 涨粉、触达新用户 |
| **Stories** | 24h 消失，互动贴纸 | 日常互动、投票调研 |
| **Carousel** | 多图滑动，高保存率 | 教程、对比、故事 |

## 视觉一致性

1. **色调统一**：选择 3-5 个主色调，保持滤镜一致
2. **网格规划**：3x3 或 6x3 网格整体视觉节奏
3. **字体规范**：标题/正文各用固定字体
4. **模板复用**：Canva/Figma 建立内容模板

## 增长策略

- **Hashtag 策略**：30 个标签用满，混合大小标签
- **合作互推**：与同量级账号互推
- **UGC 激励**：鼓励用户生成内容并标记品牌
- **SEO 优化**：用户名/Bio/Alt 文本含关键词

# 等待击球法则——少决策、大决策、高确定性决策

## 📌 核心定义

> "我们的游戏是，当好机会出现时，认出它。大部分时间我们什么都不做。我们只是坐在那里，等待好球出现。" ——芒格

## 🎯 关键要点

- 决策疲劳是真实存在的：每天做几百个小决定会消耗认知资源，导致真正重要的决定反而质量下降
- 复合效应偏向集中：复利的威力在于"把对的事做对一次然后让时间放大"，而不是"做很多次平庸的事"
- 市场和人生的"好球区"很窄：大多数时候你面对的都是"坏球"——勉强出手只会打出平庸的结果，甚至三振出局

## 📖 详细说明

### 概念解释
大多数人在大多数时候最该做的事就是**什么都不做**。真正改变人生的决策，一辈子不过几个。与其做100个60分的决定，不如等10个95分的机会出现时全力出击。


### 实际应用

1. **把决策分级**：把所有决策分为"可逆/小"和"不可逆/大"两类。小决策用规则（如固定投资日、每周菜单），大决策用等待（如换工作、买房、创业）
2. **为大决策设立"击球标准"**：提前写下"什么样的条件出现，我才出手"。条件没满足时，做任何事都是干扰
3. **用"不行动"填满等待期**：等待不是发呆——大量阅读、观察、积累判断力，为大机会做准备
4. **出手时敢于下重注**：当所有标准都满足时，不要犹豫。芒格说："好机会不常来。天上掉馅饼时，要用水桶去接，而不是用顶针。"

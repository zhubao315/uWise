## 📖 详细说明

### 概念解释
来源：《真实的幸福》（塞利格曼）
塞利格曼和彼得森提出24种品格优势，分为6大美德：

| 美德 | 品格优势 |
|------|----------|
| **智慧** | 创造力、好奇心、开放思维、热爱学习、洞察力 |
| **勇气** | 勇敢、毅力、诚实、热情 |
| **仁爱** | 爱、善良、社交智慧 |
| **正义** | 团队精神、公平、领导力 |
| **节制** | 宽恕、谦虚、审慎、自我调节 |
| **超越** | 对美和卓越的欣赏、感恩、希望、幽默、灵性 |


### 实际应用

- **每个人都有独特的优势组合**：识别自己的核心优势，在工作中更多地发挥它们。
- **识别自己的优势**：做VIA品格优势测试——找到你的核心优势。
- **发挥优势**：在工作中更多地发挥自己的核心优势。
- **用优势解决问题**：用你的优势来应对挑战——用创造力解决问题，用毅力坚持目标。

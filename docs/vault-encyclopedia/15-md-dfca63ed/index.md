# 15要点选股清单

## 📌 核心定义

> 15要点选股清单是菲利普·费雪在《怎样选择成长股》中提出的一套系统化成长股筛选标准。这15个要点涵盖了管理层素质、竞争优势、增长潜力和估值合理性四个维度，是费雪五十余年投资实践的核心总结。来源：《怎样选择成长股》（菲利普·费雪，1958年）。

## 🎯 关键要点

- **管理层维度（要点1-5）**：①管理层是否诚实且有能力开发新市场；②管理层是否持续投入研发；③管理层是否愿意为长期增长牺牲短期利润；④管理层是否拥有出色的销售组织；⑤管理层是否具备良好的成本意识和财务纪律。
- **竞争优势维度（要点6-10）**：⑥公司是否拥有独特的竞争优势（专利、品牌、规模效应）；⑦公司所在行业的竞争格局是否有利；⑧公司是否拥有足够大的市场空间；⑨公司是否具备定价权；⑩公司的利润率是否高于行业平均。
- **增长潜力维度（要点11-14）**：⑪公司是否在开发新产品或新服务；⑫公司的增长是否依赖于外部融资；⑬管理层是否坦诚面对困难；⑭公司是否拥有一支优秀的管理团队。
- **估值维度（要点15）**：⑮相对于公司的成长潜力，当前股价是否合理。费雪强调，即使前14个要点都完美，如果估值过高也不值得投资。

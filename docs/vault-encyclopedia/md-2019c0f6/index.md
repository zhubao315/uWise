# 观察学习

## 📌 核心定义

> 来源：《心理学与生活》（津巴多）

## 🎯 关键要点

- 替代强化：看到别人被奖励，自己也会模仿——看到别人被惩罚，自己也会避免。
- 自我效能感：相信自己能做到——是行为改变的关键。
- 模型的力量：孩子通过观察父母来学习——父母的行为比言语更有影响力。
- 榜样学习：找到你钦佩的人，观察他们的行为方式。
- 自我效能感：从小的成功开始积累——每次成功都会增强"我能做到"的信念。

## 📖 详细说明

### 概念解释
来源：《心理学与生活》（津巴多）
**观察学习**（班杜拉）：人可以通过观察他人来学习，不需要亲自体验。


### 实际应用

- **榜样学习**：找到你钦佩的人，观察他们的行为方式。
- **自我效能感**：从小的成功开始积累——每次成功都会增强"我能做到"的信念。
- **教育**：父母和老师的行为比言语更有影响力——以身作则。

# 景深控制

景深（Depth of Field）是画面中清晰区域的纵深范围。控制景深是摄影中最有力的视觉表达手段之一——浅景深隔离主体，深景深展现环境。

## 影响景深的三个因素

| 因素 | 浅景深（虚化强） | 深景深（全清晰） |
|------|----------------|----------------|
| 光圈 | 大光圈（f/1.4-2.8） | 小光圈（f/8-16） |
| 焦距 | 长焦（85mm+） | 广角（35mm 以下） |
| 拍摄距离 | 离主体近 | 离主体远 |

## 超焦距（Hyperfocal Distance）

当对焦在超焦距点时，从超焦距的一半到无穷远都在景深范围内。风景摄影的核心技术——让前景到远山全部清晰。

## 常见场景策略

- **人像**：f/1.4–2.8，85–135mm，浅景深隔离背景
- **街头**：f/5.6–8，35–50mm，区域对焦，兼顾主体和环境
- **风景**：f/8–16，超焦距对焦，从头到尾清晰
- **微距**：f/8–16（即使大光圈景深也极浅，需要收缩）

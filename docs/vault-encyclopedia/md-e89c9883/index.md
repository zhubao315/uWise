# 天赋等于信息乘试错

## 📌 核心定义

> 💡 别再问「我有没有天赋」，问自己「我在这个方向投入了多少信息和试错」。天赋是做出来的，不是生出来的。

## 🎯 关键要点

- **信息是乘数的一端**：在某个领域摄入足够多的信息（知识、案例、模式），你的大脑才能建立丰富的关联网络。没有信息输入，试错只是盲人摸象。
- **试错是乘数的另一端**：光有信息不行动，知识只是库存。只有通过反复实践、失败、调整，信息才能内化为直觉和能力。
- **两者缺一不可**：大量信息×0试错=纸上谈兵；0信息×大量试错=低效重复。乘法关系意味着任一项为零，结果都是零。
- **认知抑制是天赋杀手**：从小被告诉「你不是这块料」、被教育系统筛选、被社会期待框定——这些形成了「认知抑制」，让你默认跳过了许多可能的天赋方向。
- **「不擅长」可能只是「没试过」**：你认为自己没有某方面天赋，很可能只是从未获得足够的信息输入和试错机会。

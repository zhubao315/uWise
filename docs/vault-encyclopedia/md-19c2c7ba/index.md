# 爱情三角理论

## 📌 核心定义

> |------|------|------|

## 🎯 关键要点

- 完美的爱需要三个成分：亲密、激情、承诺。
- 爱情会随时间变化：初期激情高，后期亲密和承诺更重要。
- 关系需要维护：三个成分都需要持续投入。

## 📖 详细说明

### 概念解释
来源：《亲密关系》（米勒）
斯滕伯格提出爱情由三个成分组成：

| 成分 | 含义 | 表现 |
|------|------|------|
| **亲密** | 情感连接 | 信任、理解、支持 |
| **激情** | 身体吸引 | 性吸引、浪漫感 |
| **承诺** | 长期决定 | 维持关系的意愿 |


### 实际应用

在关系进入平淡期时，可定期安排约会或尝试新活动以重新点燃激情；同时通过深度沟通分享脆弱面来深化亲密感，并共同制定长期目标以巩固承诺。建议伴侣双方每半年对照这三个维度进行自我评估，识别当前关系中缺失的成分（如仅有亲密而无激情的“喜欢”），从而针对性地调整互动策略以维持关系的完整性。

# 阅读分类及感受类阅读定义

## 📌 核心定义

> 1. **阅读分类**：阅读粗略分为感受类阅读和知识类阅读

## 🎯 关键要点

- 调剂生活：带来放松感和愉悦感。
- 指引生活：帮助在众多选择中初步筛选，经进一步判断后明确自己要做什么。大学前人生轨迹较清晰，之后需思考 “我要做什么”，此为主观问题，只能靠主观感受解决，即 “做自己想做的事情”，感性负责初步筛选，理性负责进一步判断，二者同等重要。
- 认识自己：认识自己并不简单，弗洛伊德揭示人有潜意识，精神分析学说研究阻抗，霍妮在《自我分析》中探讨自我分析的可行性、任务流程、阻抗处理等，为深刻认识自己提供道路。

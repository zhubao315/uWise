# 零度写作

## 📌 核心定义

> 余华早期风格的核心特征：以极端冷静、克制的笔调描写暴力与死亡，不做道德评判，让事件本身的残酷说话。源自罗兰·巴特"零度写作"理论，余华将其推向极致——叙述者如同冰冷的摄像机，只记录不评价。

## 🎯 关键要点

- **叙述者退场**：作者不介入、不抒情、不评论，消除主观情感色彩，让文本自身呈现残酷。
- **暴力美学**：以冷静笔触描写血腥、死亡、肢解等极端场景，反差的克制加剧了冲击力。
- **早期代表**：《现实一种》《河边的错误》等作品是零度写作的典型实践。

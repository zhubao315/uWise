# 并购整合与投后管理

> 企业并购后的整合执行和投资项目的持续管理方法论。

## 整合框架

| 阶段 | 关键动作 |
|------|---------|
| **Day 1** | 交接公告、组织架构确定、关键人才锁定 |
| **100天** | 流程整合、系统对接、文化融合启动 |
| **1年** | 协同效应实现、组织稳定 |

## 投后管理要点

1. **治理参与**：董事会席位/观察员
2. **战略协同**：业务协同点识别和推进
3. **风险监控**：财务/法律/运营风险
4. **退出规划**：IPO/并购/回购路径

## 常见失败原因

- 低估文化整合难度
- 过度干涉被投企业管理
- 协同效应假设过于乐观

# 营造技艺的活态传承

## 📌 核心定义

> 营造技艺的活态传承，是指中国传统建筑技艺通过师徒制、口传心授、实践操作等方式代代相传的非物质文化遗产传承模式。与可以写入书本的理论知识不同，营造技艺中大量涉及"手感""经验""窍门"等隐性知识，只有通过师徒之间长期的共同实践才能传递。

以故宫修缮为例，单士元在《故宫营造》中详细记述了"样式雷"家族七代人执掌皇家建筑工程二百余年的传奇。雷氏家族的技艺传承不是通过学校教育，而是通过家族内部的口传心授：父亲带儿子上工地，手把手教他制作烫样、绘制图档、编制工程做法。这种传承方式保证了技艺的完整性和精确性，但也意味着一旦传承链条断裂，技艺便可能永久失传。

当代中国古建筑保护面临的最大挑战之一，正是营造技艺传承链条的脆弱性。随着老一辈工匠的离去，大量珍贵的营造技艺正在消失。故宫博物院等机构近年来启动了"官式古建筑营造技艺"传承项目，试图通过师徒制重建传承链条，但许多技艺已经难以完全恢复。

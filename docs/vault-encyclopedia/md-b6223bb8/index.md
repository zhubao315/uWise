# 幻觉现实主义

## 📌 核心定义

> 莫言获诺贝尔文学奖的官方标签（Hallucinatory Realism）。融合[魔幻现实主义](../md-ae8855c3/)与中国的民间故事、历史与当下，现实与幻觉无边界交织。与马尔克斯的魔幻现实主义相比，莫言的幻觉现实主义更感官化、更身体化、更接地气。

## 🎯 关键要点

- **诺奖定位**：2012年诺贝尔文学奖颁奖词以此概念概括莫言风格。
- **民间传说与现实的融合**：鬼怪、托梦、民间信仰等元素自然嵌入写实叙事中，不做解释。
- **感官的溢出**：视觉（浓烈色彩）、嗅觉、味觉、触觉的极致描写，让幻觉具有肉身质感。

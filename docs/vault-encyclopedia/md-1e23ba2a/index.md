# 带宽税意识

## 📌 核心定义

> 当你感到疲惫、焦虑或匆忙时，推迟重要决策——稀缺状态下的判断力会显著下降。

## 🎯 关键要点

- 当你感到疲惫、焦虑或匆忙时，推迟重要决策——稀缺状态下的判断力会显著下降。
- 稀缺会消耗认知资源，相当于缴纳了一笔"心智税"。研究发现，缺钱会让人智商下降约13分（相当于失眠一晚的影响）。这意味着：当你因为太忙而感到压力时，你做出的决策质量会变差；当你因为缺钱而焦虑时，你更容易做出短视的财务选择。这不是意志力问题，而是生理性的认知损耗。理解这一点，就能在关键时刻识别自己的状态，避免在"带宽不足"时做重要决策。
- 财务决策：不在深夜或压力大时做投资、消费决策
- 职业决策：不在焦虑状态下做跳槽、转行等重大选择
- 人际关系：不在疲惫时进行重要对话或冲突处理
- 自我反思：定期检查"我最近是否因为太忙而忽视了健康/关系/学习？"

# 刻意练习-3F循环

## 📌 核心定义

> 3F 循环是安德斯·艾利克森《刻意练习》中练习的执行引擎：**Focus（专注）→ Feedback（反馈）→ Fix（修正）→ 更高水平表征 → 再 Focus**。缺任一环节即退化为天真练习。

## 🎯 关键要点

- **Focus 专注**：无专注的练习无效——全神贯注于当前任务，拒绝自动化
- **Feedback 反馈**：无反馈无法区分"进步"vs"固化错误"——反馈是否"及时抵达"决定循环能否自持
- **Fix 修正**：据反馈调整，直到做对——每次修正项 ≤1（唯一改动项）
- **三要素缺一不可**：目标（明确可衡量）+ 专注 + 即时反馈 + 走出舒适区——缺其一退回天性
- **导师/教练的对价**：正是"及时反馈"——无导师时用客观指标/录像/数据自检替代
- **修正协议**：练习后 5 分钟记录错误点 + 下一次唯一改动项

## 📖 详细说明

### 概念解释

3F 循环把"练习"从时间概念变成结构概念：判断一次训练是否有效，不看是否"练得久"，看三个环节是否闭环——专注是否到位、反馈是否及时抵达、修正是否发生。

**"十年一万小时还是业余"的结构性原因**：循环中 Feedback 环节长期缺失——重复在舒适区内进行，错误被固化进表征，练习的"量"在放大错误而非消除错误。

### 实际应用

1. **练习前**：写下一个可衡量的目标（今天的定义域）
2. **练习中**：由导师/录像/数据提供即时反馈；反馈延迟 ≤ 练习单元时长
3. **练习后**：5 分钟修正协议——记录错误点 + 下一次唯一改动项
4. **量化**：每练习单元 ≥1 可测目标；凡缺反馈/缺专注的训练标记"无效时长"
5. **系统迁移**：知识库的 3F = 晨间计划（Focus：当日 P0）→ 晚间复盘（Feedback：完成/缺口/偏差）→ 次日还账（Fix：缺口进 P0）——uLife 循环工程就是 3F 循环的日级实现

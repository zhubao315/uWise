# 生活形式

## 📌 核心定义

> 维特根斯坦后期哲学概念。语言游戏必须嵌入特定的"生活形式"——即一个共同体共享的活动方式、文化实践和世界理解——之中才能被理解。语言不能脱离人类集体活动方式而孤立存在。不同文化有不可通约的生活形式，理解一种语言就是理解一种生活方式。

## 🎯 关键要点

- **语言的基础**：语言根植于具体的人类集体活动之中
- **不可通约性**：不同生活形式之间可能难以直接翻译和理解
- **公共性前提**：私人语言不可能，因为规则来自共同生活形式

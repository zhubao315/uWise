# 功利主义

## 📌 核心定义

> 功利主义（Utilitarianism）是由边沁和密尔发展的伦理学理论，主张行为的道德价值取决于其产生的总体幸福或效用最大化。

## 🎯 关键要点

- **最大幸福原则**：正确的行为是能为最大多数人带来最大幸福的行为
- **边沁的享乐功利主义**：快乐和痛苦是唯一的价值尺度，可用效用计算
- **密尔的高级快乐**：区分高级快乐（智力、审美）和低级快乐（感官），"做一个不满足的苏格拉底胜过做一头满足的猪"
- **行为功利主义 vs 规则功利主义**：评估单个行为 vs 评估行为规则

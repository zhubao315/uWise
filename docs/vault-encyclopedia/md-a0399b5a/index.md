# 习惯复利效应

## 🎯 关键要点

- 微小的日常改进具有指数级累积力量，但这种力量只有在足够长的时间尺度上才能被感知到。
- $$1.01^{365} = 37.78$$
- 每天进步1%，一年后你会是今天的37.78倍。
- $$0.99^{365} = 0.03$$
- 每天退步1%，一年后你只剩下原来的3%。

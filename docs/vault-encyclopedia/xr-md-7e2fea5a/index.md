# XR交互设计

> 扩展现实（VR/AR/MR）环境下的用户体验设计——不同于平面屏幕的三维空间交互范式。

## 与传统 UI 设计的区别

| 维度 | 传统 UI | XR 交互 |
|------|--------|---------|
| 输入 | 键鼠/触屏 | 手势/眼动/语音/控制器 |
| 空间 | 二维平面 | 三维空间 |
| 注意力 | 全屏聚焦 | 环境分散 |
| 反馈 | 视觉+听觉 | 视觉+听觉+触觉+体感 |

## 核心设计原则

1. **空间锚定**：UI 元素固定在物理空间中，不随头部移动
2. **舒适性**：避免晕动症（帧率 > 72fps，减少快速运动）
3. **渐进复杂**：从简单交互开始，逐步引入高级功能
4. **环境感知**：设计需考虑真实环境（光照/空间/障碍物）

## 常见交互模式

- **射线指向**：远距离选择
- **直接抓取**：近距离操作
- **手势识别**：空手交互（Pinch/Grab）
- **眼动追踪**：注视选择/隐式交互

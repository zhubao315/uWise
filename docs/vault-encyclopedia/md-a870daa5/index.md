## 📌 核心定义

> 王阳明心学的核心命题：知而不行只是未知。真正的"知"必然包含"行"的动力和能力——如果你声称知道却做不到，说明你并非真知。知行不是两件事先后发生，而是同一过程的两个维度，在心上同时完成。

## 🎯 关键要点

- **知而不行只是未知**：如果一个人说"我知道但做不到"，那不是谦虚而是误判——他其实并不知道
- **知行本体**：知与行不是先后关系而是同一本体，真知必然触发真行
- **事上磨练**：修行不在静坐空想中完成，必须在具体事务中验证和精进

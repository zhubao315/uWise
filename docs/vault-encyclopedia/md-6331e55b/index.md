# 复杂系统

## 📌 核心定义

> 复杂系统（Complex Systems）是由大量相互作用的组成部分构成的系统，其整体行为无法通过分析单个部分来预测。涌现性、非线性和自组织是其核心特征。

## 🎯 关键要点

- **涌现性**：整体大于部分之和，宏观行为从微观交互中自发涌现
- **非线性**：小因可致大果（蝴蝶效应），因果关系不成比例
- **自组织**：无需中央控制，局部规则产生全局秩序
- **适应性**：系统能根据环境变化调整自身结构
- **反馈回路**：正反馈放大变化，负反馈维持稳定

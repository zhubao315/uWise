# 最小可行习惯

## 核心定义

最小可行习惯（Mini Habits）是指将目标行为简化到"小到不可能失败"的程度，通过极低的启动成本来建立持久习惯。

## 核心原理

| 原理 | 说明 |
|------|------|
| **降低启动阻力** | 1个俯卧撑比100个更容易开始 |
| **绕过意志力** | 意志力是有限资源，不要依赖它 |
| **建立神经通路** | 重复比强度更重要 |
| **利用惯性** | 开始后往往会继续做更多 |

## 设计公式

```
最小可行习惯 = 目标行为 ÷ 10
```

**示例**：
| 目标 | 最小可行习惯 |
|------|--------------|
| 每天跑步5公里 | 穿上跑鞋走出门 |
| 每天读书1小时 | 读1页 |
| 每天写作1000字 | 写1句话 |
| 每天冥想20分钟 | 深呼吸3次 |

## 实践要点

1. **不要提高标准**：完成就是胜利
2. **庆祝微小胜利**：强化正反馈
3. **绑定现有习惯**：利用习惯叠加
4. **记录完成情况**：可视化进度

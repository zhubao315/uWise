# 思考的系统方法

## 📌 核心定义

> 把研究对象视为由要素、连接、功能共同构成的整体系统，通过识别结构（而非孤立事件）来理解行为、寻找杠杆点——"系统地思考"而非"思考系统"。

## 🎯 关键要点

- **看结构而非事件**：同一行为反复出现，必有其背后结构（回路 / 存量流量），治本须改结构
- **存量与流量**：把变化拆成"存量（累积值）与流量（流入流出）"，找到真正决定状态的是存量
- **反馈回路**：增强回路（放大）与调节回路（稳定）——系统行为由回路竞争决定
- **杠杆点**：系统性干预要打在调节回路或信息流等深层杠杆，而非表面参数
- **涌现与时间延迟**：局部简单规则 + 相互作用会涌现全局行为，且常常有时滞，须警惕过度反应

## 📖 详细说明

### 概念解释
思考的系统方法源自系统动力学（System Dynamics），强调"事件 → 模式 → 结构"的透视层次。多数管理问题之所以反复出现，是因为我们把注意力停留在事件层，而真正决定行为的是藏在事件背后的系统结构。修结构比救火更根本。

### 实际应用

- **问题诊断**：把"最近总拖延"拆成回路——启动阻力 → 逃避 → 自我否定 → 更大阻力，找到断点
- **决策杠杆**：知识库断链治理是"结构修复"而非"逐条打补丁"（对应 link_checker 的逐文件确认策略）
- **延迟预期**：习惯养成初期无感是流量与存量的时滞，系统方法帮助坚持过反馈滞后期

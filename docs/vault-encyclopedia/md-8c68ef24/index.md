# 教育心理学应用

## 📌 核心定义

> 将心理学原理（认知发展、学习理论、动机理论、发展心理学）应用于教育实践的具体方法论。它回答的核心问题是：如何基于人的心理发展规律，设计更有效的教与学过程。正面管教的理论根基就建立于此。

## 🎯 关键要点

- **最近发展区为教学设计核心**：维果茨基指出，最佳学习发生在"学生独立能做的"和"需要辅助才能做的"之间——教育者的任务不是填鸭而是搭建脚手架。
- **内在动机优于外在奖惩**：德西和瑞安的自我决定理论表明，当自主性、胜任感、关系需求被满足时，学习动机会自然涌现。过度依赖奖惩会侵蚀内在动机。
- **发展阶段的适配性**：皮亚杰的认知发展阶段论提醒我们，教育方法必须与学习者的认知成熟度匹配。对儿童说教抽象道理是无效的。

# 团战决策框架

团战是 MOBA 游戏中最核心的高频决策场景。胜负往往不在操作细节，而在团战开打前的**决策质量**。

## 开团前的四个判断

| 判断项 | 问自己 | 决定 |
|--------|-------|------|
| 人数优势 | 我方比对方多一个人吗？ | 人多必打，人少必撤 |
| 关键技能状态 | 对方闪现/大招在不在CD？ | 对方没大招就是最佳开团窗口 |
| 位置优劣 | 我方阵型是否站好？ | 被分割包围就撤，形成扇形夹击就打 |
| 目标优先级 | 这波团赢了能拿什么？ | 如果赢了也只能拿个塔就别开，等下一波拿龙/高地 |

## 团战中的角色定位

| 角色 | 核心任务 | 不要做 |
|------|---------|-------|
| 前排/坦克 | 开团/吃技能/保护后排 | 追残血脱离队伍 |
| 刺客/战士 | 切后排/等对方交控再进场 | 第一个冲进去吃满伤害 |
| 法师/射手 | 持续输出/走位拉扯 | 走位太靠前被秒 |
| 辅助 | 控制/视野/保护 | 开团时把AD扔后面不管 |

## 团战后的决策树

打赢团 → 拿什么？优先次序：
1. 高地/水晶 （可一波）
2. 主宰/暴君 （长久收益）
3. 推塔 （稳定收益）
4. 反野 （最低收益）

打输团 → 做什么？
- 存活的人去清兵线拖延对方推进
- 观察对方剩余状态，如果对方状态差可以尝试反打
- 等待队友复活期间不接任何团

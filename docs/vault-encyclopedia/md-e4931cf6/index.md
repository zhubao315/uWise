# 七大治愈钱包法则

## 📌 核心定义

> 阿卡德向国王进献的七条治愈“瘦钱包”的法则：存、控、投、守、住、保、学，覆盖一个人完整的财务生命周期。

## 🎯 关键要点

- 一存：[先支付自己十分之一](../md-3d01350f/)
- 二控：预算管住欲望，区分必要与想要
- 三投：让每一分钱去工作，钱生子女生孙
- 四守：守护本金，只投懂的领域
- 五住：自住房产，把房租变资产
- 六保：为年老与家庭预留（年金/保险）
- 七学：提高赚钱能力，能力本身也要复利

## 📖 详细说明

### 出处
《巴比伦最富有的人》核心章节，国王召集全城智者验证后颁行。

### 应用
按七条逐项打分自查：缺哪条补哪条；其中“守”与“学”最易被忽视，却是长期复利的关键。

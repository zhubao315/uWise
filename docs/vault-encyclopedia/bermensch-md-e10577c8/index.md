# 超人 Übermensch

## 📌 核心定义

> 尼采在《查拉图斯特拉如是说》中提出的理想人类类型，与"末人"（只求安逸、无远大志向的平庸之人）相对。超人不被传统道德和外在权威束缚，自我立法、自我创造、自我超越。超人并非已完成的存在，而是人类"自我超越"的方向和过程——"人是应当被超越的"。

## 🎯 关键要点

- **超越末人**：拒斥只求安逸舒适的平庸生活，追求不断自我超越
- **自我立法**：不依赖外在道德体系，创造自己的价值标准
- **方向而非终点**：超人是一个"成为"的过程，不是一种已抵达的状态

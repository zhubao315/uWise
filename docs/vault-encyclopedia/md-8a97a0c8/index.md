# 身份驱动习惯法

## 📌 核心定义

> 每个行动都是对你想成为的那个人的一次投票。不需要完美，只需要多数票。

## 🎯 关键要点

- 真正持久的习惯改变不来自目标，而来自身份认同。你不是在"试图戒烟"，而是"你不是吸烟的人"。
- 最外层：结果（Outcome）    → 我想减掉10斤
- 中间层：过程（Process）    → 我每天跑步30分钟
- 最内层：身份（Identity）   → 我是一个运动的人
- 大多数人从外向内改变：设定目标 → 找方法 → 期望改变身份。但**真正有效的方向是从内向外**：先改变身份认同 → 过程成为自然选择 → 结果自动跟随。
- 1. **目标有终点，身份没有** — 跑完马拉松后目标消失了，但"我是跑者"的身份会驱动你继续跑下一个。
- 2. **减少意志力消耗** — "我是素食者"比"我在尝试少吃肉"更容易拒绝一块牛排，因为前者是身份，后者是约束。
- 3. **每次行动都是投票** — 每次选择阅读而非刷手机，都是在为"我是读者"这个身份投一票。不需要全票通过，多数票就够了。

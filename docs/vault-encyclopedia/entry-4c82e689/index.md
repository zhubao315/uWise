# 经验晶体 人生处处是围城如何突破向往与厌倦的循环

## 📌 核心定义

> 人永远在向往和悔恨之间徘徊：得不到时觉得美好，得到后又开始厌倦。这不是个人缺陷，而是人类共同的生存悖论——"围城心态"。突破的关键不是"找到更好的城"，而是**停止美化未得到的东西，学会在已拥有的城中建造花园**。

## 🎯 关键要点

- 职业选择：跳槽前充分了解目标岗位的真实状态，而非只看到光鲜的一面

- 消费决策：购买前思考"我真的需要，还是只是想要"？
- 人生规划：接受任何选择都有代价，关键是选择后全心投入

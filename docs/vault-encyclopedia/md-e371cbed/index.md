# 自创生

## 📌 核心定义

> 卢曼社会系统理论的核心概念（借自生物学 Autopoiesis）：社会系统能够自我生产、自我维持、自我修复。社会系统不是由人组成，而是由"沟通"组成——沟通产生沟通，构成一个自创生的、不需要外部输入即可持续运作的封闭系统。

## 🎯 关键要点

- **生物学起源**：马图拉纳和瓦雷拉用此概念描述生命细胞——细胞不断自我生成维持自身的组件
- **社会学的转化**：卢曼移除了"生命"维度，保留"自我生产"逻辑——社会系统用沟通生产沟通，循环自持
- **关键含义**：社会不是人的集合，系统用"可沟通/不可沟通"二元编码筛选世界，人只是系统的环境

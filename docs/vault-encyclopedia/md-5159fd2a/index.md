# 凯撒的归凯撒，上帝的归上帝

## 📌 核心定义

> 人的生活由两部分组成，肉体生活和精神生活。“恺撒的归恺撒，上帝的归上帝”也就是要分开世俗权力和精神权力。换句话说，要政治（即“恺撒——肉体生活——世俗权力）和宗教（上帝——精神生活——精神权力）分开处理。

# 玻璃基板封装技术

## 📌 核心定义

玻璃基板（Glass Core Substrate）是以玻璃取代传统 ABF 树脂/硅中介层作为芯片封装基板的先进封装技术，通过 TGV（玻璃通孔）实现高密度互连，是 AI 芯片突破算力瓶颈的关键工艺路径。

## 🎯 关键要点

- **驱动力**：AI 芯片算力爆发，ABF 基板与硅中介层触达物理极限
- **核心优势**：平整度高、尺寸稳定、成本低、支持光电集成
- **产业链三层**：核心设备（LPKF）→ 光电集成平台（康宁）→ 基板量产（AGC/肖特）
- **国内布局**：沃格光电（代工）、大族/帝尔激光（设备）、长电科技（封测）
- **三段接力**：AI 先进封装 → HBM4 中介层 → CPO 光电共封装

## 📖 详细说明

### 传统材料三大痛点

1. **平整度**：大尺寸芯片易翘曲、对位失准；玻璃尺寸稳定、平整度极高
2. **成本**：超大硅中介片造价昂贵；大尺寸玻璃性价比优势显著
3. **远期拓展**：硅无法融合光路；玻璃可同时承载电路 TGV + 光波导，适配 CPO

### 三层产业链价值分布

#### A 层｜核心设备（高壁垒）

- **代表**：LPKF，独家 LIDE 激光 TGV 钻孔工艺
- **特征**：量产刚需，卡脖子环节
- **国内对标**：大族激光、帝尔激光储备 TGV 钻孔工艺

#### B 层｜光电集成平台（长期核心壁垒）

- **代表**：康宁 GlassBridge，内嵌光波导
- **特征**：光子芯片密度提升 4~8 倍
- **意义**：长期竞争壁垒所在

#### C 层｜基板量产制造（充分竞争）

- **代表**：AGC、肖特、SK Absolics
- **特征**：依赖上游设备，竞争充分

### 国内布局企业

| 环节 | 企业 | 定位 |
|------|------|------|
| 代工 | 沃格光电（通格微） | 国内头部玻璃基板 TGV 代工厂 |
| 激光设备 | 大族激光、帝尔激光 | 储备 TGV 钻孔工艺 |
| 封测整合 | 长电科技 | 率先落地玻璃基板封装整合 |

### 赛道长期成长逻辑（三段接力）

```
短期 ──→ AI 先进封装基板（当前主线）
中期 ──→ HBM4 存储中介层
长期 ──→ CPO 光电共封装、光子集成
```

多场景持续接力，设备与工艺可复用，行业成长周期拉长。

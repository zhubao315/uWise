## 第一款：安克雷奇 Hazy IPA（双倍浑浊IPA）

| 项目  | 内容                              |
| --- | ------------------------------- |
| 酒厂  | Anchorage Brewing（阿拉斯加，浑浊IPA顶流） |
| 品类  | IPA - New England / Hazy        |
| 规格  | 473ml                           |
| 酒精度 | 6.4%vol                         |
| 原麦汁 | 17°P                            |
| 苦度  | ~20 IBU 以内                      |

**工艺**：DDH双倍干投（银河+马赛克+西楚），纯酒花释果香，不添加果汁。高蛋白燕麦+小麦基底。

**风味**：
- 香气：开罐爆汁热带水果——芒果、橙子果肉、菠萝硬糖，尾调松树草本清香
- 酒体：金黄色重度浑浊，泡沫绵密奶白，入口顺滑奶油感
- 味觉：柑橘、黄桃、芒果甜感柔和，微苦藏尾段，回甘蜂蜜麦芽甜，酒精感完全被压制

**饮用**：冰镇8-10℃，配炸鸡、烤肉、芝士蛋糕。入门友好型美式浑浊IPA。

## 第二款：安克雷奇 私人领域  Personal Space（三倍浑浊IPA）

| 项目      | 内容                              |
| ------- | ------------------------------- |
| 品类      | IPA - Triple New England / Hazy |
| 规格      | 473ml                           |
| 酒精度     | 10%vol                          |
| 原麦汁     | 21°P                            |
| 苦度      | 70                              |
| Untappd | 4.2                             |

**工艺**：三倍酒花投放量。Phantasm幻影粉（新西兰长相思葡萄发酵粉末）+ 尼尔森苏维 + 萨布罗三重酒花。高蛋白麦芽+小麦+燕麦复合基底平衡10度酒精。

**风味**：
- 香气：白葡萄、椰子、成熟菠萝、香草、柑橘——葡萄香气是核心
- 酒体：深金黄色浑浊，厚重饱满
- 味觉：葡萄果汁感炸裂，椰子奶油顺滑中和酒精，几乎喝不出10度烈感。中段菠萝蜜橘甜，尾调松针微苦平衡
- 余韵：香草奶油麦芽回甘，层次丰富

**饮用**：冰镇6-8℃，小口慢饮（后劲足），配坚果、熟成芝士、烟熏肉类。

## 第三款：跳海酒馆 ×《还有明天》联名拉格

| 项目 | 内容 |
|------|------|

| 规格 | 330ml |

| 原麦汁 | 11.5°P |

**罐身**：大字「women还有明天」，标语「敬自由 为自己」。2025年三八妇女节限定，致敬女性平权。

**工艺**：低温拉格发酵，口感极致干净。淡色皮尔森麦芽+少量萨兹清香酒花，无增味无果汁。

**风味**：浅黄色清澈酒体，麦芽饼干香、青草花香，杀口感柔和，几乎无苦味，收尾干爽。

**定位**：日常口粮微醺酒，门槛极低。野餐、散步、独处放松。

## 第四款：沙坡尾酿造 艋舺 MONGA（双倍浑浊IPA）

| 项目 | 内容 |
|------|------|
| 酒厂 | 沙坡尾酿造（厦门） |
| 品类 | HDHC双倍干投浑浊IPA |
| 规格 | 500ml |
| 酒精度 | ≥8.5%vol |
| 原麦汁 | 19.5°P |

**设计**：手绘蓝青闽南虎纹，「艋舺」台北老地名代表市井江湖文化。台湾街巷系列（艋舺、庙口、角头）。

**工艺**：HDHC高密度酒花干投，西楚+银河+莫图卡热带果香酒花。燕麦+小麦增稠。

**风味**：
- 香气：爆炸型热带水果——蜜橘、番石榴、百香果、芒果，开罐满屋果香
- 酒体：亮橙黄色重度浑浊，泡沫丰厚
- 味觉：果汁感冲击力强，甜感明显。中段松针酒花苦平衡甜腻，8.5度隐藏很好
- 尾韵：持久柑橘果香回甘

**定位**：国产性价比口粮IPA天花板。冰镇7℃，配火锅、烧烤、卤味。

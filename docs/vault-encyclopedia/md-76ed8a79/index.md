## 一、什么是临界（相变）

系统或个人的状态在量变累积到某一阈值时，**突然发生质变**——水到 100°C 汽化、社群共识崩塌、技能平台期后的突破、执念放下后的顿悟。临界前是渐变，临界后是新秩序。

## 三、统一的操作含义

1. **识别临界信号**：监控"边际变化"而非"绝对水平"——质变前往往是斜率变了。
2. **主动逼近有利临界**：用冗余给试错留空间，让突破（刻意练习的平台期跃迁）更可能发生。
3. **防御有害临界**：用安全边际远离崩溃临界点；叙事/心理临界靠冗余（不执=心理冗余）缓冲。
4. **第一性原理推演**：从底层约束直接算临界点，不靠经验外推。

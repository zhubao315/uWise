# 成事学

## 📌 核心定义

> 冯唐融合曾国藩的经世智慧、麦肯锡的管理方法和自身跨界实践提炼的实践哲学。不空谈道德和理论，聚焦于"如何把事做成"——核心理念是持续、执行、结果。成事学的根本立场是不纠缠于"应该是什么"，而追问"怎么才能做到"。

- **三源合一**：曾国藩的"结硬寨、打呆仗"（持续积累）+ 麦肯锡的"MECE、假设驱动"（结构化执行）+ 冯唐自身的跨界验证（实战检验）
- **反空谈**：不争论"道"高不高、"德"纯不纯，只看事有没有做成——结果是最硬的检验标准
- **持续优先**：成事不靠天才的一击，而靠每天一点可积累的推进——进度比速度重要，持续比爆发力重要

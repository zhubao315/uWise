# 判断噪声

## 📌 核心定义

> 噪声是判断中**随机的、不必要的变异**。偏差是系统性的错误方向，噪声是随机的散布范围。

## 🎯 关键要点

- 噪声是判断中**随机的、不必要的变异**。偏差是系统性的错误方向，噪声是随机的散布范围。
- **水平噪声**：不同人的平均判断水平不同（有的法官判刑偏重，有的偏轻）
- **模式噪声**：同一个人在不同情境下判断不同（周一 vs. 周五）
- **场合噪声**：外部因素影响（天气、心情、最近经历）

- 医学诊断：同一患者，不同医生诊断一致率仅 60%

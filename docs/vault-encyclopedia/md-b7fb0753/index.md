# 深度学习方法

> 超越表面理解的深度学习策略——从「知道」到「理解」到「应用」。

## 学习深度层次

| 层次 | 表现 |
|------|------|
| **记忆** | 能复述 |
| **理解** | 能解释 |
| **应用** | 能解决问题 |
| **分析** | 能拆解结构 |
| **评估** | 能判断优劣 |
| **创造** | 能产出新东西 |

## 深度学习策略

1. **主动回忆**：合上书本回忆内容
2. **间隔重复**：分散学习优于集中突击
3. **交叉练习**：混合不同类型的问题
4. **费曼技巧**：用简单语言教别人
5. **关联建立**：新知识与已有知识连接

# 类型文学

## 📌 核心定义

> 区别于"纯文学"的小说创作门类：推理、科幻、武侠、言情、悬疑等遵循固定范式的小说类型。类型文学有自己的叙事公式和读者期待，长期被文学批评界视为"次等文学"，但近年（尤其在中国）凭借紫金陈、马伯庸等作家的作品质量，正从边缘走向主流文学认可。

## 🎯 关键要点

- **范式驱动**：每种类型都有稳定的叙事结构和读者期待——推理要解谜、科幻要世界观、武侠要江湖——创新在范式内完成
- **大众基础**：类型文学的核心读者是普通人而非文学圈——它的生命力来自市场而非奖项
- **地位提升**：中国类型文学正经历从"地摊读"到"主流认可"的过程——影视改编加速了这种地位跃升

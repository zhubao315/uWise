# 智利风土-品种适配模型

## 📌 核心定义

> 智利从西到东、从北到南的地理多样性决定了不同子产区各具独特的风土特征，而每个品种在特定风土条件下才能达到最佳表达，风土与品种的适配关系是智利葡萄酒品质的核心因果逻辑。

# 集中投资原则

## 📌 核心定义

> 集中投资原则由菲利普·费雪提出并践行，主张投资者应将资金集中在少数经过深入研究的企业上，而非广泛分散投资。费雪认为，真正的风险不在于集中持仓，而在于对自己持有的企业了解不够深入。来源：《怎样选择成长股》（菲利普·费雪，1958年）。

## 🎯 关键要点

- **深度优于广度**：费雪一生只投资了不到100只股票，其中大部分利润来自其中的少数几只。他认为，与其对50家企业有浅层了解，不如对5家企业有深刻理解。深度研究带来的认知优势，远比分散持仓带来的风险对冲更有价值。
- **了解企业的真实价值**：集中投资的前提是通过闲聊法和15要点清单，真正理解企业的竞争优势、管理质量和增长潜力。只有当你对一家企业的了解超过市场大多数参与者时，集中持仓才是理性的。
- **长期持有**：费雪持有摩托罗拉长达20年，德州仪器也有多年。集中投资与长期持有是一体两面——你不会频繁交易你真正了解的企业，因为你清楚它的内在价值不会因为季度波动而改变。
- **风险的重新定义**：传统观点认为集中持仓风险更高。费雪反驳说，真正的风险是永久性资本损失，而如果你不了解自己持有的企业，即使分散持仓也无法避免这种风险。

## 📖 详细说明

### 概念解释
集中投资原则由菲利普·费雪提出并践行，主张投资者应将资金集中在少数经过深入研究的企业上，而非广泛分散投资。费雪认为，真正的风险不在于集中持仓，而在于对自己持有的企业了解不够深入。来源：《怎样选择成长股》（菲利普·费雪，1958年）。


### 实际应用

- **组合构建**：一个理想的成长股组合通常包含5-10只股票，每只股票占比10%-20%。关键不是数量，而是每一只都是经过深度研究的"确信持仓"。
- **确信度分级**：将持仓分为"核心确信"（占比20%+）和"卫星观察"（占比5%-10%）。核心确信来自多年跟踪研究，卫星观察来自新发现但尚未完全验证的机会。
- **卖出纪律**：只有在三种情况下卖出：①当初买入的逻辑被证伪；②发现了更好的投资机会；③企业基本面持续恶化。不要因为市场恐慌或短期下跌而卖出。

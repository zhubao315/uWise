# 阿克梅派

## 📌 核心定义

> 20世纪初俄国诗歌流派，曼德尔施塔姆与阿赫玛托娃、古米廖夫为核心成员。反对象征主义（Symbolism）的暧昧模糊与神秘主义泛滥，强调词语的精确质地、清晰的意象、对"此世之美"的回归。阿克梅（Acme）来自希腊语，意为"顶点"或"极致"——追求语言到达其表现力的最高点。

## 🎯 关键要点

- **反象征主义**：超验/神秘的彼岸不是诗人的任务——诗人的任务是面对此岸、面对真实世界的质感
- **词语的物质性**：语词不是通向另一个世界的透明窗口，而是有自身重量、色彩、声音的"物自体"
- **古典的清晰性**：追求古希腊罗马式的均衡、明晰、节制——在混乱的时代保持形式的美

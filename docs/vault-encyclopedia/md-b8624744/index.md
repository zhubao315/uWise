# 五大品鉴维度

## 📌 核心定义

> 品鉴葡萄酒的五个核心维度：酒体、甜度、单宁、酸度和酒精，它们共同构成酒的"结构"。

## 🎯 关键要点

- 品鉴葡萄酒的五个核心维度：酒体、甜度、单宁、酸度和酒精，它们共同构成酒的"结构"。
- 五大品鉴维度是评估葡萄酒结构的标准化框架。掌握这五个维度，你就拥有了描述任何一款酒的基本词汇。
- **酒体（Body）** 是酒在口中的重量感和浓郁度。从轻如水（黑皮诺）到厚重如奶油（巴罗萨设拉子），酒体受酒精度、残糖量、萃取程度和甘油含量共同影响。酒体本身无优劣，关键是与其他维度的平衡。
- **甜度（Sweetness）** 指酒中残糖带来的甜感。干型酒的残糖通常低于4g/L，但高酒精度和果味浓郁度可能制造"伪甜感"——酒的实际含糖量很低，但口中有甜蜜的错觉。真正的甜型酒（如苏玳、冰酒）残糖可达80g/L以上。
- **单宁（Tannin）** 是红葡萄酒特有的触觉维度，来自葡萄皮、籽和橡木桶。它在口中产生收敛感和涩感，是红葡萄酒的"骨架"。单宁的质感（细腻还是粗糙）比数量更重要。白葡萄酒的单宁含量极低，几乎可以忽略。
- **酸度（Acidity）** 是酒的"脊梁"，让酒保持清爽和活力。酸度低的酒显得松散沉闷，酸度过高的酒则尖锐刺口。凉爽产区的酒通常酸度更高，炎热产区的酒酸度更低但酒精度更高。
- **酒精（Alcohol）** 在口中表现为温热感和甜感。酒精度过高会带来灼热感，破坏平衡；过低则酒体单薄。酒精度是酒体最重要的正相关因素。
- 品鉴时，先分别评估每个维度的强弱，再判断它们之间的平衡关系。平衡的酒是"所有维度各安其位"的酒。

# 自我分化

## 📌 核心定义

> 来源：《超越原生家庭》（理查森）

## 🎯 关键要点

- 心理成熟的关键：不是"切断"与家庭的关系，而是在保持连接的同时拥有独立性。
- 三角关系：当两个人之间的焦虑升高时，会引入第三个人来缓解紧张——被"三角化"的人承担了不属于自己的焦虑。
- 代际传递：焦虑会代际传递——除非有人打破这个循环。
- 觉察原生家庭的影响：问自己——"这个行为模式是从哪里来的？"
- 建立心理边界：学会说"不"——不是不爱家人，而是保护自己的心理空间。

## 📖 详细说明

### 概念解释
来源：《超越原生家庭》（理查森）
**自我分化**是鲍温家庭系统理论的核心概念——从家庭的情感系统中分化出来，成为一个独立的个体。

| 程度 | 特征 | 表现 |
|------|------|------|
| **低分化** | 与家庭过度融合 | 无法有自己的想法和感受，总是迎合家人 |
| **高分化** | 保持连接的同时有独立性 | 能在家庭压力下保持自我 |


### 实际应用

- **觉察原生家庭的影响**：问自己——"这个行为模式是从哪里来的？"
- **建立心理边界**：学会说"不"——不是不爱家人，而是保护自己的心理空间。
- **打破代际传递**：先觉察自己的焦虑来源，然后有意识地选择不同的反应方式。

### 实际应用

对每款酒依次完成以下7步记录：

1. **酒体评分（1轻 → 5重）**：感受酒在口中的重量感，像水一样轻盈还是像牛奶一样厚实。
2. **甜度评分（1干 → 5甜）**：判断残糖程度，大多数干型葡萄酒在1-2之间。
3. **单宁评分（1低 → 5高）**：感受口腔干涩和收敛感，主要出现在红葡萄酒中。
4. **酸度评分（1低 → 5高）**：感受唾液分泌量，高酸度会让两颊大量分泌唾液。
5. **酒精评分（1低 → 5高）**：感受喉咙和胸口的温热感。
6. **记录主要香气类型**：从以下大类中勾选2-4种最突出的——
   - 水果（柑橘/热带/红色/黑色）
   - 花香（玫瑰/紫罗兰/白花）
   - 草本（青草/薄荷/青椒）
   - 香料（胡椒/肉桂/香草）
   - 其他（矿石/烟熏/皮革/巧克力）
7. **拍照酒标关联**：用手机拍摄酒标照片，按"日期-酒名"命名保存，方便日后回溯和复购。

# 相对收入计算

## 📌 核心定义

> 有效时薪＝收入÷投入时间：年薪 50 万每周 80 小时，不如 30 万每周 20 小时——比较单位是自由。

## 🎯 关键要点

- 算自己的有效时薪（全部工作相关时间）
- 外包单价低于此时薪的杂事
- 涨薪要换算成时薪涨幅
- F-you Money 本质是买回时间
- 选工作先看时薪，再看年薪

# 麦家：人生的主线任务是保持健康

> 作家麦家将人生比作一场游戏——主线任务是保持健康，支线任务是找事做、培养爱好。

- **主线任务**：保持健康。一旦失败，人生"游戏结束"
- **支线任务**：找事做、培养爱好。功能是更好地完成主线任务
- **核心关系**：支线停止，主线也难以维持

健康不是人生的"锦上添花"，而是支撑一切体验的基础设施。

# 时间块规划

时间块规划（Time Blocking）是将一天划分为若干固定时间段，每个时间段分配给特定任务或任务类别的 productivity 方法。核心原则：为深度工作预留连续 90 分钟以上的无干扰时间块，为浅层任务（邮件、会议）设置专用时间池，避免任务切换的认知损耗。

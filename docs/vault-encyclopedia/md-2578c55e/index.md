# 瑞士干酪法微启动原则

> 在大任务上随意「打洞」——不按顺序，从任意小部分开始，逐步瓦解整块任务。

## 核心方法

像瑞士干酪一样，在大任务上随意打洞：
- 不需要从头开始
- 不需要连续进行
- 任意切入点都可以

## 实践示例

| 大任务 | 微启动动作 |
|--------|-----------|
| 写论文 | 先写最熟悉的那一节 |
| 整理房间 | 先收拾一个抽屉 |
| 学新技能 | 先做一个小练习 |

## 为什么有效

1. **降低启动门槛**：不需要「准备好」
2. **积累势能**：每打一个洞，任务变小一点
3. **打破完美主义**：不完美的开始 > 完美的等待

# 精神三变

## 📌 核心定义

> 精神三变是尼采在《查拉图斯特拉如是说》中提出的隐喻：骆驼→狮子→婴儿，描述精神从被动承受到主动创造的自我超越过程。

## 🎯 关键要点

- **骆驼阶段**：承载传统、责任、道德重负，"你应该"的精神状态
- **狮子阶段**：反抗旧价值，争取自由，"我要"的精神状态，但只有破坏力
- **婴儿阶段**：创造新价值，纯真的开始，"我是"的精神状态，代表永恒回归

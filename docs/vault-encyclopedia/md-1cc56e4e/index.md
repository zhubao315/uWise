# 人民诗人

## 📌 核心定义

> 兰斯顿·休斯的自我定位与文学立场：不是学院派精英诗人，不是象牙塔中的文字匠人，而是为"人民"——特别是底层黑人、劳动者、被忽视的普通人——代言的诗人。他的诗歌语言平易近人却充满力量，不设阅读门槛，让诗歌回归其古老的社会功能：为共同体吟唱。

## 🎯 关键要点

- **诗歌属于人民**：休斯反对"诗歌是少数人的雅事"的观念，主张诗歌应该能被理发店的黑人大叔和哈莱姆街头的孩子听懂并感受
- **题材的民主化**：拉皮条者、舞厅女郎、擦鞋童、疲惫的母亲——这些文学中"不体面"的人物成为休斯诗歌的主角
- **口语的直接性**：不堆砌典故，不使用晦涩的象征，用日常语言直击人心——这是一种有意识的美学选择，不是能力的局限

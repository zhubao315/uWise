# 共情

## 📌 核心定义

> 来源：《非暴力沟通》（卢森堡）《心理咨询与治疗的理论及实践》（科里）

## 🎯 关键要点

- 共情vs同情：共情是"我理解你的感受"，同情是"我为你感到难过"。
- 共情是可以训练的：通过练习可以提高共情能力。
- 共情是治愈的核心：被理解本身就是治愈。
- 倾听：放下自己的判断和建议，专注于对方的感受。
- 复述：用自己的话复述对方的意思——"你是说……对吗？"

## 📖 详细说明

### 概念解释
来源：《非暴力沟通》（卢森堡）《心理咨询与治疗的理论及实践》（科里）
**共情**是深入理解他人的感受和需要的能力——不是"同情"（怜悯），而是"理解"（感同身受）。


### 实际应用

在人际冲突或亲友倾诉时，先暂停给出建议或评判，通过复述确认对方感受（如“你是说……对吗？”）来建立连接；日常可通过阅读文学作品或观察他人情绪细节进行刻意练习，以提升识别和回应他人深层需求的能力。

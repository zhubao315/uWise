# 死是一件不必急于求成的事

## 📌 核心定义

> 史铁生在《我与地坛》中写道："死是一件不必急于求成的事，死是一个必然会降临的节日。"这是他在双腿瘫痪后，经过漫长的思考得出的对生死的终极理解。既然死是必然的，那就不用着急去死；既然活着，就好好活着。

## 🎯 关键要点

- 死是必然的，所以不必急于求成——这是一个逻辑推论，也是一种生活态度
- 既然死不用着急，那就把精力放在"如何活着"上
- 这种认知不是消极的，而是极度务实的——它把人从存在焦虑中解放出来
- 史铁生用这种思考方式走出了瘫痪后的绝望，找到了写作的意义

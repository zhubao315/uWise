# 逆境穿越三板斧

## 📌 核心定义

> 💡 低谷期三板斧：先稳住脚下，再不停走路，别管是顺是逆——穿越周期的人，靠的不是运气，是朴素的坚持。

## 🎯 关键要点

- **看脚下**：不焦虑未来、不后悔过去，只聚焦当下能做的小事——做好手头工作、照顾身体、收拾房间，先稳住局面再往前走
- **不断行**：不躺平不摆烂，哪怕每天只做一点点也保持行动惯性，只要不停下来就一定能走出低谷
- **莫存顺逆**：把顺逆都当人生常态，低谷是看清短板、沉淀能力的修行期，熬过去就更强大
- **知止止损**：发现方向违背规律，哪怕已投入大量沉没成本也要果断止损；大步后退或换山头爬，都是进取之道

# 虚荣之爱

## 📌 核心定义

> 在《《爱的艺术》-艾里希·弗洛姆》中，虚荣之爱（Vanity Love）是弗洛姆描述的一种**爱的异化形态**——人们爱的不是对方本身，而是对方带给自己的"价值确认"。本质上，这是一种**通过他人的爱来证明自己值得被爱**的心理机制。

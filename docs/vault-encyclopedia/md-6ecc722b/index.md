# 砍大钱不管小钱

## 📌 核心定义

> 房、车、保险、费率决定 90%，咖啡决定 10%：先谈下几千块的，再管几块钱的。

## 🎯 关键要点

- 大钱清单：房租、保险、投资费率、薪资
- 小钱清单：咖啡、零食、日用品比价
- 时间花在时薪最高的砍价上
- 小钱靠系统（自动）不靠意志
- 一年复盘一次大钱项即可

# 启发式与偏差模型

## 📌 核心定义

> 代表性启发式、可得性启发式、锚定效应——系统1的快捷方式如何导致系统性的判断偏差

## 🎯 关键要点

- 代表性启发式、可得性启发式、锚定效应——系统1的快捷方式如何导致系统性的判断偏差
- 启发式与偏差模型是卡尼曼和特沃斯基共同发展的认知心理学框架，用来解释人类判断中系统性的偏差。启发式（heuristics）是系统1使用的认知快捷方式——在信息不完整、时间有限的情况下，大脑用简单的规则快速做出判断。这些快捷方式在大多数情况下足够好，但会产生可预测的偏差（biases）。
- **代表性启发式**：根据事物与某个类别的"相似度"来做判断。例如，看到一个安静、爱读书的人，你会判断他更可能是图书管理员而非销售员——即使销售员的总人数远多于图书管理员。这种启发式的偏差是忽略基础概率（base rate）。
- **可得性启发式**：根据信息在记忆中的"可得性"来做判断。例如，飞机失事的新闻让你觉得飞行很危险——因为这类事件容易被记住，尽管统计上飞行比开车安全得多。这种启发式的偏差是高估生动、罕见事件的概率。
- **锚定效应**：判断时过度依赖第一个接触到的信息（"锚"）。例如，先看到一个高价，再看到正常价格时会觉得"便宜"——即使正常价格本身并不低。这种启发式的偏差是被初始信息不当地影响。
- 这些启发式不是"错误"——它们是进化赋予的高效工具。问题是：在现代社会的复杂环境中，这些快捷方式经常失灵，但系统1仍然自动使用它们，而系统2往往不去检验。
- ├─→ 代表性启发式 → 忽略基础概率
- ├─→ 可得性启发式 → 高估罕见事件

### 实际应用

1. **技术估算**：锚定效应在估算中非常常见——第一个提出的数字会锚定后续讨论。刻意让团队成员独立估算后再讨论，避免被锚定。
2. **需求分析**：可得性启发式会让你过度关注最近的、最生动的用户反馈，忽略沉默的大多数。结合数据和反馈，不只听"声音最大"的用户。
3. **面试评估**：代表性启发式会让你根据候选人的"形象"（名校、大公司背景）判断能力，忽略实际表现。用结构化面试对抗这种偏见。
4. **风险评估**：可得性启发式会让你高估罕见但生动的风险（如黑客攻击），低估常见但平淡的风险（如配置错误）。用数据而非印象评估风险。
5. **产品定价**：锚定效应在定价中非常强大——先展示高价方案，再展示中价方案，中价方案就会显得"合理"。

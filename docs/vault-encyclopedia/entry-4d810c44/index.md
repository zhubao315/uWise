- 创意的可持续方法：“成为创意的通道”
- 鲁宾提出的“[通道理论](../entry-4d810c44/)”——创作者要把自己变成“灵感的通道”，而非“灵感的主人”，具体可拆解为三个步骤：
- **清空（Clear）**：通过“冥想、散步、观察自然”等方式，清空大脑中的预设和杂念，比如他制作专辑时，会让录音室保持极简（无装饰、无电子设备），减少外界干扰；
- **接收（Receive）**：保持开放的心态，接纳任何“微小的灵感”，哪怕是“一句无意义的歌词、一个奇怪的旋律”，比如鲁宾会随身携带笔记本，记录任何突然冒出来的想法，不做“好坏评判”；
- **转化（Transform）**：用自己的独特视角将灵感转化为作品，不追求“宏大”，只追求“真实”，比如他指导新人创作者时，常说“先写一首‘只给你自己看’的歌，再考虑分享”。

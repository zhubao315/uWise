### 实际应用

每天花费约10分钟，准备1白1红两款日常餐酒：

1. **2分钟观色记录**（2分钟）
   - 白葡萄酒：观察从浅柠檬黄到深金色的色调
   - 红葡萄酒：观察从浅宝石红到深紫色的色调
   - 记录：颜色深浅、是否有棕色边缘（暗示陈年）

2. **3分钟闻香识别**（3分钟）
   - 先不摇杯，静止闻香，识别第一层香气
   - 再摇杯，释放更多香气，识别第二层香气
   - 试着用具体词汇描述：是柠檬还是青苹果？是草莓还是黑莓？

3. **3分钟品尝感受**（3分钟）
   - 小啜一口，让酒液覆盖整个口腔
   - 感受入口→中段→收尾的变化
   - 注意酸度、单宁、酒体、酒精的综合感受

4. **2分钟记录笔记**（2分钟）
   - 用五大维度品酒记录模板快速打分
   - 写下1-2句整体印象
   - 拍照酒标存档

# AI专家

> 在人工智能领域具备深厚理论基础和实战经验的专业角色，核心能力覆盖算法、工程、产品化全链路。

## 核心能力矩阵

| 能力层 | 技能 |
|--------|------|
| **理论基础** | 机器学习、深度学习、概率统计、优化理论 |
| **工程能力** | 模型训练/调参、分布式推理、数据管道 |
| **系统设计** | AI 系统架构、MLOps、模型部署 |
| **业务落地** | 需求转化、ROI 评估、效果度量 |

## 与传统软件工程师的区别

| 维度 | 软件工程师 | AI 专家 |
|------|-----------|---------|
| 确定性 | 代码逻辑确定 | 模型输出概率性 |
| 调试方式 | 断点/日志 | 实验/消融/可视化 |
| 性能指标 | 延迟/吞吐 | 精度/召回/F1 |
| 迭代周期 | 天/周 | 周/月（含实验） |

## 成长路径

```
调包工程师 → 能复现论文 → 能改进算法 → 能设计系统 → 能定义问题
```

# 有效利他主义

## 📌 核心定义

> 有效利他主义（Effective Altruism, EA）是一种用证据和理性指导善行的哲学与社会运动，其核心目标是最大化每一块钱、每一小时的边际效益。这一运动由哲学家彼得·辛格（Peter Singer）、托比·奥德（Toby Ord）等人奠基，近年来在硅谷和学术界产生了深远影响。

## 🎯 关键要点

- 有效利他主义（Effective Altruism, EA）是一种用证据和理性指导善行的哲学与社会运动，其核心目标是最大化每一块钱、每一小时的边际效益。这一运动由哲学家彼得·辛格（Peter Singer）、托比·奥德（Toby Ord）等人奠基，近年来在硅谷和学术界产生了深远影响。
- 有效利他主义建立在两个关键方法之上：（1）Cause Prioritization（优先议题排序）——系统评估哪些领域最值得投入资源；（2）Cost-Effectiveness Analysis（成本效益分析）——用量化数据比较不同干预措施的效果。例如，研究表明在非洲分发疟疾蚊帐的成本效益远高于在发达国家资助艺术博物馆。
- 有效利他主义为不同背景的人提供了四种参与方式：（1）收入捐献者——将收入的一定比例捐给最有效的慈善组织；（2）影响力职业者——选择能产生最大正面影响的职业（如AI安全研究、全球健康政策）；（3）善行传播者——推广有效利他主义的理念和方法论；（4）社群建设者——壮大有效利他主义社群，吸引更多人参与。
- 早期有效利他主义聚焦于当下可量化的问题（如疟疾防治、寄生虫治疗）。随着长期主义思潮的兴起，EA的关注范围扩展到存在性风险、AI安全、代际公平等长期议题。这种转向引发了内部争议：一些人认为长期主义使EA偏离了"用证据说话"的初心。
- 批评者指出：（1）过度依赖量化分析可能忽视无法量化的价值（如文化多样性、人的尊严）；（2）"最有效"的判断标准本身就是价值判断；（3）硅谷亿万富翁的大量介入可能使EA沦为精英主义的工具。2022年FTX丑闻更严重打击了EA的公信力。

### 概念解释

### 方法三步走

**第一步：画表格**
- 横轴：你想修炼的品质（3-13项，建议先从5项开始）
- 纵轴：一周7天
- 每天记录：做到了留空，没做到打黑点（●）

**第二步：单点突破**
- 每周只专注修炼1项美德，其他项犯错正常打黑点但不自责
- 原则：**注意力在哪里，进步在哪里**。同时追5只兔子，一只也抓不到

**第三步：循环迭代**
- 5项美德 = 5周一轮，一年可循环10轮
- 13项美德 = 13周一轮，一年4轮
- 每轮结束对比黑点数量，观察趋势

> 富兰克林自己说："我从未达到完美，也从未完全实现我最初的目标。但通过这种尝试，我成了一个比未曾尝试时更好、更快乐的人。" **重点不是消除所有黑点，而是每轮比上一轮少几个。**


### 实际应用

1. **单点聚焦避免意志力崩溃**：心理学研究证实，同时改变多个行为习惯会导致"决策疲劳"和"自我损耗"。每周只攻一项，把有限的意志力集中在一个点上
2. **数据化消除"感觉良好"偏差**：没有记录时，我们总觉得自己"还行"。黑点是客观数据——3个黑点就是3个，不会自我欺骗
3. **循环制给"不完美"留了出口**：这一周这项没做好？没关系，下周换另一项，下一轮再来过。永远不会因为"全搞砸了"而彻底放弃
4. **渐进式身份重塑**：每完成一个循环，"我是一个会自我反思并持续改进的人"这个身份就加深一层，执行越来越不需要意志力

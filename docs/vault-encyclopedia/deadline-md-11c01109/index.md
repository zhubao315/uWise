# 帕金森deadline法

## 📌 核心定义

> 工作膨胀到填满所有时间——用极短 deadline 逼出效率，给任务定“离谱但可能”的期限。

## 🎯 关键要点

- 估算耗时先砍半再排期
- deadline 精确到小时而非“这周”
- 配合 80/20：只给高价值任务短期限
- 对外承诺留缓冲，对内执行用短限
- 超时复盘是估算问题还是摸鱼问题

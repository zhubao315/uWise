# 用户心理研究

## 📌 核心定义

> AI产品设计中理解用户认知模式、决策偏见和情感需求的方法论。核心目标是通过心理学的洞察，设计出更符合人类自然认知习惯的产品交互，降低使用摩擦，提升体验深度。这是人机协作设计的认知基础。

## 🎯 关键要点

- **认知模式决定产品架构**：用户不是按照功能菜单思考，而是按任务场景和心智模型操作。产品设计应匹配而非对抗用户的自然认知路径。
- **决策偏见需要"顺势设计"**：默认选项效应、损失厌恶、社会认同等偏见不可消除，但可以被善用——通过选择架构引导而非强制用户做出更好决策。
- **情感需求驱动长期粘性**：功能好用只是及格线，情感共鸣（掌控感、归属感、成长感）才是用户持续使用的深层动力。

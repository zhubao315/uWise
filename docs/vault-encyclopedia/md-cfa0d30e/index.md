# 肉体之爱

## 📌 核心定义

> 在《《爱的艺术》-艾里希·弗洛姆》的框架中，肉体之爱（Sensual Love）是爱的一种原始形态，指**以生理吸引和身体快感为核心驱动力的情感连接**。弗洛姆并不贬低肉体之爱，但他指出，如果爱仅仅停留在这一层面，它将不可避免地走向倦怠。

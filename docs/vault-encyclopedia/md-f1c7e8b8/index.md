# 钟摆理论

## 📌 核心定义

> 钟摆理论（Pendulum Theory）是霍华德·马克斯在《投资最重要的事》第七章"钟摆意识"中提出的市场情绪模型。该理论认为，市场情绪像钟摆一样在贪婪与恐惧两个极端之间摆动，极少停在理性的中心点。投资者不需要预测钟摆会摆向哪里，只需要判断它现在在哪里。

## 🎯 关键要点

- **钟摆从不停在中间**：市场很少处于"合理定价"状态，总是在过度乐观和过度悲观之间摇摆
- **极端位置是均值回归的起点**：当钟摆摆到极端位置时，反转的概率最大，这是投资的最佳时机
- **不要预测时间，要识别位置**：你不需要知道钟摆何时反转，只需要知道它在极端位置时，反转的引力最强
- **极端可以更极端**：钟摆到达极端位置后，可能继续摆得更远。不要因为过早反向布局而焦虑，用仓位管理应对

# MAF180心率公式

## 📌 核心定义

> MAF(Maximum Aerobic Function)心率=180-年龄，再根据训练历史和健康状况微调(±5)，是有氧训练的心率上限。

## 🎯 关键要点

- MAF(Maximum Aerobic Function)心率=180-年龄，再根据训练历史和健康状况微调(±5)，是有氧训练的心率上限。
- MAF心率是训练上限而非目标心率；受伤/生病/停训期间需额外减5；长期系统训练者可加5。

### 概念解释

### 实际应用

跑步或骑行前，先计算基础值（180-年龄），若过去一年有规律训练且无伤病则加5，若有伤病史或停训超过3个月则减5，得出个人MAF心率上限。训练时佩戴心率表监控实时数据，确保全程心率不超过该上限，以此维持有氧代谢效率并避免过度疲劳。

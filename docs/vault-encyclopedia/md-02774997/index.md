# 金字塔加仓法

## 📌 核心定义

> 杰西·利弗莫尔在《股票大作手回忆录》中实践并完善的仓位管理方法：在盈利的头寸上逐步加仓（加仓规模递减），在亏损的头寸上绝不摊平成本。这一方法的核心是"让利润奔跑，截断亏损"，是利弗莫尔交易体系中最重要的风险管理和利润放大工具。

## 🎯 关键要点

- **只在盈利时加仓**：只有当初始头寸已经产生浮盈，且趋势得到确认后，才考虑加仓。亏损时绝不加仓摊平成本，这是铁律。
- **金字塔结构**：加仓规模逐次递减。例如：初始买入1000股，第一次加仓500股，第二次加仓300股，第三次加仓200股。这种结构确保平均成本不会被过度拉高。
- **每次加仓都需要新的确认信号**：不能因为"已经在赚钱了"就随意加仓，每次加仓都应基于新的技术信号或基本面确认。
- **突破关键点位后加仓**：价格突破重要的阻力位或创出新高后，趋势延续的概率增大，是加仓的好时机。
- **回踩确认后加仓**：价格突破后回踩前期关键点位并获得支撑，确认突破有效后加仓。

# 单宁

## 📌 核心定义

> 单宁不是一种味道，而是一种触感——口腔中的收敛涩感，来源于葡萄皮、葡萄籽和橡木桶。

## 🎯 关键要点

- 单宁不是一种味道，而是一种触感——口腔中的收敛涩感，来源于葡萄皮、葡萄籽和橡木桶。
- 单宁（Tannin）是一类多酚化合物，与口腔黏膜中的蛋白质结合后产生干燥、紧缩的触感。初学者常将单宁误认为"苦味"，但苦味是味觉感受，而单宁是触觉——它让口腔黏膜产生类似喝浓茶或吃未熟柿子时的涩感。
- 单宁的三大来源：**葡萄皮单宁**是最主要的来源，红葡萄酒因浸皮发酵而单宁含量远高于白葡萄酒；**葡萄籽单宁**较粗糙苦涩，压榨力度过大会增加这类单宁；**橡木桶单宁**来自陈酿过程，质地更细腻柔和，常伴随香草和烘烤气息。
- 单宁在葡萄酒中的作用至关重要。它是红葡萄酒的"骨架"——没有足够的单宁，酒会显得松散无力。单宁也是天然的防腐剂，高品质红葡萄酒之所以能陈年数十年，正是因为单宁在瓶中缓慢聚合、软化，最终形成天鹅绒般的口感。
- 判断单宁品质的标准是"质感"而非"数量"。优质单宁如丝绸般细腻，即使量大也不会让人感到不适；劣质单宁粗糙干涩，像嚼了一口生核桃。年轻的赤霞珠单宁强劲紧实，陈年后变得柔顺圆润——这是单宁聚合反应的结果。
- 品鉴单宁时，留意舌头和牙龈的收敛感，以及这种感觉消退的速度和方式。

## 📖 详细说明

### 概念解释
单宁不是一种味道，而是一种触感——口腔中的收敛涩感，来源于葡萄皮、葡萄籽和橡木桶。
单宁（Tannin）是一类多酚化合物，与口腔黏膜中的蛋白质结合后产生干燥、紧缩的触感。初学者常将单宁误认为"苦味"，但苦味是味觉感受，而单宁是触觉——它让口腔黏膜产生类似喝浓茶或吃未熟柿子时的涩感。

单宁的三大来源：**葡萄皮单宁**是最主要的来源，红葡萄酒因浸皮发酵而单宁含量远高于白葡萄酒；**葡萄籽单宁**较粗糙苦涩，压榨力度过大会增加这类单宁；**橡木桶单宁**来自陈酿过程，质地更细腻柔和，常伴随香草和烘烤气息。

单宁在葡萄酒中的作用至关重要。它是红葡萄酒的"骨架"——没有足够的单宁，酒会显得松散无力。单宁也是天然的防腐剂，高品质红葡萄酒之所以能陈年数十年，正是因为单宁在瓶中缓慢聚合、软化，最终形成天鹅绒般的口感。

品鉴单宁时，留意舌头和牙龈的收敛感，以及这种感觉消退的速度和方式。


### 实际应用

品鉴红葡萄酒时，可含一口酒液在口中停留10-15秒，重点感受舌头两侧及牙龈的干燥紧缩感以区分单宁与苦味；选购需陈年的赤霞珠或西拉等品种时，应优先选择单宁结构紧实、质地细腻的酒款，利用其天然防腐特性延长保存期。

# 君子求诸己——问题面前先反求自身

## 📌 核心定义

> **出了问题，第一反应应该是"我能做什么不同"，而不是"谁该为此负责"。**

## 🎯 关键要点

- 求诸己：的人，把注意力放在自己可控的部分，因此永远有行动空间，永远不被动
- 求诸人：的人，把注意力放在外部，需要别人改变才能解决问题，因此永远在等待和抱怨

## 📖 详细说明

### 概念解释
**出了问题，第一反应应该是"我能做什么不同"，而不是"谁该为此负责"。**
《论语》中"君子求诸己，小人求诸人"揭示了一个认知模式差异：
- **求诸己**的人，把注意力放在自己可控的部分，因此永远有行动空间，永远不被动
- **求诸人**的人，把注意力放在外部，需要别人改变才能解决问题，因此永远在等待和抱怨

这不是道德说教，而是一个**效能原则**——你能改变的只有自己，所以先从自己入手效率最高。


### 实际应用

1. **暂停：** 问题发生时，先意识到自己的"甩锅冲动"（这是正常的，不必自责）
2. **翻转：** 把问题表述从"他/她/它让我……"改成"在这件事中，我可以……"
3. **行动：** 找到一个自己能立刻做的微小改变，先做起来

# 情绪书写与心理疗愈

## 📌 核心定义

> 通过规律性地将情绪与心事外化成文字（日记 / 列表 / 自由书写），把模糊的内在体验转化为可观察、可分析的对象，从而降低情绪强度、恢复认知资源、实现心理自愈的技术。

## 🎯 关键要点

- **外化即澄清**：情绪在脑中是一团混沌，落地成文字后自动被结构化——"写着写着就想通了"
- **情绪颗粒度**：越能精确命名情绪（愤怒/失望/挫败），越能定位其来源，是情绪智力训练
- **安全对象**：书写只对纸 / 私密文档，无评判者，是比倾诉更低门槛的释放通道
- **与运动互补**：跑步释放身体压力，书写梳理认知压力——二者配合构成身心双通道调节

## 📖 详细说明

### 概念解释
情绪书写是表达性写作（Expressive Writing）的实践形式。它不追求文笔，只追求"诚实地把感受写出来"。当情绪被语言化，大脑从前额叶的抑制模式转向理性整合，负性情绪强度下降，并形成"回头看"的新视角。

### 实际应用

- **情绪日记**：夜晚写 5 分钟，今日最强烈的情绪 + 触发事件 + 命名
- **情绪列表**：压力大时把"所有烦心事"写成清单，逐条判断"能改变 or 不能改变"（呼应 控制论视角下的反馈闭环）
- **创伤处理**：对强烈事件进行多次结构化书写，间隔评估，促进意义重构
- **危机干预补充**：重度情绪困扰仍需专业咨询，书写是日常养身，非治疗替代

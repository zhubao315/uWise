# 情感账户

## 📌 核心定义

> 情感账户（Emotional Bank Account）是史蒂芬·柯维在《高效能人士的七个习惯》中提出的关系模型：把人际关系比作银行账户——礼貌、诚实、守信、兑现承诺是"存款"，粗鲁、失信、背叛是"取款"。账户余额决定关系的容错空间与沟通成本。

## 🎯 关键要点

- **存款行为**：礼貌、诚实、理解对方、兑现小承诺、真诚赞美、尊重边界
- **取款行为**：失信、粗鲁、越界、背后议论、轻慢对方的感受
- **余额效应**：高余额 → 沟通顺畅、容错空间大、"什么都说得通"；低余额 → 一次小事即触发破裂、"什么都说不对"
- **复利效应**：长期小额存款 > 偶尔大额存款——一次道歉大餐救不了长期透支
- **先存款再提要求**：余额足够时，提出要求（反馈/边界）对方才听得进去
- **自我账户**：对自己的失信（说好的运动没做、说好的早睡没守）同样透支情感账户

## 📖 详细说明

### 概念解释

情感账户是习惯 4（双赢思维）与习惯 5（知彼解己）的公共地基——没有余额，双赢和移情都没有承载的容器。

关键洞察在于**复利结构**：情感账户不是"今天吵架、明天道歉"的即时结算系统，而是长期累积的资产曲线。每天的小额存款（一句真诚的"谢谢"、一次不带评判的倾听、一个兑现的小承诺）在复利下形成高余额；而透支往往来自"我以为没事"的无意识取款（一次失信、一次打断、一次敷衍）。

低余额的识别信号：**关系开始出现"什么都说不对"**——这不是沟通技巧问题，是余额不足的结构性信号。此时任何"解决问题"的尝试都会被读成"攻击"，唯一正确动作是切换到存款模式（道歉/陪伴/兑现承诺），先恢复余额再谈问题。

### 实际应用

1. **每日存款自检**：今天对核心关系存了什么？（赞美/倾听/兑现承诺各 ≥1）
2. **冲突处理顺序**：先理解（存款）→ 再表达；低余额时立即停止"解决问题"
3. **自我账户**：对自己的承诺（运动/复盘/早睡）同样记账——失信于自己是最大的取款
4. **关系体检**：某段关系"摩擦成本"突然升高时，先查余额再查沟通技巧

## 💡 个人理解

情感账户最反直觉的一点：**它把"关系好不好"从性格/缘分问题变成了记账问题**——不再问"他为什么总是不理解我"，而是问"我的账户里到底还有多少余额"。对我最直接的映射是肖雪关系：08-20 的星元皮肤事件（她早就看好大司命和猪八戒，等我拆开那一刻）是教科书级的大额存款——**"记住你随口一提的喜好并精心准备惊喜"，是情感账户里利率最高的存款方式**。

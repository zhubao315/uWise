# 代际公平

## 📌 核心定义

> 代际公平（Intergenerational Equity）是指不同世代之间在资源分配、环境责任和道德义务上的公平问题。它追问：当代人对尚未出生的未来世代负有怎样的道德责任？

## 🎯 关键要点

- 代际公平（Intergenerational Equity）是指不同世代之间在资源分配、环境责任和道德义务上的公平问题。它追问：当代人对尚未出生的未来世代负有怎样的道德责任？
- 代际公平面临一个根本性的不对称：未来世代无法参与当下的决策，但当下的决策却深刻影响着他们的生存条件。当代人消耗化石燃料、排放温室气体、制造核废料，其后果将由未来世代承担。这种"代际外部性"是否构成一种不公正？
- 在长期主义的框架下，代际公平是最重要的伦理议题之一。如果人类文明有潜力延续数百万年甚至数十亿年，那么未来世代的数量将远远超过当代人口。从纯粹的数量角度看，未来世代的福祉在道德考量中的权重应该远超当代人。这为气候变化政策、核废料处理、公共债务等议题提供了新的伦理视角。
- 代际公平在经济学中的核心争议是"折现率"（discount rate）。高折现率意味着未来世代的福祉"打折扣"，低折现率则赋予未来世代与当代人相近的道德权重。尼古拉斯·斯特恩（Nicholas Stern）的《斯特恩报告》采用接近零的折现率，得出结论：应立即大幅减排。而威廉·诺德豪斯（William Nordhaus）采用更高的折现率，得出更温和的减排建议。折现率的选择看似技术性，实则蕴含深刻的伦理立场。
- 代际公平原则已渗透到多个政策领域：（1）气候变化——《巴黎协定》的1.5度目标本质上是代际公平的体现；（2）核废料处理——如何向一万年后的世代传达核废料存储地的危险信息；（3）公共债务——当代人的财政赤字由未来世代偿还是否公平；（4）生物多样性——物种灭绝是不可逆的代际损失。
- 批评者指出：（1）我们无法确知未来世代的偏好和需求；（2）过度为未来负责可能牺牲当代弱势群体的利益；（3）技术进步可能解决许多当前担忧的问题。如何在当代人的权利与未来世代的利益之间取得平衡，是代际公平面临的永恒难题。

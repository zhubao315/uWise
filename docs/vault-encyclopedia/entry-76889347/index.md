# 做事先研究——行动前的深度研究是最高杠杆

## 📌 核心定义

> **"做事要研究。"** ——褚时健

## 🎯 关键要点

- **"做事要研究。"** ——褚时健
- **"我做事前都要先想好困难，准备好解决困难的办法。"** ——褚时健
- 行动效能 = 研究深度 × 执行精度 / 行动速度
- 盲动 → 试错成本↑ → 返工↑ → 效能↓
- 研究 → 问题本质清晰 → 行动精准 → 效能↑
- **大多数人失败不是因为不努力，而是因为研究不够就急于行动。** 褚时健75岁种橙，不是拍脑袋决定——他花了大量时间研究土壤、气候、灌溉、品种，把农业问题当工程问题拆解。在糖厂改进煮糖技术时，他不是换更大的锅，而是研究锅具厚度与燃料消耗的关系，找到真正的杠杆点。表面看"研究"浪费时间，实际上它把试错成本从"推倒重来"降到"微调优化"。
- **问题即机会**：真正的高手看到问题不急着解决，而是先研究问题的本质结构。褚时健把"观察-实验-迭代"三步法用到极致——观察找到真问题，实验验证假设，迭代逼近最优解
- **痛苦+行动=成长**：挫折不可怕，可怕的是不研究就重复犯错。褚时健保外就医期间研究灌溉系统，把农业对天气的依赖从70%降到30%——他在最低谷时仍在"研究"

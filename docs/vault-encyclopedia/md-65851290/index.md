# 第二层次思维决策法

## 📌 核心定义

> 没有第二层次思维，你只能获得平均回报。有了它，你才有机会获得超额收益。

## 🎯 关键要点

- 投资决策：判断某项资产是否被高估或低估
- 职业选择：热门行业是否已经过度竞争，冷门方向是否有未被发现的机会
- 商业战略：当所有竞争对手都在做同一件事时，差异化的机会在哪里
- 任何竞争性领域：体育、博弈、谈判 — 但凡存在"对手"，就需要超越对手的思考层次

## 📖 详细说明

### 概念解释
做出重要决策时，必须超越显而易见的第一层次结论，进入第二层次思考。关键问题：**如果所有人都认为 X，那么这个机会已经被定价了。反面的真相是什么？**

第二层次思维不是"我认为公司前景好"，而是"我认为公司前景好，但大家也都这么认为，股价已经反映了乐观预期，所以实际应该卖出"。投资的本质不是做出正确判断，而是做出**比共识更正确的判断**。


### 实际应用

- **投资决策**：判断某项资产是否被高估或低估
- **职业选择**：热门行业是否已经过度竞争，冷门方向是否有未被发现的机会
- **商业战略**：当所有竞争对手都在做同一件事时，差异化的机会在哪里
- **任何竞争性领域**：体育、博弈、谈判 — 但凡存在"对手"，就需要超越对手的思考层次

# 检查清单思维

## 📌 核心定义

> 检查清单思维（Checklist Thinking）是查理·芒格极力推崇的决策框架，核心理念是：将理性决策流程外化为可重复执行的清单，用制度化的冷静对抗人性中的认知偏差。芒格认为，即使是最聪明的人也无法在压力下可靠地调用所有需要的思维模型，因此必须借助清单来弥补认知局限。

## 🎯 关键要点

- **清单不是智力不足的标志，而是智力谦逊的体现**：专家比新手更需要清单，因为专家的自信最容易导致遗漏
- **清单对抗的是人性，不是问题复杂度**：人类大脑在压力、情绪、时间压力下会退化为直觉模式，清单强制你回到理性模式
- **好的清单必须简洁且可执行**：超过7项的清单难以执行，每项必须是具体动作而非抽象原则
- **清单需要持续迭代**：每次犯错后，问自己"这个错误能否通过修改清单来预防"，如果能，就更新清单

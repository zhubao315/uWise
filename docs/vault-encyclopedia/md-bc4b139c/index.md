# 个人主义文艺观

## 📌 核心定义

> 木心最核心的文艺立场：艺术的本质是个人主义的。所有伟大的艺术——从荷马史诗到鲁迅散文，从米开朗基罗的雕塑到贝多芬的交响乐——都不是集体意志的产物，而是个体灵魂卓越而不可复制的表达。木心在这点上近乎极端：艺术没有"我们"，只有"我"。

## 🎯 关键要点

- **个人即全部**：人类文艺史上每一次真正的突破都来自某个具体的人，而不是"人民""时代""阶级"的抽象力量
- **反集体主义文艺**：木心坚定反对任何形式的集体主义文艺观——社会主义现实主义、民族主义文艺，本质上都是对艺术的戕害
- **孤独的尊严**：艺术家必须承受个人主义的代价——不被理解、不被接纳、甚至不被允许存在——但这就是艺术家的命运和尊严

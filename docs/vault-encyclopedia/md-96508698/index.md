# 苦难叙事与底层视角

## 📌 核心定义

> 路遥在《平凡的世界》中采用了一种独特的叙事策略：以底层视角书写苦难，不美化、不煽情、不居高临下。他笔下的苦难是具体的、日常的——一顿饭、一件衣服、一个住所的困难，而非抽象的、戏剧化的。这种叙事方式让读者真正"看见"了底层人民的生活。

## 🎯 关键要点

- **底层视角**：不是旁观者的同情，而是参与者的体验
- **日常苦难**：不是戏剧化的悲剧，而是日复一日的困境
- **不煽情**：苦难就是苦难，不需要被美化或升华
- **尊严感**：即使在最困难的处境中，人依然保有尊严

# 自我设限

## 📌 核心定义

> 你以为的极限不是极限，那只是你当前认知的边界。

## 🎯 关键要点

- "我做不到"：还没尝试就放弃
- "这不是我擅长的"：拒绝学习新领域
- "我没有天赋"：用天赋作为不努力的借口
- "太难了"：遇到困难就退缩

## 📖 详细说明

### 概念解释
你以为的极限不是极限，那只是你当前认知的边界。
1. **过去的失败**：一次失败让你认为"我不行"
2. **他人的评价**：别人说你不行，你就真的相信了
3. **比较心理**：和别人比较后觉得自己不够好
4. **舒适区**：习惯于现状，不敢突破

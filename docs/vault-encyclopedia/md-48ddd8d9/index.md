# 积精累气

## 📌 核心定义

> "仙人道士非有异，积精所致为专年。" ——张至顺

## 🎯 关键要点

- 节制性欲：不过度耗散精气
- 减少焦虑：思虑伤脾，消耗后天之精
- 充足睡眠：睡眠是身体修复和能量积累的关键时期
- 避免过劳：过度运动会消耗精气
- 合理饮食：脾胃是后天之本，饮食是后天之精的来源

## 📖 详细说明

### 概念解释
"仙人道士非有异，积精所致为专年。" ——张至顺

**公式**：生命能量 = 先天之精（不可替代）+ 后天之精（可补充）- 日常消耗

**关键**：不消耗比补充更重要——"养肾固精的核心是藏而非补"

## 📌 核心定义

## 🎯 关键要点

- **不过度期待**：对他人期待越高，失望越大；降低期待，反而容易感到满足
- **不过分亲近**：保持适度的边界感，尊重彼此的独立性
- **不强求改变**：接受他人本来的样子，而不是你希望他们成为的样子
- **适度付出**：付出不求回报，但也不过度牺牲自己

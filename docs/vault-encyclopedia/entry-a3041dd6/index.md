# 键盘政治

> 在网络空间发表政治观点、参与政治讨论的行为模式——低门槛表达、高情绪化、低信息密度。

## 特征

- **表达成本低**：一条评论即可「参政」
- **情绪驱动**：立场先行，事实后置
- **回音室效应**：算法推荐强化既有观点
- **极化倾向**：温和立场被极端声音淹没

## 信息环境分析

| 因素 | 影响 |
|------|------|
| 匿名性 | 降低责任感，放大攻击性 |
| 碎片化 | 复杂议题被简化为口号 |
| 社交奖励 | 点赞/转发激励极端表达 |
| 信息茧房 | 只看到支持自己观点的内容 |

## 理性参与建议

1. **区分事实与观点**：「X 发生了」vs「X 是对的」
2. **主动接触对立观点**：打破信息茧房
3. **延迟判断**：重大事件等 48 小时再下结论
4. **关注可行动的层面**：从「吐槽」转向「能做什么」

# 防御机制

## 📌 核心定义

> 来源：《也许你该找个人聊聊》（戈特利布）《梦的解析》（弗洛伊德）

## 🎯 关键要点

- 防御机制在短期内保护了我们：但长期来看阻碍了成长。
- 觉察是改变的第一步：意识到自己在使用什么防御机制。
- 不是所有防御机制都是坏的：升华是健康的防御机制。
- 觉察自己的防御机制：问自己——"我在用什么方式保护自己？"

## 📖 详细说明

### 概念解释
来源：《也许你该找个人聊聊》（戈特利布）《梦的解析》（弗洛伊德）
**防御机制**是潜意识用来保护自己免受痛苦的心理策略。

| 防御机制 | 含义 | 例子 |
|----------|------|------|
| **否认** | 拒绝承认现实 | "这件事没有发生" |
| **合理化** | 为行为找借口 | "这样其实挺好的" |
| **投射** | 把自己的问题归咎于别人 | "不是我有这个问题，是你有" |
| **回避** | 逃避面对问题 | 用忙碌、酒精来逃避 |
| **升华** | 把负面能量转化为建设性行为 | 把愤怒转化为运动 |


### 实际应用

- **觉察自己的防御机制**：问自己——"我在用什么方式保护自己？"
- **区分健康和不健康的防御**：升华是健康的，否认和回避是不健康的。
- **逐步放下防御**：在安全的环境中（如心理咨询）逐步放下防御。

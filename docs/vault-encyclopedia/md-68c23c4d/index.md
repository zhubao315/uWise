# 博弈论

## 📌 核心定义

> 研究理性决策者在策略互动中如何做出最优选择的数学理论，广泛应用于经济学、政治学、生物学等领域。

## 🎯 关键要点

- **纳什均衡**：所有参与者在给定他人策略下都不会单方面改变自己的策略
- **囚徒困境**：个体理性导致集体非理性，合作难以达成
- **零和博弈 vs 非零和博弈**：一方所得即另一方所失 vs 可以双赢
- **重复博弈**：长期关系中合作更容易维持（以牙还牙策略）
- **信息不对称**：不完全信息下的策略选择

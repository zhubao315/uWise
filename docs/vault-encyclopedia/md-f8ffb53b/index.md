# 兵线运营

兵线运营是 MOBA 类游戏（王者荣耀、LOL）的核心战术维度。**谁控制了兵线，谁就控制了地图的节奏**——兵线不仅提供经济和经验，更是地图压力的来源。

## 兵线的三种状态

| 状态 | 做法 | 目的 | 适用时机 |
|------|------|------|---------|
| 推线（Shove） | 快速清掉所有小兵 | 让己方兵线进入塔下 → 迫使对方守塔 → 创造人数差 | 准备打团/拿龙/入侵野区 |
| 控线（Freeze） | 只补最后一刀，不去碰满血兵 | 让兵线停留在自家塔前安全位置 | 己方劣势/等待打野支援 |
| 慢推（Slow Push） | 只清远程兵 | 让己方兵线慢慢积累成一波大车 | 准备越塔/推塔/回家补给后不亏线 |

## 核心原则

- **观察小地图决定兵线行为**：看到对方打野在上路，下路就可以压线；不知道对方打野位置时，控线在自己塔前
- **边线牵制**：推深边路线 → 迫使对方派人去清 → 利用人数差开团或拿龙
- **回城前处理兵线**：要回城前一定把兵线推到对方塔下，否则回来发现亏一波以上

## 与高分段的关系

低分段玩家看重击杀，高分段玩家看重兵线。能管好兵线的玩家，即使操作不如对手，也能靠经济差和地图压力赢下比赛。

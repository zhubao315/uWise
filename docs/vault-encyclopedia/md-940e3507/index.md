# 像镜子一样应事而不伤

## 📌 核心定义

> 真正的心理韧性不是"硬扛"，而是像镜子一样：事情来了如实反射（应），事情走了不留痕迹（不藏）。不主动追逐（不将），不刻意抗拒（不迎）。

## 🎯 关键要点

- **"至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤。"** ——《庄子·应帝王》

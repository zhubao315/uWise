# 检索练习取代被动复习

## 📌 核心定义

> 💡 判断学习是否有效的唯一标准：合上书/关掉视频后，你能回忆起多少？如果答案是"很少"，说明你一直在用被动学习——切换到检索练习，同样的时间，效果翻倍。

## 🎯 关键要点

- **被动学习是"沙滩写字"**: 反复看书、划线标注只是让信息在大脑中"路过"，没有形成深层编码。看似努力，实则低效。
- **主动检索是"石头刻字"**: 合上书后主动回忆，会强制大脑重新激活和巩固记忆痕迹，这个过程本身就是最有效的学习。
- **间隔重复的节奏**: 根据艾宾浩斯遗忘曲线，在遗忘临界点（1天、3天、7天、14天、30天）进行复习，比集中突击的效果好数倍。
- **"教别人"是最强检索**: 费曼学习法的核心就是检索练习——用自己的话向别人解释，无法解释清楚的地方就是知识盲区。
- **错题比对题更有价值**: 错误暴露了思维漏洞，按"错误类型"（概念误解、计算失误、思路中断）分类错题，纳入间隔重复计划。

## 📖 详细说明

### 概念解释
被动复习（看书、划重点、听讲）的留存率仅约30%，而主动检索（合上书回忆、默写、讲解）的留存率可达70%以上。学习效果的差距不在于"花了多少时间"，而在于"用了什么方法"。

### 实际应用

下次复习时，合上书本或笔记，尝试在空白纸上默写核心概念或解题步骤，无法回忆的部分即为需要重点补强的盲区。建立基于艾宾浩斯曲线的间隔重复计划（如1、3、7天后），专门针对按“概念误解”或“思路中断”分类的错题进行主动提取。若需深度巩固，尝试用通俗语言向他人讲解该知识点，将无法清晰解释之处标记为新的检索练习目标。

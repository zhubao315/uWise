# 选择性奢侈

## 📌 核心定义

> Selective extravagance：热爱的大方花，不爱的砍到零——节俭的反面是挥霍，而是有选择。

## 🎯 关键要点

- 先列热爱清单（3 项封顶）与讨厌清单
- 热爱项预算拉满且不愧疚
- 讨厌项砍到零不心疼
- 清单每季度复核，防止漂移
- 可持续的系统必须包含“浪费额度”

### 应用

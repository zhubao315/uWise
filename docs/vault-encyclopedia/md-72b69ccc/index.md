# 系统基模

## 📌 核心定义

> 系统基模（Archetypes）是复杂系统中反复出现的、由结构驱动的行为模式。它解释了"为什么好人会在好意图下把系统搞砸"——不是人出了问题，而是系统的结构（反馈回路、时滞、局部优化）驱动了结果。

## 🎯 关键要点

- **结构决定行为**：基模不是"坏人做坏事"，是好人用正确的局部逻辑，在错误的结构里共同走向崩坏
- **转嫁负担/舍本逐末（Shifting the Burden / Addiction）**：临时解见效 → 症状消失 → 更没动力解根本 → 依赖加深 → 崩盘
- **目标侵蚀（Drift to Low Performance）**：绩效基准被过去糟糕表现拖低 → 目标被动下调 → 平庸固化
- **公地悲剧 / 政策阻力**：局部各自最优化 → 与整体目标冲突 → 集体灾难
- **破局思路**：识别自己当前处于哪个基模，然后打杠杆点（改变结构）而非拧参数
- **AI 时代头号陷阱**：用 AI 输出替代独立思考 → 独立判断力存量无声消耗（转嫁负担回路）

## 📖 详细说明

### 概念解释

系统基模源于德内拉·梅多斯《系统之美》（Thinking in Systems）。她指出，社会系统和个人系统中的许多顽疾并非道德或能力问题，而是结构问题。理解基模的关键在于：**放弃线性思维（A→B）而拥抱环形思维（A→B→C→A）**，看到反馈回路如何让行为自我强化或自我耗竭。

三大高频基模：
1. **转嫁负担**：用见效快的临时解缓解症状 → 破坏系统自身恢复力 → 对干预上瘾 → 根本问题越积越深，直到临时解也撑不住，系统崩盘。
2. **目标侵蚀**：绩效基准受过去糟糕表现影响。实际表现下滑时，目标被动下调，陷入恶性循环走向平庸。
3. **公地悲剧/政策阻力**：每个局部都做对自己最有利的选择，累加起来却损害整体——局部最优 ≠ 全局最优。

### 实际应用

1. **识别当前基模**：面对反复出现的问题，先问"我处于哪个回路？"（转嫁负担？目标侵蚀？）
2. **断有害回路**：识别并切断"临时解"（AI 代写、囤积课程、刷短视频），恢复系统自身恢复力
3. **构建调节回路**：打通关键信息流，让系统自我纠偏（把"电表"装到玄关）
4. **注入增强回路**：让核心存量跨越临界点，形成正向飞轮

# 中式餐酒搭配

> 中餐各菜系与葡萄酒的搭配原则——打破「白酒配中餐」的单一思维。

## 搭配原则

| 原则 | 说明 |
|------|------|
| **风味呼应** | 酒体风格与菜系口味匹配 |
| **甜配辣** | 甜型酒（雷司令）平衡辣味 |
| **酸解腻** | 酸度高的酒解油腻 |
| **单宁避油** | 红酒单宁遇油腻会变苦 |

## 菜系搭配指南

| 菜系 | 特点 | 推荐酒款 |
|------|------|---------|
| **川湘菜** | 麻辣鲜香 | 雷司令半干、微起泡 |
| **粤菜** | 清淡鲜美 | 长相思、霞多丽 |
| **鲁菜** | 咸鲜浓厚 | 黑皮诺、歌海娜 |
| **江浙菜** | 甜糯软烂 | 琼瑶浆、灰皮诺 |
| **海鲜** | 鲜甜清爽 | 白诗南、夏布利 |

## 常见误区

- ❌ 红酒配所有中餐（单宁+油腻=苦涩）
- ❌ 忽视甜味（中餐甜味会放大酒的酸度）
- ❌ 追求名酒（适配度 > 价格）

# 从众心理

## 25种人类误判心理学清单

## 📌 核心定义

> 查理·芒格在《穷查理宝典》中系统整理的25种人类心理倾向清单，是其原创的认知偏差分类框架。芒格认为，人类大脑在进化中固化了大量心理捷径，这些捷径在现代复杂环境中频繁导致系统性误判。该清单是多元思维模型中最重要的心理学工具。

## 🎯 关键要点

- **1. 奖励和惩罚超级反应倾向**：激励机制是驱动人类行为的最强力量。"给我看激励机制，我告诉你结果。"人们会朝着激励的方向扭曲一切行为，甚至扭曲认知。
- **2. 喜欢/热爱倾向**：人会因为喜欢某人/某物而忽视其缺点、扭曲事实、过滤信息。爱屋及乌的心理让人对喜欢的对象丧失客观判断力。
- **3. 讨厌/憎恨倾向**：与喜欢倾向相反，人会因为讨厌而忽视对方优点，放大缺点，并在信息筛选中强化负面证据。
- **4. 避免怀疑倾向**：大脑不喜欢悬而未决的状态，倾向于快速做出决定以消除不确定性，即使仓促决定质量不高。
- **5. 避免不一致性倾向**：人一旦形成某种认知或承诺，会极力维护它，拒绝改变。大脑会自动过滤掉与已有信念矛盾的信息。

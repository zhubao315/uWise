# 买房租房4%公式

## 📌 核心定义

> 年租金 ÷ 房价 ≥4% 才考虑买，否则租＋差额定投；房子是消费，不是投资。

## 🎯 关键要点

- 持有成本超租金 1.5 倍直接租
- 首付挤占全部流动性＝拆城墙盖房
- 一线城市绝大多数结论都是租
- 省下的首付进指数，复利替你打工
- 居住先算账后谈情怀

## 📖 详细说明

### 出处
大项决策章，与巴比伦自住房法则互证。

### 应用
看房前 1 分钟公式初筛，不过线连中介费都省了。

# 正反馈循环

## 📌 核心定义

> 正反馈循环（Positive Feedback Loop）是指系统的输出反过来增强输入，导致变化不断放大的机制。与负反馈（维持稳定）相反，正反馈推动系统远离平衡状态。

## 🎯 关键要点

- **放大效应**：小变化被不断放大，最终产生巨大差异
- **临界点**：到达某个阈值后，变化速度急剧加快
- **双刃剑**：良性循环加速成长，恶性循环加速衰退
- **路径依赖**：早期微小优势可通过正反馈固化为巨大领先

# 不时不食——应季饮食的古老智慧

## 📌 核心定义

> "不时不食。" ——《论语·乡党》

## 🎯 关键要点

- "不时不食。" ——《论语·乡党》
- "春生，夏长，秋收，冬藏，是气之常也，人亦应之。" ——《黄帝内经》
- "不时不食"——不到时令不吃。反季节食物违背自然节律，不利于健康。
- 应季蔬果的营养价值高于反季节蔬果
- 人体的代谢节律与季节变化同步——冬天需要更多热量，夏天需要更多水分
- 遵循自然节律的饮食有助于维持生物钟的稳定
- 与 子午流注与老年养生 的关系：日维度的时间养生
- 与 四时养生 的关系：季节维度的时间养生

### 实际应用

制定每周食谱时，优先选择当季本地食材（如春季多吃韭菜、芽菜，冬季适量摄入羊肉、核桃），并依据季节调整烹饪方式：夏季侧重凉拌或清蒸以清热解暑，冬季则采用炖煮或煲汤以温补御寒。

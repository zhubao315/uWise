### 概念解释

### 数据漂移（Data Drift / Covariate Shift）

**定义**：训练数据的输入分布 P(X) 与生产环境的实际输入分布 P'(X) 不一致，但输入与输出的关系 P(Y|X) 保持不变。

**典型成因**：
- **季节性变化**：电商推荐模型在双十一期间面对的用户行为分布与平日截然不同。
- **数据源变化**：更换了传感器型号、日志格式变更、新的用户群体涌入。
- **上游管道变更**：ETL 逻辑修改导致数据特征偏移。
- **自然演化**：用户偏好随时间自然变化，语言习惯随流行文化演变。

**检测方法**：
- **统计检验**：Kolmogorov-Smirnov 检验、卡方检验、Population Stability Index (PSI) —— 对比训练集与在线数据的特征分布。
- **距离度量**：Wasserstein 距离、KL 散度、JS 散度 —— 量化两个分布之间的差异。
- **模型监控**：跟踪输入特征的均值、方差、分位数等统计量的时间序列变化。
- **可视化**：特征分布直方图对比、PCA/t-SNE 降维后观察数据聚类偏移。

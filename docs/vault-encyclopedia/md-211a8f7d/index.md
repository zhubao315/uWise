## 🎯 关键要点

- **道可道，非常道** — 真正的道理无法用语言完全表达
- **上善若水** — 最高的善像水一样，利万物而不争
- **无为而治** — 不妄为，顺应自然规律
- **反者道之动** — 事物发展到极端就会向反面转化
- **知足常乐** — 知道满足的人才是真正富有

# 改变的代价

## 📌 核心定义

> 来源：《也许你该找个人聊聊》（戈特利布）

## 🎯 关键要点

- 改变需要勇气：放弃旧的自我需要勇气——因为旧的自我虽然痛苦，但是"熟悉"的。
- 改变是渐进的：不是一夜之间的转变——需要持续的努力。
- 改变有风险：你不知道改变后会怎样——但不改变的代价更大。
- 接受改变的代价：问自己——"如果我不改变，5年后我会后悔吗？"
- 小步前进：不要试图一夜之间改变——从小的改变开始。

## 📖 详细说明

### 概念解释
来源：《也许你该找个人聊聊》（戈特利布）
改变是有代价的——当你改变时，周围的人可能会不适应：

- 你不再讨好别人，别人可能会生气。
- 你开始设立边界，关系可能会暂时紧张。
- 你变得更真实，可能会失去一些"朋友"。


### 实际应用

- **接受改变的代价**：问自己——"如果我不改变，5年后我会后悔吗？"
- **小步前进**：不要试图一夜之间改变——从小的改变开始。
- **找到支持**：在改变过程中找到支持你的人。

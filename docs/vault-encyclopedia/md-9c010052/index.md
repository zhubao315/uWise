# 香气三层体系

## 📌 核心定义

> 葡萄酒的香气按来源分为三个层次：一类香气（品种香）、二类香气（工艺香）和三类香气（陈年香）。

## 🎯 关键要点

- 葡萄酒的香气按来源分为三个层次：一类香气（品种香）、二类香气（工艺香）和三类香气（陈年香）。
- 理解香气的三层体系是品酒闻香阶段的核心知识框架。每一层香气讲述的是酒的不同"人生阶段"。
- **一类香气（品种香/Primary Aromas）** 来自葡萄果实本身，是品种基因决定的香气特征。长相思的百香果和猫尿味、雷司令的汽油和青苹果味、黑皮诺的红樱桃和覆盆子味——这些都是品种自带的"指纹"。一类香气在年轻时最为鲜明，随着陈年逐渐被三类香气覆盖。同一品种在不同产区的表达会有差异，但核心特征是共通的。
- **二类香气（工艺香/Secondary Aromas）** 来自酿造过程。苹果酸-乳酸发酵带来黄油和奶油的质感；酒泥陈酿（sur lie）带来饼干和酵母的香气；橡木桶陈酿赋予香草、烘烤、烟熏和椰子的气息。不锈钢罐低温发酵保留更多一类香气，而橡木桶发酵则增加二类香气的复杂度。酿造决策是酿酒师塑造风格的主要工具。
- **三类香气（陈年香/Tertiary Aromas）** 来自瓶中陈年。红葡萄酒发展出皮革、烟草、蘑菇、森林地表的复杂气息；白葡萄酒发展出蜂蜜、坚果、焦糖和汽油的风味。三类香气是时间的馈赠——只有高品质、高结构的酒才能在漫长的陈年中发展出优雅的三类香气，否则只会变得沉闷乏味。

### 实际应用

在品酒时，先静置酒杯捕捉易挥发的一类品种香，随后摇杯引入氧气以激发二类工艺香与三类陈年香。通过辨识黄油、橡木等二类香气可判断酿造风格，若出现皮革或蘑菇等三类香气则表明酒款已度过适饮期并具备陈年潜力。

# 行动偏误

## 📌 核心定义

> 足球运动员罚点球，有1/3的概率是射向球门中央，1/3的概率射向左边，1/3的概率射向右边。守门员会怎么办？他们或者扑向左，或者扑向右。反正他们很少待在中间——虽然有1/3的球会射向那里。这是为什么？因为扑向错误的一侧要比傻瓜似的呆立原地，看着球从左边或右边飞过去好看得多，看起来也没那么难堪。这就是行动偏误：即使毫无用处，也要采取行动。

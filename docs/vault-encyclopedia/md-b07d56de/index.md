# 货机崇拜科学

## 📌 核心定义

> 费曼在 1974 年加州理工学院毕业典礼演讲中提出的著名概念，被视为对伪科学的最有力批判。Cargo Cult Science 模仿了科学研究的形式——实验室、论文、术语、数据——但完全缺失了科学精神的核心：诚实、质疑、自我批判。像太平洋岛民模仿机场运转却不懂飞机为何来一样，模仿了外壳而没抓住本质。

## 🎯 关键要点

- **隐喻来源**：二战时太平洋岛屿上的原住民看到飞机送来物资，战后他们建造了"机场"（跑道、塔台、耳机），但飞机不再来——他们完美复制了形式，但不理解背后的因果
- **科学诚信的核心**：真正的科学家主动公布不支持自己假设的数据、主动寻找推翻自己的证据、不因为想要某个结果而扭曲数据
- **自我批判**：费曼说"首要原则是不要欺骗自己——而你是最容易被自己欺骗的人"——科学的灵魂是永远对自己保持怀疑

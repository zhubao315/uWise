# HBM高带宽存储器

> High Bandwidth Memory——通过 3D 堆叠 DRAM 芯片实现超高带宽、低功耗的存储方案，GPU AI 训练的核心组件。

## 技术特点

| 参数 | HBM3 | GDDR6X |
|------|------|--------|
| 带宽 | 819 GB/s | 1008 GB/s |
| 功耗 | 较低 | 较高 |
| 堆叠 | 3D 垂直堆叠 | 传统封装 |
| 典型容量 | 24-48GB | 16-24GB |

## 为什么 AI 需要 HBM

AI 大模型训练的瓶颈往往不是计算，而是**数据搬运**。HBM 的高带宽解决了 GPU 与显存之间的「内存墙」问题：

- LLM 训练中，参数和梯度需频繁读写
- HBM 的带宽比传统 GDDR 高数倍
- 3D 堆叠节省面积，允许多芯片封装

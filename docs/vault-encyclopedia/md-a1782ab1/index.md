# 偏斜度

## 📌 核心定义

> 偏斜度（Skewness）是纳西姆·塔勒布《随机漫步的傻瓜》中的核心风险模型：**收益分布的形状比均值更重要**——正偏斜（经常亏小钱、偶尔赚大钱）可持续，负偏斜（经常赚小钱、偶尔亏大钱）是毁灭预告。

## 🎯 关键要点

- **正偏斜（Positive Skew）**：左端小亏密集，右端大赚稀疏——期权买方/风险投资/彩票/写作实验
- **负偏斜（Negative Skew）**：左端大亏稀疏，右端小赚密集——保险承保/期权卖方/"稳定收益"策略/"一直赚钱"的明星基金经理
- **核心不等式**："年化 15% 但可能归零" < "年化 5% 但永不归零"——形状优先于均值
- **"毁灭的利息"**：负偏斜策略的持续小利润，是未来毁灭性损失的利息支付（巴林银行：里森 2 年明星，一次爆仓炸掉 233 年历史）
- **识别信号**："一直赚钱且几乎无回撤" = 高危信号（不是能力证明，是尾部风险积累中）
- **与风险真面目的关系**：永久损失（归零）才是风险，偏斜度是它的分布学表述

## 📖 详细说明

### 概念解释

均值（平均收益）是风险度量的最大谎言——它把"99 天小赚 + 1 天归零"和"100 天稳定小赚"显示为可能相同的数字。偏斜度把度量基准从"平均"换到"形状"：

- 正偏斜结构：多数时候小额亏损（可承受、可重复），极少数时候巨大收益（覆盖所有损失还有余）——**失败是常态且便宜，成功是例外且巨大**（VC 的 100 投 1 中就是这个结构）；
- 负偏斜结构：多数时候小额盈利（给人"稳定"的错觉），极少数时候灾难性损失（一次抹平全部）——**成功是常态且廉价，失败是例外且致命**。

### 实际应用

1. **偏斜度审计**：每季度对每个头寸/项目标注"正/负偏斜 + 最坏损失"——负偏斜且最坏损失="归零"的立即减仓
2. **火鸡检查联动**："一直赚钱无回撤"的头寸 = 负偏斜嫌疑，做极端情景拷问
3. **系统迁移**：知识库建设是正偏斜活动（多数投入平庸，少数关键连接产生巨大价值）——多数投入"看起来没回报"是结构的常态，不是停止的信号
4. **杠铃联动**：杠铃策略 = 用结构保证正偏斜敞口（15% 极端机会）+ 安全垫（85% 永不归零）

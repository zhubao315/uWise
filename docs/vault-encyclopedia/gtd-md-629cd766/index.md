# GTD

## 📌 核心定义

> GTD 是戴维·艾伦提出的时间管理和个人效率框架。核心理念：将所有待办事项从大脑中清空到外部系统，通过五个步骤实现"心如止水"的专注状态。

## 🎯 关键要点

- **两分钟规则**：能在两分钟内完成的事立即做
- **下一步行动**：每个项目必须定义明确的下一步物理动作
- **情境清单**：按@电脑/@电话/@外出等情境组织任务
- **每周回顾**：GTD系统的生命线，没有回顾系统就会崩溃

## 📖 详细说明

### 概念解释
GTD 是戴维·艾伦提出的时间管理和个人效率框架。核心理念：将所有待办事项从大脑中清空到外部系统，通过五个步骤实现"心如止水"的专注状态。


### 实际应用

1. **收集（Capture）**：将所有待办、想法、承诺收集到收件箱
2. **理清（Clarify）**：逐一判断每项是否需要行动
3. **组织（Organize）**：分类归档到项目/日程/等待/参考等列表
4. **回顾（Reflect）**：每周回顾所有列表，保持系统可信
5. **执行（Engage）**：根据情境、时间、精力、优先级选择行动

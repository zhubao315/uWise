# 番茄工作法图解

## 📌 核心定义

> 番茄工作法（Pomodoro Technique）是由弗朗西斯科·西里洛于 1980 年代发明的时间管理方法，通过 25 分钟专注工作 + 5 分钟休息的循环来提升效率。

## 🎯 关键要点

- 核心循环：25 分钟专注（一个番茄钟）→ 5 分钟短休息 → 每 4 个番茄钟后 15-30 分钟长休息
- 关键规则：番茄钟不可分割，被打断则作废重来
- 配套工具：任务清单、番茄计数器、干扰记录
- 适用场景：需要深度专注的知识工作、写作、编程、学习

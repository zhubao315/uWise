# 平台+插件

## 📌 核心定义

> 一种软件架构设计模式：核心平台提供稳定、通用的基础能力（数据存储、API、权限等），插件则按需扩展特定功能，不修改核心代码。这种模式在知识管理领域同样适用——Obsidian 就是典型代表：核心编辑器保持简洁，社区插件生态提供无限定制可能。

## 🎯 关键要点

- **核心稳定，边界开放**：平台只做最本质的事，插件负责多样性。这让系统既有结构又不失灵活性。
- **渐进式增强**：用户可以从最小可用版本开始，按需添加插件，避免"全功能臃肿"的设计陷阱。
- **社区驱动创新**：插件由社区贡献，平台方无需预判所有需求，创新发生在边缘而非中心。

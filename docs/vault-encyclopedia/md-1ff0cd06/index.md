# 高墙与鸡蛋

## 📌 核心定义

- **鸡蛋**：每一个具体的人，其脆弱性、尊严与独一无二的生命体验
- **立场选择**：写作者（以及一切人文实践者）的道德责任是站在弱者、被碾压者一边，即使鸡蛋碎了也见证其存在

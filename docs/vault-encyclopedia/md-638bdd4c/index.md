# 五仙三成

## 📌 核心定义

> | 鬼仙 | 最低 | 阴神出窍，未能超脱 |

## 🎯 关键要点

- 小成：身体健康，精力充沛——养生的基本目标
- 中成：身心合一，内在安定——修行的进阶目标
- 大成：超越自我，与万物一体——修行的最高目标

## 📖 详细说明

### 概念解释
> 来源：《钟吕传道集》
"五仙三成"是钟吕丹法的修行次第框架：

**五仙**：
| 仙 | 层次 | 特征 |
|----|------|------|
| 鬼仙 | 最低 | 阴神出窍，未能超脱 |
| 人仙 | 初级 | 延年益寿，但未能超越 |
| 地仙 | 中级 | 长生不死，但未能飞升 |
| 天仙 | 高级 | 超脱生死，与道合一 |
| 神仙 | 最高 | 无形无相，与道同体 |

**三成**：
| 成 | 对应 | 内容 |
|----|------|------|
| 小成 | 人仙 | 炼精化气——固摄精气，延年益寿 |
| 中成 | 地仙 | 炼气化神——气满神全，长生不死 |
| 大成 | 天仙 | 炼神还虚——超越自我，与道合一 |


### 实际应用

可将“小成”阶段作为日常养生基准，通过固摄精气改善亚健康状态；进阶者依据“中成”标准进行气机调和以追求身心安定；高阶修行者则参照“大成”境界，以炼神还虚为指引突破自我局限，实现与万物一体的终极目标。

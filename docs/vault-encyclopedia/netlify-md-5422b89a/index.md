# Netlify

> JAMstack 静态站点托管平台——Git push 即部署，内置 CI/CD、边缘函数、表单处理。

## 核心能力

| 功能 | 说明 |
|------|------|
| **自动部署** | Git push 触发构建，支持 GitHub/GitLab/Bitbucket |
| **边缘函数** | Netlify Edge Functions（Deno 运行时） |
| **表单处理** | 无需后端的表单收集 |
| **身份认证** | Netlify Identity（集成 GoTrue） |
| **Split Testing** | A/B 测试，边缘路由 |

## 竞品对比

| 平台 | 定位 | 适合 |
|------|------|------|
| Netlify | JAMstack 静态/Serverless | 前端项目、文档站 |
| Vercel | Next.js 深度集成 | React/Next.js 项目 |
| Cloudflare Pages | 全球边缘网络 | 性能敏感型站点 |

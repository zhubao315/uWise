# 真相常流失于涕泪交加中

## 📌 核心定义

> 情绪会遮蔽真相——当泪水模糊了视线，事实就被忽略了

## 🎯 关键要点

- 情绪会遮蔽真相——当泪水模糊了视线，事实就被忽略了
- 柴静在《看见》中总结的这条原则，揭示了一个反直觉的真相：强烈的感情反应往往是理解真相的障碍，而非通道。当一个故事让人"涕泪交加"时，人们倾向于停止追问、停止怀疑、停止分析，转而沉浸在情绪的满足中。但真相往往藏在泪水够不到的地方——那些不那么感人的、复杂的、矛盾的细节中。
- 这条原则的深层逻辑是：情绪是一种认知捷径。当我们被感动时，大脑会跳过分析步骤，直接给出"这是好的/坏的"的判断。这种捷径在日常生活中很高效，但在需要深入理解复杂问题时就会误导人。柴静在采访中多次发现：最催人泪下的故事版本，往往不是最接近真相的版本。
- 这不是说情感不重要，而是说情感应该是发现真相的动力，而不是替代真相的安慰剂。一个让人流泪的故事可以激发你去追问，但泪水本身不是答案。

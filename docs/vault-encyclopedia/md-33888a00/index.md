# 幸福等于想要更少而非拥有更多

## 📌 核心定义

> **一句话记住**：幸福不是拥有更多，而是想要更少。当你不再被欲望绑架，自由就来了。

## 🎯 关键要点

- 大多数人把幸福定义为「拥有更多」，但纳瓦尔的公式是：**幸福 = 想要更少**。痛苦 = 欲望 - 能力，满足欲望是无底洞，降低欲望才是通往幸福的捷径。
- 人的欲望是无限的，而能力是有限的。当你把幸福绑定在「下一个目标达成」上，你永远处于不满足的状态。反过来，**区分「需要」与「想要」**，主动削减不必要的欲望，幸福阈值就会大幅降低。
- **每日记录**：晚上花5分钟，写下今天的消费欲望，标注「需要」还是「想要」
- **延迟满足**：对「想要」设置30天冷静期，到期后再决定是否购买
- **冥想训练**：每天10分钟正念冥想，提升对欲望的觉察力
- **定期断舍离**：每季度清理一次物品和信息订阅
- 消费频率下降但满意度不降
- 不再因「别人有我没有」而焦虑

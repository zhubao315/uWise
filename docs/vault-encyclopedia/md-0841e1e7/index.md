# 亲代投资理论

## 📌 核心定义

> 亲代投资理论是一个重要的知识概念。

## 🎯 关键要点

- 女性投资更多：怀孕、哺乳、养育——投资远大于男性。
- 女性更挑剔：因为投资更多，所以更谨慎地选择伴侣。
- 男性更竞争：因为投资更少，所以更倾向于通过竞争获得伴侣。
- 理解择偶行为：从进化角度理解男女择偶差异。
- 管理嫉妒：理解嫉妒的进化功能——保护关系的机制。

## 📖 详细说明

### 概念解释
来源：《进化心理学》（巴斯）
**亲代投资理论**：投资更多的一方在择偶时更挑剔——因为投资更多，损失更大。


### 实际应用

- **理解择偶行为**：从进化角度理解男女择偶差异。
- **管理嫉妒**：理解嫉妒的进化功能——保护关系的机制。
- **现代环境的错配**：我们的大脑是为祖先环境设计的——不一定适合现代环境。

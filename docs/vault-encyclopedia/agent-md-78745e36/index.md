# Agent编排

> 多个 AI Agent 协同工作的调度与协调机制——决定谁做什么、何时做、如何传递上下文。

## 编排模式

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| **串行管道** | Agent A → B → C 线性传递 | 文档处理流水线 |
| **并行扇出** | 多 Agent 同时执行，汇总结果 | 多源调研/对比分析 |
| **路由分发** | 根据输入类型分配给不同 Agent | 客服/多任务处理 |
| **层级委托** | 主 Agent 拆解任务，子 Agent 执行 | 复杂项目管理 |
| **协作辩论** | 多 Agent 互评，达成共识 | 决策/评审 |

## 关键设计要素

1. **上下文传递**：子 Agent 看到多少父 Agent 的历史？
2. **错误处理**：子 Agent 失败时如何降级/重试？
3. **并发控制**：同时运行的 Agent 数量上限
4. **结果聚合**：多个 Agent 输出如何合并为最终结果

## 工具/框架

- **LangGraph**：基于图的状态机编排
- **CrewAI**：角色扮演式多 Agent 协作
- **AutoGen**：微软的多 Agent 对话框架
- **OpenAI Swarm**：轻量级 Agent 交接

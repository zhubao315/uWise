# 天心静坐法

## 📌 核心定义

> 来源：《张至顺道家养生智慧》（金莲田 整理）

## 🎯 关键要点

- 不要用力：放松而非紧张
- 不要追求特殊感觉：任何感觉都是正常的，不执着
- 持之以恒：每天练习，不要三天打鱼两天晒网
- 配合动功：先练习金刚功，再静坐

## 📖 详细说明

### 概念解释
来源：《张至顺道家养生智慧》（金莲田 整理）
天心静坐法是张至顺道长传授的静坐方法——以"天心"（两眉之间）为注意力焦点，进行静坐修炼。


### 实际应用

1. **姿势**：端坐，脊柱正直，双手结定印
2. **收心**：将注意力从外部世界收回到天心（两眉之间）
3. **守静**：保持安静，不追随念头，不压制念头
4. **深入**：从表面的安静深入到深层的安静
5. **时长**：初学者每次15-30分钟，逐渐延长

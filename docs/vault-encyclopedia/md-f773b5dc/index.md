# 晶体-情绪不会消失只会变形

## 📌 核心定义

> "未被表达的情绪永远不会消亡。它们只是被活埋，并将在未来以更加丑陋的方式涌现。" ——弗洛伊德

## 🎯 关键要点

- 觉察：当出现莫名情绪时，不急于压制，先问"我在回避什么？"
- 表达：用文字/倾诉/艺术将情绪外化，而非内耗
- 接纳：允许自己有"不体面"的欲望和情绪，接纳≠纵容，而是承认它的存在

## 📖 详细说明

### 概念解释
"未被表达的情绪永远不会消亡。它们只是被活埋，并将在未来以更加丑陋的方式涌现。" ——弗洛伊德
被压抑的情绪（焦虑、愤怒、欲望）不会凭空消失，它们会通过三种"变形"出口重新浮现：
1. **梦境**：以荒诞情节表达（如反复梦见追赶/坠落）
2. **身体症状**：莫名头痛、失眠、肠胃不适（心身疾病）
3. **行为失控**：口误、莫名发火、拖延、成瘾行为


### 实际应用

- 莫名焦虑或烦躁时
- 反复做同一类噩梦时
- 总在某件事上拖延/回避时
- 身体不适但查不出病因时

## 📖 详细说明

### 概念解释
生成对抗网络（Generative Adversarial Network, GAN）由伊恩·古德费洛（Ian Goodfellow）于2014年提出，是深度学习中最具创意的框架之一。它通过**两个神经网络的对抗训练**来学习数据的生成分布。
GAN包含两个网络：

### 生成器（Generator）
- 输入：随机噪声向量。
- 输出：生成的假数据（如假图片）。
- 目标：生成足以"欺骗"判别器的数据。

### 判别器（Discriminator）
- 输入：真实数据或生成器生成的假数据。
- 输出：判断输入是"真"还是"假"的概率。
- 目标：尽可能准确地区分真假数据。

用一个比喻：生成器是**造假者**，判别器是**鉴定师**。造假者不断提升伪造技术，鉴定师不断提升鉴别能力——双方在对抗中共同进步。


### 实际应用

- **图像生成**：从噪声生成逼真的人脸、风景等。

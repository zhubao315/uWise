# 战略OKR管理

## 核心定义

OKR（Objectives & Key Results）是把**战略意图**翻译成**可度量结果**的目标管理框架：Objective 是"要去哪"（定性、鼓舞人心），Key Result 是"怎么知道到了"（定量、可验证）。它源于 Intel，由 Google 普及。

## 关键要素

- **对齐（Alignment）**：公司 O → 团队 O → 个人 O 逐层承接，公开透明。
- **聚焦（Focus）**：每季度 3–5 个 O，每个 O 配 3–5 个 KR；少即是多。
- **节奏（Cadence）**：季度设定 + 周检查 + 月复盘。
- **CFR 配套**：Conversation（对话）、Feedback（反馈）、Recognition（认可）——OKR 的"另一半"。
- **与 KPI 的区别**：KPI 是持续考核，OKR 是阶段性突破；OKR 不与薪酬直接挂钩（避免保守设定）。

## 常见失败模式

| 失败 | 症状 |
|------|------|
| 把 KR 写成任务清单 | "发布 X 功能"而非"X 指标提升到 Y" |
| O 不可鼓舞 | 只有数字，没有方向 |
| 与绩效绑定 | 目标被压低，失去挑战性 |
| 无节奏 | 设完就忘 |

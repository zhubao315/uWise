## 📖 详细说明

### 概念解释
在恐惧中买入，在贪婪中卖出。逆周期投资是长期战胜市场的核心策略。
```
扩张期 → 增加风险资产（股票、商品）
顶部期 → 逐步减仓，增加现金和债券
收缩期 → 持有现金和避险资产
底部期 → 逐步加仓，买入被低估的资产
```

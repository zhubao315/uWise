# 深度阅读方法论

> 超越速读的深度理解策略——从「读过」到「读懂」到「能用」。

## 阅读层次

| 层次 | 方式 |
|------|------|
| **检视阅读** | 快速浏览，判断值不值得读 |
| **分析阅读** | 逐章精读，理解论证结构 |
| **主题阅读** | 多本书对比，形成自己的观点 |

## 深度阅读步骤

1. **预览**：目录/序言/结论，建立框架
2. **精读**：逐段理解，标注关键论点
3. **笔记**：用自己的话重述核心观点
4. **关联**：与已有知识建立链接
5. **输出**：写书评/讲给别人听

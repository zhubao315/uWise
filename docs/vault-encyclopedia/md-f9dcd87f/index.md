# 欲不可绝——节制而非禁绝

## 📌 核心定义

> 来源：《三元延寿参赞书·欲不可绝篇》（李鹏飞）

## 🎯 关键要点

- **欲不可绝**：完全禁欲对健康有害——"孤阳不生，独阴不长"
- **欲不可纵**：过度放纵对健康更有害——"纵欲伤身"
- **关键在于"节"**：适度、有节制的性生活是健康的一部分

### 概念解释

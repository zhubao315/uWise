# 相对力量与绝对力量

## 📌 核心定义

> **绝对力量**：人体能够产生的最大力量值，通常以公斤为单位（如深蹲150kg）。

**相对力量**：绝对力量与体重的比值（如深蹲150kg ÷ 体重75kg = 2.0），反映"每公斤体重能产生多少力量"。

## 🎯 关键要点

- **绝对力量**：人体能够产生的最大力量值，通常以公斤为单位（如深蹲150kg）。
- **相对力量**：绝对力量与体重的比值（如深蹲150kg ÷ 体重75kg = 2.0），反映"每公斤体重能产生多少力量"。
- 绝对力量高不代表相对力量高——体重100kg深蹲150kg（相对力量1.5）不如体重70kg深蹲140kg（相对力量2.0）
- 相对力量对跑者、攀岩者、体操运动员更重要
- 绝对力量对举重运动员、橄榄球运动员更重要
- 自重训练（如囚徒健身）天然强调相对力量，因为无法增加外部负重

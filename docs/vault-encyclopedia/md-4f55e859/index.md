# 投资人的看人学

## 📌 核心定义

> 投资就是投人。识别创始人的品格、能力和格局，是投资决策中最重要的一环。

## 🎯 关键要点

- **品格优先**：能力可以培养，品格难以改变
- **格局判断**：看创始人是想做大事业还是赚快钱
- **执行力**：想法再好，没有执行力等于零
- **学习能力**：市场变化快，持续学习能力是核心竞争力

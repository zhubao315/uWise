# 时间分散化

> 把资金均匀地分配到一生的各个年份，而不是集中在少数几个年份——这是被大多数人忽视的分散化维度。

## 核心要点

- **原理**：不同年份的股市回报相关系数很低（接近零），因此分散投资于不同年份和分散投资于不同股票一样可以降低风险。传统投资组合做的是"跨资产分散化"，时间分散化做的是"跨时间分散化"。
- **方法**：年轻收入少时用杠杆增大股市敞口，年老收入多时降低股市敞口，使每一年暴露在股市中的资金量大致相等。
- **案例**：200/50策略（年轻时200%股市敞口到50岁时降到50%）可以将终身投资组合的标准差降低21%，或不增加风险的情况下将退休资产提高60%。

## 跨领域应用

- **架构师**：系统容灾设计——不要把大部分备份资源集中部署在某一年，而是逐年均匀更新
- **投资人**：核心投资框架——评估任何策略时，不仅要看"赚了多少"，还要看"风险在时间上的分布是否均匀"
- **学习者**：技能积累——不要把学习集中在某个年龄段，而是均匀分布在人生各个阶段
- **艺术家**：创作节奏——作品产出均匀分布在职业生涯中，避免巅峰期后断崖式下滑

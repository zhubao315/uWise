| **饼图** | 占比 |

## 叙事结构

```
1. 提出问题 → 2. 展示数据 → 3. 揭示洞察 → 4. 建议行动
```

## 设计原则

1. **数据墨水比**：最大化数据信息，最小化装饰
2. **视觉层次**：最重要的数据最突出
3. **颜色有目的**：用颜色编码含义，不是装饰
4. **标注关键点**：直接标注数据点

# 群体极化

## 📌 核心定义

> 来源：《社会心理学》（迈尔斯）《乌合之众》（勒庞）

## 🎯 关键要点

- 信息性影响：在讨论中，你会听到更多支持你观点的信息——让你更确信。
- 社会比较：你想表现得"比别人更忠诚于群体"——导致观点更极端。
- 去个性化：在群体中，个人身份感消失——更容易做出极端行为。
- 警惕群体讨论：群体讨论可能让观点更极端——保持独立思考。
- 引入反对意见：在群体讨论中引入反对意见——防止极化。

## 📖 详细说明

### 概念解释
来源：《社会心理学》（迈尔斯）《乌合之众》（勒庞）
**群体极化**：群体讨论会让观点更极端——原来温和的观点变得更激进。


### 实际应用

- **警惕群体讨论**：群体讨论可能让观点更极端——保持独立思考。
- **引入反对意见**：在群体讨论中引入反对意见——防止极化。
- **网络极化**：社交媒体上的群体极化更严重——因为算法只展示你认同的内容。

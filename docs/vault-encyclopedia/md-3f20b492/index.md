# 全局工作空间理论

## 📌 核心定义

> 全局工作空间理论是一个重要的知识概念。

## 🎯 关键要点

- 无意识：大部分信息在大脑的局部模块中处理，不进入意识。
- 意识：当某个信息"赢得"了注意竞争，它会被"广播"到全脑——这就是意识。
- 意识是冰山一角：大脑的大部分处理是无意识的——意识只是"聚光灯"。
- 注意是意识的门户：没有注意，就没有意识——你只能意识到你注意到的东西。
- 无意识不是"黑暗"的：无意识是非常高效的处理系统。

## 📖 详细说明

### 概念解释
来源：《脑与意识》（迪昂）
**全局工作空间理论**（迪昂）：意识是大脑中信息被"广播"到全局的过程。

- **无意识**：大部分信息在大脑的局部模块中处理，不进入意识。
- **意识**：当某个信息"赢得"了注意竞争，它会被"广播"到全脑——这就是意识。


### 实际应用

- **管理注意力**：意识到注意是有限的——选择性地分配注意力。
- **利用无意识加工**：面对复杂问题时，先"放下"让无意识继续处理。
- **提高元认知**：练习内省——觉察自己的思维过程。

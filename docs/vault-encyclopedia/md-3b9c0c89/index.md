# 人生商业模式杠杆模型

## 📌 核心定义

> 人生商业模式 = 能力 × 效率 × 杠杆；能力是内核，效率是方法论，杠杆是放大器——没有强内核，杠杆只会放大你的平庸。

## 🎯 关键要点

- 职业规划时：：用公式诊断自己——当前是能力不足、效率太低，还是完全没用杠杆？找到瓶颈对症下药。
- 评估副业/创业机会时：：看这个机会是否引入了新杠杆（如产品杠杆），还是只是用更多时间换更多钱。
- 学习新技能决策时：：优先学习那些能提升"能力内核"的硬技能，而不是追热点学一堆皮毛。
- 年度复盘时：：审视过去一年自己在能力、效率、杠杆三个维度分别有什么进步。

## 📖 详细说明

### 概念解释
人生商业模式 = 能力 × 效率 × 杠杆；能力是内核，效率是方法论，杠杆是放大器——没有强内核，杠杆只会放大你的平庸。


### 实际应用

在评估副业或创业机会时，优先选择能引入产品杠杆（如软件、内容）而非单纯时间交换的项目；年度复盘时，分别量化能力、效率与杠杆三个维度的具体增量，以精准定位下一阶段的优化重点。

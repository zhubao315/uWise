# 埃里克森心理社会发展

## 📌 核心定义

> 来源：《发展心理学》（费尔德曼）《婴儿、儿童和青少年》（伯克）

## 🎯 关键要点

- 每个阶段有其核心任务：成功解决才能健康发展。
- 身份认同是青春期的核心任务："我是谁？我想成为什么样的人？"
- 发展是毕生的过程：不是在成年后就停止。
- 反思自己的阶段：问自己——"我目前处于哪个阶段？核心任务是什么？"
- 理解青少年：身份认同是青春期的核心——允许探索、允许失败。

## 📖 详细说明

### 概念解释
来源：《发展心理学》（费尔德曼）《婴儿、儿童和青少年》（伯克）
埃里克森提出人的一生有八个心理社会发展阶段：

| 阶段 | 年龄 | 核心冲突 | 成功解决 |
|------|------|----------|----------|
| 婴儿期 | 0-1岁 | 信任 vs 不信任 | 希望 |
| 幼儿期 | 1-3岁 | 自主 vs 羞耻 | 意志 |
| 学前期 | 3-6岁 | 主动 vs 内疚 | 目的 |
| 学龄期 | 6-12岁 | 勤奋 vs 自卑 | 能力 |
| 青春期 | 12-18岁 | 身份认同 vs 角色混乱 | 忠诚 |
| 成年早期 | 18-40岁 | 亲密 vs 孤独 | 爱 |
| 成年中期 | 40-65岁 | 繁衍 vs 停滞 | 关怀 |
| 成年晚期 | 65岁+ | 完整 vs 绝望 | 智慧 |


### 实际应用

- **反思自己的阶段**：问自己——"我目前处于哪个阶段？核心任务是什么？"
- **理解青少年**：身份认同是青春期的核心——允许探索、允许失败。
- **中年危机**：中年的核心任务是"繁衍"——为下一代做出贡献。

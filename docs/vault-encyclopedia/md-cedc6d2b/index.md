# 小赢连击供能

## 📌 核心定义

> 把大目标切成每天能赢一小步的刻度，用连胜感供能——动力是赢出来的，不是等出来的。

## 🎯 关键要点

- 目标拆到“今天能完成”的粒度
- 连胜记录可视化（日历打叉）
- 断签不戒断：断一天第二天立刻续上
- 小赢标准：小到不可能失败
- 连击 21 天后升级难度

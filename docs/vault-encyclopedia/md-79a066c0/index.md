# 全球化视野下的价值发现

## 📌 核心定义

> 全球化视野下的价值发现是约翰·邓普顿的核心投资洞察：同一行业的企业，在不同国家和地区的资本市场上可能有截然不同的估值。这种估值差异并非完全由基本面差异解释，而往往反映了投资者情绪、市场流动性和信息不对称的差异。全球化的视野能帮助投资者发现被本国市场忽视的价值机会。来源：《邓普顿教你逆向投资》（约翰·邓普顿，2008年）。

## 🎯 关键要点

- **市场分割带来的机会**：不同国家的投资者对同一行业可能有截然不同的估值偏好。例如，日本投资者对银行股极度悲观时，美国投资者可能对银行股相对乐观。这种情绪差异创造了跨市场套利的机会。
- **信息不对称的价值**：本国投资者往往对本国企业有更深入的了解，但也可能被本地新闻和情绪所左右。外国投资者可能因为信息不足而忽视某些机会，但也可能因为不受本地情绪影响而做出更客观的判断。
- **汇率因素**：全球投资需要考虑汇率风险，但邓普顿认为，汇率波动在长期会趋于购买力平价。因此，基本面强劲的企业，即使在汇率不利的情况下，长期也能为投资者创造价值。
- **先发优势**：邓普顿是全球投资的先驱者。在互联网和信息全球化之前，他就通过实地考察和本地研究，发现了大量被国际投资者忽视的机会。今天，虽然信息更加透明，但全球投资的认知优势依然存在——大多数投资者仍然过度投资于本国市场。

# 产业投资视角

## 📌 核心定义

> 张磊在《价值》中提出的核心投资视角：真正的价值投资者应从企业主而非交易者的角度理解投资，把自己当作企业的长期合伙人，关注企业的真实价值创造能力、产业链地位和长期发展潜力，而非短期股价波动和市场情绪。

## 🎯 关键要点

- **交易者思维**：关注价格、趋势、催化剂、市场情绪，投资收益来自买卖差价，核心能力是择时和博弈。
- **企业主思维**：关注商业模式、竞争优势、管理层质量、长期增长潜力，投资收益来自企业价值创造，核心能力是判断企业质量。
- **视角决定行为**：交易者思维导致频繁交易和追涨杀跌；企业主思维导致深度研究和长期持有。
- **不只看企业，更要看产业**：企业的命运与其所处产业链的位置和产业链的整体演变密切相关。理解产业链的结构、权力分配和演变趋势，才能准确判断企业的长期前景。
- **寻找产业链的关键控制点**：那些控制产业链关键环节的企业，往往拥有最强的议价能力和最持久的竞争优势。

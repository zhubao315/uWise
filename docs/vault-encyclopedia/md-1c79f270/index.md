# 性命双修——身心并养的核心逻辑

## 📌 核心定义

> "只修性，不修命，修行第一病。" ——张三丰

## 🎯 关键要点

- 只运动不修心：身体好但心理问题多（焦虑、抑郁）
- 只修心不运动：心态好但身体差（亚健康、慢性病）
- 性命双修：身心并养，才是完整的健康
- 命功（身体）：每天30分钟运动——跑步、八段锦、金刚功
- 性功（心性）：每天15分钟静坐——听息法或正念冥想

## 📖 详细说明

### 概念解释
"只修性，不修命，修行第一病。" ——张三丰
"性命双修"是道教修炼的核心方法论——性功（心性修炼）与命功（身体修炼）不可偏废。

| 维度 | 性功 | 命功 |
|------|------|------|
| 对应 | 心性、精神 | 身体、能量 |
| 方法 | 静坐、冥想、去执念 | 导引、吐纳、服食 |
| 目标 | 明心见性 | 延年益寿 |
| 偏废后果 | "万劫阴灵难入圣" | "修行第一病" |


### 实际应用

建议将每日30分钟的身体锻炼（如八段锦或跑步）与15分钟的静坐冥想（如听息法）组合为固定流程，先通过运动激活身体能量，再借由静坐沉淀心神以消除焦虑。这种“动后入静”的交替练习能避免单纯运动带来的精神耗竭或单纯静坐导致的体能衰退，从而在微观层面实现身心状态的同步平衡。

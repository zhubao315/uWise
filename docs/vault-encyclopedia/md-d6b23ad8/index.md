# 垄断与竞争

## 📌 核心定义

> 彼得·蒂尔在《从0到1》中提出的核心商业论题：竞争是输家的游戏，垄断才是成功企业的终极形态。真正的价值创造来自创造全新的市场（从0到1），而不是在已有市场中争夺份额（从1到N）。

## 🎯 关键要点

- **竞争的代价**：竞争让企业将注意力从创造价值转向打败对手，利润被蚕食，创新被模仿取代
- **垄断的好处**：垄断企业有利润空间投资长期研发、善待员工、创造真正的新东西
- **从0到1**：创造新市场 > 抢夺已有市场。垄断者用差异化定义市场，竞争者被市场定义

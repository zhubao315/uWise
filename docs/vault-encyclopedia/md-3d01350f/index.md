# 先支付自己十分之一

## 📌 核心定义

> 发薪日先把收入的十分之一存起来，剩下的再安排生活——顺序决定一切，比例低到无法失败。

## 🎯 关键要点

- 储蓄是“先存再花”，不是“剩多少存多少”
- 10% 是起点，习惯建立后可逐步提高
- 配合自动转账，靠系统不靠意志
- 还债期间也不停存（见[骆驼商人还债公式](../md-c8582af8/)）
- 这是全书唯一的发动机，其余法则都是变速箱

## 📖 详细说明

### 出处
出自阿尔加米什传授阿卡德的第一课，也是《通往财富的简单之路》《我教你变成有钱人》共同的起点动作。

### 应用
发薪日设置自动转账 10% 到独立账户，剩下的再做预算；还债期同样执行，守住储蓄习惯不断。

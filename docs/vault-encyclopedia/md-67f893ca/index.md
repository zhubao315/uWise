# 潜意识

## 📌 核心定义

> 来源：《梦的解析》（弗洛伊德）《荣格自传》（荣格）

## 🎯 关键要点

- 意识：（水面上）：你能觉察到的想法和感受——只占10%。
- 前意识：（水面附近）：你暂时没注意到但可以回忆的内容。
- 潜意识：（水面下）：你无法直接觉察的内容——占90%。
- 潜意识影响行为：你以为自己在"理性决策"，其实大部分是潜意识在驱动。
- 潜意识通过症状表达：压抑的情绪会以症状（焦虑、恐惧、身体不适）的方式表达。

## 📖 详细说明

### 概念解释
来源：《梦的解析》（弗洛伊德）《荣格自传》（荣格）
**潜意识**是弗洛伊德最核心的发现——大部分心理活动是无意识的。

**冰山模型**：
- **意识**（水面上）：你能觉察到的想法和感受——只占10%。
- **前意识**（水面附近）：你暂时没注意到但可以回忆的内容。
- **潜意识**（水面下）：你无法直接觉察的内容——占90%。


### 实际应用

- **自我觉察**：觉察自己的潜意识模式——为什么我会对某些事情有强烈反应？
- **梦的分析**：记录和分析梦境——了解潜意识的关注点。
- **心理治疗**：通过自由联想、移情分析等技术探索潜意识。

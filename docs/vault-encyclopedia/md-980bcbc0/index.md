# 斯多葛主义

## 📌 核心定义

> 古希腊罗马哲学流派，由芝诺创立，经塞内卡、爱比克泰德、马可·奥勒留发展完善。核心主张：专注于可控之事，接受不可控之事，通过理性达到内心平静。

## 🎯 关键要点

- **控制二分法**：区分可控（自己的判断和行动）与不可控（外部事件和他人行为）
- **美德即幸福**：智慧、勇气、正义、节制是唯一的善
- **消极想象**：预想最坏情况，减少恐惧和焦虑
- **命运之爱（Amor Fati）**：热爱命运，无论好坏都是成长的机会
